# Task 特异度实验结论（2026-08-01）

数据：`merged_2s`，被试独立五折，`seed=42`，模型：ShallowFBCSPNet。  
验收：Spec≥0.40 且 Rec≥0.75 且 BalAcc≥0.65（F1 仅附报）。

---

## 1. 问题背景

旧基线 Task 常见 **F1≈0.82 虚高、Spec≈0.02–0.15、BalAcc≈0.50–0.55**：模型偏「全猜任务」。  
目标改为回答：**静息与任务能否分清**，不以 F1 为主结论。

## 5. 总结论（可写进报告）

1. **加权 CE + BalAcc 早停有效改变目标**：相对旧基线 Spec 上升、F1 虚高下降；`w0=2.2` 是 Spec/Rec 最均衡一档。  
2. **仍未达到「分得清」验收**：五折均值 BalAcc 长期卡在 **≈0.55–0.57**，达不到 0.65。  
3. **batch balance（B1）** 进一步提高 Spec，但 Rec 掉到线下；**B2（加权+balance）不稳定且易过偏静息**，不建议作主臂。  
4. **SMOTE（S1）对 raw EEG 无效甚至有害**（Spec 回落到 0.32），支持方案中「不做 SMOTE」的判断。  
5. **阈值扫描不能五折过关**；余量不足以靠调 τ 解决。  
6. 综合：在 **Shallow + merged_2s** 上，仅靠损失加权 / 采样 / SMOTE / 阈值，**不能稳定宣称基线已分清静息与任务**。
