# 方案：OpenBMI · MI 特征是否明显（find_best_trail）

## 0. 目的

参考《脑电特征提取指标与模板量化分析》，回答：

> 在 **OpenBMI** 上，每个被试的左手/右手 MI 相对静息，是否呈现出可量化的经典 MI 特征（对侧 Mu ERD、偏侧性、频带特异性、时间形态等）？

本实验**只分析 OpenBMI**；范围 **全部 54 名被试（subj01–54）**。  
语料写死：**仅官方 `EEG_MI_train`**（sess01+sess02 同人合并；**不读** `EEG_MI_test`）。  
后续可在此目录扩展：按试次打分、筛选「最佳试次」、服务模板/自监督。

---

## 1. 数据与切段（写死 · 对齐 hop100）

标准版本：**`OpenBMI_MI_feature_v2_hop100`**

| 项 | 取值 |
|----|------|
| 原始 | `DATA/openbmi/openbmi/openbmi/sess*_subj*_EEG_MI.mat` |
| 块 | **仅 `EEG_MI_train`**（OpenBMI 官方 train；**禁止** `EEG_MI_test`） |
| 被试范围 | **subj01–54**（54 人；`--subjects` 可子集） |
| 被试键 | `openbmi:subjNN`；sess01+sess02 **同人合并** |
| 通道 | `Cz, C3, C4, CP3, FC4, FC3, CP4, CPz`（与 hop100 训练一致） |
| 预处理 | CAR → notch50 → bandpass **8–30 Hz** |
| 采样 | 重采样 **250 Hz** |
| **Rest 段** | Cue 前 **4 s**（`cue−4s : cue`；可缩短以避让上一 MI） |
| **MI 段** | Cue 后 **0–4 s**（`cue : cue+4s`；Cue 前 0.5 s 基线校正） |
| **滑窗** | 段内 **\(T_w=2\,\mathrm{s}\)**，步长 **hop = 100 ms** → 窗形 `(1,8,500)` @250 Hz |
| z-score | **不做**窗内 z-score（保绝对功率，便于 ERD%） |
| **禁止** | 使用 hop100 训练用的、已窗内 z-score 的 `openbmi_*.npy` 算绝对功率 ERD |

几何与 `preprocess_lab` 的 `openbmi_2s_hop100` **一致**，仅去掉窗内 z-score。  
每条约 4 s 段 → 约 **21** 个 2 s 窗（起点 0, 0.1, …, 2.0 s）。

左手期望核心通道：**C4 / CP4**；右手：**C3 / CP3**。

## 2. 为何重定标准（相对原文档）

原文档模板偏理想优秀样本，例如：

- Mu ERD：**−50% ~ −65%**
- 静息 Mu 占 8–30 Hz：**≥ 60%**
- 时间：0.5 s 起降、1.2–1.5 s 谷底等

若直接套到 OpenBMI 真实库，几乎全体「不合格」，无法区分被试强弱。  
因此冻结本库合格线（名称见上：`OpenBMI_MI_feature_v2_hop100`）。

### 2.1 合格阈值对照

| 维度 | OpenBMI 合格线 | 原文档优秀线（对照） |
|------|----------------|----------------------|
| 对侧 Mu ERD | ≤ **−15%**（优秀 ≤ **−35%**） | −50% ~ −65% |
| 偏侧性 `laterality = ERD_ipsi − ERD_contra` | ≥ **8** 百分点（对侧更负） | 对侧远强于同侧 |
| Mu vs 低频 Beta(13–20) | Mu ERD 不弱于 βL（+5 pp 容差） | Mu 降幅最大 |
| 静息 Mu/(Mu+βL+βH) | ≥ **0.40**（优秀 ≥ 0.55） | ≥ 0.60 |
| 时间形态 | hop 曲线：0.4–0.9 s 相对前 0.3 s 下降 ≥ 8%，谷底 ∈ [0.7, 2.0] s | 0.5 s 起降、1.2–1.5 s 谷底 |

### 2.2 计分与总评

- 左右手各自 5 项核心检查：`mu_erd_contra` / `laterality` / `mu_vs_betal` / `rest_mu_frac` / `time_pattern`
- 单侧通过率：≥ 0.8 → **明显**；≥ 0.5 → **中等**；否则 → **弱/不明显**
- **被试总评** = 左右手通过率平均，再按同上阈值定级
- `excellent`（对侧 Mu ERD ≤ −35%）仅作附加标记，不单独改总评阈值

## 3. 提取的指标（对应原文档五大类，已落地子集）

| 类 | 本实验已算 |
|----|------------|
| 频率 | Mu / βL / βH 功率；相对 Rest 的 ERD% |
| 空间 | C3/C4/CP3/CP4 Mu ERD；对侧 vs 同侧；laterality |
| 功率 | 静息 Mu 占比 |
| 时间/动态 | 按 hop 起点的对侧 Mu 功率曲线：早段→中段降幅；谷底时刻 |
| 复合 | C3–C4 皮尔逊相关（Rest → MI） |

未强制复现原文档全部「工人」细项；以能否判定「特征是否明显」为优先。
