# 游戏得分反馈方案：得分留后台 · 前端伸手拿杯

> 日期：2026-08-25  
> 状态：**方案待拍板**（未实现）  
> 适用范围：`v2_session` **游戏轮**被试屏反馈；D8 计分公式不改  
> 相关：[`游戏方案_定稿_v3_20260824.md`](./游戏方案_定稿_v3_20260824.md)（D8）、`trial_v2.py` / `v2_bridge.js` / `scene.js`

---

## 1. 目标

- **被试屏不显示数字分数**（不出现 Score 0–5、百分比进度条）。
- **后台仍完整保留 D8 计分**（累加、早停、有效/无效、events 落盘；操作台可读数字）。
- **被试只看身体反馈**：想象越好 → 手臂越伸 → **满分 = 拿到杯子**。

---

## 2. 现状（简要）

| 层 | 现状 |
|----|------|
| 后端 | `OnlineScoreTracker`（D8）；`Score≥5` → `score_reach` 早停 |
| 被试屏 | HUD 显示 `Score x.x`；`calProgress` 画进度条 |
| 场景 | 已有 `v2GameLevel(level, reach)`（伸手档位 + 抓杯），**未与连续得分稳定映射**，且与数字 HUD 并存 |

结论：计分已在后台；缺的是「分数 → 伸手/拿杯」的统一视觉协议，并去掉被试侧数字。

---

## 3. 推荐映射（核心）

后端连续分 `score ∈ [0, 5+]` → **4 档伸手 + 满分拿杯**：

| 后端 score | 前端视觉 | 语义 |
|------------|----------|------|
| 0 – &lt;1.25 | 手在身侧 / 微动 | 未形成有效想象 |
| 1.25 – &lt;2.5 | 伸手 **1/4** | 开始靠近 |
| 2.5 – &lt;3.75 | 伸手 **2/4** | 明显伸出 |
| 3.75 – &lt;5.0 | 伸手 **3/4** | 接近杯子 |
| **≥ 5.0**（`score_reach`） | **伸满 + 抓住杯子** | **满分成功** |

- 映射阈值建议由**后端**算出并下发 `arm_level: 0..4`、`cup_grasp: bool`，前端只认这两项（避免前端私自改阈值）。
- 落盘：`events.jsonl` 继续写完整 `score`（科研/复盘）；被试屏永远不渲染数字。

---

## 4. 消息与职责划分

```text
后端 D8（公式不变）
  judge → score / pred / gated / signal_bad
  score≥5 → score_reach（早停）
       ↓ 规范下发
  v2_stage: judge | score_reach
    data: { arm_level, cup_grasp, ... }   # score 可仍带给操作台，被试不显示
       ↓
被试屏：只驱动手臂/杯子动画 + 短文案（「请继续想象」/「拿到了」）
操作台：仍可显示 Score / 有效性（给操作者）
```

---

## 5. 单次游戏试次画面时间线

| 阶段 | 画面 |
|------|------|
| prep | 十字；双手复位；杯子在桌上 |
| cue | 左/右提示；杯子可高亮；手尚未伸出 |
| mi + 各 judge | **同侧手按 `arm_level` 平滑伸出**（插值，不跳档闪烁） |
| score_reach / touch | **抓住杯子并略抬起**（满分反馈，约 0.8–1.2s） |
| iti | 放手、杯子复位、手回休息位 |

Rest 试次：无伸手、无拿杯。

---

## 6. 交互细节（建议冻结）

1. **平滑**：档位变化用 150–300ms 插值，避免 0.6s 一跳太机械。  
2. **只前进不后退（默认）**：同试次内 `arm_level` 单调不减，减少「伸了又缩」干扰想象；可选开关 `arm_allow_retract`。  
3. **signal_bad**：不伸手、不拿杯；可选极淡提示「信号不稳」（仍无分数）。  
4. **错类作废**：手臂回缩 + 杯子不抓；操作台显示原因。  
5. **标定轮 vs 游戏轮**：游戏轮必须用伸手–拿杯；标定轮可更克制（或共用映射，由拍板决定）。

---

## 7. 与现有 D8 的对齐（不改计分公式）

| D8 规则 | 前端等价物 |
|---------|------------|
| Score 累加 | 伸手档位上升 |
| Score≥5 早停 | **拿到杯子** |
| touch | 同满分拿杯（或优先真实触碰） |
| Score≤3 无效 | 试次结束未拿到杯 + 操作台记 invalid |
| 操作者看分 | 仅 operator 面板 |

「满分拿杯」≡ 现有 `score_reach`，语义清楚，便于写入采集文档。
