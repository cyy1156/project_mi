# 操作者 / 被试按键设计

> **版本**：v0.2  
> **日期**：2026-07-23  
> **状态**：**Phase 3 已实现**  
> **配套**：`游戏内容规格.md`、`ws_protocol.md`、`项目计划.md`

---

## 1. 目标

实验现场通常有两人：

- **被试（Subject）**：做运动想象，注意力在画面上  
- **操作者（Operator）**：控流程、看信号、处理异常  

需要**分开的按键/控件**，避免被试误触「结束会话 / reject / 跳过」等危险操作。

---

## 2. 角色与权限

| 能力 | 被试 | 操作者 |
|------|------|--------|
| 确认说明弹窗（继续 / 我明白了） | ✓ | ✓（可代点） |
| 学习各 Step「开始本步」 | ✓ | ✓ |
| 正式采集准入确认 | ✗ | ✓（`allow_subject=false`） |
| 暂停 / 继续计时 | ✗ | ✓ |
| 标记当前 trial `reject` | ✗ | ✓ |
| 紧急停止采集 | ✗ | ✓ |

## 3. 键位（已实现）

### 3.1 被试端

| 按键 | 动作 |
|------|------|
| `Space` / `Enter` | 确认当前 prompt（准入弹窗除外） |

### 3.2 操作者端（页顶操作者条 + 键盘）

| 按键 / 按钮 | 动作 |
|-------------|------|
| `P` / 暂停 | 暂停 / 恢复（冻结 trial 时钟） |
| `N` / 代确认 | 代被试确认 prompt |
| `G` | 准入确认（`gate_ok`） |
| `R` / Reject | 标记当前 trial 为 reject（写入 `trial_reject`） |
| `B` / 中场换场 | 见 §3.3 |
| `Q` / 问卷 | 见 §3.4 |
| `Esc` / 中止 | 紧急结束会话（二次确认） |

### 3.3 `B` 中场换场（实体手具身休息 → 新 session 继续）

配合「操作者抬被试双手对照画面」的中场休息使用；**每按一轮 B，前后数据落在不同 session 文件夹**：

1. 正式采集段按第一次 `B`：当前 trial 正常走完 → 打 `session_split` / `phase_end` 事件 → 停止本场录制并完整落盘（目录布局/对齐/自动切窗与正常结束一致）；
2. 诱导页弹出「中场休息」引导（被试按键无效），操作者引导抬手对照画面；
3. 按第二次 `B`：同一 subject 自动开新 session（`ses01 → ses02`，无数字后缀则 `_s2`），重开录制，先静坐缓冲（`experiment.split.settle_s`，默认 15 s，注视十字）再继续剩余 trial；
4. 中场等待中按 `Esc` 可放弃剩余 trial（已落盘数据保留）。

约束：`B` 仅正式采集段生效（适应/学习期按下会在进入正式段后的下一个 trial 边界生效）；继续段自动跳过适应/学习/准入。

### 3.4 `Q` 采集结束问卷（手动）

问卷**不自动注入**任何 session，由操作者按 `Q`（或点「问卷」按钮）手动推送到诱导页：MIQ 三视角 × 左右手 + 策略 + 诱导有效性 + 质控（是否不自主真动过手）+ 负荷，约 3 分钟。结果写入关联会话目录 `99_summary/questionnaire_post_<时间戳>.json`（优先当前/最近会话），操作台显示动觉均分等摘要。
