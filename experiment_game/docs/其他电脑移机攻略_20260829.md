# 其他电脑移机攻略（2026-08-29）

> **适用**：把本仓库迁到另一台 Windows 笔记本，跑通操作台 / 诱导 / 采集 / 采后 FT。  
> **原则**：不改 `session_v3`、前端游戏、FT 超参；只动环境、机位配置、大文件。  
> **配套**：更细的背景见 [`换机最小运行与可移植性重构建议_20260828.md`](换机最小运行与可移植性重构建议_20260828.md)；架构总册见 [`采集系统重构方案_20260829.md`](采集系统重构方案_20260829.md)。

---

## 0. 五分钟对照表

| 要做 | 不要做 |
|------|--------|
| `git clone` / `git pull` 到任意盘符 | 假设路径永远是 `D:\MI` |
| 复制 `machines/_template/` → `machines/<新机名>/` | 改共享根 `experiment_game/open_operator.bat` 迁就新机 |
| 拷贝 P0 权重 + OpenBMI `_t0` | 把旧机 `operator_defaults.json` 原样拷过去（常含 `D:\` / COM） |
| conda 装依赖 + `check_deps` | 在业务代码里写死 COM / 用户名 |
| UI 里选本机 COM / 板型 | 为换机去改范式时序 |

## 1. 从旧机带走什么

### 1.1 必带（P0）

在**相对仓库根**相同路径放置：

| 相对路径 | 用途 |
|----------|------|
| 整仓代码（`git`） | 业务与配置 |
| `code/train_lab/out/.../run_*/three/fold0/best_three.pt` | 在线推理 / FT 起点（与 yaml 中 `s3_three_ckpt` 一致） |
| 同上树 `…/task/fold0/best_task.pt` | task 头 |
| `code/preprocess_lab/out/openbmi_3s_hop100_t0/`（至少 `openbmi_X.npy`、`openbmi_y_three.npy`、`openbmi_subjects.npy`） | FT replay；`X` 约数 GB |

> 权重/ckpt 的**准确相对路径**以 `experiment_game/config/v3_session.yaml`（及 e1f 配置）为准；上表为示意。

### 1.2 按需（P1）

| 相对路径 | 何时需要 |
|----------|----------|
| `DATA/bci2a/A01T.mat` … | 只做 BCI2a 仿真 |
| `experiment_game/data/subjects/<被试>/` | 要在新机继续该被试 FT / 看历史 session |
| Cyton USB 驱动 / OpenBCI 文档 | 真机采集 |

### 1.3 不要原样拷

| 文件 | 原因 |
|------|------|
| `experiment_game/config/operator_defaults.json` | 常含旧盘符、COM、本机 `ft_runs`；已 gitignore，新机用 example 重生 |
| 旧机 `machines/5070_laptop/_resolve_python.bat` 里写死的 `C:\Users\yy\...` | 换用户必炸；用 `_template` |

## 2. 新机落地步骤（按顺序勾）

### 步骤 A · 放代码

```powershell
# 任意盘，例如：
cd C:\
git clone <你的仓库 URL> MI
cd MI
git checkout main
git pull
```

仓库根以下简称 `<REPO>`（不要写死 `D:\MI`）。

### 步骤 B · 拷大文件

用网盘 / 移动硬盘，把 §1.1 的文件放到 `<REPO>` 下**相同相对路径**。  
缺文件时 Preflight / 操作台会报路径不存在。

### 步骤 C · Python 环境

推荐 conda（与现网一致）：

```powershell
conda create -n cyy python=3.11 -y
conda activate cyy
# 按本机 CUDA 装 torch（无独显则装 CPU 版即可）
pip install numpy pandas scipy websockets pyyaml braindecode
# 采集另需：
pip install brainflow pylsl
```

可选可编辑安装（仓库根已有 `pyproject.toml`）：

```powershell
cd <REPO>
pip install -e ".[dev]"
```

自检：

```powershell
python -c "import torch, numpy, websockets, yaml; print(torch.__version__, 'cuda=', torch.cuda.is_available())"
```

### 步骤 D · 建本机机位目录

```powershell
cd <REPO>\experiment_game\machines
xcopy /E /I _template 我的新机名
```

编辑 `machines/我的新机名/machine.json`：

```json
{
  "machine_id": "我的新机名",
  "hostname": "本机计算机名",
  "gpu": "本机 GPU 或 none",
  "repo_root": "C:\\MI",
  "python": {
    "prefer": "conda",
    "conda_env": "cyy",
    "example_exe": "%USERPROFILE%\\.conda\\envs\\cyy\\python.exe"
  },
  "board": {
    "mode": "synthetic",
    "serial_port": "COM3"
  },
  "updated": "YYYY-MM-DD"
}
```

要点：

- `repo_root` = 新机真实绝对路径（仅登记用；业务代码用相对路径）
- **禁止**在 bat 里写死别人的 `C:\Users\...`
- 启动只用本目录 bat，**不要**去改仓库根共享 bat

若模板缺 `open_operator.bat`，可从 `machines/5070_laptop/` 复制后改环境探测，或：

```powershell
cd <REPO>
conda activate cyy
python -m experiment_game.tools.open_operator
```

### 步骤 E · 本机 defaults

```powershell
cd <REPO>
# 若误拷了旧 defaults，先删：
del experiment_game\config\operator_defaults.json
# 从示例生成（相对 save_root，无 D:\）：
copy experiment_game\config\operator_defaults.example.json experiment_game\config\operator_defaults.json
```

首次打开操作台也会自动写 defaults；**在 Setup 里把串口改成本机设备管理器中的 COM**。

### 步骤 F · 预检

```powershell
cd <REPO>
conda activate cyy
python -m experiment_game.tools.preflight
# 或双击 machines\我的新机名\check_deps.bat
```

期望：依赖、权重路径、端口占用等无硬错误。有 `D:\` 的 `save_root` 会警告——改回相对路径。

### 步骤 G · 冒烟（约 15 分钟）

1. 启动操作台 → 浏览器打开 Setup  
2. 登录测试被试缩写（如 `test01`）  
3. **先合成板**：开采集 · 板模式「合成板」· 模式 **v3 探针** · 开始实验  
4. 确认诱导页能 ready；跑完看  
   `experiment_game/data/subjects/test01/sessions/.../`  
   是否有 `eeg.csv`、`events.jsonl`、`eeg.meta.json`（Bus 单写）  
5. 真机：关 OpenBCI GUI 串口直播 → 选 Cyton → 填 COM → 可先 **v4 帽检** 再 v3  
6. （可选）勾选 session → 微调 → 看 `models/ft_runs`  

通过后在 `machines/VERIFIED.md` 追加一行。

## 3. 环境变量（可选覆盖）

解析链：**`MI_*` 环境变量 > `machines/*/machine.json` > `config/protocol.yaml`**。

| 变量 | 作用 |
|------|------|
| `MI_REPO_ROOT` | 强制仓库根（极少需要） |
| `MI_SERIAL_PORT` | 默认串口覆盖 |
| `MI_CONDA_ENV` | conda 环境名提示 |

日常换机：**一般不用设**；UI + machine.json 足够。

---

## 4. 真机采集注意（新机常踩坑）

1. **关掉 OpenBCI GUI 的 Serial/直播**，否则 COM 被占、LSL 无数据  
2. Cyton 开机、dongle 插牢；设备管理器确认 COM 号  
3. 现网 EEG：**板卡只推 LSL**，`eeg.csv` 由 `LiveEegCapture` 经 Bus 写入（勿再开旧双轨 Recorder）  
4. 防火墙：本机操作台用 `127.0.0.1`；平板连诱导页用 `open_operator_lan.bat` 并放行端口

## 5. 故障速查

| 现象 | 处理 |
|------|------|
| `未找到 LSL 流 OpenBCI_EEG` | 先开采集；合成板也会推流；真机关 GUI 占口 |
| `缺权重` / ckpt 不存在 | 对照 yaml 相对路径拷文件；跑 Preflight |
| FT 中途缺 replay | 拷 `_t0` npy，或临时关 replay（正式被试不建议） |
| 操作台记住错误盘符 | 删 `operator_defaults.json`，从 example 重建 |
| bat 找不到 python | 检查 `%USERPROFILE%\.conda\envs\cyy\`；或 `set MACHINE_CONDA_ENV=...` |
| 端口 8080/8765 占用 | Preflight 会提示；关掉旧操作台进程 |
| 依赖方向 / 单测 | `pytest experiment_game/experiment/tests -q`（约数秒） |
