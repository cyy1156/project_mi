## 在做什么

在 **BCI2a 纯 Cue MI**（与 OpenBMI/fnz 同口径）上，检验 Exp27 策略并回答：**累积多少 run 的 FT，在线 trial acc 能达到 ≥60%**。

| 项 | 取值 |
|----|------|
| 数据 | `A01T`…`A09T`（**仅 T**）· 每人 **6 run 全部用完** |
| **主实验 Run Ramp** | Leave-Next：R0–R5 · 固定 **B2** · **trial acc** |
| 辅实验 | Prefix→run₆；F@~310 窗对照 fnz |
| 双轨网格（可选） | Track S/M · 8 arms · 144 runs |
| 策略 | B2：T0-36 replay · ratio=0.10 · 每轮从底座重训 |
| 60% 判定 | 队列平均 trial acc ≥0.60；辅：≥6/9 人个体 ≥0.60 |
