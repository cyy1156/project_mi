## F5 冻结正文（2026-08-29 操作方确认）

**废除计分 / 主判定双轨；废除正式路径上的置信 τ 早停门控。**

| 层级 | 规则 |
|------|------|
| **窗级** | E1f 融合 `p_three` → **因果平滑**（当前窗与前两窗：`n,n−1,n−2`）→ **`pred = argmax`** |
| **试次（MI）** | 各窗 `pred` **多数票** = 试次结果 = 计分依据 = 主判定；对则 **+1** |
| **试次（专用 Rest）** | **同一规则**（因果平滑 + 多数票）；判 Rest 对则 **+0.5** |
| **τ / e1f_conf_stop** | **退出正式 SOP**（仅可作离线分析旁路） |

### 场景

| | 约定 |
|--|------|
| **v3 探针/采集** | 计分 = 主判定 = 上表；继续落盘；FT 仍 Cue+0–4s 与 Rest 段满段切窗 |
| **v2 正式游戏** | **实时反馈 = 每窗因果平滑后 argmax**；试次结算若启用则 **同一多数票**；可不落盘 |

### 历史数据

- **不重采**；旧 session 可按新规则回放重算。  
- **不重训**实验 26；OpenBMI 上多数票离线约 **0.6125**（对照 E1f 早停 0.6173）。

### 配置默认

- `readout_mode=e1f`（窗概率）  
- `primary_judge_mode=majority`（与计分同轨；实现含因果平滑）
