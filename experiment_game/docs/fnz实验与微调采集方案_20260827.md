## 2. 微调策略（需求定稿）

### 2.1 核心结论

**采用：E1f/OpenBMI 3s 底座（默认 5090 shallow fold0 task+three）+ 本被试合格 v3 session + Leave-Next heldout + T0 replay（默认 ratio=0.10）**  
**不在 session 内做轮间在线 FT。** **v4 帽检数据不入 FT**（冻结 F11）。

### 2.4 微调 SOP（冻结）

```
阶段 0  底座固定
         默认：5090 E1f shallow fold0
           …/run_20260823_095327/task|three/fold0/best_*.pt
         （对照可选 5070 单模 run_20260822_094942）

阶段 1  采集门槛
         每被试 ≥ 2 个「电极合格」**v3** session 再启动 FT
         **排除** phase_mode=v4_session；不合格电极 session 不并入

阶段 2  训练集（Leave-Next 优先）
         合格 v3 session 的 MI + **专用 Rest 段** 3s/hop100
         标签：Left/Right=MI；Rest=`[t_rest_start,t_rest_end)`（不含 prep）
         Leave-Next：前序 session 训练，下一场 heldout（非默认试次 70/30）

阶段 3  Replay
         pool = T0-36；replay_ratio = 0.10（爬坡后几档可为 0）

阶段 4  超参
         early_stop · max_epochs=20 · patience=5 · lr=1e-4 · batch=32 · 全模型双头

阶段 5  发布验收
         heldout 门控（acc / 类占比 / train-gap / 三类均有预测）
         结果**始终写入** ft_runs/；门控 FAIL 可警告后仍 promote（F8）
```
**命令示例：**

```bash
python experiment_game/tools/ft_subject_from_v3.py \
  --session experiment_game/data/sessions/fnz_ws01_20260826_164149 \
  --session experiment_game/data/sessions/fnz_ws02_20260826_171537 \
  --out-dir experiment_game/data/models/fnz
```

**不采用：** 将 OpenBMI、Stieger、BCI2a 与 fnz **平权混训**（见 §7）。

### 2.5 ws03 是否并入下一轮 FT

**建议：否。** Cz、CPz 全程 ±4191 µV 平线。等电极修复后新 session（如 ws04）再合并。

## 4. MI 指导语（明天实验采用）

块前口头强调；guided 块 **复述指导语**，不做伸手演示。

| 试次 | 指导语 |
|------|--------|
| **左手** | 「请想象 **左手正在握紧** 桌上的杯子，感受手指收紧、前臂用力，**不要真的动**。」 |
| **右手** | 「请想象 **右手正在握紧** 桌上的杯子，感受手指收紧、前臂用力，**不要真的动**。」 |
| **静息** | 「身体放松，什么都不要想，保持安静。」 |

**意象原则：** 同侧手 **抓握动感（kinesthetic MI）**；**不强调**「眼看杯子、手伸过去够它」（视觉–伸肌混合，与 OpenBMI 训练分布不一致）。

**guided 块说明：** 动觉引导 = 被试**两手分别抓握**桌上杯子、**记住抓握动作**，再睁眼按 §4 指导语想象复现（非伸手动画）。fnz ws03 曾示 guided primary 低于 no_guide；现场仍以 **复述抓握指导语** 为主。

## 5. MI 判定标准（2026-08-27 定稿 · 多数票）

### 5.1 统一口径（废除 D8）

| 轨道 | 规则 | 用途 |
|------|------|------|
| **操作台实时概率条** | hop100 判定点，MI 4s 内 11 档（3.0…4.0s） | 操作员实时看 |
| **primary_judge** | MI 全程 **多数票** | 报告准确率、特征对齐、块统计 |
| **试次 score / valid** | 因果平滑后多数票 == 标签 → MI **+1** / Rest **+0.5**；**跑满 4s MI** | events、本场得分（满分 54） |

**已废除：** D8 加权分、score≥5 早停、wrong_race 错类熔断、连 5 无效会话熔断。

### 5.2 多数票算法

```
输入：judgment_times = OpenBMI hop100 窗尾 [3.0, 3.1, …, 4.0]（MI=4s 共 11 档）
步骤：
  1. 剔除 signal_bad 的档
  2. 对 gated_pred 做多数票（mode）
  3. 平票：取该 pred 在 p_three 上概率之和最大的一类
  4. score = 1.0 if pred == label else 0.0；valid = True（有判定窗且非全 signal_bad）
  5. events 写 `trial_score`（试次计分摘要）
```

### 5.3 操作台显示

- 主显示：**多数票 pred** + 三分类概率（最后一档或多数票对应档）
- 试次得分条：**0 / 1**（非 D8 0–5）

## 6. Rest 基线与块前校准（需求）

### 6.1 「为什么静息好像不要？」

| Rest 数据 | 用途 | 当前状态 |
|-----------|------|----------|
| **块前 30s 静息** | 帽检、操作台波形、v4 | ✅ **会话开场一次**；换块不重复 |
| **ERD 特征基线** | 块前 30s seed + 试次间 Rest 4s 滚动 | ✅ 已灌入；换块 `reset_block` **保留 seed** |
| **块内 Rest 试次** | **已取消**（排程仅 Left/Right） | 静息 = 块前 30s + **专用试次间 Rest 4s**（`rest_start`/`rest_end`，不含 prep） |
| **换块** | `reset_block()` 清空 MI 累计，**恢复块前 seed** | 块 2 开头即可算 ERD |

### 6.2 需求定稿：三层基线策略

| 层级 | 策略 | 目的 |
|------|------|------|
| **会话级** | **开场一次** `baseline_rest_s=30` Rest；灌入 ERD seed；换块 **保留 seed**、不再重复 30s | 帽检 + 块 1 起即可算 ERD |
| **试次间** | **每试次专用 Rest 4s**（`inter_trial_rest`，在 prep 之前；含块内首试） | 灌入 ERD 滚动基线；**FT Rest 窗来源**（`rest_start/rest_end`） |
| **试次级** | prep **2s** = 注视稳定（不做判定）→ **Cue 先行 1s** → MI 4s | 判定/切窗锚定 **`mi_start`** |
| **特征侧** | 块前 seed + 专用 Rest 4s 滚动；**无 Rest 想象试次** | — |

**块前 30s 不能替代修电极**；但用于发现 Cz/CPz 平线等问题。

### 6.3 fnz_ws01「±5 变 ±500」说明

| Session | C3/CPZ 量级 | 结论 |
|---------|-------------|------|
| **ws01** | C3≈0.5 µV，CPZ≈2 µV，**全程稳定** | 数据正常；±500 可能来自 **ws02/ws03** 或操作台显示尺度 |
| **ws02/ws03** | C3≈400 µV；CPZ/Cz **±4191 常数** | **大 DC / dead 通道**；污染 CAR 与分类 |

## 7. 多 session 合并 + replay + 验收（详解）

### 7.1 多 session 合并

```
合格 session 列表（例：fnz0830_w01…w05）
    ↓ 每 session：eeg.csv → CAR+8–30Hz → Cue[0,4) + 专用 Rest 切 3s 窗 → z-score
    ↓ 合并 X, y_three, split_id = "{session}:{trial_id}"
    ↓ **Leave-Next**：前序 session train / 下一场 heldout（非 leave 时才 70/30）
    ↓ 仅 train 窗进入 FT（heldout 只用于验收；展示=smooth，门控=raw）
输出：data/subjects/{id}/models/ft_runs/<stamp>/ + 默认晋升 current
```

### 7.2 Replay 机制

```
每个 epoch 每个 batch：
  n_fnz = len(fnz_train_windows)
  n_replay = round(n_fnz * replay_ratio)   # 例：0.15 ~ 0.30
  从 OpenBMI ReplayPool 按类均衡抽 n_replay 窗
  batch = shuffle(fnz_train + replay_sample)
  cross_entropy → backward
```

**作用：** 防止 FT 把决策边界推成「永远 Left/Right」（ws02 教训）。

### 7.3 验收（发布前人工检查）

> **方案 A（2026-08-31）**：cohort **展示**用窗级 **因果平滑** `heldout_acc`；**门控 G1** 仍用 **raw** `heldout_acc_raw`（阈值 `max(0.40, 类先验+0.05)`）。早停选 checkpoint 用 **smooth**。详见 [`统计口径方案A_20260831.md`](统计口径方案A_20260831.md)。

| # | 检查项 | 阈值 | 数据源 | 不通过 |
|---|--------|------|--------|--------|
| 1 | heldout 三分类 acc | ≥ 自适应下限 | **raw** 窗级 | 不建议 promote |
| 2 | heldout 任一类 pred 占比 | < 60% | raw pred | 塌缩 |
| 3 | train − heldout acc 差 | < 0.35 | raw 窗级 | 过拟合 |
| 4 | 最新 session 电极 | Cz/CPz 有波动 | — | 不采、不 FT |
| 5 | heldout pred 分布 | 三类均有 | raw pred | 写 meta/report |
