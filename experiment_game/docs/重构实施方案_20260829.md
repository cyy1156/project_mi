## 1. 目标架构与依赖规则

### 1.1 目标分层（本期）

```text
┌─────────────────────────────────────────────────┐
│ 入口层  tools/（open_operator、replay、分析脚本） │  可调用所有人
├─────────────────────────────────────────────────┤
│ 应用层  experiment/（orchestrator、session_*、   │  可调 core / acquisition
│         inference、judge、scoring）              │  禁止调 tools / offline
├─────────────────────────────────────────────────┤
│ 采集层  acquisition/                            │  只可调 core
├─────────────────────────────────────────────────┤
│ 离线层  offline/                                │  只可调 core
├─────────────────────────────────────────────────┤
│ 核心层  experiment_game/core/                   │  零依赖（仅标准库）
│         channel_layout · atomic_io ·(后)windowing│
└─────────────────────────────────────────────────┘
```

### 1.2 依赖方向白名单（用测试锁死）

| 上层 | 允许 import | 禁止 import |
|------|------------|------------|
| `experiment_game.core` | 标准库 | 其它一切项目包 |
| `offline/`、`acquisition/` | core | experiment / tools / 彼此 |
| `experiment/` | core、acquisition | tools、offline |
| `tools/`、入口脚本 | 全部 | — |

**执行机制**：新增 `experiment/tests/test_dep_directions.py`（AST 扫描）。违规 = 测试红。  
（可选后续：import-linter；本期以 pytest 闸门为准。）

**例外**：`experiment → acquisition` 仅允许「通道常量 / 板卡门面」类符号；禁止 session 逻辑反向依赖 acquisition 内部实现。阶段 0.3 后通道常量应以 core/channel_layout 为准。
