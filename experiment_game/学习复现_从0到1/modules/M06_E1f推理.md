# M06 · E1f 四成员推理

## 目标

搞清在线「谁在投票」：四个 three 头 + 温度 + 权重；以及 json 里哪些字段正式不用。

## 成员（冻结）

| name | arch | 角色 |
|------|------|------|
| shallow | shallow | S3 骨干 |
| t_shallow | shallow | t0 降权训练的 shallow |
| eegnet | eegnet | 轻量 CNN |
| conformer | conformer | 注意力骨干 |

融合：`temperatures` + `weights=[0.2,0.2,0.3,0.3]` → `p_three`。
