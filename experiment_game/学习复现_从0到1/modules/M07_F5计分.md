# M07 · F5 计分（因果平滑 + 多数票）

## 目标

会手算一小段，并指到实现。正式路径：**无 τ 早停**。

## 规则（背）

1. 每窗已有 `p_three`（来自 E1f）  
2. **因果平滑** lookback=2：窗 n 用 `mean(p[n-2], p[n-1], p[n])`（边界裁剪）再 argmax → `pred`  
3. 试次内所有窗 `pred` **多数票** = 试次结果  
4. MI 对 +1；Rest 对 +0.5；平票看各类 `p_three` 之和  

`rule` 名：`causal_smooth_majority`。
