## 规则背诵（实现前）

1. 输入：长度为 N 的 `p_three` 序列。  
2. 对每个下标 i：取 `p[max(0,i-2):i+1]` 做平均 → argmax → `pred[i]`。  
3. 对 `pred` 做多数票 → 试次标签。  
4. 与真值比：Left/Right 对 +1；Rest 对 +0.5。
