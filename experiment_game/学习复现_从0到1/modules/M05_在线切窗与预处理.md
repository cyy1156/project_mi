## 你要写的签名草稿

### `windowing.py`

```python
@dataclass
class WindowSpec:
    t_start: float  # 相对锚点
    t_end: float

def iter_window_specs(task_s=4.0, win_s=3.0, hop_s=0.1) -> list[WindowSpec]:
    specs = []
    t0 = 0.0
    while t0 + win_s <= task_s + 1e-9:
        specs.append(WindowSpec(t0, t0 + win_s))
        t0 += hop_s
    return specs
```
