# M05 · 在线切窗与预处理

## 目标

理解模型看到的不是「原始连续 CSV 随便切」，而是 **与 OpenBMI 训练同构的 3s/hop100 窗**。

## 关键规格（F26）

| 项 | 值 |
|----|-----|
| 模式 | `online_window_mode: openbmi_hop100` |
| 窗长 / hop | 3.0 s / 0.1 s |
| Task 段 | `[Cue, Cue+4s)` |
| 首窗 | 相对 Cue `[0, 3] s` |
| 末窗 | 约 `[1, 4] s`（约 11 窗） |
| 段级基线 | Cue 前 **0.5 s** 减均值 |
| 窗内 | 每通道 **z-score** |
| 滤波族 | 通常 CAR + 陷波 + 8–30 Hz（以 `OnlinePreprocessor` 为准） |

## 对应代码

| 内容 | 路径 | 看什么 |
|------|------|--------|
| 在线预处理 + 取窗 | `experiment/inference_v2.py` | `OnlinePreprocessor` · `InferenceService` 取窗/`judge` 前半 |
| 切窗几何（权威） | `experiment_game/core/windowing.py` | 与离线同构的窗函数 |
| 判定时刻 | `experiment/openbmi_align_config.py` | `build_openbmi_judgment_times` 一类函数 |
| 配置 | `v3_session.yaml` 中 `win_s` / `win_hop_s` / `baseline_before_cue_s` | |
| 文档 | `docs/范式对齐_…` §2.3–2.4 | 在线 vs FT 切窗表 |

## 精读顺序

1. 范式文档切窗表（先建立几何直觉）  
2. `openbmi_align_config.py` 判定时刻  
3. `OnlinePreprocessor`：输入连续缓冲 → 输出 `(8, 750)` 一类张量前的步骤  
4. （可选）`core/windowing.py` 与 preprocess_lab 对照  

## 动手题

1. 计算：4s 段、3s 窗、hop 0.1s，有多少个满窗？  
2. 说明「窗尾 = 判定点」时，第一个可判时刻为什么是 Cue+3.0s。  
3. 区分：**采集侧滤波默认关** vs **模型侧预处理开**（联系 M01）。
