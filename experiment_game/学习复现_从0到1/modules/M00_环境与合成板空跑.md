# M00 · 环境与合成板空跑

## 目标

不接真板，先把「操作台 → 会话目录」跑通，建立信心与目录直觉。

## 对应代码 / 文件

| 角色 | 路径 |
|------|------|
| 启动脚本 | `experiment_game/open_operator.bat` |
| Python 入口 | `experiment_game/tools/open_operator.py` |
| 编排服务 | `experiment_game/experiment/orchestrator.py`（先当黑盒） |
| 前端 Setup | `experiment_game/web/operator.html` · `web/js/operator.js` |
| README 操作说明 | `experiment_game/README.md` |

## 动手步骤

1. 仓库根激活 `.venv`（见 README / 移机攻略）。  
2. 双击 `open_operator.bat`，浏览器应开 `http://127.0.0.1:8080/operator.html#setup`。  
3. Setup：
   - 登录临时被试 id（如 `learn_m00`）
   - **开启采集** · 板模式选 **合成板**
   - 模式 **v3 探针** · 权重默认 E1f
   - 开始实验  
4. 让会话跑完（或中途合法结束）。  
5. 到 `experiment_game/data/sessions/` 找到最新目录，列出文件名。

## 精读（可选，30 分钟）

打开 `tools/open_operator.py`，看它如何启动 HTTP/WS 与 `OperatorService`。  
**不要**现在通读整个 `orchestrator.py`。
