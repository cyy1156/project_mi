## 你要创建的文件（逐个建）

在仓库根 `D:\MI\` 下：

```text
mi_scratch/
  README.md
  requirements.txt          # 可先写 pytest\nnumpy\npyyaml
  config/
    protocol.yaml           # 从原版复制再改注释
  src/
    mi_scratch/
      __init__.py           # 空文件即可
  tests/
    test_smoke.py
  tools/
    .gitkeep
```

为让 `import mi_scratch` 方便，可在 `mi_scratch` 根加空的 `conftest.py`，或把 `src` 加到 PYTHONPATH。最简单：`tests` 里写：

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "src"))
```

### `tests/test_smoke.py` 示例

```python
def test_package_imports():
    import mi_scratch
    assert mi_scratch is not None
```

### `config/protocol.yaml`

1. 复制 `experiment_game/config/protocol.yaml` 到 `mi_scratch/config/protocol.yaml`。  
2. 文件最上面加一行注释：`# 来源: experiment_game/config/protocol.yaml，学习用副本`。  
3. **先不要改数字**。

### `README.md` 至少写

```text
对照原版 session 路径：……
作业目标：自己实现 experiment_game 流水线
复用声明：（暂时无）
```

## 逐步操作（照着点）

### A. 原版空跑

1. 按原版 README 激活 conda/venv。  
2. 双击或运行 `open_operator.bat`。  
3. 浏览器打开操作台 Setup。  
4. 被试 id：`learn_m00`；采集：**合成板**；模式：**v3**；权重：E1f。  
5. 开始 → 等结束（或合法停止）。  
6. 到 `experiment_game/data/sessions/` 找最新文件夹，把**完整路径**粘到 `mi_scratch/README.md`。

### B. 脚手架

1. 建上面的目录。  
2. 复制 protocol。  
3. 跑：`python -m pytest mi_scratch/tests/test_smoke.py -q`（在 `D:\MI` 或 `mi_scratch` 下，按你的 path 设置）。  
4. 绿了就勾进度。

## 常见坑

| 现象 | 处理 |
|------|------|
| 找不到会话目录 | 看操作台日志里的 session 路径 |
| pytest 找不到包 | 检查 `sys.path` 或在 `mi_scratch` 下用 `pip install -e .`（可后做） |
| 想改 orchestrator | 停；作业不在那里写 |
