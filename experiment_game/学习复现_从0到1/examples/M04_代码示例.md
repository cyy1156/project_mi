# M04 教学代码示例 · Trial FSM

> **对照**：`config/protocol.yaml` 的 `timing_v3`；`trial_v2.py` 事件顺序。  
> **先核对**：你对照场里 `cue` 与 `mi_start` 的时间是否相同，再改下面锚点策略。

## 三句话

1. 从 yaml 读五个时长。  
2. 用**累加时间**模拟试次（单测不 sleep）。  
3. 每个边界 `emit` 一个事件名。

---

## `timing.py`

```python
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import yaml


@dataclass
class TrialTiming:
    rest_s: float
    prep_s: float
    cue_s: float
    imagine_s: float
    iti_s: float


def load_timing(path: Path) -> TrialTiming:
    cfg = yaml.safe_load(Path(path).read_text(encoding="utf-8"))
    t = cfg["timing_v3"]
    return TrialTiming(
        rest_s=float(t["inter_trial_rest_s"]),
        prep_s=float(t["prep_s"]),
        cue_s=float(t["cue_s"]),
        imagine_s=float(t["imagine_s"]),
        iti_s=float(t["iti_s"]),
    )
```

## `trial_fsm.py`（逻辑钟完整版）

下面示例采用一种常见写法：**`cue` 时刻开始展示；`mi_start` 与 `cue` 同刻**（若你的对照场不同，只改标注处）。

```python
from __future__ import annotations

from typing import Callable

from teach_demo.timing import TrialTiming

EmitFn = Callable[..., None]  # emit(name, t, **fields)


def run_trial(
    label: str,
    timing: TrialTiming,
    emit: EmitFn,
    *,
    t0: float = 0.0,
) -> float:
    """跑完一个 trial，返回结束时间 t。不 sleep。"""
    t = float(t0)

    emit("rest_start", t, label=label)
    t += timing.rest_s
    emit("rest_end", t, label=label)

    emit("prep_start", t, label=label)
    t += timing.prep_s

    # ----- 锚点：请用对照场 events 核实后锁定 -----
    emit("cue", t, label=label)
    emit("mi_start", t, label=label)  # 若原版 mi 在 cue 之后，改为 t += timing.cue_s 再 emit
    # 若 Cue 需要单独占 cue_s 时长再进入 MI，可在 mi_start 之后或之前累加 cue_s
    # 教学默认：imagine 从 mi_start 起走 imagine_s
    t += timing.imagine_s
    emit("mi_end", t, label=label)

    emit("iti_start", t, label=label)
    t += timing.iti_s
    return t
```

> 现行 `protocol.yaml` 有 `cue_s: 1.0`。更贴原版的写法可能是：打 `cue` 后先走 `cue_s`，再打 `mi_start`，再走 `imagine_s`。  
> **以你对照场 `events.jsonl` 为准**改这两行即可。

更贴近「Cue 展示 1s 再 MI」的改法示例：

```python
    emit("cue", t, label=label)
    t += timing.cue_s
    emit("mi_start", t, label=label)
    t += timing.imagine_s
    emit("mi_end", t, label=label)
```

## 测试

```python
def test_event_order():
    from teach_demo.timing import TrialTiming
    from teach_demo.trial_fsm import run_trial
    names = []
    def emit(n, t, **kw):
        names.append(n)
    timing = TrialTiming(4, 2, 1, 4, 3)
    run_trial("Left", timing, emit)
    assert names[0] == "rest_start"
    assert "mi_start" in names
    assert names[-1] == "iti_start" or "iti" in names[-1]
```
