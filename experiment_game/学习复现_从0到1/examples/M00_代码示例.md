# M00 教学代码示例 · 脚手架（不写算法）

> **对照原版**：跑一场合成板 v3，得到对照场 `data/sessions/...`。  
> **作业路径**：只建仓库骨架，代码目录统一为 `self_learing/`（不要用旧文里的 `mi_scratch` 当新作业名）。  
> **纪律**：本示例只教「目录长什么样」；**禁止**把示例整树复制交差——你要自己 `mkdir` / 写文件。

## 三句话

1. 先有对照场，再写代码。  
2. 作业包名固定 `self_learing`。  
3. `pytest` 能发现包，才算脚手架过关。

---

## 放到哪（目标树）

在仓库旁或仓库内建（路径以你本机为准，下同）：

```text
self_learing/
  README.md                 ← 三句话说明本作业要干什么
  requirements.txt          ← numpy, pyyaml, pytest, …
  config/
    protocol.yaml           ← 可从 experiment_game/config/protocol.yaml 抄 timing 数字
  src/
    self_learing/
      __init__.py           ← 可空
  tests/
    test_smoke.py           ← 本模块唯一必写测试
  tools/
    .gitkeep
  data/                     ← 可选；对照场也可仍用原版 data/sessions
    .gitkeep
```

`pyproject.toml` 或 `PYTHONPATH=src` 任选一种，让 `import self_learing` 成功即可。

## `tests/test_smoke.py`

```python
from __future__ import annotations


def test_import_package() -> None:
    import self_learing

    assert hasattr(self_learing, "__version__")


def test_protocol_exists() -> None:
    from pathlib import Path

    # 以「跑 pytest 时的 cwd = self_learing 根」为准
    p = Path("config/protocol.yaml")
    assert p.is_file(), "请把 protocol.yaml 放到 self_learing/config/"
```

