# 教学代码示例怎么用

> 这些是**老师写的参考答案**，用来「看懂长什么样」。  
> 作业仍在 **`D:\MI\self_learing`** 里**自己重写**；不要整文件夹复制过去交差。

## 建议学法

1. 打开对应 `M0x_代码示例.md`  
2. 先看「这段代码在干什么」三句话  
3. 对照原版精读表里的函数名  
4. **合上示例**，在 `self_learing` 里凭记忆/笔记自己敲  
5. 卡住再睁眼看示例 10 行，再合上继续
