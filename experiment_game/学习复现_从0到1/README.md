# experiment_game · 从 0 到 1 学习复现

> **给谁看**：用 AI 写过代码、想自己把整条链路啃明白的人。  
> **你的起点**：串口 / COM 较熟；LSL、会话、推理、计分、微调不熟。  
> **目标**：能自己讲清「一帧脑电从板卡到得分再到落盘」发生了什么，并能独立跑通合成板 v3 + 理解 Leave-Next。

## 怎么用这个文件夹

1. 先读 [`01_整体设计逻辑.md`](01_整体设计逻辑.md)（半天内建立地图）  
2. 按 [`02_学习路线图.md`](02_学习路线图.md) 从 **M00** 往下走  
3. 每学完一模块：打开 [`进度.md`](进度.md) 勾选、写日期与笔记  
4. 细节卡壳时翻 `modules/Mxx_*.md`，里面写了「读哪几个函数」
