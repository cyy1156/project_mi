## 学习 / 实现纪律

1. **先图后码**：纸上 5 框 → 再写测试 → 再实现。  
2. **先红后绿**：没有失败测试不要写实现。  
3. **只精读原版标出的函数**做行为 diff，禁止整文件粘贴。  
4. **orchestrator 不通读**：需要时只搜 `_handle_`。  
5. **进度日更**：当天写「自写文件路径 / 复用了什么 / 卡点」。  
6. **数字以 `protocol.yaml` 为准**（例如现行 `cue_s` 以仓库文件为准）。
