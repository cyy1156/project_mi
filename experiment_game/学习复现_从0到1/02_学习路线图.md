## 学习纪律（防再次「只会跑不会讲」）

1. **先图后码**：每模块先在纸上画 5 框流程图，再打开文件。  
2. **只精读标出的函数**，不要通读 `orchestrator.py`。  
3. **改一行实验**：例如临时 `print` 判定时刻，跑合成板验证，再还原。  
4. **进度日更**：当天在 `进度.md` 写「卡点 / 已懂」。  
5. **冲突以配置为准**：冻结表 / `protocol.yaml` > 旧文档。
