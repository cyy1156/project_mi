## 1. 系统全貌：先把整张地图装进脑子

### 1.1 系统在干什么（三句话）

1. 被试戴 Cyton 8 导帽，看网页游戏：想象左/右手抓杯子，或静息。
2. 电脑同时做五件事：**采脑电 → 打时间标签 → 在线分类 → 计分反馈 → 落盘**。
3. 一场结束后，用 **Leave-Next**（拿前几场训练、留下一场考试）对被试做少样本微调。

核心矛盾：游戏画面可以卡；**「哪一毫秒开始想象」的标签不能漂**——模型靠「标签时刻 + 那段 EEG」学习。

### 1.2 两条流 + 一条采后链

```text
数据流（宽·电压）: COM 串口 → BrainFlow/LSL @250Hz → RingBuffer → EEGBus → CSV / 在线推理 / 波形 / 健康
控制流（窄·事件）: TrialFSM → events.jsonl(+LSL marker) → 窗尾判定×11 → E1f 融合 → F5 计分
采后（离线）    : session 落盘 → Leave-Next 爬坡 → 少样本 FT → subjects/<id>/models/current
```

记忆钩子：**数据流管电压，控制流管「现在是 Rest 还是 MI、该不该判分」，采后管「让模型越来越懂你」。**
你的串口知识只用在最上游（COM→LSL）；进 LSL 之后，代码不再碰 COM。

```python
class EventLogger:
    def __init__(self, path):
        self.path = Path(path)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self._f = open(self.path, "a", encoding="utf-8")

    def emit(self, event: str, t_lsl: float, **fields) -> dict:
        row = {"t_lsl": float(t_lsl), "event": event}
        row.update({k: v for k, v in fields.items() if v is not None})  # 原版行为：None 字段丢弃
        self._f.write(json.dumps(row, ensure_ascii=False) + "\n")
        self._f.flush()
        return row

    def close(self):
        self._f.close()
```

### M04 · Trial FSM（1 天）

**文件**：`timing.py`、`trial_fsm.py` + 测试。

`load_timing` 读 `protocol.yaml` 的 `timing_v3`，键名【已核实】：`inter_trial_rest_s / prep_s / cue_s / imagine_s / iti_s`。

**★修正模块笔记草稿：mi_start 在 cue 之后 +cue_s**（原版 `trial_v2.py` L204–208：cue 展示完才 emit mi_start；§3-#9）。修正版 `run_trial`：

```python
def run_trial(label: str, timing: TrialTiming, emit, *, t0: float = 0.0, trial_id: int = 1) -> float:
    """逻辑钟版：不 sleep，用 t 累加。事件序=原版 trial_v2（见 §3-#11）。"""
    t = t0
    emit("trial_start", t, trial_id=trial_id, label=label)
    emit("prep_start",  t, trial_id=trial_id)
    t += timing.prep_s
    emit("cue", t, trial_id=trial_id, label=label)
    t += timing.cue_s                    # ★ cue 展示 1s 后 MI 才开始（原版行为）
    emit("mi_start", t, trial_id=trial_id)
    t += timing.imagine_s
    emit("mi_end", t, trial_id=trial_id)
    emit("iti_start", t, trial_id=trial_id)
    t += timing.iti_s
    emit("trial_end", t, trial_id=trial_id)
    return t
```

### M05 · 切窗 + 预处理（1 天）

**文件**：`windowing.py`、`preprocess.py` + 测试。

窗数公式（照 `n_windows_for_duration` 行为）：

```python
def n_windows(task_s=4.0, win_s=3.0, hop_s=0.1) -> int:
    if task_s < win_s - 1e-9:
        return 0
    return int(1 + round((task_s - win_s) / hop_s))   # 4s → 11
```

`iter_window_specs(task_s, win_s, hop_s)` 产出 `WindowSpec(t_start, t_end)`（相对锚点）；`slice_window(data, fs, anchor_t, spec)` 返回 **(8, 750)**。
`preprocess.py`：`baseline_correct`（减锚点前 0.5s 每通道均值）+ `trial_zscore`：

```python
def trial_zscore(x_tc, eps=1e-8):          # x_tc: (T, C)，与原版同布局
    mean = x_tc.mean(axis=0, keepdims=True)
    std = x_tc.std(axis=0, keepdims=True)
    std = np.where(std < eps, 1.0, std)
    return (x_tc - mean) / std
```

红灯测试：`n_windows(4.0)==11`；造假 `(8, 1000)` 数据切窗 `out.shape == (8, 750)`；zscore 后每通道 mean≈0、std≈1。

**坑**：
- 布局约定**全项目写死一种**（推荐：缓冲/切窗用 `(T,C)`，喂模型前转 `(C,T)` 即 (8,750)），写进 README；
- 【已核实】原版 `extract_segment_baseline` 在**拿不到基线**（锚点前不足 0.5s）时直接返回原样数据、不做基线校正——照抄这个行为并在注释声明；
- 滤波只在 preprocess 一处（现在可 noop + 注明），Source 不滤。

```python
def apply_temperature_probs(p, temperature):
    t = max(float(temperature), 1e-4)
    p = np.clip(np.asarray(p, dtype=np.float64), 1e-8, 1.0)
    logits = np.log(p) / t
    logits = logits - logits.max()
    e = np.exp(logits)
    return e / e.sum()

def fuse(member_probs, temperatures, weights):
    w = np.asarray(weights, dtype=np.float64); w = w / w.sum()
    cal = [apply_temperature_probs(p, t) for p, t in zip(member_probs, temperatures)]
    return np.tensordot(w, np.stack(cal, axis=0), axes=(0, 0))
```

    raw = [np.asarray(p, dtype=np.float32) for p in probs]
    out = []
