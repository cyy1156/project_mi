## 0. 一句话目标

在 **sub02 / sub03** 各自会话上，沿用 01 的切段 / 段内 2 s·100 ms 合法窗 / Top-5 模型 / 段级 Acc_paper 主报；与 01 的唯一结构性差异是：

1. 用该被试 **前一半合法 trial** 的窗做 **全模型微调**（从 BCI2a Acc_paper 权重初始化；**不冻结**任何层）；  
2. 仅用 **后一半合法 trial** 做与 01 同形的 **伪在线回放评测**。

两人仍 **分开报数**；本臂结果与 01 对照时，须用 **同一后半测试集** 上的零样本分数（见 §9），不可直接拿 01「全会话」表与本臂「后半」表混比夺冠。

## 2. 数据划分（本臂核心 · **已冻结**）

### 2.1 划分单位

**按合法 acquire `trial_id` 升序对半**，不是按窗、不是按墙钟秒、不是按 MI/REST 段条数单独切。

流程：

1. 与 01 相同：对齐 PASS → reject 过滤 → 得到合法 trial 列表 \(T=\{t_0,\ldots,t_{N-1}\}\)（升序）。  
2. \(N_{\mathrm{train}}=\lfloor N/2\rfloor\)，\(N_{\mathrm{eval}}=N-N_{\mathrm{train}}\)。  
3. **训练 trial**：\(T_{\mathrm{train}}=\{t_0,\ldots,t_{N_{\mathrm{train}}-1}\}\)。  
4. **评测 trial**：\(T_{\mathrm{eval}}=\{t_{N_{\mathrm{train}}},\ldots,t_{N-1}\}\)。

每个合法 trial 仍含 **MI 段 ⊕ REST 段**（与 01 §4.2 一致）；该 trial 整包进 train 或整包进 eval，**禁止**同一 trial 的 MI 进训、REST 进测。

| 集合 | 可用段 | 用途 |
|------|--------|------|
| \(T_{\mathrm{train}}\) | 其全部合法 MI + REST | 出窗 → **微调 Train/Val** |
| \(T_{\mathrm{eval}}\) | 其全部合法 MI + REST | 出窗 → **伪在线测试（只推理）** |

### 2.2 规模预期（实施时写入 meta，此处为量级）

以 01 审计为参考（reject 后）：

| 被试 | 合法 trial 量级 | 前半 / 后半（约） | 满段窗数/段 |
|------|-----------------|-------------------|-------------|
| sub02 | ~62（REST 略少 1） | ~31 / ~31 | 21 |
| sub03 | 62 | 31 / 31 | 21 |

精确 \(N\)、\(N_{\mathrm{train}}\)、窗数以切分脚本输出的 `split_manifest.json` 为准。

### 2.3 泄漏禁令（硬）

1. \(T_{\mathrm{eval}}\) 的任何窗 **不得**进入 loss / 早停 Val / 任何超参搜索。  
2. 连续流若仍拼接，**评测滑窗不得跨 train|eval 接缝**（与 01「禁跨缝」同理；推荐 **训、评两套独立流**，从根上消灭接缝泄漏）。  
3. 预处理统计（若有全局 z-score 等）**只允许在 \(T_{\mathrm{train}}\) 上估计**；本臂主路径沿用 01 的 **窗内** 基线+z-score，则无跨半统计泄漏。  
4. 禁止用后半分数回挑 lr / epoch / 是否微调后再报主表。

### 2.4 前半内部 Train / Val（对齐 Acc_paper 包）

对齐 `baselines_2s_hop100_accpaper` 的 `val_ratio=0.2`：

| 集合 | 划分 | 用途 |
|------|------|------|
| **FT-Train** | \(T_{\mathrm{train}}\) 内按 trial **随机**划出 \((1-\mathrm{val\_ratio})\) | 窗级 CE + **balbatch** |
| **FT-Val** | \(T_{\mathrm{train}}\) 内剩余 \(\mathrm{val\_ratio}\) trial | **Val Acc_paper 早停**（段/试次聚合；DataLoader 不 shuffle） |
| **FT-Test（伪在线）** | \(T_{\mathrm{eval}}\) 全部 | 主报表；**不参与训练** |

- 划分种子：`seed=42`（与 SharedTrainHP 一致）；写入 meta。  
- 聚合键：游戏侧用 `(subject_id, trial_id, seg)` 或等价「段」——与 01 段级 Acc_paper 一致；Val 早停对 **段** 算 Acc_paper（Rest/Task 或 0/1/2）。  
- 若某折 FT-Val 段数过少导致 Acc_paper 噪声大：仍保持协议，在 MD 标注 `n_val_segments`；**不**为此改用后半做 Val。

可选附录（不进主表）：`val_ratio=0`、固定 epoch 微调——仅敏感性，不替代主协议。

### 4.2 初始化与优化（**已冻结**）

| 项 | 约定 |
|----|------|
| Init | `train_lab/out/baseline_2s_hop100_accpaper/<model>_2s_hop100_balbatch_accpaper/.../fold{k}/best_{task\|three}.pt` |
| **微调范围** | **全模型权重**（backbone / 卷积 / 注意力 / 全连接分类头等 **全部参与梯度更新**） |
| **禁止** | `requires_grad=False` 冻结特征层；只训 `classifier` / `fc` / 最后一层；任何 head-only / linear-probe 变体当主表 |
| 头 | Task / Three **分开**各训一套全模型（与 Acc_paper 两套头一致；仍是全参数 FT，不是「只训头」） |
| Loss | 窗级 CE |
| Sampler | `balanced_invfreq`（balbatch）；`no_rap` |
| 早停 | **Val Acc_paper**（仅 FT-Val） |
| **主表超参（已确认）** | `lr=1e-4`，`wd=1e-4`，`drop=0.50`，`batch_train=32`，`val_ratio=0.2`，**`max_epochs=300`**，**`patience=20`** |
| meta 必写字段 | `finetune_mode=full_model` · `freeze_backbone=false` · `head_only=false` |

实施时：加载 init 后 **不得**再对除 BatchNorm running stats 以外的参数关梯度；优化器 `param_groups` 须覆盖 `model.parameters()` 全集。  
若冒烟不收敛，只允许在 **前半 Val** 上调参并修订方案版本号；**禁止**偷看后半；**禁止**为提分改成只训分类器却仍写本臂名。

### 4.3 「五折」在本臂的含义

与 01 对齐叙事：

```text
for fold in 0..4:
  load BCI2a Acc_paper best_*.pt[fold]
  fine-tune on subject’s T_train (internal Val for early stop)
  evaluate on subject’s T_eval (pseudo-online, segment Acc_paper)
→ report mean±std over 5 folds
```

- **不是**游戏内五折 CV。  
- **不是**从后半挑最好折。  
- 每人独立微调；sub02 的权重不用于 sub03。

### 4.4 读数后缀 / 协议串

```text
game_pseudo_online_ft
  Tw=2s hop=100ms
  arm=02_finetune_first_half_train_second_half_eval
  finetune_mode=full_model
  freeze_backbone=false head_only=false
  split=trial_order_half
  init=bci2a_2s_hop100_balbatch_accpaper
  train=game_first_half_windows
  eval=game_second_half_pseudo_online
  early_stop=val_acc_paper
  max_epochs=300 patience=20 lr=1e-4
  balbatch no_rap no_otta
  metrics=segment_acc_paper_main + balacc_maj + window_balacc_aux
```

## 7. 实验矩阵

```text
被试 {sub02, sub03}
  × 模型 ×5
  × init fold {0..4}
  × 头 {Task, Three}
  → 前半微调 + 后半伪在线评测
  → mean±std
```

规模：\(2 \times 5 \times 5 \times 2 = 100\) 次「微调+评测」流水线（与 01 推理次数同量级，但每折多一段训练）。
