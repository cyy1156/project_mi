### 3.3 S07-03 / S07-04（←03 / 04）· **质量门控（写全）**

#### 3.3.1 门控在干什么（人话）

模型对每个 **3 s 滑窗** 先出预测，再按试次/段把多窗投票成 Acc_paper。  
**质量门控** = 投票前先丢掉「看起来不像可靠 MI」的窗，只让留下的窗参与 >50% 正确率判定。

- **不改**模型权重、**不改** Acc_paper 公式，只改「哪些窗进分母」。  
- **REST（静息）窗默认全部保留**；门控只筛 **Left/Right（MI）窗**。  
- 某试次筛完后 **0 窗可投** → 该试次记 **abstain（弃权）**：不进 Acc_paper 分母，但要附报弃权率。

本套对齐历史 03-P2 / 04 的 **在线门控**（可在 Stieger 流上当场算，不查 OpenBMI 离线清单）。

#### 3.3.2 字母代号一览（本臂会用到的）

| 代号 | 全称含义 | 一句话 |
|------|----------|--------|
| **Q0** | 04 的「无门控」读数位 | = 零样本、所有窗都投票 ≡ **H0** ≡ **S07-01** |
| **Q1** | 04 的「开门控」读数位 | = 同一套零样本流上扫 **H0–H3** ≡ **S07-03** |
| **H0** | 无门控对照 | 所有窗都进投票（基线） |
| **H1** | **主部署门控**（硬阈值） | MI 窗须同时满足：对侧 μ-ERD ≤ −15 **且** laterality ≥ 8 |
| **H2** | 放宽门控 | 只要求 laterality ≥ 8（不卡 ERD） |
| **H3** | 相对门控 | 每个试次内，MI 窗按 laterality 取 **top-50%** 再投票 |
| **abstain** | 弃权 | 门控后该试次无可投窗 → 不计分母 |

历史 03-P1 还有 **G0–G3**（OpenBMI 离线 mask：G0=无门控，G1=高 laterality 明显子集，G2=teachable 清单，G3=试次内 top-p%）。  
**H1 ≈ 当时 G2 的阈值**，但 G 系依赖离线名单，**Stieger 复现只用 H0–H3，不跑 G0–G3**。

#### 3.3.3 每个窗怎么算「质量分」（与 03/04 同公式）

对每个 **MI（左/右）窗**（质量特征在 **未做推理 z-score** 的窗上算；推理仍可按原协议 z-score）：

1. 取 **同试次 REST 段** 窗作基线功率 \(P^{\mathrm{rest}}\)（μ 带，约 8–12 Hz；通道 C3/C4）。  
2. 算该 MI 窗功率 \(P^{\mathrm{mi}}\)。  
3. 各通道：\(\mathrm{ERD}_c = 100\cdot(P^{\mathrm{mi}}_c - P^{\mathrm{rest}}_c)/P^{\mathrm{rest}}_c\)（负值 = 相对静息抑制，符合 ERD 直觉）。  
4. 期望：左手 → 对侧 **C4**；右手 → 对侧 **C3**。  
5. \(\mathrm{laterality} = \mathrm{ERD}_{\mathrm{同侧}} - \mathrm{ERD}_{\mathrm{对侧}}\)（越大 = 对侧抑制更强、偏侧越好）。  
6. **H1 过门**：\(\mathrm{ERD}_{\mathrm{对侧}} \le -15\) **且** \(\mathrm{laterality} \ge 8\)。

| 门控 | MI 窗保留条件 | REST 窗 |
|------|----------------|---------|
| **H0** | 全部保留 | 全部保留 |
| **H1** | ERD对侧≤−15 **且** lat≥8 | 全部保留 |
| **H2** | 仅 lat≥8 | 全部保留 |
| **H3** | 该试次 MI 窗中 laterality **最高的 50%** | 全部保留 |

#### 3.3.4 S07-03 / S07-04 怎么跑、怎么报

| 项 | 约定 |
|----|------|
| 权重 | 同 S07-01（S3 零样本，不微调） |
| 评测流 | Stieger **全量**试次（与 01 同一批窗） |
| 必报门控 | **H0、H1、H2、H3** 四行；主决策看 **H1 vs H0** |
| S07-04 表 | 只做读数汇总：**Q0 = H0 = S07-01**；**Q1 = S07-03 的 H0–H3 表**（不再另训） |
| 附报 | 各门控 abstain 率；可选「abstain 计错」灵敏度 |
| 成功线 | 分被试 Task 或 Three Acc_paper：**H1 − H0 ≥ +0.02** → 门控可候选；abstain 写入表（历史游戏约 16–21%，Stieger 以实测为准） |

主问题（人话）：**在 Stieger 上，丢掉「弱 MI」窗之后，段级准确率会不会比「全窗投票」更高？**
