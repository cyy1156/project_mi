## 0. 一句话目标

在 **Acc_paper 段/试次聚合之前**，按 MI 质量规则丢掉不可信窗，再对剩余窗做 >50% 正确率判定；对照臂 = **无门控**（与现行伪在线同形）。  
主看：段级 Acc_paper 是否升，或「因窗太少而拒判」的可控率；**不**追求全库离线均值夺冠。

| 问 | 本臂约定 |
|----|----------|
| 改权重吗？ | **默认不改**；只用正式冻结 ckpt |
| 改 Acc_paper 定义吗？ | 聚合公式不变；仅改变「哪些窗进入聚合」 |
| 与 01/02 | 协议同形对照；产物独立目录，**禁止覆盖** 01/02 `results/` |

## 1. 动机（来自 06，一句话）

全库 Three≈54% 含大量弱 MI；好 laterality 试次上正式模型已可到 ~75%。  
继续堆通道 FE（05）无效；B2 全库微调会伤大众。  
伪在线更合理的杠杆是：**先判断「这窗值不值得投票」**。

### P1 · OpenBMI 离线门控（必须先做 · 校准）

**目的**：在与 06 同一语料上验证「门控改变聚合」是否按预期抬条件 Acc，并标定默认阈值。

| 项 | 取值 |
|----|------|
| 数据 | `preprocess_lab/out/openbmi_2s_hop100` |
| 权重 | 正式 5060 shallow（主）· eegnet（附）；`run_20260807_135828` / `run_20260806_172218` |
| 折 | 被试独立 5 折 · seed=42（与正式同） |
| 无门控对照 | 等同 06 B1-R0（应复现 ~Task 0.69 / Three 0.54） |
| 门控来源 | **只读** `teachable_window_masks_v1.npz`（分析臂真分，非 05 假质量） |

**门控变体（单因子）**：

| 代号 | 进入投票的窗 | 说明 |
|------|--------------|------|
| G0 | 全部 test 窗 | 无门控对照 |
| G1 | `high_lat_eval`（明显12 ∩ lat≥8） | 对齐 06 B1-R2 |
| G2 | `teachable`（T1） | 对齐清单主线 |
| G3 | 每试次内 laterality **top-p%** 窗（默认 p=50） | 试次内相对门控（不依赖明显12名单） |

**空窗试次**：某试次门控后窗数 = 0 → 该试次记 **abstain**（不计入 Acc_paper 分母；附报 abstain 率）。  
主表另给一列「abstain 计错」敏感性（可选）。

**成功线（P1）**：

| 指标 | 门槛 |
|------|------|
| Three Acc_paper（G1 或 G2 vs G0） | **≥ +0.03**（期望贴近 B1 条件增益量级） |
| abstain 率 | 写入表；G1 允许高（仅 12 人），G2/G3 更可部署 |
| Task | 不强制升；若掉 >0.02 需在决策里说明 |

P1 未达线 → **停**，先查 mask/聚合，不开 P2。

### P2 · 游戏会话在线门控（伪在线主战场）

**目的**：在游戏流上，用 **可在线计算** 的质量分做门控（不能直接查 OpenBMI 清单）。

| 项 | 取值（**现行 · 与 04 对齐**） |
|----|------|
| 会话 | 与 01/04 相同：sub02 / sub03 |
| 切段 / 滑窗 | **完全对齐 01**：MI⊕REST 连续流 · 2s/hop100 |
| 权重 | **OpenBMI** Acc_paper shallow `run_20260807_135828` |
| 通道 | 推理前重排游戏序 → OpenBMI 序（同 04） |
| 对照 | H0 = 本臂无门控（≡ 04 Q0）；H1–H3 同阈值 |
| 历史对照 | `--weight-domain bci2a`：对齐 01，门控阴性（已冻结，不改） |

> 与 04 的关系：04 的 Q0/Q1 即本臂 P2·OpenBMI 的同协议复验；**部署读数以 OpenBMI-P2 / 04 为准**。

**在线质量分（冻结 · 窗级，仅 MI 段窗）**：

对每个 MI 窗，用 **同 trial 的 REST 段** 作短基线（01 流内已有 REST）：

1. 取该 trial REST 合法窗的 C3/C4 Mu 功率均值 → \(P^{\mathrm{rest}}\)  
2. 当前 MI 窗 Mu 功率 → \(P^{\mathrm{mi}}\)  
3. \(\mathrm{ERD}_c = 100\cdot(P^{\mathrm{mi}}_c-P^{\mathrm{rest}}_c)/P^{\mathrm{rest}}_c\)  
4. 左手期望对侧 C4、右手 C3；`laterality = ERD_ipsi − ERD_contra`  
5. **过门**：`mu_erd_contra ≤ −15` **且** `laterality ≥ 8`（与 teachable_v1 / 分析臂同阈值）  
6. REST 段窗：**默认仍全部入投票**（门控只滤 MI）；附录可试「REST 不门控 / REST 也置信过滤」  

若该 trial 无可用 REST 基线 → 该 trial MI 窗 **全部 abstain**（保守）。

**变体**：

| 代号 | 规则 |
|------|------|
| H0 | 无门控（复现 01） |
| H1 | 上述硬阈值门控 |
| H2 | 仅 `laterality ≥ 8`（放宽） |
| H3 | 试次内 MI 窗 laterality top-50%（相对门控） |

**成功线（P2）**：

| 指标 | 门槛 |
|------|------|
| 段级 Acc_paper（主：Three 或 Task，与 01 主报一致分列） | 相对 H0 **≥ +0.02**（sub02/sub03 **分别**看；不跨人夺冠） |
| 或 | Acc 持平但 **left↔right 混淆下降** 且 abstain 率 < 40% |
| 失败 | Acc 掉且 abstain>50% → 记阴性，阈值列入 v2 |

每人独立报表；可附两会话宏平均，**不**替代分测。
