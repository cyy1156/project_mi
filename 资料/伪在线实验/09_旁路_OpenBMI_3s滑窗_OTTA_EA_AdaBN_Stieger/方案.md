## 0. 定位与要回答的问题

07 的结论：跨库零样本不可部署（Three 0.42）；**前半 FT** 后半评是最大杠杆（Three 0.659，24/24）；FT 后 H1 门控再 +4.1 pp（弃权 59%）。

本方案补上 07 未测的整块：**无标签在线阶段的分布校正（OTTA）**，并正面检验用户提出的「模型小、可接受全量微调」这一想法的边界。三个问题：

1. **Q1**：EA + AdaBN 在零样本场景能收回多少跨库损失（论文称去 EA 损 ~10%）？
2. **Q2**：FT 之后，OTTA 还能不能继续叠加增益（此时域间隙已小，是否仍有效）？
3. **Q3**：在线阶段用伪标签**全量微调**小模型，是否优于冻结权重的 OTTA？（用户假设：模型小 → 全量 FT 可承受。）

### 0.1 关于「全量微调」的界定（重要，先读）

「模型小可以全量微调」成立与否取决于**三个不同层面**，本方案分别处理：

| 层面 | 标签 | 现状 | 本方案动作 |
|------|------|------|-----------|
| ① 标定阶段全量 FT（有标签） | 开机采集少量标定试次后微调 | **已经在做**：S07-02/05 的 FT 本来就是全参数微调（shallow ≈17k 参数，无冻结） | 直接复用其 ckpt，不重跑 |
| ② 在线阶段冻结权重、只做统计量校正（OTTA） | 无标签流式 | 未测 | **A/B 系列主测** |
| ③ 在线阶段伪标签全量 FT | 无真值，用模型自身置信输出当标签 | 未测；论文明确警告（决策边界漂移破坏人机共同学习、伪标签错误累积） | **C 系列对照臂**，预注册崩塌判据 |

模型小只解决「算力上能不能」，不解决「该不该」：③ 的风险是错误累积与边界漂移，与参数量无关。C 系列就是把这个判断交给数据。

## 2. 方法定义（冻结）

### 2.1 EA · 欧氏对齐（输入层）

对被试 s 的通道重排后 EEG，用其**前半**数据估计协方差 `Σ_s`（8×8），白化并对齐到参考协方差 `Σ_ref`：

```text
X_aligned = Σ_ref^(1/2) · Σ_s^(-1/2) · X
```

- **参考协方差两档**（必做消融）：
  - `ref=src`：OpenBMI 训练集平均协方差（不含任何被试信息，真·零样本）；
  - `ref=cal`：该被试前半数据协方差（只用无标签标定段，与 FT 臂信息量对齐）。
- 施加位置：通道重排之后、z-score 之前（若 07 口径已含 z-score，则保持其后步骤不变；顺序消融作附报）。
- 附报变体（非主线）：流式递增估计 `Σ_s`（每 trial 更新，仅用已过去数据），验证一次性前半估计不构成显著损失。

### 2.2 AdaBN · 自适应批归一化（特征层）

- 冻结全部卷积 / 分类权重与 BN 的 γ、β；**只更新 Shallow 内 BN 层的 running_mean / running_var**。
- 流式：后半每个窗前向（train 模式的 BN 统计更新，无梯度），momentum=0.1 起步（附报 0.05/0.2）；预测用更新后的统计量 → 天然因果。
- 前 1~2 个 trial 为统计量热身段，照常输出（计入指标，不剔除）。

### 2.3 置信度滤波（输出层）

- softmax 最大概率 `p_max < τ`（τ=0.5 起步）→ 该窗弃权（不参与投票）；τ 消融 {0.4, 0.5, 0.6} 附报。
- 与 H1/H2 门控**可叠加**（先生理门控、后置信度，弃权率分开登记）。

### 2.4 C 系列 · 在线伪标签全量微调（用户假设的检验臂）

- 基座 = B3（FT 权重 + EA + AdaBN 之上）。
- **每 trial 末**更新一次（不逐窗）：取该 trial 通过置信度过滤（τ=0.6）的窗的多数票伪标签，若置信窗占比 ≥50%，则以这些窗为伪标签数据，全参数一步 SGD/Adam（lr=1e-4，一步=对该 trial 置信窗一个 epoch）；否则跳过本 trial。
- 判别头与特征全更新（模型小，无算力问题——检验的是稳定性不是速度）。
- 附报 C2（风险臂，仅 6 被试子集）：TENT 式逐窗熵最小化，观察最激进在线更新的崩塌形态。

## 4. 预注册成功线与判定

| 对比 | 门槛 | 判定 |
|------|------|------|
| A3 − A0（Three） | **≥ +0.02** / 被试（macro ≥ +2 pp） | OTTA 在零样本跨库有效；不达 → EA/AdaBN 对大域间隙无力，Q1 阴性 |
| A1 / A2 − A0 | 附报拆分 | 定位 EA vs AdaBN 各自贡献（论文预期 EA 主导） |
| B3 − B0（Three） | **≥ +0.015**（macro ≥ +1.5 pp） | FT 后 OTTA 仍可叠加；不达 → 域内残余漂移已被 FT 吸收，OTTA 仅零样本场景必要 |
| B4 − B0（Three） | ≥ +0.025（macro ≥ +2.5 pp）且弃权 ≤ 50% | 部署形态成立；绝对值线：**B4 Three ≥ 0.68** |
| **C1 − B3** | ≥ +0.015 且**无崩塌** → 「小模型在线全量 FT 优于冻结 OTTA」成立；∈(−0.5, +1.5) pp → 持平，维持论文冻结立场（工程更简单者胜）；< −0.5 pp → 在线全量 FT 有害，明确弃用 | Q3 判定 |

**崩塌判据（C 系列专用）**：将后半 trial 均分为三段，若**末 1/3 段 Acc < 首 1/3 段 − 3 pp**，或任一被试 Acc 跌破其 A0（零样本）水平，记为崩塌；崩塌被试数登记入表。

**统计**：24 被试配对 Δ（每被试后半 Acc_paper 差），报 mean、std、达标数（Δ≥+0.02）、Wilcoxon p；门控臂附弃权率。

## 5. 读数与登记

每臂必登：

6. meta：参考协方差档、momentum、τ、EA 施加位置、07 loader 口径核对记录。

## 6. 工程与实现注意

1. **A/B 系列零训练**：复用 07 的 FT ckpt 与 S3 权重，只写回放评测脚本 → 新包 `5070_stieger_otta_3s_hop100`（或并入 `5070_stieger_pseudo_online_3s_hop100` 加 `--otta` 开关，二选一在实现时定，勿覆盖 07/08 out）。
2. **EA 与 z-score 顺序**：实现前先核对 07 的 Stieger loader 是否已含 z-score 及其统计量来源；冻结「重排 → EA →（07 原有预处理）」次序并单测：扰动单通道方差 / 通道间协方差，验证 EA 确实改变协方差结构。
3. **AdaBN 只动 BN 统计**：单测断言——在线前后所有 requires_grad 参数逐位相等，仅 BN running 统计变化。
4. **C1 的伪标签隔离**：伪标签生成用更新前权重（先预测后更新），避免同窗自证。
5. **因果性单测**：打乱后半窗顺序重放，EA（前半估计版）结果不变、AdaBN/流式版本结果允许变（这是设计使然，登记说明）。
6. 结果只写 `资料/伪在线实验/09_.../results/` 与独立 out；不与 07/08、游戏 04 混比。
