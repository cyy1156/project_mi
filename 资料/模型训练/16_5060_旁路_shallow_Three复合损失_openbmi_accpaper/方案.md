## 0. 为何小参数 + 复杂损失

- 窗数 ≫ 参数，但**有效信息受被试数限制**；大模型易背被试癖好。  
- 正式 Three 上 shallow≈deep → 瓶颈不在容量。  
- 单一窗 CE 被 idle↔MI 主导；左右梯度弱 → **分解损失**专打 L↔R。

标签：`0=idle, 1=left, 2=right`。

---

## 1. 损失（单 3-logit 头 · 推理不变）

```text
L = λ_ce*L_CE + λ_mi*L_MI + λ_lr*L_LR
  + λ_mg*L_margin + λ_id*L_idle_suppress
  + λ_tr*L_trial_cons          # 仅 H3；需 trial 分组，首版可关
```

| 项 | 公式要点 | 为何 |
|----|----------|------|
| L_CE | CE(z,y) | 保底三分类 |
| L_MI | CE([z0, logsumexp(z1,z2)], idle vs MI) | 显式 rest/MI |
| L_LR | 仅 y∈{1,2}：CE([z1,z2], L/R) | **核心**：打左右互串 |
| L_margin | ReLU(m − (z_pos−z_neg)) | 锐化左右边距，稳众数投票 |
| L_idle_suppress | idle 罚 p_L+p_R；MI 罚 p_idle | 校准，防乱报 |
| L_trial_cons | 同试次 KL（H3） | 对齐 Acc_paper 众数 |

冻结 λ（H1/H2）：`ce=1, mi=0.5, lr=0.75, mg=0.3, id=0.2, m=1.0`；H3 再开 `tr=0.1`。

**Task（2 类）**：仍用纯 CE 或 T1 二分类边界加强；**不用** L_LR。

---

## 2. 实验臂

| 臂 | 损失 | 角色 |
|----|------|------|
| S0 | 纯 CE | 锚点 |
| **H1** | CE+MI+LR | **主探** |
| H2 | H1+margin+idle_suppress | 锐化 |
| H3 | H2+trial_cons | 对齐试次；H2 弱有用后 |
| T0/T1 | Task 上 CE / 边界加强 | 冲 0.75；与 Three 解耦 |

顺序：S0 fold0（可对齐正式量级）→ **H1 Three fold0** → 门控 → H2 → H3 / 五折。

## 3. 成功线（Three · 相对同跑 S0）

| 等级 | Acc_paper | sym_LR |
|------|-----------|--------|
| 弱有用 | ≥ S0 +1.0pp | 下降或持平 |
| 达标 | ≥ S0 +1.5pp | 建议再降 |
| **绝对冲刺** | **≥ 0.60** | 显著低于 ~0.23 |
| 阴性 | 无增益 | 停扩 |

Task 绝对目标 **0.75**；相对 T0 弱有用 +1pp。未达绝对目标但相对达标 → 登记差距，不进正式表。
