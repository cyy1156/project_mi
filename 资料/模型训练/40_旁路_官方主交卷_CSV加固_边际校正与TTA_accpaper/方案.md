### 2.3 TTA 协议（写死 · v0.2）

**设计缺陷（v0.1）**：官方 block 内 trial 起点为 0,750,…,21750（**背靠背、无间隙**）。对连续 EEG 做 cue+δ 重切时，δ>0 必然吃进下一题开头 → **跨 trial 标签污染**。「越界丢弃」只挡块边界，挡不住 trial 边界。

**修正协议（强制）**：

```text
输入：已落盘、已切窗、已 z-score 的 trial 张量 X ∈ R^{C×750}（或 B×C×750）
采样率：250 Hz（元数据为准）
视图集（冻结）：δ ∈ {0, 20, 40} 采样点 —— 仅「向内缩起点」单向
  δ=0：原窗
  δ>0：取 X[:, δ:750]，左侧用 X[:, 0]（边缘首点）复制补 δ 列
禁止：向外伸、负向移位吃上一 trial、循环填充、零填充、反射填充
补边时机：切窗 + z-score 之后（推理侧）；不得回到原始连续 EEG
成员：R-B8 同四成员；每 δ 前向得概率 → 算术平均 → 再套该折嵌套 E1f θ（与 Exp39 R-B8 同 θ）
评估：leave-fold 嵌套 Acc；TTA 不引入新自由参数
不做 T0：直接全 6 折出逐折 Δ
```

实现含义：纯 `numpy/torch` 时间维切片+pad，**无需**连续 EEG；风险表「需原始连续 EEG」整条作废。

### 2.4 边际校正协议（写死）

```text
输入：R-B8 每折 OOF 融合概率（或等价：嵌套 θ 作用于成员 Val 概率）
偏置 b ∈ R^3：logit 加性；在 fit 折上最小化 NLL（同 Exp36 MC0）
折 k：用其余折拟合 b_k → 作用于折 k
主读：嵌套 6 折 Acc vs 原 R-B8；另计 n_folds_ge = #{k: Acc_MC[k] ≥ Acc_R-B8[k]}
诊断：test 用 H2 全局 b（900 Val 一次拟合）；报三类边际与 distance_to_uniform
警告：Q2 收拢是 MC 定义效应，不是发现；不得放松 §5.1 Acc/折条件
```

## 5. 预注册决策规则（跑数前冻结）

### 5.1 加固是否替换 R-B8 CSV

```text
定义 fold_ok(arm) ⟺ #{k: Acc_arm[k] ≥ Acc_R-B8[k]} ≥ 4

候选集 C = { R-B8_raw }
  ∪ { MC-B8  if nested(MC) ≥ 0.540  AND fold_ok(MC) }
  ∪ { TTA-B8 if Δ(TTA,R-B8) ≥ +0.005 AND fold_ok(TTA) }
  ∪ { MC∘TTA if 已跑 AND nested ≥ max(R-B8, 已进单臂)
                 AND fold_ok(MC∘TTA) }

终态 W*：
  1. nested_mean 最高
  2. 若差 <1pp：取更简
     简序：R-B8_raw < TTA-B8 < MC-B8 < MC∘TTA
  3. 若 MC 未进 C：风险栏写
     「Rest/类边际偏斜不可校准、属模型本性」
  4. 写出 submission_exp40_*_final.csv（若 W*=R-B8_raw 可复制/软链 Exp39 CSV 并标注 final）
  5. S0 CSV 归档保留作回退；科学叙事不改
  6. 登记表宣布：官方算法线冻结
```

### 5.2 Q2 边际收拢（不否决，只标注 · 禁止放松门槛）

```text
定义 distance_to_uniform = Σ_c |p_c − 1/3|
若 MC-B8 的 test 边际 distance 相对 R-B8_raw 下降 → margin_improved=true
否则 margin_improved=false
注意：MC 在机制上倾向推均匀 → Q2 常为 true；
      **绝对禁止**因 margin_improved 而放松 nested / fold_ok 条件。
```

### 5.3 明确禁止

- 因 H1/T1 阴性再开新骨干或 Exp41  
- 用 test 边际/Hamming 反推改 Val 规则  
- 材料中引用 Exp36 的 0.604/0.626 为预期  
- 跑完后改补边方式（零 ↔ 边缘复制）或改 δ 集  
- 用 fold0 单独冒烟结果否决全嵌套
