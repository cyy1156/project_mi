## 1. 动机：三个回放级缺口

方案 26 的 E1f 已封顶 0.6173，但成员池与推理栈的经济性未闭合——以下三问均可在**已有概率 dump** 上回答，**零训练**：

| # | 问题 | 若成立的含义 |
|---|------|--------------|
| **Q1** | **平滑能否单独撑起增益？** | 相对 S3（0.5839），邻域平滑 + 可选 τ_conf 是否已接近多成员融合收益 → 部署可退化为**单模 + 后处理** |
| **Q2** | **{shallow, eegnet} 两成员够不够？** | val 重拟合温度/权重/平滑后，两成员栈能否逼近 E1f → 可砍 conformer（及训练/推理成本） |
| **Q3** | **T-shallow 可否砍？** | 四成员相对三成员仅 +0.04 pp（E1e vs E1d），且 val 权重仅 0.20 → 边际成员是否值得保留 |

均为**回放级**消融；结论直接约束在线链成员表与 `experiment_game` 融合配置，不涉及重训。

## 2. 七个臂（零训练 · 全部回放）

复用 5090 包 `5090_ens_recipe_3s_hop100_accpaper` · `replay_e1.py` / `e1_fusion_core.py` · dump 格式同 26。  
每臂：**val-only** 拟合温度 / 权重 / smooth / τ_conf；**test 各只读一次**。

| 臂 | 成员池 | 推理配置 | 对照 / 意图 |
|----|--------|----------|-------------|
| **R0** | {shallow} | 无后处理 | 单模 sanity · 复现 **0.5839** |
| **R1** | {shallow} | 温度 + val 加权 + smooth（E1c 流程，n=1 退化） | **Q1**：平滑单独增益 |
| **R2** | {shallow} | R1 + **τ_conf**（val-only） | **Q1**：单模能否叠早停到 W/E 量级 |
| **R3** | {shallow, eegnet} | 全配置重拟合（temp + weights + smooth） | **Q2**：两成员下限 |
| **R4** | {shallow, eegnet} | R3 + **τ_conf** | **Q2**：两成员 + 早停 · 主决策臂 |
| **R5** | {shallow, conformer} | 全配置重拟合 + τ_conf | 对照：砍 eegnet 留 conformer |
| **R6** | {S, T, E, C} | E1f 配置复现（τ_conf=0.4 等） | sanity · 复现 **0.6173** |

**R1/R2 说明**：单成员时 val 加权网格退化为 uniform；实质变量为 smooth_radius 与 τ_conf。  
**R3/R4/R5**：成员子集变化 → 温度/权重/smooth/τ 均在 val 上**重新搜索**（禁止沿用 E1f 四成员超参）。

## 3. 预注册判定线与决策树

### 3.1 判定线（test Three Acc_paper）

| 读数 | 线 | 含义 |
|------|-----|------|
| R1 | **≥ 0.5980**（S3 +1.41 pp） | 单模 + 平滑已具融合级收益 |
| R4 | **≥ 0.6143**（E1f −0.3 pp） | 两成员 {shallow, eegnet} 可替代四成员 |
| R6 | **= 0.6173 ± 0.0005** | 回放链 sanity |
| R0 | **= 0.5839 ± 0.0005** | dump / 聚合 sanity |

附报带：相对 E1f 的 Δpp；R5 vs R4 成员替换 Δ。

### 3.2 决策树（预注册 · test 读后执行）

```text
跑 R0–R6（test 各一次）
    │
    ├─ R1 test ≥ 0.5980
    │     → 采纳「单模 shallow + smooth + τ_conf」部署栈
    │     → 成员表砍至 1；附报 R2 是否再 +τ_conf
    │
    ├─ R1 < 0.5980 且 R4 test ≥ 0.6143
    │     → 采纳「两成员 {shallow, eegnet} + 全 E1 后处理」
    │     → 砍 conformer + T-shallow
    │
    └─ 否则
          → 维持 E1f 四成员主读数
          → **仅砍 T-shallow**（权重 0.20、边际 +0.04 pp）
          → conformer 保留（val 权重 0.30 证据）
```

**不触发**：R5 优于 R4 仅作附报，不改变预注册树（eegnet 为 val 顶权成员，R5 为反向对照）。
