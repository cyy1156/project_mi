| 项 | 取值 |
|----|------|
| 数据 | `openbmi_2s_hop100`（A0）· `openbmi_2s_hop100_pf1000`（A1+，protocol_version≥3） |
| 主指标 | Test **Acc_paper**（试次级） |
| 链 | `A0_ref → A0 → A1 → P0 → A2 → P1 → P2`；完整 B/C/U 见实验方案 |
| 早停 | Val Acc_paper · balbatch |
