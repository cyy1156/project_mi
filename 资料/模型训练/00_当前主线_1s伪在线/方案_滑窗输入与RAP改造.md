# 滑窗输入与 RAP 改造方案

> 状态：**P0/P1/P2 代码已落地**（预处理 + `baselines_1s`）；伪在线 / RAP 臂仍属阶段 B。  
> 文档位置：`资料/模型训练/00_当前主线_1s伪在线/`（旧整段实验已迁入 `资料/模型训练/归档/`）。  
> 操作手册：[`实验操作手册.md`](./实验操作手册.md)。  
> 依据：Wimpff et al. Continual Online EEG MI（1 s / 25 Hz 滑窗 + RAP + 伪在线评估）及 RAP 原文。  
> **协议范围**：**BCI2a 与 Stieger 同一套滑窗逻辑**（离线 40 ms 重叠切 1 s / 伪在线缓冲 / 试次过半投票 / RAP·OTTA 分工）。  
> **Rest 统一**：**两库静息均取 Cue 前 4 s**，再按与 Task **完全相同**的 `slide_1s(hop=40ms)` 切片输入；**不再**用 Stieger `down` 主动静息当 Rest。  
> **数据**：`out/bci2a_1s`、`out/stieger_1s`（Stieger = **DATA/stieger 全部会话**），`(N,1,8,250)`。  
> **本阶段改**：① 两库 1 s 预处理；② 单窗训练（无 RAP 缓存、无 OTTA）；③ 八基线原结构选型（BalAcc + batch balance），见 [`分析_baselines_1s_离线选型.md`](./分析_baselines_1s_离线选型.md)；④ 冠军后再伪在线（EEGNet 可选 RAP 臂）。  
> **本阶段不做 / 已替换**：旧整段 2s/4s 主训、merged 夺冠、特异度套件当主线、窗数组冒充伪在线；**禁止** padding；选型阶段不对八基线统一上 RAP。

## 0. 需求与范围

| 要回答的问题 | 判据 | 不回答的问题 |
|--------------|------|--------------|
| 如何在 **BCI2a + Stieger** 上用同一套 **1 s / 40 ms** 协议完成离线训练与伪在线评估？ | 两库训练输入=在线输入分布；试次级精度可复现 | 是否超过旧 2s/4s 整段基线数字本身 |

**参数冻结（全文共用）**

| 项 | 值 |
|----|-----|
| 窗口长度 \(T_w\) | **1 s** → **250** 点 @ 250 Hz |
| 滑动步长 | **40 ms** → **10** 点 |
| 更新频率 \(f_u\) | **25 Hz**（每 40 ms 一个新窗 / 一次预测） |
| RAP 四元组（\(P=2\)） | `(k1,s1,k2,s2) = (5, 5, 50, 2)`，\(f_{\mathrm{inter}}=50\,\mathrm{Hz}\) |

**最少工作流**

1. 预处理：完整源区间 → 40 ms 重叠 1 s 切片 → `bci2a_1s` / `stieger_1s`  
2. 离线训练（选型）：八基线 **原结构** + 单窗独立前向/loss；**Val BalAcc 早停** + **train batch balance**；**关** RAP 几何、**关** RAP 缓存、**关** OTTA；**两库分开训，不 merged**  
3. 伪在线评估（选型后）：流式缓冲滚动出窗；结构须与冠军权重同构；若冠军为 EEGNet 且启用 RAP，则 **可开** RAP 缓存、**开** OTTA（与论文对齐时）；试次过半投票报精度

## 1. 一句话整体逻辑（两库共用）

**BCI2a、Stieger 共用同一套机制**（含 Rest）。

- **离线**：源段（Task 或 Rest）→ **40 ms** 重叠切 **1 s**。  
- **伪在线**：缓冲滚动 → RAP / OTTA → **过半投票**。  
- **Rest（两库相同）**：**Cue 前 4 s** 定长源段 → 同一切窗；语义均为 **被动/间隔空闲**（对齐比赛空闲，不用主动静息）。  
- **Task**：BCI2a 为 Cue 后 0~4 s；Stieger 为变长反馈全程（可提前终止）——仅此处时长分布不同。  
- **禁止**：整段 4 s 直接训再上线喂 1 s；Stieger 用 down 当 Rest。

## 2. 离线训练滑窗 vs 伪在线推理滑窗（高频混淆点）

| 项目 | 离线训练滑窗（预处理 + 训练） | 伪在线推理滑窗（论文主评估环境） |
|------|------------------------------|----------------------------------|
| 数据来源 | 硬盘上**已完整保存**的试次信号 | **仿真实时流**：采样点逐点进入缓冲区 |
| 窗口产生 | **一次性**按 40 ms 步长全部切片写 npy（两库相同） | 随时间**动态**生成；源段结束或试次提前终止则**立刻停切**（两库相同；Stieger 提前终止更常见） |
| 样本顺序 | 训练集一般 **shuffle**，窗间无时序连续 | **严格时间有序** |
| 输入形状 | 每条固定 `[C, 250]`（本库 8 导） | 同上，每次送入最近 1 s |
| RAP **特征缓存**复用 | **关闭** | **开启**（仅加速；关掉应与完整重算数值一致） |
| OTTA（EA + AdaBN） | **关闭** | **每个滑动窗口执行一次**（论文设定） |
| 梯度 | 开启，每窗独立反传 | `torch.no_grad()` |
| 标签 | 整条试次标签赋予该试次所有窗 | 只输出预测，评估时用试次真值做投票 |
| 目的 | 构造训练数据集 | 模拟真实 BCI 设备运行并评估 |
| 是否等于「把切好的窗数组 for 一遍」 | 是（训练） | **否**——必须维护缓冲、模拟流入 |

```text
【离线】完整试次 ──40ms hop──► 大量 (8,250) ──shuffle──► 独立前向/loss
                              （无 RAP 缓存 / 无 OTTA）

【伪在线】采样点流 ──► 1s 环形缓冲 ──每+40ms──► 一窗
                              │
                              ├─ RAP 缓存（可选加速）
                              ├─ OTTA（EA+AdaBN）
                              └─ 预测；试次结束停窗
                                   │
                                   ▼
                         正确窗占比 > 50% → 该试次计对
```

## 3. 离线训练滑窗（预处理阶段）

### 3.1 做什么

对每条**已完整保存**的试次源区间（**BCI2a / Stieger 同一切片函数**），用步长 **40 ms** 做**重叠**滑窗切片：

- **Rest 源段（两库）**：**Cue 前 4 s** → 满段时理论 \(N_w=76\)；不足 4 s 则按实际可取长度切（越界丢窗，不 padding）；  
- **Task**：BCI2a Cue 后 0~4 s → 76 窗；Stieger 反馈 2 s→26 窗、6 s→126 窗（按真实 \(T\)）；  
- 每一输出固定 **`[通道, 250]`**；窗标签：Task 窗继承该试次左/右；Rest 窗一律 `y_task=0`（`y_three=0`）。

窗数（源时长 \(T\) 秒，\(T \ge 1\)）：

\[
N_w = 1 + \frac{T - T_w}{0.04} = 1 + (T - 1)\cdot 25
\]

| 源时长 \(T\) | \(N_w\)（\(T_w=1\,\mathrm{s}\), hop=40 ms） |
|--------------|-----------------------------------------------|
| 2 s | 26 |
| 4 s | 76 |
| 6 s | 126 |
| \(T<1\,\mathrm{s}\) | **0**（丢弃该试次或该源段，**不 padding**） |

不足 1 s 的尾部不单独成窗；**禁止**零填充/截断凑成固定 6 s。

### 3.2 目的（三个核心）

1. **统一输入尺寸**：无论 BCI2a 定长 4 s 还是 Stieger 变长 2–6 s，CNN 只收 1 s。  
2. **对齐在线输入分布（两库都适用）**：若离线直接训完整 4 s（BCI2a）或整段反馈（Stieger），上线喂 1 s → **域不匹配，精度暴跌**。  
3. **数据增强**：40 ms 重叠覆盖在线会出现的各种 1 s 相位。

### 3.3 重要约束（离线）

1. 切完后样本集一般 **shuffle**；窗之间**失去时序连续性**——属预期。  
2. **不启用 RAP 特征缓存**：每窗独立完整前向、独立 loss 反传。  
   - shuffle 后缓存会串试次；即便不 shuffle，反传跨窗纠缠也会学错。  
   - **RAP 缓存只属于推理。**  
3. **OTTA（EA、AdaBN）离线完全不运行。**  
4. 离线滑窗 = **纯粹预处理 + 常规 DataLoader 训练**，不是实时流式系统。

### 3.4 源区间表（Rest 两库对齐；切片逻辑零分叉）

原则：

1. 取源段 → **同一** `slide_1s(hop=40ms)` → `(8,250)`；  
2. Rest **两库都是 Cue 前 4 s**，禁止再分「被动 ITI / 主动 down」两套 Rest；  
3. 禁止整段一条样本、禁止 Stieger「反馈末 2s/4s 一条」、禁止 padding。

**Cue 锚点（实现时钉死）**

| 库 | Cue 时刻 | Cue 前 4 s 含义 |
|----|----------|-----------------|
| **BCI2a** | 试次 Cue 样本点 | `[cue-4s, cue)`；若与上一试次 MI 重叠则按避让规则缩短/丢窗（不与上一 Cue+0~4 s 重叠） |
| **Stieger** | **反馈起点** `fb0`（官方约 t=2000 ms；其前为 ITI 2 s + 目标呈现 2 s） | `[fb0-4s, fb0)`，正好覆盖范式上的 ITI+目标呈现共约 4 s |

| 库 | 角色 | 源区间 | 切窗 / 标签 |
|----|------|--------|-------------|
| **两库** | **Rest** | **Cue 前 4 s** | `slide_1s(40ms)`；`y_task=0`, `y_three=0` |
| **BCI2a** | Task | Cue 后 **0~4 s** | 同上切窗；左/右 → `y_task=1`, `y_three∈{1,2}` |
| **Stieger** | Task | 反馈 **`[fb0, fb1)` 全程**（左/右试次） | 同上切窗；左/右 → Task |
| **Stieger** | 丢弃 | `target==3`（双手 up）、**`target==4`（down，不再作 Rest）**、artifact、反馈 &lt; 1 s | 本协议 Rest 只来自 Cue 前 4 s |

> 旧流水线「Stieger down = 主动静息」**作废于本 1 s 协议**；与比赛「被动空闲」及 BCI2a Cue 前 Rest 对齐。

### 3.5 输出目录与形状

```text
preprocess_lab/out/bci2a_1s/    → bci2a_X.npy  (N,1,8,250)
preprocess_lab/out/stieger_1s/  → stieger_X.npy (N,1,8,250)
```

`data_paths` 注册 `bci2a_1s` / `stieger_1s`。旧 `*_2s/*_4s` 保留对照，**不混训**。

建议附加元数据（便于伪在线与试次投票）：`trial_id`、窗起点、subject、session——若暂不落盘，伪在线评估须能从原始试次重放，而不是只拿打乱后的窗数组循环。

## 4. 伪在线推理滑窗（两库共用评估环境）

**BCI2a 与 Stieger 跑同一套伪在线代码**；这里**不**把「预先切好的训练窗数组」拿来 for 一遍冒充在线。

### 4.1 流程（库无关）

1. 维护缓冲区，不断接收新采样点（重放该试次源段 EEG）；  
2. 凑够最近 **1 s** → 构成一窗送入模型；  
3. 每新增 **40 ms** 采样点，更新缓冲，形成下一滑动窗口；  
4. **源段结束**或试次提前终止（Stieger 光标触边等）→ **立刻停窗**。  
   - BCI2a 通常跑满约 4 s MI 源段后自然结束，仍用同一停窗条件，不另写「定长整段评估」。

### 4.2 同时开启的三件事

1. **RAP 缓存复用**：利用相邻窗大部分重叠，复用上一帧中间特征，降延迟。  
   - ⚠️ **只加速，不改变窗口输入内容**；关闭缓存完整重算，理论输出应一致。  
   - 与「RAP 重设 pool 几何」不同：几何在训练/推理都用；**缓存仅推理**。  
2. **OTTA（EA + AdaBN）**：每个滑动窗口执行一次分布校正（论文设定）。  
3. **每窗输出分类预测**。

### 4.3 试次级投票（评价公平性，非常关键）

一条试次无论生成 26 窗（约 2 s）还是 76 窗（BCI2a 4 s）或 126 窗（满 6 s）：

\[
\text{正确窗占比} > 50\% \;\Rightarrow\; \text{该试次判定正确}
\]

**两库都报试次精度（trial-wise accuracy），不是窗口精度。**

- 防止长试次（或 BCI2a 固定 4 s 相对短 Rest）窗多、在指标里权重更大；  
- Stieger 变长与 BCI2a 定长用**同一投票规则**，评估口径一致。

## 5. RAP：池化几何 vs 特征缓存（勿混）

> **选型阶段（八基线）**：两者都关，用 braindecode / 原脚本默认池化。  
> 下表仅适用于 **阶段 B · EEGNet RAP 臂**（冠军为 EEGNet 且决定上 RAP 时）。

| 概念 | 含义 | 离线训练（RAP 臂） | 伪在线推理（RAP 臂） |
|------|------|-------------------|----------------------|
| **RAP 池化几何** | 按 \(T_w,f_u,f_s\) 重设 AvgPool 为 `(5,5,50,2)` | **启用**（须与在线同构） | **启用** |
| **RAP 特征缓存** | 重叠窗中间特征复用加速 | **禁止** | **允许**（可关作数值对照） |

单窗预测语义：只依赖当前 1 s 输入；缓存不得改变该语义。

EEGNet RAP：薄包装 `EEGNetRAP`，`n_times=250`；不 fork braindecode。选型用默认 EEGNet；RAP 另开脚本/臂重训，禁止把默认权重直接加载进 RAP 网。

## 6. 常见踩坑点（复现必避）

1. ❌ **离线用完整试次训练，在线喂 1 s**（含「BCI2a 整段 4 s 训练」）  
   → 分布不一致，精度暴跌。  
   ✅ **两库**离线都必须切 1 s（40 ms hop）。

2. ❌ **离线开启 RAP 特征缓存**  
   → shuffle 串特征；或不 shuffle 也导致反传跨窗纠缠。  
   ✅ 缓存只属于推理（两库相同）。

3. ❌ **离线切片后，伪在线直接遍历切好的窗数组**  
   → 不是真伪在线。  
   ✅ **两库**都维护缓冲、模拟采样点流入。

4. ❌ **用窗口精度当主指标**  
   → 长试次 / 多窗试次主导。  
   ✅ **两库**试次过半投票 → 试次精度。

5. ❌ **padding / 截断到固定时长**（含把 Stieger 补到 6 s，或把 BCI2a 当「不必滑窗」）  
   → 破坏分布或破坏协议统一。  
   ✅ 滑窗拆解；短于 1 s 丢弃。

6. ❌ **BCI2a 一套逻辑、Stieger 另一套**（含 Rest 一边 ITI、一边 down）  
   → 指标不可比。  
   ✅ 同一 `slide_1s` / 同一伪在线；**Rest 统一 Cue 前 4 s**；仅 Task 源段配置不同。

7. ❌ **Stieger 继续用 down 当 Rest**  
   → 主动静息 ≠ 两库统一的 Cue 前被动空闲。  
   ✅ down 丢弃；Rest 只从 `[Cue-4s, Cue)` 切。

8. ❌ **预处理 hop=1 s 无重叠**  
   → 与在线 25 Hz 不对齐。  
   ✅ 离线 hop **固定 40 ms**（Task/Rest、两库）。

## 7. 训练 / 推理伪代码

### 7.1 离线训练（每窗独立）

```text
# 预处理已生成 X:(N,1,8,250), y:(N,)，可含 trial_id
for x, y in DataLoader(shuffle=True):   # x:(B,8,250)
    logits = model(x)                   # (B,C)；无特征缓存
    loss = CE(logits, y)                # 每窗独立；无 OTTA
    loss.backward(); step()
```

### 7.2 伪在线（单试次示意）

```text
buf = empty
correct_w = total_w = 0
for chunk in stream_samples(trial):     # 模拟逐点/逐块流入
    if trial_aborted: break
    buf.append(chunk)
    if len(buf) < 1s: continue
    if not due_for_update_40ms: continue
    x = buf.last_1s()                   # (8,250)
    with no_grad:
        x = OTTA_EA_AdaBN(x, state)     # 每窗
        pred = model.forward_rap(x)     # 可开特征缓存
    total_w += 1
    correct_w += (pred == y_trial)
trial_ok = (correct_w / total_w) > 0.5
```

### 7.3 离线验收（可分两档）

| 档 | 内容 |
|----|------|
| A. 训练冒烟 | `bci2a_1s` / `stieger_1s` 五折；窗级 Acc/Spec/Rec/F1/BalAcc（监控用） |
| B. 论文对齐评估 | 伪在线环 + 试次过半投票 → **试次精度**（主报）；RAP 开关数值一致性抽检 |

本阶段工程成功：A 跑通；B 的缓冲+投票至少可跑（OTTA 可按实现进度接入，但方案上属于伪在线默认组件）。

## 8. 排除与后续

| 排除 | 原因 |
|------|------|
| 旧库整段 2s/4s 主训 | 与 1 s 在线分布不一致 |
| 离线 RAP 缓存 / 离线 OTTA | 语义错误 |
| padding 定长 | 破坏分布 |
| 窗口精度作唯一金牌指标 | 评估不公 |
| 混库时仍把 Stieger down 当 Rest | 与本协议 Cue 前 4 s Rest 冲突 |
| 两库 Rest 用不同切法 | 破坏「相同逻辑输入」 |

后续：源预训练 + joint sequential；自采数据同样 **Cue前4s Rest + 1 s/25 Hz**。

## 10. 决策摘要（冻结）

| 项 | 冻结值 |
|----|--------|
| 协议 | **BCI2a ≡ Stieger**（滑窗/训练/伪在线） |
| Rest | **两库均为 Cue 前 4 s** + 同 `slide_1s(40ms)`（被动空闲） |
| Task | BCI2a Cue+0~4 s；Stieger 左/右全反馈段 |
| Stieger Cue | 反馈起点 `fb0`（Cue前4s≈ITI+目标呈现） |
| \(T_w\) / hop / \(f_u\) | 1 s / **40 ms** / 25 Hz |
| 盘上样本 | `(N,1,8,250)` |
| 离线 / 伪在线 | 同前文；试次过半投票 |
| 选型模型结构 | **原基线默认池化，不做 RAP** |
| 选型训练 | Val **BalAcc** 早停 + **batch balance** + 普通 CE；Task-only；**单库不合并** |
| Stieger 数据范围 | **DATA/stieger 全部会话**（`--subjects all`） |
| 滤波 | CAR + 50 Hz notch（短试次自适应 FIR）+ 8–30 Hz |
| RAP 几何（仅 EEGNet 后继臂） | `(5,5,50,2)` |
| 禁止 | down 当 Rest；整段训+1s 测；免滑窗；离线缓存；窗数组冒充伪在线；padding；默认权重塞进 RAP 网；选型阶段 merged；用归档旧数字夺冠 |
