## 0. 两套阵容总览

| | **在线系统**（CausalFuse-8） | **离线交卷**（S0 = E1f-A59） |
|---|---|---|
| 应用场景 | 连续脑电流的**因果流式**解码（100ms 步进滑窗），面向自采被试的在线演示 | 官方指定数据集**单窗 3s** 三分类盲测（S07/S08） |
| 通道/协议 | 8ch · OpenBMI 协议 | 59ch · 官方协议 |
| 成员 | shallow / **t_shallow** / eegnet / conformer | shallow / **shallow_b** / eegnet / conformer |
| 训练方式 | OpenBMI 预训练 + 真被试**增量微调**（Leave-Next R0→R5） | 官方 6 被试从零训练（LOSO 六折） |
| 融合 | E1f：温度校准 + 静态加权 + 平滑 + 置信早停（τ_conf=0.4）→ 试次级**多数票** | E1f-A59：每折 Val 拟合温度/权重 → **S-ens 六折概率平均** |
| 关键战绩 | OpenBMI test 0.6173（折内口径）；真被试 MI acc 0.417→0.944 爬坡（实验 33） | 折内 0.558 / 嵌套诚实 0.511（双标注）；备选 R-B8（8ch 热启动栈）嵌套 0.540 |

两套阵容的**差异点只有第二席**：在线用 `t_shallow`（训练目标变体），离线用 `shallow_b`（种子变体）。原因：t_shallow 的 t0 降权机制依赖滑窗场景的时间结构，官方单窗数据下失效（详见 §2.2）。

## 1. 四个骨干架构逐一说明（在线离线通用）

### 1.1 ShallowFBCSPNet（shallow —— 两套系统的基准成员）

- **框架**：卷积滤波器组型浅层网络（braindecode 实现），结构模拟经典 FBCSP 流程：
  `时间卷积（带通滤波器组）→ 深度空间卷积（逐滤波器跨导联加权）→ 平方激活（能量化）→ 平均池化 → 时间平滑卷积 → 全连接`
- **角色**：参数量小、与 FBCSP 频段能量特征可解释对应；两侧阵容的"主力卷积成员"。
- **在线单模**：Task 0.7424 / Three 0.5839（OpenBMI）；**离线**：59ch 从零（seed 42）。

### 1.2 t_shallow（在线专属 · 训练目标变体）

- **框架**：与 shallow **完全同构**（ShallowFBCSPNet），差异在训练目标：损失按窗口时间起点 t0 加权（α=0.6）——**离提示近的窗权重高、早期窗降权**。
- **设计动机**：流式解码中早窗 MI 尚未成型、信噪比低；t0 加权让该专家专门学"提示邻域"的可靠判别。
- **在线单模**：Task 0.7403 / Three 0.5886（OpenBMI）。

### 1.3 shallow_b（离线专属 · 初始化变体）

- **框架**：与 shallow **完全同构**，仅随机种子不同（seed 43）。
- **设计动机**：官方单窗数据无 t0 结构，t_shallow 的机制无处发挥；以**零成本的第二初始化**占据其槽位，提供"同构异 initialization"多样性。
- **关键事实**：其 8ch 热启动版（b8_shallow_b，由 OpenBMI 权重微调）是全项目**诚实评估下最好的单模型**（嵌套 Val 0.528），并在 B8 融合的 fold2 拿到 0.80 的融合权重。

### 1.4 EEGNet（eegnet —— 两套系统的轻量成员）

- **框架**：紧凑型分离卷积网络（braindecode 实现）：
  `时间卷积 → 深度卷积（空间，逐时间滤波器）→ 可分离卷积（深度+逐点）→ 平均池化 → 全连接`
- **角色**：参数量极小（~2k 级）、感受野与归纳偏置与前两者不同，提供**容量异构**的多样性。
- **在线单模**：Task 0.7240 / Three 0.5629；**离线**：59ch 从零。

### 1.5 EEGConformer（conformer —— 两套系统的最强单模）

- **框架**：Transformer 混合架构（braindecode 实现）：
  `时间分块嵌入（patch 切分+时间卷积）→ 空间卷积 → Transformer 编码器（时间轴多头自注意力）→ 池化 → 全连接`
- **角色**：唯一具备**长程时间依赖建模**能力的成员；各栈单模最强。
- **在线单模**：Task 0.7597 / Three 0.5767；**离线**：59ch 从零，是嵌套评估下 A59 融合塌缩后的"幸存者"（见 §3.2）。

## 2. 融合与判决框架

### 2.1 在线（CausalFuse-8）：两级多专家判决

```
第 1 级（窗级）：4 专家各自出三分类概率
  → 温度校准 T=[1.95, 1.89, 1.18, 2.50]
  → 静态加权 w=[0.2, 0.2, 0.3, 0.3]（验证集拟合）
  → 时间平滑（smooth=1）+ 置信早停（τ_conf=0.4）
第 2 级（试次级）：因果平滑（lookback=2）→ 多数票 → 门控晋升
```

### 2.2 离线（S0 = E1f-A59 + S-ens）

```
每个 LOSO 折 k：4 成员概率 → 温度校准 T_k + Val 拟合权重 w_k → 融合概率 p(k)
最终：p_final = (1/6)·Σ_k p(k)（六折隐式混合集成）→ argmax
```

第二席差异说明：官方数据为单窗 3s，无滑窗时间结构 → t0 加权机制失效 → 该槽位由零成本种子变体 shallow_b 接管（两套配置均为各自场景的正确解）。

## 3. 这算不算"多专家"？——算，且建议这样表述

### 3.1 成立的部分

本方案**符合"异构多专家集成"（multi-expert heterogeneous ensemble）的定义**，多样性来自四个独立来源：

1. **架构异构**：FBCSP 系卷积 / 轻量分离卷积 / Transformer 自注意力，三种归纳偏置；
2. **训练目标异构**：t_shallow 的 t0 加权损失 vs 其余成员的标准交叉熵；
3. **初始化异构**：shallow_b 的第二种子；
4. **数据视角异构**：在线 8ch 流式 vs 离线 59ch 单窗；B8 轨（OpenBMI 热启动）与 A59 轨（从零）互补。

融合层采用**温度校准 + 验证集拟合加权**，并叠加**跨折集成（S-ens，六折概率平均）**——这是"专家产出 → 校准 → 加权 → 再集成"的完整多专家流水线。

### 3.2 必须写清的边界（答辩防线）

- 本方案的专家权重是**每折固定的静态权重**，不是经典 MoE 的**输入动态门控网络**。表述建议用"多专家异构集成 / 专家委员会加权投票"，避免直接自称 MoE。
- 选择静态融合而非动态门控是**有实验依据的设计决策**：动态门控路线（可学习门控、掩码未来双专家）在本项目曾实测，嵌套评估下未通过显著性检验（实验 17/37），故最终采用更稳健的静态校准加权。
- 诚实的消融口径：嵌套评估显示融合相对最强单模（conformer / b8_shallow_b）的增益为 +0~1.7pp、未过显著性检验——技术报告中应将**多专家架构 + 防自欺嵌套评估方法论**共同作为创新点表述，而非单独宣称融合带来大幅提升。

### 3.3 材料引用口径（硬规则）

- 在线栈 0.6173：OpenBMI 折内口径，标注数据集；
- 离线 S0：0.558（折内）/ 0.511（嵌套）**双标注**；
- **禁止**在任何材料中引用实验 36 的 0.604 / 0.626 作为预期性能；
- 备选栈 R-B8 = 0.540（嵌套），作为工程对照归档引用。

## 4. 一段可直接嵌入报告的文字（草稿）

> 本系统采用**异构多专家集成**架构：由 FBCSP 系浅层卷积网络（含面向流式场景的时间起点加权变体）、轻量分离卷积网络 EEGNet 与 Transformer 混合架构 EEGConformer 组成四专家委员会，覆盖从局部频段能量到长程时间依赖的互补归纳偏置。专家输出经逐成员温度校准后，按验证集拟合的权重融合；离线评测进一步叠加六折交叉集成（S-ens）以降低单折方差，在线系统则叠加因果平滑与试次级多数票以适配实时流式决策。针对跨被试泛化这一核心难点，我们为在线与离线两类场景分别配置了与数据结构匹配的专家阵容（流式场景启用时间起点加权专家，单窗场景以初始化多样性替代），并以预注册的嵌套评估协议对所有集成决策进行防乐观偏差校验。
