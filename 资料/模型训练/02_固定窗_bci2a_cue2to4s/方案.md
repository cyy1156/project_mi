# 实验方案：BCI2a 固定窗 · Cue 后 2–4 s（BalAcc + batch balance）

> 状态：**十一模型已跑完**；完整汇总见 [`实验结果汇总_baselines_fixed_2s_bci2a.md`](./实验结果汇总_baselines_fixed_2s_bci2a.md)  
> 主结论：Task/Three 冠军 **shallow**（0.6539 / 0.5349）；EEGNet Task **0.6395**（对齐历史锚点）  

> 定位：用 **BCI2a 全量**做 **固定 2 s 窗** 对照选型（**非**滑窗主训协议）；经典 **Cue 后 2–4 s**。  
> 训练配方与主线阶段 A [`../01_旁路_2s滑窗100ms/`](../01_旁路_2s滑窗100ms/) 对齐：**Val BalAcc 早停 + train batch balance + 普通 CE + 无 RAP**。  
> 现行主线：[`../00_当前主线_2s滑窗100ms/`](../00_当前主线_2s滑窗100ms/)。**不动**：`baselines_2s_hop100/`、`baselines_1s/`（冻结）、`baselines_single/`。  
> **放弃 Stieger**；不与滑窗主线数字混比夺冠。

---

## 0. 定位与动机

| 问 | 答 |
|----|----|
| 为什么要做？ | 旁路 2s/100ms 滑窗窗级 BalAcc≈0.60；历史固定 2s EEGNet≈0.64。需要在 **同一配方**（BalAcc+balbatch）下把固定窗 **十一模型** 跑全。 |
| 和滑窗旁路差在哪？ | **无 hop、无重叠**；每试次 Task **恰好 1 窗**（Cue+2~4s），Rest **恰好 1 窗**。 |
| 本阶段报什么？ | 窗级 = 试次级；主报 Test **BalAcc**；Task→Three 完整指标。 |

## 1. 协议冻结

| 项 | 取值 |
|----|------|
| 数据集 | **仅 BCI2a 全量**（`A01T`–`A09T`） |
| Task 窗 | Cue 后 **[2, 4) s** |
| Rest 窗 | **Cue 前 2 s** |
| \(T_w\) | **2 s** → `n_times=500` @ 250 Hz |
| hop | **无** |
| 输出 | `(N,1,8,500)`（已有 `out/bci2a_2s`：N=1719，Rest=556，Task=1163） |
| 训练 | CE；Val **BalAcc**；**batch balance**；Task→Three；**无 RAP** |

读数口径：`Tw=2s fixed cue+2_4s rest_cue_before_2s bci2a_only balacc+balbatch no_rap`
