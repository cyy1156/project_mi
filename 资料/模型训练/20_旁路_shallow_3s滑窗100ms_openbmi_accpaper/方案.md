## 0. 一句话目标

在 **其他训练与评估条件完全冻结** 的前提下，只把滑窗长度从 **2 s → 3 s**，用同一套 **braindecode `ShallowFBCSPNet`** + 同一套 Acc_paper 训练环，回答：

> OpenBMI 上，窗长加长到 3 s（hop 仍 100 ms）后，Shallow 的 Task / Three Test Acc_paper 相对正式 2 s 基线是升还是降？幅度多大？

## 2. 单变量约定（冻结 vs 变更）

### 2.1 必须保持不变（相对正式 2s 基线包）

| 项 | 取值 |
|----|------|
| 模型 | **仅 Shallow**：`braindecode.models.ShallowFBCSPNet`（与 `baseline_shallow.py` 同构造） |
| 库 / 块 | OpenBMI · sess01+02 · **仅 `EEG_MI_train`** |
| 被试键 | `openbmi:subjNN`（方案 A，两场同人） |
| 通道 | 8 导（与 hop100 配置一致） |
| 重采样 | 250 Hz；窗内 z-score（与 2s 臂一致） |
| hop | **100 ms**（25 点 @250Hz） |
| 划分 | 被试独立五折 · `seed=42` · `val_ratio=0.2` |
| 损失 | 窗级 CE + **balbatch**（`balanced_invfreq`） |
| 早停 / 主报 | Val / Test **Acc_paper**（试次内正确窗占比 > 0.5） |
| 头 | **先 Task（2 类）再 Three（3 类）**（`task_runner` 默认） |
| 优化 | Adam `lr=1e-4` · `wd=1e-4` · `patience=20` · `max_epochs=300` |
| drop_prob | 0.5 |
| Fast 默认 | batch **128/256** · AMP · `num_workers` 按本机（5060 可 2；内存紧用 0） |
| 源 epoch | Task：**Cue 后 0–4 s**；Rest：Cue 前满 4 s 同几何（与 04 方案一致） |

### 2.2 唯一主动变更

| 项 | 2s（对照） | **3s（本实验）** |
|----|------------|------------------|
| 窗长 \(T_w\) | 2.0 s | **3.0 s** |
| `n_times` | 500 | **750** |
| 数据 tag | `openbmi_2s_hop100` | **`openbmi_3s_hop100`**（新建） |
| 每 4 s 段窗数 | \(1+(4-2)/0.1=21\) | \(1+(4-3)/0.1=\)**11** |

> 注：源试次仍是 **4 s MI epoch**；窗变更长 → **每试次窗更少、单窗上下文更长**。这是本实验要观察的效应，不是 bug。

### 2.3 明确不做

- 不跑十一模型全表（本实验 **只 shallow**）  
- 不改 hop、不改 Acc_paper 定义、不加 RAP  
- 不上方案 17 pf1000 / 掩码未来 / T 系列  
- 不把手写 `self_model` Shallow 混进本臂（那是方案 18）  
- 不把 3s 权重写进 `5060_baseline_openbmi_2s_hop100_accpaper/`

### 5.2 解释口径（本轮结论）

| 结果形态 | 本轮 |
|----------|------|
| S3 > S2（Task/Three） | **成立**：Task / Three 均约 **+4.7 pp**，std 未恶化 |
| 含义 | 在冻结协议下，**更长窗（3s）对 Shallow Acc_paper 有益**；是否升格主线另议，**不改写正式 2s 十一模型表** |

**注意**：每 trial 窗数 21→11；本轮 mean 与 std 均优于或持平对照，支持「上下文加长净收益」。

风险：

1. **4s 源段 + 3s 窗** → 合法起点变少；若 Rest/Task 平衡被破坏，须在 meta 中明示并考虑是否延长源段（**默认不延长**，保持与 04 同源 epoch）。  
2. `ShallowFBCSPNet` 对 `n_times=750` 的池化长度是否仍合理：用库默认即可；若前向报错再记「结构不适配」并停训。  
3. 显存：750 点相对 500 略增；OOM 时仅降 `batch_train`（96/192），**不改协议语义**。

## 8. 结论

在冻结协议下，OpenBMI Shallow **Tw=3s / hop=100ms** 相对正式 **2s** 基线：

- Task Acc_paper **0.7415±0.0306**（**+4.74 pp**）
- Three Acc_paper **0.5876±0.0296**（**+4.72 pp**）

更长窗有净收益；本臂为旁路证据，**不自动改写**正式 2s 十一模型主表。
