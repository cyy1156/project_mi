## 0. 你要回答的唯一问题

> 在 **同一 OpenBMI · 被试独立 · Acc_paper** 协议下，JEPA 学到的表征（冻住线性头或轻量微调）能否让 Three **相对同骨干随机初始化 / 相对正式 shallow** 有可见提升？

| 等级 | 条件（Three Test Acc_paper） |
|------|------------------------------|
| **表征有用** | 冻住线性探测 ≫ 同 Enc 随机冻住探测（建议 Δ≥ **+0.03**） |
| **弱成功（相对 shallow）** | 微调后 ≥ shallow + **0.010** |
| **达标** | 微调后 ≥ shallow + **0.015** |
| **阴性** | 微调后 ≤ shallow，且冻住探测不优于随机+0.03 → **停，不扩跨窗门控** |

Task 只作护栏：微调后 ΔTask ≥ **−0.01**。

## 1. 最小系统（先不要做你的跨窗加权版）

本阶段 **只做窗内 JEPA**，证明框架本身有用；跨窗 \(z_t\oplusẑ_{t+k}\) 留到 **本方案阳性之后**。

### 1.1 Token 与 Mask（方案 B · 冻结）

> 相对初版「L/R/Mid 三组 × 时间 + 时间整条全通道 / 半球整侧」，现改为 **按导联独立 token + 稀疏多块 25%**，便于保留偏侧可见信息。与 **11 号同构**，便于对照损失目标（EMA-JEPA vs LeJEPA）。

| 项 | 冻结值 |
|----|--------|
| 输入 | \(x\in\mathbb{R}^{8\times 500}\)（2s @ 250Hz；对照可试 4s） |
| 通道序 | `Cz, C3, C4, CP3, FC4, FC3, CP4, CPz`（与 hop100 一致） |
| 时间块 | `patch_time=25`（100ms）→ 每通道 **20** 个时间 token |
| Token 网格 | **8 通道 × 20 时间 = 160**；下标建议 `ch * 20 + t` |
| 嵌入 | 每 token：该通道该 100ms 波形 → Linear→`embed_dim`（起步 64） |

**Mask（预训）**：

| 规则 | 说明 |
|------|------|
| 块数 | 固定 **4** 个时空矩形块（通道维 × 时间维） |
| 总面积 | 四块并集约占 token 的 **25%**（目标约 40/160；允许 0.22–0.28） |
| 单块形状 | 随机：通道高 \(h\in\{1,2,3\}\)、时间宽 \(w\in\{2..6\}\)，再裁剪到网格内；四块面积之和逼近 25%（可重叠，以并集计） |
| 禁止 | **同一时间步 \(t\) 不得遮满全部 8 通道**（该 \(t\) 至少留 1 个可见通道） |
| 不做（默认） | 不再使用「整段时间三组/全通道一条遮」或「整侧半球全时间遮」 |

被遮 token 换可学习 `mask_token`；预测目标仍在 mask 位置（I-JEPA 风格）。

```text
输入 x: (8, 500)
Token:  8ch × 20×100ms  = 160
Mask:   随机 4 块，并集 ≈25%；禁止同 t 灭全通道

E_ctx  可训
E_tgt  = EMA(E_ctx)
P      小预测头

L_jepa = MSE( P(可见上下文),  sg(E_tgt(全图))[mask] )
```

### 1.2 骨干建议（5060 可跑）

- **PatchEmbed**：逐通道时间块线性投影（方案 B）  
- **Context**：1–2 层 Transformer（或 MLP mixer 冒烟）  
- 宽度先小：embed dim 64–128，别一上来 ViT-B

## 3. 实验臂（按顺序，可停）

### J0 · 监督对照（同骨干、无 JEPA）

- 同 Enc + 分类头，**从头监督**训 Three（协议对齐正式：balbatch、Acc_paper 早停、seed=42）。  
- 目的：把「骨干容量」和「JEPA 预训」拆开。  
- 若 J0 已 ≥ shallow，说明是骨干问题；JEPA 仍可做，但解读要变。

### J1 · 纯 JEPA 预训（无分类损失）

- 只优化 \(L_\text{jepa}\)。  
- 保存 `E_ctx`（及超参）。  
- 冒烟：1 折被试子集、短 epoch，确认 loss 下降且非塌缩（表征方差别→0）。

### J2 · 冻住线性探测（核心证据）

- 冻住 `E_ctx`，只训线性（或 1 层 MLP）Three 头。  
- 对照：**同一 Enc 随机初始化冻住 + 线性头**。  
- 主看试次 Acc_paper。  
- **过线（表征有用）才进入 J3。**

### J3 · 解冻微调 Three

- 全量或分阶段解冻 Enc，lr 小于分类头（如 1e-5 / 1e-4）。  
- 早停 Val Acc_paper；主报 Test Acc_paper。  
- 与正式 shallow、与 J0 同表登记。

### J4（可选）· 联合 \(L_\text{jepa}+λL_\text{cls}\)

- 仅当 J3 弱成功想再挤一点；λ 从小到大。  
- **不是**第一周必做。

### 本阶段不做

- 跨窗 Pred + 门控加权分类（你的 T-臂想法）  
- 多库大规模 foundation  
- 改正式表 / 游戏伪在线夺冠

## 4. 你「下一步具体怎么做」（操作清单）

### 第 1–2 天：跑通前向

1. 旁路包已建：`code/train_lab/src/step/5060_jepa_three_probe_openbmi_accpaper/`  
   - `jepa_model.py`：方案 B（8ch×100ms token）+ EMA + 四块 25% mask  
   - `run_j1_pretrain.py` / `run_three_downstream.py`  
2. 冒烟：`python run_j1_pretrain.py --max-folds 1 --pretrain-epochs 5`（核对 `mask_frac≈0.25`）

### 第 3–5 天：一折冒烟

1. 取正式折 0 的 train 被试，切无标签 2s 窗预训 J1（短程即可）。  
2. J2 冻住探测 Three（可用 `--max-folds 1`）。  
3. 同步跑「随机 Enc 冻住探测」。  
4. 看 Δ：有 **+3pp 级** 再开五折；否则先改 mask（块数/总面积/单块高宽）、窗长 2s↔4s、预测维数。**勿**在未登记的情况下退回「全通道时间条 / 半球整侧」。

### 第 6–14 天：五折结论

1. 五折各自预训（或「留出 test 被试」协议写死）。  
2. 跑满 J2 + J3。  
3. 填本目录 `总结/结果登记表.md`。  
4. **阳性** → 再开文档做 T-臂（\(z_t\) 门控融合 \(ẑ_{t+k}\)）；**阴性** → 结论写清，转回 09 Shallow 结构或数据侧。

## 7. 决策树（避免纠结）

```text
J2 JEPA冻住 是否明显 > 随机冻住？
  否 → 改 mask/窗长/骨干；仍否 → JEPA思想在本数据未成立，停
  是 → J3 微调
         ├─ ≥ shallow+1.5pp → 达标；可做跨窗门控 T-臂
         ├─ ≥ shallow+1.0pp → 弱成功；可轻量扩 J4 或 T-臂冒烟
         └─ < shallow       → 表征有用但下游未超浅层；可写论文式阴性/部分阳性，不替换部署
```
