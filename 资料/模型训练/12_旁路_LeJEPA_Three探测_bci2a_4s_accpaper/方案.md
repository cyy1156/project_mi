## 0. 要回答的问题与成功线

### 0.1 唯一问题

在 **BCI2a · 被试独立 · 固定 4s 窗 · Acc_paper 风格评测** 下，用与 11 号相同的 **LeJEPA（预测 + λ·SIGReg，无 EMA）** 预训后：

1. 冻住线性探测 Three 是否 **明显优于** 同骨干随机冻住？（J2 − J2_random）  
2. 解冻微调是否 **不低于** 同骨干从头监督？（J3 ≥ J0）  
3.（可选）相对本库同协议浅层 / 历史 BCI2a 基线是否有讨论价值——**不**用 OpenBMI shallow 0.540 当夺冠锚。

### 0.2 成功 / 失败等级（Three Test Acc_paper）

与 11 号 **同结构**，锚点改为 **同跑内部**：

| 等级 | 条件 | 解读 |
|------|------|------|
| **表征有用** | J2 − J2_random ≥ **+0.030** | SIGReg+预测学到了可用结构 |
| **框架赢** | **J3 ≥ J0**（同折、同缩水或同全协议） | 预训不再拖累同骨干监督 |
| **阶段阴性** | J3 ≪ J0（如差 ≥0.05），或 J2−random &lt; +0.01 | **停扩**；不进 T-臂 |
| 弱成功 / 达标 vs 外部浅层 | **本阶段不设 OpenBMI 数字线**；若日后有 BCI2a·4s·同 8 导 shallow 五折，再单开对照行 | 避免跨库混比 |

Task 护栏（若顺带评）：微调后 ΔTask ≥ **−0.01**（主报仍是 Three）。

### 0.3 对照关系（读数纪律）

| 对照 | 用法 |
|------|------|
| **11 号 OpenBMI·2s·hop100** | 只比「方法是否换库仍阴性/阳性」的 **趋势**；注明 data_tag / 窗长 / 被试数 |

## 3. 方法细节（与 11 同构处不重复推导）

### 3.1 输入与 Token（方案 B · 4s）

| 项 | 冻结值 |
|----|--------|
| 数据 | `preprocess_lab/out/bci2a_4s`（`data_tag=bci2a_4s`，前缀 `bci2a`） |
| 预处理约定 | Cue 后 0–4s 任务 + Cue 前 4s 静息；`target_chans` 与 OpenBMI 同序：`Cz, C3, C4, CP3, FC4, FC3, CP4, CPz`（见 `preprocess_lab/config/bci2a_4s.yaml`） |
| 窗 | `(B, 8, 1000)` · **4s @ 250Hz**；**固定窗**（非 hop100 滑窗） |
| 时间块 | `patch_time=25`（100ms）→ 每通道 **40** 个时间 token |
| Token 网格 | **8 × 40 = 320**；下标 `ch * n_time + t` |
| 嵌入 / 编码器 | 同 11：Linear patch → dim64；2 层 TransformerEncoder（4 head，norm_first） |

实现：自 11 号包浅拷贝 `lejepa_model.py`，仅 `n_times_expected=1000`；`PatchEmbed` 已按 `n_times // patch_time` 推导，无需改 mask 语义。

**算力提示**：token 数 160→320，自注意力约 **4×**；相对 11 的 batch 256 下调为 **128**（OOM 再降到 64/32），登记注明。

### 3.2 双视图 Mask（方案 B · 不变规则）

与 11 完全相同：

- 每窗独立采 \(m_1,m_2\)  
- **4** 块时空矩形；并集 ≈ **`mask_ratio=0.25`**（约 80/320 token）  
- \(h\in\{1,2,3\}\)，\(w\in\{2..6\}\)（时间维更长，可保持同范围；若块过碎可在附录扫描 \(w\) 上限，**默认不扫**）  
- **禁止**同一 \(t\) 遮满 8 通道  

### 3.3 损失（LeJEPA · 不变）

```text
L = L_pred + λ * L_sigreg
```

默认 λ=**0.05**；无 EMA / 无 stop-grad；双侧反传。SIGReg 实现复用 11 号 `sigreg.py`。

### 3.4 下游读出（不变）

| 臂 | 骨干 | 头 | 训练 |
|----|------|-----|------|
| J2 / J2_random | 冻住 | Dropout + Linear→3 | 只训头 |
| J3 | 解冻 | 同上 | Enc `lr_encoder=1e-5`，头 `lr=1e-4` |
| J0 | 随机同结构 | 同上 | 全参数 `lr=1e-4` |

### 3.5 评测：Acc_paper 在固定窗上的定义

`bci2a_4s` **无** `*_trial_id.npy`（每窗通常已对应一次 cue 切段）。约定：

| 项 | 约定 |
|----|------|
| `trial_id` | 代码内生成 **`np.arange(N)`**（一窗一试次） |
| Acc_paper | 仍走与正式相同的 `aggregate_windows_to_trials` 接口；此时与 **窗级 Acc** 数值等价，但管线与登记列名保持 Acc_paper，便于和 11 对照读表 |
| 早停 / 选优 | **Val balanced accuracy（BalAcc）**；连续 `patience` 个 epoch 无提升则停，保存 Val BalAcc 最优权重 |
| 主报 | Test Acc_paper 与 Test BalAcc **一并登记**；成功线 §0.2 仍以 Acc_paper 判级（与 11 对照），但 checkpoint 不以 Acc_paper 选 |

登记表必须写明：**固定窗 · 一窗一试次**。

## 4. 数据与防泄漏

| 项 | 约定 |
|----|------|
| 来源 | 仅 `bci2a_4s` 全量 `bci2a_X.npy` + `bci2a_y_three.npy` + `bci2a_subjects.npy`（T 会话；已有产物则 **不重跑预处理**，除非校验失败） |
| 预训标签 | **不用** y |
| 预训被试 | 该折 `train ∪ val`；**禁止** test 被试 |
| 下游 | 同折 `train / val / test`；y=`y_three`（idle/left/right；BCI2a 已 drop 脚想象类，与 yaml `drop_codes` 一致） |
| 折划分 | `iter_subject_kfold` · **`n_folds=5`** · `val_ratio=0.2` · `seed=42` |
| 被试数警告 | 仅 **9** 人 → 每折 test≈1–2 人，方差大；**主报 fold0 冒烟 + 五折均值±std**，解读保守 |
| 样本量 | 全库 ~1719 窗 → **禁止**照搬 11 的 max-windows=50000；默认 **用尽该折可用窗** |

标签语义：与现预处理一致（左/右 MI + 静息）；**不要**假设与 OpenBMI 类先验完全同分布。

## 5. 实验臂（严格顺序 · 同 11）

```text
J1 预训 → J2_random 与 J2 → 过「表征有用」或弱正向后再解读 J3
         → 始终跑 J0（同协议）
```

| 臂 | 脚本（计划包内） | 目的 |
|----|------------------|------|
| **J1** | `run_j1_pretrain.py` | 只优化 \(L\) |
| **J2_random** | `run_three_downstream.py --arm j2_random` | 随机冻住下界 |
| **J2** | `--arm j2 --j1-dir .../j1` | 冻住探测 |
| **J0** | `--arm j0` | 同骨干监督 |
| **J3** | `--arm j3 --j1-dir .../j1` | 解冻微调 |

### 本阶段不做

- 改 mask / λ / 骨干宽度（那些属 11 消融，不在 12 混做）  
- 换回 OpenBMI 或 2s 却宣称「12 的增益」  
- 跨窗门控 T-臂  
- 覆盖正式 OpenBMI 权重 / 改写十一模型表

## 10. 决策树

```text
S-长 fold0：
  J2 − random
    < +1pp  → 阴性倾向；最多 λ×3；仍无 → 停（BCI2a·4s 上 LeJEPA 未成立）
    +1～3pp → 弱正向；看 J3≥J0？
    ≥ +3pp  → 表征有用；必报 J0/J3
  J3 vs J0
    J3 ≥ J0 → 框架赢；可考虑 F-全五折
    J3 ≪ J0 → 与 11 同类失败；停 T-臂
  禁止：用 OpenBMI shallow 0.54 判定本方案成败
```
