## 0. 一句话目标

在 5090 上跑完定稿方案全链（含消融 B/C 与结构升级 U），判定「掩码未来 + 双专家」能否稳定超过可见上下文单专家 **A1**。

## 1. 协议摘要

| 项 | 取值 |
|----|------|
| 主数据 | OpenBMI · `openbmi_2s_hop100` / `openbmi_2s_hop100_pf1000` v3 |
| 几何 | 当前窗 2 s · hop 100 ms · pf1000 = past+cur+future |
| 主指标 | Test Acc_paper |
| 默认链 | `A0_ref → A0 → A1 → P0 → A2 → P1 → P2` |
| 扩展 | B/C 消融 · U 结构升级 · T token（附报） |

训练–推理契约、损失与模块定义以**定稿方案正文**为准（本文件不重复公式）。

## 2. 本机要点

| 项 | 说明 |
|----|------|
| A0 / 自写 500pt | 需已有 `out/openbmi_2s_hop100` |
| A1+ pf1000 | 三类 Rest+L/R，`protocol_version≥3`；旧 no_rest 需 `--reset` |
| workers | Windows 默认可 0；本机可试 `--num-workers 2` |
| 并存任务 | 建议 `--batch-train 128` |

## 3. 怎么跑

```powershell
cd code/train_lab/src/step/5090_mask_future_dual_expert_accpaper
python chain_all.py
# 或 run_chain_detached.bat
```

A1+ 数据：

```powershell
cd code/preprocess_lab
python -m src.datasets.openbmi_pf1000.batch --reset
```
