## 本归档是什么

旧「当前主线」曾规定：

- 窗长 **1 s** / 步长 **40 ms**（\(f_u=25\,\mathrm{Hz}\)）
- 库：**BCI2a + Stieger**（同逻辑；Rest=Cue 前 4 s）
- 选型：八基线原结构、无 RAP；冠军后再伪在线
- RAP 几何（1s）：`(5,5,50,2)`

## 为何废止

| 旧设定 | 现行主线 |
|--------|----------|
| 1 s / 40 ms | **2 s / 100 ms** |
| Stieger 主力外库 | **放弃 Stieger**；后续 **OpenBMI** |
| 八基线均衡深研 | 选型后深研 **shallow / eegnet / conformer** |
| 旁路才是 2s/hop100 | 2s/hop100 **升格为主线** |

配方中 **Val BalAcc + batch balance** 被现行主线继承并写死为不可协商项。
