## 0. 为什么换协议

| 旧做法（已归档） | 问题 | 现做法 |
|------------------|------|--------|
| 整段 2s/4s 一条样本训练 | 上线是 1 s 滑窗 → **域不匹配** | 离线也切 **1 s / 40 ms** |
| Stieger `down` 当 Rest | 与 BCI2a / 比赛「被动空闲」不一致 | 两库 Rest = **Cue 前 4 s** |
| merged 两库混训夺冠 | 掩盖单库差异 | **单库分别训** `bci2a_1s` / `stieger_1s` |
| 八基线直接上 RAP | 多数模型不适配，对比不公 | 选型 **原结构无 RAP**；冠军再谈 RAP |
| 窗数组 for 一遍当在线 | 不是流式伪在线 | 阶段 B：缓冲 + 40 ms 更新 + 试次投票 |

旧结果目录：[`../归档/03_实验结果_整段2s4s与merged/`](../归档/03_实验结果_整段2s4s与merged/) — **只对照，不夺冠**。

## 2. 预处理

工作目录：`code/preprocess_lab`

```bash
# 冒烟
python -m src.common.steps.test_slide_1s

# BCI2a → out/bci2a_1s  (N,1,8,250)
python -m src.datasets.bci2a.batch --cfg config/bci2a_1s.yaml

# Stieger 全库 DATA/stieger（默认 --subjects all）→ shard
python -m src.datasets.stieger.batch_1s --out out/stieger_1s --reset --no-merge --subjects all

# shard 齐后合并为训练用 npy
python -m src.datasets.stieger.batch_1s --out out/stieger_1s --merge-only
```

要点：

- 滤波：CAR + 50 Hz notch（短试次 **自适应 FIR 长度**）+ 8–30 Hz  
- Stieger：**全部会话**；不用 down 作 Rest  
- 输出可含 `trial_id` 供日后伪在线投票

## 3. 离线选型（阶段 A）

工作目录：`code/train_lab/src/step/baselines_1s`

```bash
python smoke_models.py
python baseline_eegnet.py --data bci2a_1s
python run_all.py --data bci2a_1s
python run_all.py --data stieger_1s --continue-on-error
# 或
python run_all.py --data both --continue-on-error
```

冻结习惯：

- 原结构 / **无 RAP** / 无 OTTA  
- Val **Balanced Accuracy** 早停  
- train **batch balance**（普通 CE）  
- Task-only  
- MD → `资料/模型训练/runs/`；权重 → `train_lab/out/baseline_1s/`
