**36 提出，37 证伪，38 盖棺；39 只补洞、不定新假说。**

| 表观读数 | 折内（36/34） | 嵌套（37/38） | 含义 |
|----------|---------------|--------------|------|
| S0 / E1f-A59 | 0.558 | **N0 = 0.511** | ~**4.7pp** in-sample 乐观 |
| M7 / M7_ABC | 0.604 / 0.626 | 0.523 / ≈0.510 | 涨点 **3/4～全部** 是伪影 |
| 跨家族 F1 | — | = N0 | 结构多样性无价 |
| 嵌套最高已测 | — | **b8_shallow_b = 0.528**（p=0.69） | 信号在 B8 单模，不在融合 |
| **E1f-B8-ft** | **0.573±0.140**（Exp34） | **从未嵌套** | **本方案唯一必测缺口** |

机制已写死、本实验不再重开：

1. N0 六折 E1f 权重全塌成纯 conformer → A59 四成员融合折外一文不值。  
2. fold0 嵌套后未塌回 A59，而是 w_B8=0.4 造成 **−8.7pp** → 跨视角权重被试特异，LOSO 无信息。  
3. 6 折 Wilcoxon 地板与 ±7~13pp 折间噪声 → **≤2pp 效应结构性不可显著**；继续用「p&lt;0.05 才许换卷」等于永不换卷。

→ 39 的正当性问题不是「还能不能涨」，而是：**诚实排行榜缺一行（E1f-B8-ft），且科学纪律与交卷工程需要分轨写死。**

| 臂 | 层级 | 定义 | 训练？ |

| **R-pool-S0** | 工程变体 | θ 在 **全部 6 折 Val（900）** 一次拟合 → 每折用同一 θ 评估（诊断）；同 θ 写 test CSV | 否 |

| **R-uni50** | 穷尽对照 | A59-E1f(折内已 fit 的流概率，或每折单用 conformer) × B8-E1f，**跨流 w≡0.5/0.5、不拟合**；流内可用已嵌套/折内 dump 概率 | 否 |

说明：

- **R-B8** 的嵌套定义必须与 N0 **同构**（仅换轨），保证 Δ 可解释。

- **R-uni50** 流内概率优先取 **嵌套 OOF 流概率**（若 37 已存）；否则用各折成员 dump 的折内 E1f 流概率再固定 50/50（登记时注明）。

| 项 | 值 |

## 5. 预注册决策规则（跑数前冻结）

### 5.1 科学主行（纪律 · 默认）

```text
科学结论默认维持：
  「官方算法旁路 34–38 已收敛；主交卷科学叙事 = Exp34 S0；
   真实水位口径 = 嵌套 0.51–0.53；融合/跨视角/选池均未过嵌套显著性。」

即使 R-B8 嵌套均值高于 N0，只要 Wilcoxon p≥0.05：
  → 科学主行仍写 KEEP_S0_discipline（与 37/38 一致）。
  → 允许同时输出「工程选卷 ≠ 科学主行」的第二行（§5.2）。
```

理由：继续把 n=6 Wilcoxon 当唯一换卷闸 = 结构性永不换卷；但 **显著性叙事** 不能被均值规则偷换——故分轨。

### 5.2 工程选卷（提交选择 · 本实验新增）

候选集合 \(\mathcal{C}\)（仅含本方案已测 + 只读复用臂）：

```text
C = { S0_csv(=折内 E1f-A59 既有提交),
      R-B8 嵌套栈生成的 test CSV,
      V1 = b8_shallow_b 单模 CSV,
      R-pool-B8 CSV,
      R-pool-S0 CSV,          # 仅当与 S0_csv 差可解释时考虑
      R-uni50 CSV }           # 仅当 §5.3 门槛过才进入 C
```

裁决（写死）：

```text
1. 以 leave-fold nested_mean 为排序键（S0_csv 的嵌套代理 = N0；
   R-pool-* 的排序键仍用其对应 leave-fold 同构臂：pool-S0→N0，pool-B8→R-B8；
   不得用 pool 的 in-sample Val 争冠）。
2. 取 nested_mean 最高者 W*。
3. 若存在另一候选 W 满足 nested_mean(W*) − nested_mean(W) < 0.01：
     在 {W*, W} 中取「参数更少 / 成员更少 / 工程更简」者
     （单模 < 四成员 E1f < 跨流融合 < pool 全局θ 与 leave-fold 同复杂度时取已有 S0 文件）。
4. 登记表必须写：
     decision_science = KEEP_S0_discipline（或例外）
     decision_engineering = <W*>
     label = 「工程选择，非显著性结论」
5. 仅当决策要求写新文件时才生成 submission_exp39_*；旧 S0 归档不删。
```

### 5.3 R-uni50 进入候选的门槛（防钓鱼）

```text
R-uni50 进入工程候选集 C 当且仅当：
  (a) ≥5/6 折 Acc ≥ F1 同折 Acc
  (b) pooled Acc ≥ 0.53
否则只附报「无拟合融合已穷尽 · 未过门槛」。
```

### 5.4 明确禁止的事后动作

- 看到 R-B8 略高就改回「Wilcoxon 过线才换」或反过来改 α  
- 把 R-pool-* 的 in-sample Val 写进「嵌套排行榜」冠军行  
- 因本实验数字再开 Exp40 训练臂  
- 在材料中引用 Exp36 的 0.604/0.626 为预期 test 性能
