## 3. 冻结协议（对齐基线包，禁止私改）

数据与训练环 **只读拷贝 / 浅引用** `5060_baselines_openbmi_2s_hop100_accpaper`：

| 项 | 取值 |
|----|------|
| 数据 | `preprocess_lab/out/openbmi_2s_hop100/` |
| 窗 | Tw=2s @250Hz → `(N,8,500)`，hop=100ms |
| 划分 | 被试独立五折 · `seed=42` · `val_ratio=0.2` |
| 损失 | 窗级 CE + **balbatch**（`balanced_invfreq`） |

| 优化 | Adam `lr=1e-4` · `wd=1e-4` · `patience=20` · `max_epochs=300` |
| Fast 默认 | batch 128/256 · AMP · 本机可 `num_workers=0～2`（5070 内存紧时用 0） |

HP 来源：同包 [`shared_hparams.py`](../../../code/train_lab/src/step/5060_baselines_openbmi_2s_hop100_accpaper/shared_hparams.py)。

## 4. 差异检查清单（先结构，后训练）

### 阶段 A · 静态结构审计（不训练，半天内）

写脚本 `compare_shallow_impl.py`（建议放旁路包），对同一 `(8,500,3)` 配置打印：

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 参数量 | `sum(p.numel())` | 应对齐或差可解释（如 bias 有无） |
| 模块拓扑 | `repr` / 层名表 | 时间卷积→空间卷积→BN→Square→Pool→Log→Drop→分类头 顺序一致 |
| `state_dict` 键 | 键名列表 | **允许不同**（手写是 `conv_time.conv.weight`；库是扁平名）；记入表，不做硬对齐权重加载 |
| 形状轨迹 | 钩子记录每层 `shape` | 同输入下特征图 `(B,C,T',…)` 一致 |
| 默认超参 | 读两边 `__init__` 默认值 | filter/pool/BN momentum/`SafeLog` eps 逐项对照 |

**已知预期差异（先验，待实测确认）**：

1. **命名空间**：手写模块化 vs braindecode `nn.Sequential` 扁平名。  
2. **可选注意力**：手写多 `attn=` 分支；本实验强制 `None`。  
3. **BN / bias**：手写 `ConvSpat(..., bias=not batch_norm)`；需核对库版是否同逻辑。  
4. **SafeLog eps / pool 边界**：可能影响数值，不一定影响 Acc 量级。

### 阶段 B · 前向数值对齐（随机权重 / 拷贝权重，不训练）

| 子实验 | 做法 | 判定 |
|--------|------|------|
| B1 同分布随机 | 两边独立 `seed` 初始化，只比形状 | 输出 `(B,C)` 形状一致 |
| B2 尽量拷贝权重 | 手写建表映射库权重键 → 灌入；同输入 `X` | `max|logit_L−logit_S|` 与 `max|prob差|`；目标 **&lt;1e-5**（浮点），否则记「结构不等价」 |
| B3 梯度冒烟 | 同一 CE，`backward` 一次 | 无 NaN；主层 grad 范数同量级 |

若 B2 失败：列出第一处 shape/数值分叉层，**先修手写或接受「近似实现」**，再进阶段 C。

### 阶段 C · Acc_paper 五折对照（主结论）

| 臂 | 命令意图 | 主指标 |
|----|----------|--------|
| L0 | `baseline_shallow.py`（库） | Task / Three · Test Acc_paper mean±std |
| S0 | `baseline_shallow_self.py`（手写） | 同上 |

门控顺序：

1. 各臂 `--max-folds 1` 冒烟（同 seed）。  
2. 通过后 **五折 Fast**。  
3. 可选：同机 `--repro --max-folds 1` 抽检（非正式）。

**主判定（建议）**：

| 结果 | 含义 | 后续 |
|------|------|------|
| \|Δ Three Acc_paper\| ≲ **0.01** 且结构/B2 对齐 | 手写可视为官方等价替换 | 方案 17+ 继续用自写 Encoder |
| 结构对齐但 Δ ≳ 0.01 | 初始化/数值细节仍有差 | 修 init / eps / BN，或文档标明「近似」 |
| B2 失败且 Acc 差大 | 实现有实质性偏差 | **优先修 `shallowfbcsp.py`**，暂停新方法扩扫 |

历史锚点（仅参考，非正式对照）：正式基线 shallow（库）OpenBMI Acc_paper 量级见  
`资料/模型训练/5060_openbmi_accpaper_实验与权重清单.md`（Task≈0.69 / Three≈0.54 量级）。
