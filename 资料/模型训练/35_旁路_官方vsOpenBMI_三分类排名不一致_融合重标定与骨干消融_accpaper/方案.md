## 7. 轨 F · 融合重标定与约束（回放 · P0）

> 输入：A59 四成员在各折 Val/Test 上的概率（由 ckpt 导出一次）。  
> **禁止**用 test 选约束超参。

### 7.1 臂定义

| 臂 ID | 名称 | 规则 |
|-------|------|------|
| **F0** | Exp34 复现 | 无约束网格 fit T+w（应复现 Val mean≈**0.558**） |
| **F1** | OpenBMI 权重迁移 | T 可在 Val 重拟合；**w 冻结**为 OpenBMI 四成员语义对齐后的映射（见 §7.2） |
| **F2** | 均匀融合 | w=均匀；T 可 Val 拟合 |
| **F3** | 排名先验软约束 | 单模 Val Acc 越高，w 下限越高（见 §7.3） |
| **F4** | 弱模权重上限 | 强制 `w_eegnet ≤ 0.15`（超参来源=fold0 Val；冻结后全折） |
| **F5** | 强模权重下限 | 强制 `w_conformer ≥ 0.40`（同样 fold0 冻结） |
| **F6** | F4∧F5 | 同时施加 |
| **F7** | 温度夹紧 | T∈[0.5, 5]；再无约束搜 w（抑制 Exp34 极端 T） |

### 7.2 OpenBMI 权重映射（F1）

官方成员名：`shallow, shallow_b, eegnet, conformer`  
OpenBMI：`shallow, t_shallow, eegnet, conformer` · w=`[0.2,0.2,0.3,0.3]`

映射：

```text
w_shallow   ← 0.2
w_shallow_b ← 0.2   # 对齐 T-shallow 槽
w_eegnet    ← 0.3
w_conformer ← 0.3
```

### 7.3 排名先验（F3）硬定义

每折 Val 上算四成员单模 Acc，记名次 r∈{1,2,3,4}（1=最好）。  
搜索 w 时附加约束：

```text
w_(r=1) ≥ 0.35
w_(r=4) ≤ 0.15
Σw = 1, w≥0
```

若可行域空：放宽为 `w_(r=1)≥0.30` 且 `w_(r=4)≤0.20`（登记「放宽」）。

### 7.4 主指标与判定线（相对 F0 = Exp34 E1f）

| 读数 | 线 | 含义 |
|------|-----|------|
| F0 | Val mean ∈ **0.558±0.005** | sanity（复现失败则停查 dump） |
| 任一约束臂 F3–F7 | Val mean ≥ **F0 − 0.005** 且 **≥ F0** 优先 | 「不掉点」；若 **≥ F0 + 0.010** → **采纳候选** |
| F1 | 附报 | 迁移权重是否灾难性掉点（预期掉；量化幅度） |
| F2 | 附报 | 均匀下限 |

**折间稳定性附报**：报告每折 `w_eegnet` 的均值/最大；约束臂应显著低于 F0。

### 7.5 决策（轨 F 内部）

```text
若 F0 sanity 失败 → 修 dump / fit 代码，不进入 M/S
若存在 Fx∈{F3..F7} 且 Val ≥ F0+0.010 → Fx 进入轨 S 交卷候选
否则若存在 Fx 且 Val ≥ F0−0.005 且 max(w_eegnet) 明显下降 → Fx 作为「稳健候选」进 S（即使不涨点）
否则轨 F 结案：维持 Exp34 无约束，转轨 M 靠缩池解决
```

## 8. 轨 M · 成员池消融（回放 · P0）

对齐方案 28 精神，但对象改为**官方 A59**。

| 臂 ID | 成员池 | 融合 |
|-------|--------|------|
| **M0** | {S, Sb, E, C} | 同 F0（sanity） |
| **M1** | {C} | 单模 · 无融合 |
| **M2** | {S, Sb, C} | Val 无约束 fit（**无 eegnet**） |
| **M3** | {S, C} | Val fit |
| **M4** | {C, E} | Val fit（对照：强+弱） |
| **M5** | {S, Sb, E} | Val fit（**无 conformer**） |
| **M6** | {C}×2 seed（若有第二 conformer；否则跳过） | — |

默认：**每个非单模臂**用与 F0 相同的 T+w 网格；另对 M2 再跑一版 **F6 约束**（记 **M2c**）。

### 8.1 判定线

| 读数 | 线 |
|------|-----|
| M1（conformer） | 与 Exp34 A59-conformer **0.511±0.005** sanity |
| M2 | ≥ **max(F0, M1)** − 0.005 → 「去 eegnet 不掉点」 |
| M2 ≥ F0 + 0.010 | **采纳缩池**（强成功） |
| M5 | 预期 ≤ M1；若 M5 ≥ M1 → 排名翻转假说受冲击（须复查） |
| M4 | 附报；若 M4 ≫ M1 则「弱模互补」成立（与 OpenBMI 类似） |

### 8.2 决策树（与轨 F 合并进轨 S）

```text
M2 或 M2c 显著 ≥ F0  → 主融合候选改为「无 eegnet」
M1 ≥ F0 − 0.005     → 单模 conformer 进入交卷决赛圈
M5 ≥ M1             → 触发数据/标签审计（意外）
```

## 9. 轨 S · 交卷候选（P0 · 触及交付）· **v0.2 三候选强制决赛**

### 9.1 决赛池（结构候选 **恒进** + S0 锚）

| 候选 ID | 结构名 | 定义 | 选取规则 |
|---------|--------|------|----------|
| **S0** | 锚 | F0 / Exp34 无约束 E1f | 恒对照 |
| **C_fuse**（报表可标 S2） | 约束融合 | 轨 F 约束臂 **F3–F7** 中 Val mean 最优 | **即使 Val&lt;F0 也进决赛** |
| **C_pool**（报表可标 S3） | 缩池 | 优先 M2/M2c；否则 M2/M2c/M3 中最优 | **即使未过旧「晋级线」也进决赛** |
| **C_conf**（报表可标 S1） | conformer 单模 | M1 | 恒进决赛 |

F1/F2 仍为附报，**不进** C_fuse 竞选。同源臂不重复写 CSV。

### 9.2 主读数选择（预注册 · 只看 LOSO Val mean）

```text
决赛池 = {S0, C_fuse, C_pool, C_conf}
内部主读数 = argmax ValAcc(决赛池)
若并列（差 < 0.005）：优先级 C_pool > C_fuse > C_conf > S0
  （偏好：更少弱模、更可解释、更贴近单模排名）
```

**禁止**：因「CSV 标签分布更好看」选主交卷。

### 9.3 对外替换 Exp34 主 CSV（仍须 §12.1）

内部可以宣布「决赛胜者 / 敏感性读数」；**覆盖/宣称** `submission_exp34_e1f_a59_sens_*.csv` 为新主文件前，必须过 §12.1。  
**v0.2.1**：§12.1 未过 → 该文件 **S0 定稿**（不再标未定稿）；S2 等仅附报。

### 9.4 配对显著性（附证 · 不改主交卷规则）

| 项 | 冻结 |
|----|------|
| 单位 | 6 折 LOSO **折上 Acc** 配对 |
| 对比 | C_fuse / C_pool / C_conf **各 vs S0** |

| 臂 | 相对 Exp34 A59-shallow | 变更 |
|----|------------------------|------|
| **H0** | 复现 | 同 Exp34 超参 · 应 ≈0.453 |
| **H1** | 有效 batch↑ | accum 再×2（注意 8GB） |
| **H2** | drop 0.50→0.25 | 减正则 |
| **H3** | patience 20→40 | 更长早停 |
| **H4** | lr 1e-4→3e-4 | 更快拟合（易不稳，fold0 先过） |
| **H5** | 对齐 OpenBMI 3s S3 可读超参差异清单后的「最接近包」 | 登记差异表 |

**对照**：**Hc** = Exp34 conformer 只读 0.511（不重训，除非 H 包改了数据）。

### 10.3 判定

| 结果 | 判定 |
|------|------|
| 最佳 Hx 与 Hc 差距 **&lt; 0.020** | 支持 H-a；可考虑把新 shallow 替入成员池再跑 M2 |
| 最佳 Hx 仍落后 Hc **≥ 0.030** | 支持 H-b；**停止**为官方主路径抬 shallow；shallow 仅作融合配角或可砍 |
| 差距 ∈ [0.020, 0.030) | **灰区**：默认按「不抬升」操作（不替入 M2）；须写明未达 H-a |
| H0 无法复现 ±0.01 | 先用多种子估 σ；若 σ 可解释漂移则不必先修训练链 |

### 10.4 资源闸门

- 先 **fold0** 冒烟全臂 → 仅对 fold0 Val 相对 H0 **≥ +0.02** 的臂开满 6 折  
- 总 GPU 预算建议上限：与 Exp34 轨 A 单成员同级的 **≤ 2 个满折臂**（防止无限配方扫）

## 11. 轨 D · B8 域桥融合诊断（回放 · P1）

### 11.1 目的

检验：热启动是否不仅抬 Acc，还让**融合权重/成员贡献**更接近 OpenBMI。

### 11.2 臂

| 臂 | 数据 | 融合 |
|----|------|------|
| **D0** | B8-scratch 四成员 | 无约束 Val fit（复现 E1f-scratch≈0.523） |
| **D1** | B8-ft 四成员 | 无约束 Val fit（复现 E1f-ft≈0.573） |
| **D2** | B8-ft | F1 式 OpenBMI 冻结 w |
| **D3** | B8-ft | M2 式去 eegnet |
| **D4** | B8-scratch | M2 式去 eegnet |

### 11.3 判定（描述性 + 轻决策）

| 观察 | 含义 |
|------|------|
| D1 的 `w_conformer` 分布相对 D0 下降、shallow 系上升 | 热启动在「拉回 OpenBMI 排名」 |
| D3 ≥ D1 | FT 域上也可砍 eegnet |
| D4 ≥ D0 | 从零 8ch 与 A59 一致：缩池有益 |
