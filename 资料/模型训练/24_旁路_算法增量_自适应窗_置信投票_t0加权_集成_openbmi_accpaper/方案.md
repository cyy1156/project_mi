## 1. 臂 V · 置信/时间加权投票（推理侧 · 零训练）

### 1.1 动机与方法

Acc_paper 的试次过半投票是**均匀投票**；23 证明信息在窗内完备后，试次内多窗是同分布重复观测——加权聚合是最直接的推理侧杠杆。

- 重放 5070 S3 五折 ckpt，dump **val + test 每窗** softmax（`--dump-probs`，§5 格式）。
- 投票权重：`w = p_max^γ · exp(κ·t0_norm)`，`t0_norm=(t0−0.4)/0.6`；网格 γ∈{0,1,2} × κ∈{0,1,2}（含 γ=κ=0 ≡ 现行均匀投票）。
- 试次预测 = 加权票数最大类；Acc_paper 口径不变（仍是试次级 >50% 正确率判定流程）。

### 1.2 判定

| 结果 | 结论 |
|------|------|
| Three ≥ 均匀投票 **+0.5 pp**（paired p<0.1） | 采纳：评测读数与游戏部署投票均换加权版 |
| [+0.2, +0.5) pp | 附报；仅部署侧采用 |
| <+0.2 pp | 维持均匀投票；置信加权在 3s 上无效 |

附报：Task 头同法；逐类先验校正。成本：半天重放。

## 2. 臂 W · 自适应窗长在线递进（cue 锁定 · 1 个五折 + 重放）

### 2.1 动机

已测得的「时刻–精度」标定：1s 窗 0.5615 → 2s 0.5763 → 3s 0.588（实验 20）。3s 已是滑窗协议顶格（4s 窗在 past+可滑约束下退化为固定窗），下一格不是更长窗，而是**按置信度早出**：简单试次早决策省时延，困难试次多等换精度。

### 2.2 模型与数据

- 复用 23 的 **O1s_m / O2s_m**（同锚点集 t0∈{0.4…1.0}、同划分）。
- **新增 O3s_m**：画布 1000pt = past100 + cur750 + zero150（同锚点集；cur750 ⊂ MI 窗 ⇒ t0≤1.0，与 2s 臂完全同锚点 → 被试级严格配对）。泄漏验收沿用 23（shuffle-y / future 扰动 ratio>100 / 推理无 X_full）。
- 一个五折（5090 23 包续跑）。

### 2.3 在线策略（冻结主设计）

- 决策时刻网格：τ ∈ {1.4, 1.5, …, 4.0} s（cue 起 100 ms 步）。
- 各 τ 用**可结束于 τ 的最长窗模型**：τ<2.4 → M1（O1s）；τ∈[2.4,3.4) → M2（O2s）；τ≥3.4 → M3（O3s）。
- 触发：当前窗 `p_max ≥ τ_conf`（全局单阈值，**val 上选定冻结**）→ 立即出该窗预测；τ=4.0 强制出。
- 附报变体：running-vote 触发（触发时用至今同模型窗的多数票）；双阈值（早严晚松）。

### 2.4 读数与判定

读数（新指标，非 Acc_paper）：**决策正确率**（trial 级）+ 决策时刻分布（mean / median / P90）+ 各模型触发占比。

| 对照 | 时刻 | 正确率锚点 |
|------|------|-----------|
| 固定 1s | 1.4 s | ≈ O1s_m 0.5615 |
| 固定 3s | 3.4 s | ≈ O3s_m（待跑） |

判定：**决策正确率 ≥ O3s_m − 0.3 pp 且 E[τ] ≤ 2.2 s** → 成功（较固定 3s 省 ≥1.2 s 时延不掉分）；正确率 ≥ O3s_m → 强成功。失败（正确率掉 >0.3 pp 或时延 >2.6 s）→ 记录置信-正确性失联，W 弃用。

## 3. 臂 T · t0 软降权训练（3s · 1 个五折）

### 3.1 动机与方法

23 的 A1_all（训练锚点解禁）**−1.10 pp（p=0.033）**：晚锚点训练窗是净伤害——trial 尾部标签劣化 / 分布偏移。把该结论正向用在 3s 主线训练：

- 权重：`w(t0) = 1 − α·(t0−0.4)/0.6`，t0∈{0.4…1.0}。
- **主跑 α=0.6**（t0=1.0 窗权重 0.4）；附报 α=0.3 与硬过滤 t0≤0.7。
- 数据 / 划分 / 其余超参全部不动（仅损失按 w 加权）；5070 3s 包加 `--t0-weight α` 开关。

### 3.2 判定

| 结果 | 结论 |
|------|------|
| Three ≥ S3（0.5873）**+0.5 pp** | **回填 3s 训练默认**（主线级改动） |
| [+0.2, +0.5) pp | 附报；部署权重采用 |
| <+0.2 pp | 维持均匀锚点；晚窗伤害未迁移到 3s |

附报：Task 头同法。成本：主 1 五折（~1 h）。

## 4. 臂 E · 三骨干概率集成（3s · 2 个五折）

### 4.1 动机与方法

23 杀死的是「同骨干加模块」；**不同归纳偏置骨干的融合**从未测过——2s 十一模型表成员互有胜负、错误模式不同，且 B5b 已证固定平均 ≈ 可学习混合。

- 成员：**shallow**（= S3 已有）+ **eegnet** + **conformer**（新训两个五折，5070 3s 包加对应 `baseline_*.py`；`run_baseline_main` 为通用 runner，改动机械）。
- 融合（冻结）：**验证折上不加权、测试折概率算术平均** `ḗ = mean_k softmax_k`；**禁止学权重/ stacking**（B5b 教训，亦防 val 过拟合）。
- 成员须同折同划分（同 subject 5-fold、seed 42）；登记各成员参数量与单模成绩。

### 4.2 判定

| 结果 | 结论 |
|------|------|
| 融合 Three ≥ 最优单成员 **+1.0 pp**（paired p<0.05） | **部署候选**（与 V 叠加后进游戏权重清单） |
| [+0.5, +1.0) pp | 附报 |
| <+0.5 pp | 集成在 3s 上无效，结构线彻底封箱 |

附报：两两组合矩阵；Task 头同法。成本：2 五折（~2–3 h）+ 重放。

## 5. 工程要点

1. **dump-probs 统一格式**（V/W/E 共用）：每窗一行 `subject, fold, split(val/test), trial_id, t0, pred, y, p_max, softmax[3]`；三个包各加 `--dump-probs`。回放脚本只读该表，不碰模型。
2. **阈值纪律（防 test 窥视）**：τ_conf（W）、γ/κ（V）、α（T 附报档）全部只在 **val** 上选定、写入登记表后，test 只复评一次。
3. **W 泄漏验收**：O3s_m 沿用 23 三件套；决策回放只用 τ 时刻已发生窗（构造时按 t0+cur≤τ 检查，写单测断言）。
4. **E 同折对齐**：成员 run 的 fold 划分逐被试比对一致（脚本断言），否则该成员重跑。
5. **命名**：3s 腿 out 前缀 `5070_alg_incr_3s_*`；W 腿续 `5090_mech_verify_accpaper`（O3s_m run 名带 `_O3s_m`）。不覆盖任何历史 out。

① V 重放（零训练，半天）            → 免费先做

## 7. 组合性与部署衔接

- **V × E 正交**：集成融合后逐窗概率仍可做加权投票（融合+加权叠加读数登记一版）。
- **T 若胜** → 回填 3s 训练默认 → E 成员后续重训自动继承。
- **W 若胜** → 进游戏部署链（与 09 OTTA 的置信度滤波统一阈值口径）。
- 全部推理侧改动（V/W/E 融合）可与 08-E / 09 的 EA·AdaBN·门控叠加，顺序：先权重/训练侧（T、E），后推理侧（V、W、OTTA）。
