## 0. 想法冻结

### 0.1 一句话

在 **不改 Shallow 时空卷积与池化头** 的前提下，于输入 `(B, C=8, T)` **之前（最前）** 插入通道注意力，让网络先学「哪几个导联更重要」，再进原版 Shallow：

| 臂 | 模块 | 来源 |
|----|------|------|
| **A · SE** | Squeeze-and-Excitation | Hu et al., CVPR 2018 |
| **B · ECA** | Efficient Channel Attention | Wang et al., CVPR 2020 |

「沙漏 / shallow」在本方案中统一指 **braindecode `ShallowFBCSPNet`**（本室正式浅层骨干）。

### 0.2 为什么是「前面」而不是池化后

| 接法 | 含义 | 本方案 |
|------|------|--------|
| **前置（冻结）** | 对 **8 个 EEG 导联** 做通道重加权 → 再进 CombinedConv | **采用** |
| 中置（BN 后） | 对 40 个滤波器响应做注意力 | 附录可选；主报不做 |
| 后置（Log 后） | 对池化后特征做注意力 | 附录可选；主报不做 |

前置动机：MI 判别常依赖 C3/C4 等少数导联；用 SE/ECA 显式标定通道，参数极少，适合 8ch 小样本。

### 0.3 结构草图

```text
输入 X ∈ R^{B×8×T}     （本室 hop100 窗，协议内预处理不变）
        │
        ▼
   ┌─────────┐
   │  SE 或   │  仅通道维；输出同形 (B,8,T)
   │  ECA     │
   └────┬────┘
        ▼
   ┌─────────────────┐
   │ ShallowFBCSPNet │  与正式同超参（默认核/池化/drop）
   │ CombinedConv →  │
   │ Square→Pool→Log │
   │ → 分类头        │
   └────┬────────────┘
        ▼
     Softmax / CE
```

**SE（臂 A）**

```text
(B,8,T) → GAP 沿 T → (B,8)
       → FC↓ (8→8/r) → ReLU → FC↑ (8/r→8) → Sigmoid
       → 广播乘回 (B,8,T)
```

- 默认 **reduction r=2**（C=8 时 r=4 会过窄；r=2 隐藏维=4）。  
- 无空间/时间卷积支路。

**ECA（臂 B）**

```text
(B,8,T) → GAP 沿 T → (B,8)
       → 1D Conv（k 自适应或固定 k=3）→ Sigmoid
       → 广播乘回 (B,8,T)
```

- **无降维 FC**；跨通道局部交互。  
- C=8 时推荐 **k=3**（或论文自适应公式取奇数）。

## 2. 实验臂顺序

```text
S0  原版 Shallow 复现锁（或只读正式 0.694/0.540）
 → A0 SE 冒烟（1–2 ep / fold0）
 → A1 Shallow+SE fold0（Task+Three）
 → B0 ECA 冒烟
 → B1 Shallow+ECA fold0
 →（弱有用）A2 / B2 五折
 →（可选附录）中置/后置 SE·ECA；r 与 k 敏感度
```

| 臂 | 结构 | 说明 |
|----|------|------|
| S0 | 原版 Shallow | 协议锁；可复用正式数或旁路自跑 |
| A1 | **SE → Shallow** | 主臂 1 |
| B1 | **ECA → Shallow** | 主臂 2 |
| A2 / B2 | 同上 · 五折 | 门控后 |

### 本阶段不做

- 改正式 shallow 权重 / 正式表  
- 同时上 SE+ECA+CBAM 大杂烩  
- 把方案 13 CIACNet 与本臂绝对值夺冠  
- 用 P 轨 BCI2a 被试内配置冒充本室 L 结论

## 3. 成功线（相对同协议原版 Shallow）

以 **S0 / 正式 shallow** 为锚：

| 等级 | Three | Task 护栏 |
|------|-------|-----------|
| **弱有用** | ≥ 锚 +**1.0pp** | Δ ≥ **−1.0pp** |
| **达标** | ≥ 锚 +**1.5pp** | Δ ≥ **−1.0pp** |
| **阴性** | 两端均无实质增益 | 停五折扩扫 |

两臂比较：若仅一臂达标，主推该臂；若均达标，报 Δ 与参数量，选更稳（五折 std 更小）者。
