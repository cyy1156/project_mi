## 0. 一句话目标

用分析臂 **真 ERD / laterality** 产出 **可教试次清单**，再在该清单上：  
**(B0) 固化名单** → **(B1) 只评不训，量现有权重天花板** → **(B2 可选) 冻骨干/小 lr 子集微调**。  
主模型默认 **正式 shallow**；附报 eegnet（同权重协议）。主看 **条件 Acc_paper（Three / Task）** 与伪在线可用性，不改正式全库均值叙事。

| 问 | 本臂约定 |
|----|----------|
| 做什么？ | 清单 + 子集评估 +（可选）子集 FT |
| 质量分从哪来？ | find_best_trail / 分析臂（无窗内 z-score） |
| 评什么权重？ | 正式 5060 `best_task.pt` / `best_three.pt`（按折） |
| 与 05 | 05 结案阴性；本臂 **不** 继续堆通道 |

## 1. 动机（承接 05）

| 05 结论 | 本臂对策 |
|---------|----------|
| A1 差模通道 ≈ 无效 | 不再改输入张量 |

## 2. 协议冻结

### 2.1 数据与指标（与正式一致处）

| 项 | 取值 |
|----|------|
| 推理/微调数据 | `preprocess_lab/out/openbmi_2s_hop100`（含窗内 z-score；与正式训练同） |
| 切窗 | 2s / hop100 · `(N,1,8,500)` @250Hz |
| Acc_paper | 与 04_5060 / 正式表 **同定义**（试次级聚合） |
| 折 | 被试独立 5 折 · seed=42 · 与正式 shallow 同折划分 |
| 设备 | RTX 5060 · 评估可 CPU/GPU；FT 用 Fast |

### 2.2 质量分与清单（与训练 npy 解耦）

| 项 | 取值 |
|----|------|
| 分析标准 | `OpenBMI_MI_feature_v2_hop100`（见 find_best_trail 方案） |
| 语料 | **仅** `EEG_MI_train`；sess01+sess02 同人合并 |
| z-score | 算 ERD/laterality 时 **不做**窗内 z-score（从 mat 重切或分析缓存） |
| **禁止** | 用 hop100 训练 npy 的绝对功率直接算 ERD%；用 05 `trial_quality` 假代理作本臂主分 |

几何与 hop100 **对齐**（通道序、2s、hop100ms），仅分析臂去掉窗内 z-score；清单需带 **hop100 窗索引映射** 字段，供 B1/B2 使用。

### 2.3 冻结的「明显」12 人（v2 hop100 · 54 人报告）

```text
openbmi:subj03, 04, 06, 17, 18, 19, 32, 33, 36, 38, 44, 45
```

若日后重跑分析导致总评变化：**升版清单版本号**，本方案表格不静默改写；新旧版本分目录存档。

### 2.4 试次级合格线（可教 · teachable）

在被试总评 ∈ {**明显**, **中等**} 内，按 **该试次所属手**（left/right）计分（与分析臂同侧指标）：

| 规则 ID | 条件 | 用途 |
|---------|------|------|
| T0 入池 | `subject_tier ∈ {明显, 中等}` | 弱被试默认不进可教池 |
| T1 核心 | `mu_erd_contra ≤ −15%` **且** `laterality ≥ 8`（百分点） | **teachable=true** 主线 |
| T2 模板级 | T1 且（`mu_erd_contra ≤ −35%` **或** `time_pattern` 通过） | `template_grade=true` |
| T3 高 laterality 评测子集 | 明显 12 人 ∩（该试次 `laterality ≥ 8`）；若某被试无试次过线则该人本臂「高 lat」为空 | **B1 第三行** |

说明：

- 试次分优先用 **试次内 hop 聚合**（与分析脚本一致：对侧 Mu 曲线 / 试次级 ERD），再映射到该试次下全部 hop100 窗。  
- B1「高 laterality」默认 = **明显12 ∩ laterality≥8**（可含未过 T1 的 mu_erd，但登记表须注明条数）。  
- 主报同时给出 **明显12 ∩ T1** 作为敏感性行（可选第四行）。

## 3. 三相顺序（严格）

```text
B0_teachable_list → B1_subset_eval_frozen_weights → B2_subset_finetune（仅当 B1 支持）
```

### B0 · 可教试次清单（必须先做）

**目的**：对齐 find_best_trail §6.1–6.2；为伪在线/模板/B1/B2 提供唯一权威名单。

**产出**（建议路径）：

| 文件 | 内容 |
|------|------|
| `find_best_trail/out/teachable_trials_v1.json`（或 csv） | 逐试次记录 |
| `find_best_trail/out/teachable_trials_v1_README.md` | 阈值、复跑命令、版本 |
| 可选 `template_features_v1.npz` | 模板特征向量（非 raw μV） |

**每行必含字段**：

| 字段 | 说明 |
|------|------|
| `subject_id` | `openbmi:subjNN` |
| `subject_tier` | 明显 / 中等 / 弱 |
| `subject_pass_rate` | 总评通过率 |
| `trial_uid` | 可回溯（sess / trial 序 / cue 时间） |
| `hand` | left / right |
| `mu_erd_contra` | % |
| `laterality` | 百分点 |
| `time_pattern_ok` | bool |
| `teachable` | T1 |
| `template_grade` | T2 |
| `rank_in_subject_hand` | 同被试同手内按 laterality 降序 |
| `hop100_window_ids` | 映射到 `openbmi_2s_hop100` 的样本下标列表 |
| `schema_version` | `teachable_v1` |

**本相不做**：训练、改权重、改正式表。

**验收**：54 人可复现；明显 12 人名单与 §2.3 一致；teachable 条数 > 0 且左右手均有覆盖；映射抽检 ≥ 20 条 cue 对齐无误。

---

### B1 · 子集上评估现有权重（只评不训）

**目的**：量条件天花板——「好样本上现有模型能到多高？」

**权重（冻结路径，勿覆盖）**：

| 模型 | 约定 |
|------|------|
| shallow（主） | `train_lab/out/5060_baseline_openbmi_2s_hop100_accpaper/shallow_openbmi_2s_hop100_balbatch_accpaper/` 各折 `best_task.pt` / `best_three.pt` |
| eegnet（附） | 同协议正式 run |

**评测子集（每折 Test 内再筛）**：

| 行号 | 子集 | 含义 |
|------|------|------|
| R0 | 全库 test | 对照正式表（应复现量级） |
| R1 | test ∩ 明显 12 人 | 被试级条件 Acc |
| R2 | test ∩ 明显 12 ∩ laterality≥8 试次 | 高偏侧试次天花板 |
| R3（可选） | test ∩ T1 teachable | 与清单主线对齐 |

**报表要求**：

- Task / Three **Acc_paper** 五折 mean±std；附每折 **被试数 / 试次数**（避免空集伪精度）。  
- Three 附 left/right Recall 与 left↔right 混淆（至少 R1、R2）。  
- **泄漏禁令**：清单与质量分可用全 train 语料统计（分析臂本就仅 EEG_MI_train）；评估权重时 **不得** 用 test 标签调阈值。阈值已在 §2.4 冻结。

**决策门槛（是否开 B2）**：

| 观察 | 动作 |
|------|------|
| R2 Three − R0 Three ≥ **+0.03**（或 R1 ≥ +0.02）且试次数充足 | **建议开 B2** |
| 差值 ∈ [+0.01, +0.03) | 可开 B2 但缩小 scope（仅 head / 更短 epoch） |
| 差值 < +0.01 或 R2 接近随机 | **不开 B2**；转向伪在线门控 + 模板（只用 B0） |

数字为旁路启发式，不是正式夺冠线。

---

### B2 · 子集微调（可选 · B1 通过后）

**目的**：用可教/高 lat 试次小步适配，避免 A2 全库重加权。

| 项 | 取值 |
|----|------|
| 起点 | 正式 shallow（主）对应折 `best_*.pt` |
| FT 池 | **仅该折 train 被试** 内：`teachable`（T1）或「明显∩laterality≥8」；写死一种，默认 **T1** |
| Val | 该折原 val 被试；早停主指标 Acc_paper；另记录 FT 池内 val 曲线（不用于改门槛） |
| Test | 该折 test：**全库 R0 + R1 + R2** 三行都报 |
| 优化 | **默认冻骨干**（时空卷积），只训分类头；备选整网 lr=1e-5 |
| 预算 | max_epochs≤50 · patience≤10 · batch 与正式同量级 |
| 蒸馏 | **本版不做**；列入 v2 |

**成功线（旁路）**：

| 指标 | 要求 |
|------|------|
| R2 Three | 相对同权重 B1 的 R2 **≥ +0.01** |
| R0 Three（全库） | 相对正式 / B1-R0 **≥ −0.005**（不显著伤全库） |
| Task R0 | **≥ −0.01** |

任一「伤全库」超线 → 记阴性，权重不晋升；清单与门控仍保留。

**明确不做**：从零全库重训；弱被试等权灌入 FT；05 A2 式全库加权 CE。

## 4. 与伪在线 / 模板的接口

B0 清单直接服务：

1. **模板库**：`template_grade=true` 试次 → 特征向量（功率/ERD 曲线等，非 μV）。  
2. **推理门控**：伪在线滑窗多数票时，可丢弃 laterality 过低窗 → **已开旁路** [`../../伪在线实验/03_旁路_teachable质量门控/方案.md`](../../伪在线实验/03_旁路_teachable质量门控/方案.md)（P1 OpenBMI 校准 → P2 游戏在线门控）。  
3. **会话内 FT 选样**：前半只取 teachable 试次（对齐伪在线 02 思路时引用本清单版本；列 03 方案 v2）。

本臂 **不** 改写伪在线 01/02 冻结表；门控数字只进 03 登记表。
