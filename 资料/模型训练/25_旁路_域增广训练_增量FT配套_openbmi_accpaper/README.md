# 25 · 旁路 · 域增广训练 + 增量 FT 配套（OpenBMI→Stieger 跨库）

> **完整方案**：[`方案.md`](./方案.md)（**v1.1-5090 本机执行**）  
> **结果登记**：[`总结/结果登记表.md`](./总结/结果登记表.md)  
> **决策来源**：用户部署工作流 = 全量 FT · 小模型 · 新用户采集时**少量多次增量微调**（在已微调权重上继续）→ meta-learning 的"省算力/省步数"卖点贬值，**增广优先**（改善出厂起点 + 全程正则）；辅以两个与该工作流强耦合的配套臂（REPLAY 回放 / FT 轻增广）。

**5090 本机要点（2026-08-23 冻结）**

| 项 | 设定 |
|----|------|
| Stieger 数据 | ✅ `code/preprocess_lab/out/stieger_3s_hop100`（含 `stieger_X_noz.npy`） |
| A0 权重 | **5090 自训 S3** `run_20260823_095327`（0.5839±0.027） |
| G1 护栏 | vs **5090 S3 − 1 pp**（≥ 0.5739） |
| 跑序 | **G1 → G1 评测 → G2 → G3 → A0（末段）** |
| out | `5090_aug_3s_accpaper` · `--train-device 5090` |

| 臂 | 一句话 | 成本 | 主判定 |
|----|--------|------|--------|
| A0 锚点 | **5090 S3** + **增量爬坡曲线**（**G 系列跑完后末段执行**） | 复用权重 + 1 次评测 | G1−A0 爬坡对比 |
| **G1 域增广离线训练** | OpenBMI 3s 五折 + 冻结增广集（噪声/时移/通道 dropout） | 1 个五折 | Stieger 零样本 ≥ +2 pp；爬坡早期 ≥ +2 pp；域内护栏 ≥ −1 pp |
| G2 = G1 + REPLAY | 用户增量 FT 每步混 10–20% 源域窗回放（防遗忘/防漂移） | FT 侧变体 | 爬坡后期不衰退（k 大处 ≥ G1） |
| G3 = G1 + FT 轻增广 | 用户 FT 时也加轻量增广（少样本正则） | FT 侧变体 | 早期爬坡 ≥ G1 |

**关键工程事实（阶段 0 已核实）**：现行管线**逐窗 z-score** → 幅度类增广会被归一化抵消；增广须在**归一化之后**施加，集以噪声/时移/通道 dropout 为主。这也意味着 17 pp 域间隙**不是**边际幅度差（z-score 已消掉），而是噪声水平/时间对齐/通道质量/协方差结构——增广集正对这些。
