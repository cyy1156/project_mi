## 0. 一句话目标

fnz 只有 3 session、窗数 ~200–350，无法区分「策略不行」与「样本太少」。  
实验 29 在 **同一 OpenBMI 3s 底座 + Exp27 统一 FT 策略** 下，对 **5 名 Stieger 被试 × 3 个 MI session** 做离线 FT 网格，回答：

1. **大样本下** B2（T0-36 · replay=0.10 · 全模型）是否稳定？  
2. **单 session FT**（Track S）与 **合并 FT**（Track M）孰优？  
3. heldout 高是否等于 **下一场 session 在线** 更好？（复现 Exp27 教训）

---

## 1. 为什么用 Stieger Cue 而不是反馈段 / BCI2a

| 选项 | 结论 |
|------|------|
| **Stieger 反馈段**（`stieger_3s_hop100`） | Task 取自闭环反馈段，与 fnz **open-loop Cue MI** 域不一致 → **不作主实验** |
| **BCI2a T** | 范式对齐，但仅 9 人、无自然 3-day session → 不适合本实验主设计 |
| **Stieger Cue 段**（`stieger_cue_3s_hop100`） | Task = **Cue 后 0–4 s**，Rest = **Cue 前 4 s**，与 OpenBMI/fnz **同口径**；62 人 × 多 session |

| `subjects` 键 | `S{n}|Session_{m}`（例 `S1|Session_2`） |

## 3. 实验设计（镜像 Exp27 双轨）

### 3.1 Track 定义

| Track | FT 训练 session | 模拟场景 | 在线评估 session |
|-------|-----------------|----------|------------------|
| **S** | 仅 Session_2 | 第一次 FT 后进入 Session_3 | Session_3 |
| **M** | Session_2 + Session_3 合并 | 合并 FT 后进入 Session_4 | Session_4 |

每被试每 track 独立跑网格；共 **5 被试 × 2 track × N arms**。

### 3.2 划分（固定）

| 项 | 取值 |
|----|------|
| train / heldout | **Cue 级 70 / 30** · `seed=42` |
| `split_id` | `{subject}|{session}|trial_id` |
| heldout | **仅本被试、本 track 所含 session 的窗** |
| 在线评估 | **整 session 留作 forward**（Session_3 或 4），不参与 train/heldout |

> 不用 `split_cues_half`（50/50）；与 Exp27 / `ft_subject_from_v3` 一致。

### 3.3 固定 FT 策略（与 Exp27 拍板相同）

| 项 | 取值 |
|----|------|
| 底座 | `run_20260822_094942` · `best_{task,three}.pt` |
| Replay 池 | **T0-36** · `openbmi_3s_hop100_t0` |
| 默认冠军臂 | **B2** · `pool=t0` · `replay_ratio=0.10` · 全模型 · 5 epoch |
| 超参 | `lr=1e-4` · `wd=1e-4` · `batch=32` · `seed=42` |
| 标签 | 预处理 `y_three`（Rest=0/Left=1/Right=2） |
| 门控 | G1–G4 **仅发布参考**；不阻断写盘 |

### 3.4 网格臂（首轮）

| arm | pool | replay_ratio | head_only | 说明 |
|-----|------|--------------|-----------|------|
| A0 | none | 0 | 否 | 无 replay 基线 |
| B1 | t0 | 0.05 | 否 | ratio 扫描 |
| **B2** | **t0** | **0.10** | **否** | **Exp27 统一策略** |
| B3 | t0 | 0.15 | 否 | ratio 扫描 |
| B4 | t0 | 0.20 | 否 | ratio 扫描 |
| E1 | none | 0 | **是** | 冻 head 对照 |
| F-A0 | none | 0 | 否 | 窗数下采样 ≈ fnz（~310 窗）对照 |
| F-B2 | t0 | 0.10 | 否 | 下采样 + 统一策略 |

首轮：**5 × 2 × 8 = 80 runs**（脚本：`experiment_game/tools/exp29_stieger_cue_replay_grid.py`，待实现）

## 4. 主指标与验收

| 优先级 | 指标 | 说明 |
|--------|------|------|
| P0 | **下一场 session 在线 trial acc** | 比 heldout 更贴近部署 |
| P1 | heldout three acc + 三类 pred | 与 Exp27 可比 |
| P2 | train − heldout · max_class_frac | 过拟合 / 塌缩 |

**成功判据（实验级，非单臂硬门槛）：**

- 多数被试 Track M + **B2** 在线 ≥ **0.45** 且三类均有 pred  
- 若大样本下仍普遍 < 0.40 → 更支持「OpenBMI→新被试域移」为主因，而非 fnz n 过小  
- 若仅 F 臂（~310 窗）接近 fnz 而全量窗远优 → 支持「fnz 样本量不足」

| 实验 | 数据 | 目的 |
