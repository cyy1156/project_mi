## 0. 一句话目标

在 **嵌套融合准则** 下，把官方主交卷的成员池从「继承自 OpenBMI 的四骨干」重选为 **跨结构家族 ∪ 跨输入视角（B8-ft / C1-45）∪（可选）时间半窗** 的去相关池，并用嵌套贪心决定留谁；过线则替换主 CSV，否则结案阴性并保留 37/36 结论。

## 0.1 为何开 38（证据前提 · 只读）

| 证据 | 含义 |
|------|------|
| Exp35 M2：砍 eegnet 显著掉点，但 eegnet 单模最弱 | 成员价值 ≠ 强度，= 对融合补的**相关性缺口** |
| Exp36 P1：同结构多种子扩池 −3.4pp | 同家族无多样性，只加参数与过拟合 |
| Exp36 M7 / M7_ABC：+4.7~6.8pp（8ch-ft、45ch-C1） | 真正付钱的是**输入视角差**，不是骨干差 |
| Exp35 M4 {C,E}=0.528 > 单模 C | 强弱搭配只要家族不同就能涨 |
| 官方集只训过 shallow / shallow_b / eegnet / conformer | 「四成员」是继承名，不是搜出来的 |

→ **重选目标函数必须换掉**：不再最大化单模 Acc，而是最大化 **嵌套融合 Val**（误差去相关的可操作代理）。

## 3. 协议冻结

| 项 | 值 |
|----|-----|
| 数据 | 主：`challenge_mi_3s_59ch`；跨域成员用既有 8ch / 45ch dump |
| 划分 | LOSO6 · 1 trial=1 窗（半窗仅改时间切片，标签与 trial 对齐） |
| **选池准则** | 嵌套融合 Val：折 \(k\) 用其余 5 折 Val 拟 T/w → 折 \(k\) 评估；回报 6 折 mean |
| **贪心** | 从最强单模（嵌套单模 Acc）起；每次加入使嵌套融合增益最大的候选；**单步增益 &lt;0.5pp 停止** |
| 统一入池 | 一次 E1f over 选中池；禁止「先轨内 E1f 再跨轨」作为主报（该结构仅作对照臂 **U0**） |
| 参数纪律 | 默认池 ≤**6**；若贪心想留更多 → 改用分组（同族共享 T、跨视角组共享 w）或 5 折 pooled（750）拟 T/w |
| 约束 | 跨域组权重可设上限（继承 36：`w_B8≤0.4`，`w_C1≤0.5`）作敏感性；主报先无额外上限的嵌套版，附报带 cap |
| 主检验 | 与 **Exp37 同尺**：嵌套 6 折 Δ vs 对照锚 ≥+1pp **且** Wilcoxon p&lt;0.05 |
| 辅证 | McNemar + 被试 cluster bootstrap（同 37 v0.2） |

### 3.1 嵌套贪心伪代码

```text
anchor = Exp37 定稿栈的 nested 折外预测  # 或 nested-S0
pool = {seed}  # seed = 嵌套单模 Acc 最高者（通常 conformer@A59）
candidates = 家族新训 ∪ 现有四成员 ∪ B8-ft ∪ C1 ∪ (可选半窗)
while True:
  best, best_gain = None, 0
  for c in candidates \ pool:
    score = NestedE1fAcc(pool ∪ {c})
    gain = score - NestedE1fAcc(pool)
    if gain > best_gain: best, best_gain = c, gain
  if best is None or best_gain < 0.005: break
  pool = pool ∪ {best}
# 主报 pool；对照：U0=两级 M7 式；S_full=一次性大池未贪心截断（附报，受参数纪律约束）
```

## 5. 预注册决策规则（跑数前冻结）

```text
G* 过线 ⟺
  (A) nested_mean(G*) − nested_mean(A0) ≥ +0.01
  (B) Wilcoxon(nested_fold_accs_G*, nested_fold_accs_A0) p < 0.05

过线 → 换主 CSV 为 G* 栈；旧 CSV 归档；技术报告写「误差去相关选池」。
不过线 → 维持 A0 对应交卷；38 结案阴性/弱阳性。

平局 / 多臂：
  · 主报只认 G*；U0/F1/V1/H1 不直接竞选换卷。
  · 若 G* 与 U0 嵌套差 <1pp → 取参数更少、工程更简单者（通常 U0 或更小池），
    并在登记表注明「视角补丁已足够，家族搜索未追加」。
```

辅证（McNemar / cluster bootstrap）规则同 Exp37 v0.2：CI 含 0 或单被试驱动 → 登记风险，**不**单独否决主读数，但换卷须勾选知情。
