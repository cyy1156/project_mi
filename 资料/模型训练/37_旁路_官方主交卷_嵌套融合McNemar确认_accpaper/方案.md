## 0.1 为何开 37（对 36 的尺子诊断 · 只读）

Exp36 三次撞上 **Wilcoxon p=0.0625**：

| 机制 | 说明 |
|------|------|
| fold0（Val=S01）病态 | 150 试次上拟合跨流参数失败 → 额外路径权重塌回 0 → 该折 Δ≡0 |
| 符号秩掉到 n=5 且全正 | 精确双侧地板 = \(2/2^5=0.0625>0.05\) |
| 「可退化到 S0」的臂 | 在折内拟合尺子下几乎不可能过线 |

复算（盘上 fold Acc）：

| 臂 | Val（折内 in-sample） | 逐折 Δpp vs S0 | Wilcoxon | 配对 t |
|----|----------------------|----------------|----------|--------|
| M7 | 0.604±0.084 | [0, +6.7, +4.7, +11.3, +4.0, +1.3] | 0.0625 | ≈0.037 |
| M7_ABC | 0.626±0.095 | [0, +9.3, +4.7, +19.3, +6.0, +1.3] | 0.0625 | ≈0.064 |

**v0.2 关键洞见**：fold0 的 Δ=0 是 **拟合失败产物**，不是「融合无效」。嵌套后 fold0 的 θ 改用其余 5 折（750 试）拟合 → **塌缩大概率消失** → n 回到 6 → Wilcoxon 精确地板降至 \(2/2^6=0.03125&lt;0.05\)。因此嵌套不只是伪影检查，**有机会一次解开显著性墙**。

反面同样预注册：若嵌套后 Δ 从 +6.8pp 缩到 +2~3pp 甚至 &lt;1pp → 说明原读数含大量 150 试次 in-sample 水分——**亦为有效结案**。

## 3. 协议冻结

| 项 | 值 |
|----|-----|
| 划分 | 官方 LOSO6 · 1 trial=1 窗 · 与 34/36 相同 |
| 对齐 | `val_idx` / `val_y`；概率级融合，禁止通道拼接 |
| **嵌套** | 折 \(k\)：其余 5 折 Val（750）拟全部 θ → 折 \(k\)（150）评估 |
| θ | 各轨 E1f 的 T+成员权重 + 跨轨流权重（及流温度，沿用 36 网格） |
| 约束 | `w_B8≤0.4`；`w_C1≤0.5` |
| **主检验** | 嵌套 6 折 Acc：候选 vs N0 的 **配对 Wilcoxon 双侧**（α=0.05） |
| **辅证** | （1）pooled 900 试次 **McNemar 精确二项双侧**；（2）**被试级 cluster bootstrap**（6 被试有放回 ≥2000 次）报 Δ 的 95% CI |
| 必登 | 每折拟合出的流权重（专看 fold0 是否仍塌缩到 w_extra=0） |
| 附报 | 配对 t；与 Exp36 折内数对照表 |

### 3.1 嵌套伪代码

```text
for fold k in 0..5:
  fit_pool = concat(val of folds ≠ k)          # 750
  θ_k = FitFusion(fit_pool)                    # under caps
  pred_k = Apply(θ_k, val of fold k)           # 150 OOF
  record w_streams[k]                          # fold0 塌缩诊断
nested_accs = [Acc(pred_k) for k]
Wilcoxon(nested_accs_arm, nested_accs_N0)
# 辅证
McNemar(concat(pred), concat(pred_N0), y)
ClusterBootstrap_subjects(Δ, n_boot≥2000)
```

## 5. 预注册决策规则（跑数前冻结 · 禁止事后改）

### 5.1 主路径（唯一默认换卷臂）

```text
N7 过线 ⟺
  (A) nested_mean(N7) − nested_mean(N0)  ≥  +0.01
  (B) Wilcoxon_two_sided(nested_fold_accs_N7, nested_fold_accs_N0)  p < 0.05

过线 → 换主 CSV 为 N7 栈（写 submission_exp37_*）；旧 S0 CSV 归档不删。
不过线 → 维持 S0；进入 §5.2 / §5.3 结案分支。
```

### 5.2 附报升级（仅当主路径已过线）

```text
仅当 N7 已过线 且
  nested_mean(N7_ABC) − nested_mean(N7) ≥ +0.01
时，才「升级讨论」是否改用三流（须同时看 cluster-bootstrap CI 是否被单一被试驱动）。
N7_AC / N7b 同理只作附报；N7b 与 N7 嵌套差 <1pp 时取参数结构更简单者（通常同构 → 记稳健）。
```

### 5.3 两种结局都预写处置

| 结局 | 处置 |
|------|------|
| N7 过线 | 换 CSV；辅证写入登记表；技术报告写嵌套协议 |
| 嵌套 Δ≥1pp 但 Wilcoxon 仍 p≥0.05（少见） | **不换**；附报 McNemar/CI；结案弱阳性 |
| 嵌套 Δ&lt;1pp（涨点缩水） | **不换**；结案：36 的 +4.7~6.8pp 含显著折内水分；M7 家族敏感性附报 |
| fold0 嵌套后仍塌缩 | 登记；主检验仍按 6 折（含可能的 0）；不改规则 |

**提交窗口兜底**：来不及等 37 → **继续交 S0**；37 留档供修改窗口/决赛升级。
