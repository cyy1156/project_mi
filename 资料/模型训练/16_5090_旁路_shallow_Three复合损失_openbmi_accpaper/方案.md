| 项 | 5060 | **5090** |
|----|------|----------|
| `num_workers` | 0 | **4** |
| `batch_train` / `batch_eval` | 128 / 256 | **256 / 512** |
| `pin_memory` | False | **True** |
| `keep_fold_packs` | True | False |
| H* 默认折数 | fold0 | **五折**（`--max-folds 0`） |
| 推荐入口 | 单臂 fold0 | **`chain_all.py` 全链** |

### 与本机并存其他 GPU 任务时（勿关其他任务）

默认 `batch_train=256` 会占满显存。若同卡还有别的训练，请 **显式降 batch / workers**，例如：

```powershell
python run_arm.py --arm S0 --max-folds 1 --batch-train 128 --batch-eval 256 --num-workers 2
```

全链前可在 `chain_all.py` 的 `STEPS` 里为各步追加 `--batch-train 128` 等（或等独占 GPU 再跑全量五折）。

读数：与 5060 相同，建议 `squeeze_raw_2s_openbmi`（`openbmi_X_raw8_f16.npy`）；协议与 seed=42 对齐以便对照。
