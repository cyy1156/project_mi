## 2. 与现行「采集主线」的对齐 / 差异（必须写清）

### 2.1 对齐项（保持不变）

| 项 | 现行 OpenBMI / 在线 | 本方案官方集 |
|----|---------------------|--------------|
| 滤波链 | CAR → notch 50 → bandpass **8–30** | **同**（在 **单 trial 750 点**上做） |
| 窗长 | 3 s = 750 点 @250 Hz | **同**（官方 trial = 一整窗） |
| 窗内归一化 | per-channel **z-score** | **同**（trial 内） |
| 标签语义 | Rest / Left / Right 三分类 | **同**（编码 2/0/1 与线上 `{0,1,2}` 对齐：方案内统一 `y=0 Left, 1 Right, 2 Rest`） |
| 训练配方 | Adam · lr/wd `1e-4` · drop 0.5 · batch 256/512 · AMP · balbatch · patience 20 · Val Acc 早停 · seed 42 | **同**（见 §6.4） |
| 骨干 | ShallowFBCSPNet +（线上）E1f 四成员 | **同构重训**（§6；通道改为 59） |
| 融合 | 温度校准 + val 加权 | **同**；温度/权重在 **本数据 Val 上重拟合**（不照搬 OpenBMI 数值） |
| 读出 | F5：因果平滑 lookback=2 + 多数票 | **接口对齐**；本数据 1 trial=1 窗 → 平滑退化为恒等，pred=argmax(融合 p) |

### 2.2 差异项（由官方范式决定，不得硬套 hop100）

| 项 | 现行 OpenBMI / 采集 | 官方集 | 本方案裁决 |
|----|---------------------|--------|------------|
| 段长 | Cue 后 MI **4 s** 内 hop100 | 每 trial **恰好 3 s** | **1 trial = 1 窗**；不做 trial 内 hop100 |
| Rest | 专用间隔 Rest | trigger `204` | 直接用 Rest trial |
| 通道数 | 8 | **59 EEG** | 主路径 59；旁路 8（Pz→CPz） |
| CPz | 有 | **无，有 Pz** | **已冻结：Pz → CPz 槽** |
| 划分 | Subject **5-fold** | 仅 6 名 train 被试 | **被试级 6-fold LOSO**（每折 Train5 / Val1，对齐「五折精神」）（§3） |
| t_shallow 的 t0 降权 | 滑窗 t0 加权 | 无多窗 t0 | 见 §6.2（多样性替代，保留四成员槽位） |

> 官方每 trial 单窗 → 试次 Acc = 窗 Acc。登记 Three Acc + recall / specificity / 混淆矩阵。

## 3. 划分协议（冻结 · v0.2）

### 3.1 结论先说

| 问题 | 裁决 |
|------|------|
| 要不要五折？ | **要被试级交叉验证**。6 人 → 做 **6-fold LOSO**（每折 = 你说的「5 人训 / 1 人验」轮转），与 OpenBMI Subject 5-fold **同纪律**。 |
| Val 随机抽 trial 更好吗？ | **不更好，禁止作为主协议**。随机窗/试次级 Val 会把同一被试分进 Train+Val，**被试泄漏**，虚高且与采集/OpenBMI「被试独立」不一致。 |
| 官方 test | S07–S08 始终盲测；**调参只看 LOSO Val**；submission 只导出一次（或固定脚本一键重导）。 |

### 3.2 主协议 · 被试 6-fold LOSO（对齐采集侧「五折」）

对 `k ∈ {S01…S06}`：

| 集合 | 定义 | n_trial |
|------|------|---------|
| Train | 其余 5 名被试全部 block | 750 |
| Val | 被试 `k` 全部 block | 150 |
| Test | S07–S08（所有折共用，无标签） | 120 |

- 每折独立训练（含早停看该折 Val）。  
- **主报表**：6 折 Val Acc / macro-R / macro-S 的 **mean±std**（对标 OpenBMI 五折汇报习惯）。  
- seed=42；折序固定 S01→…→S06。

### 3.3 提交模型（盲测 CSV）怎么从 6 折得到

任选其一（批准时勾死；推荐 **S-ens**）：

| 策略 | 做法 | 优点 |
|------|------|------|
| **S-ens（推荐）** | 6 折各出最优 ckpt，对 test 概率 **算术平均**（或按 Val Acc 加权）再 argmax | 不浪费数据；稳 |
| S-retrain | 超参见 6 折（epoch/融合）冻结后，**6 人全量重训**一轮，early-stop 改用「6 折平均 Val 曲线」或固定 epoch=median(stopped) | 单模型部署简单 |
| S-pick | 只取 Val 最高那一折的 5 人模型直接推 test | 简单但浪费、偏置大 → **不推荐** |

E1f 四成员：每位成员各自做 LOSO；融合温度/权重 **在每折 Val 上重搜**（网格与方案 26 同族，步长可略粗以省时间）。

### 3.4 泄漏红线

- Val 被试样本不得进该折 Train。  
- **禁止**把 6 人 trial 随机打乱抽 20% Val。  
- 标准化统计量仅用该折 Train 估计。  
- 禁止用 test 调参 / 多次人工改 CSV 碰运气。

## 5. 预处理流水线（逐 trial）

官方要求 + OpenBMI 对齐：

```text
对每个 trial 切片 signals[:, start:start+750]   # 先切，禁止跨 trial 滤波
→ 选通道（A59 或 A8 映射）
→ CAR（仅所选 EEG 通道上）
→ notch 50 Hz（实现与 preprocess_lab notch_and_bandpass 同族）
→ bandpass 8–30 Hz
→ per-channel z-score（本 trial 750 点内）
→ float32 窗
```

实现约束：

- 滤波器状态 **每个 trial 重置**（或用 filtfilt 零相位且仅在 750 点内）。  
- 与 OpenBMI 训练 fs=250 输出一致，**无需再重采样**。  
- 不做官方未要求的 0.5–45 采集端预滤波。

## 6. 模型栈 · 对标采集系统（冻结意图）

### 6.1 与采集系统一一对应

| 采集系统（experiment_game） | 本方案官方集 59ch |
|------------------------------|-------------------|
| ShallowFBCSPNet three 头 | **A59-shallow**：`n_chans=59` **从头训**（不能直接加载 8ch OpenBMI 权重） |
| T-shallow（t0 降权） | **A59-shallow_b**：同结构；因无 hop/t0，用 **seed=43**（或 drop=0.6）做多样性，占四成员第 2 槽 |
| EEGNet | **A59-eegnet** · `n_chans=59` |
| Conformer | **A59-conformer** · `n_chans=59` |
| 温度校准 + 加权融合 | **E1f-A59**：每折 Val 上拟合 `T_m` + 权重网格（**重拟合**，不照搬 OpenBMI 数值） |
| F5 因果平滑 + 多数票 | 推理管线调用同一套 API；**单窗 trial 上平滑=恒等**，`pred = argmax(p_fuse)` |
| τ 早停 | **不用**（与线上 F5 一致） |

> **主提交读数** = **E1f-A59**。单模 A59-shallow 必跑作消融。A8（Pz→CPz）为阶段 B 旁路。

### 6.2 执行臂顺序

| 优先级 | 臂 | 说明 |
|--------|-----|------|
| P0 | A59-shallow · 6-fold LOSO | 单模基线 |
| P0 | shallow_b / eegnet / conformer · 同 LOSO | 凑齐四成员 |
| P0 | **E1f-A59** + **S-ens** submission | **主交付** |
| P1 | A8-shallow | 8 导掉点 |
| P2 | R1 配方等 | 仅当 Val 不够 |

### 6.3 训练超参（对齐 5090 SharedTrainHP）

| 项 | 值 |
|----|-----|
| seed | 42（shallow_b=43） |
| max_epochs / patience | 300 / 20 |
| batch_train / eval | 256 / 512（可降 64/128 并登记） |
| lr / wd / drop | 1e-4 / 1e-4 / 0.50 |
| sampler | balanced_invfreq |
| early_stop | 该折 Val Acc |
| AMP / 优化器 | True / Adam |

### 6.4 融合要点

每折 Val 重拟合温度与权重；禁止直接套用 `e1f_four_member.json` 的 OpenBMI 数值。因果平滑保留调用路径以便与采集代码同构。

## 10. 判定与风险

| 风险 | 对策 |
|------|------|
| 59ch + 仅 750 train trial 过拟合 | 早停；drop 0.5；对照 A8；E1f 融合降方差 |
| 随机 Val 虚高 | **禁止**；只用被试 LOSO |
| 照搬 OpenBMI 温度/权重 | 每折 Val **重拟合** |
| 因果平滑「没用」被质疑 | 文档写明单窗退化；代码路径与采集一致便于阶段 B |
| conformer 过拟合 | 看 Val；若崩则 E1f 降权或踢出成员 |
| 在线 8 导 ≠ 离线 59 导 | A8 旁路量化；不宣称线上=A59 |

**成功标准**：E1f-A59 六折 Val 报表齐全 + 合法 submission + A59-shallow 消融表 + A8 掉点表。
