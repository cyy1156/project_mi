## 0. 一句话目标

在**主办方指定集**上交出可填 Excel 的离线主读数（**轨 A · 59ch**），并用 **轨 B · 8ch（OpenBMI→官方再训）** 量化与采集系统同构的迁移；另以 **轨 C · 自采 8ch · 5 轮 Leave-Next 爬坡** 佐证系统与微调方法（**不计入指定集 60 分主行**）。

---

## 0.1 三轨总览（v0.3 合并点）

| 轨 | 数据 | 通道 | 训练起点 | 交付角色 |
|----|------|------|----------|----------|
| **A · 指定集主路径** | 官方 train/test | **59 EEG** | 从零（+ E1f） | **Excel / submission 主行** |
| **B · 指定集桥接** | 官方 train/test | **8**（Pz→CPz） | **OpenBMI 8ch 权重 → 官方 8ch 再训** | 对照行；对标采集 |
| **C · 自采佐证** | 本队 8ch 多会话 | **8**（设备序） | 轨 B 或线上 E1f 底座 | 报告「训练数据+有效性」；**非 60 分主行** |

- 指定集上**性能测试** → 轨 A（必）、轨 B（建议）  
- 自采 ≥20 人**训练数据、佐证有效性** → 轨 C（5 轮爬坡证明微调方法；人数继续扩）

## 2. 与采集主线对齐 / 差异

### 2.1 对齐

| 项 | 采集 / OpenBMI 管线 | 本方案 |
|----|---------------------|--------|
| 滤波 | CAR → notch50 → **8–30** | 同（单 trial 内） |
| 窗长 | 3 s @250 Hz | 同（1 trial = 1 窗） |

| 超参 | 5090 SharedTrainHP | 同（§6.3） |

### 2.2 差异

| 项 | 采集 | 官方指定集 | 裁决 |
|----|------|------------|------|
| hop100 | 有 | 无 | 1 trial=1 窗 |

| CPz | 有 | 无 | **Pz → CPz 槽** |
| 划分 | Subject 5-fold | 6 人 train | **6-fold LOSO** |
| OpenBMI 权重 | 8ch | 59 不能加载 | 仅轨 B 热启动 |

## 3. 划分协议（指定集 · 轨 A/B 共用）

### 3.1 冻结

| 问题 | 裁决 |
|------|------|
| 交叉验证 | **6-fold LOSO**（Train5 / Val1） |
| 随机 Val | **禁止** |
| Test | S07–S08 盲测；调参只看 LOSO Val |
| 提交 | 推荐 **S-ens**（6 折概率平均） |

### 3.2 每折规模

| 集合 | n_trial |
|------|---------|
| Train | 750 |
| Val | 150 |
| Test | 120（无标签） |

主报表：6 折 Val Acc / macro-R / macro-S 的 **mean±std**。

### 3.3 泄漏红线

Val 被试不得进 Train；标准化只用该折 Train；禁止用 test 调参。

## 4. 通道协议

### 4.1 轨 A · 59 EEG

```text
EEG_59 = ch_names[0:59]   # Fpz … O2
输入 (B, 1, 59, 750)
```

### 4.2 轨 B · 8 导（加载 OpenBMI 权重时必须用 **模型输入序**）

OpenBMI / 训练权重通道轴（`openbmi_3s_hop100`）：

```text
Cz, C3, C4, CP3, FC4, FC3, CP4, CPz
```

官方选取（名称不敏感）：

| 模型槽 | 官方通道 |
|--------|----------|
| Cz | Cz |
| C3 | C3 |
| C4 | C4 |
| CP3 | CP3 |
| FC4 | FC4 |
| FC3 | FC3 |
| CP4 | CP4 |
| **CPz** | **Pz** |

> 设备落盘序可能是 `FC3,C3,CP3,Cz,CPz,…`；**进模型前必须 permute 到上表 OpenBMI 序**，否则热启动无效。

### 4.3 轨 C · 自采

沿用 `experiment_game` 冻结通道与 `permute_ch_time_to_model`；不改 F25。

## 5. 预处理（指定集 · 逐 trial）

```text
切 signals[:, start:start+750]   # 先切
→ 选通道（A59 或 B8）
→ CAR → notch 50 → bandpass 8–30
→ per-channel z-score（本 trial 内）
→ float32
```

滤波器每 trial 重置；fs=250 无需重采样。

## 6. 三轨详细设计

### 6.1 轨 A · 指定集 59ch（主交付）

| 成员 | 说明 |
|------|------|
| A59-shallow | `n_chans=59` 从零 |
| A59-shallow_b | seed=43（占 T-shallow 槽） |
| A59-eegnet / conformer | `n_chans=59` |
| **E1f-A59** | 每折 Val 重拟合 T + 权重 |

- 读出：F5 API；单窗 → 平滑恒等，`argmax(p_fuse)`  
- **主 submission** = E1f-A59 + **S-ens**  
- Excel「指定数据集」主行 = 本轨

### 6.2 轨 B · OpenBMI 8ch → 官方 8ch 再训（对照）

| 步骤 | 做法 |
|------|------|
| 1 初始化 | 加载现行 OpenBMI 3s E1f 各成员 8ch 权重（shallow / T-shallow / eegnet / conformer） |
| 2 数据 | 官方 train 按 §4.2 抽 8 导；同 LOSO |
| 3 再训 | 小 lr 微调或全量续训（登记一种；默认 lr=`1e-4`，patience 20；若过拟合改为 `3e-5`） |
| 4 融合 | 每折 Val **重拟合** T/权重 → **E1f-B8** |
| 5 提交 | 可选第二份 CSV `submission_exp34_b8_sens_*.csv`（对照，非主行） |

消融：**B8-scratch**（同 8 导从零）vs **B8-ft**（OpenBMI 热启动），看热启动是否涨点。

### 6.3 轨 C · 自采 8ch · **5 轮 Leave-Next 爬坡**（佐证）

> 对应你确认的「五次微调」= **5 轮 Leave-Next**，不是 5 种配方。  
> 协议对齐实验 31/33 + 冻结 F7/F8/F9；读出 **F5**。

| 项 | 冻结 |
|----|------|
| 被试 | 优先已有多会话 v3：`syj0828` 等（≥6 session 方可做满 R0→R5）；名单登记表填写 |
| 轮次 | **R0** 零样本底座 → **R1…R5** 共 **5 次**采后增量微调（Leave-Next：训=已完成会话，测=下一会话） |
| FT 范围 | 默认 **all4** + force（与线上一致；对照可附 so） |
| replay | R1–R3 = **0.10**；其后按 `ft_policy`（可 0） |
| 底座起点 | **C-from-B**：轨 B 官方再训后的 8ch E1f；若 B 未完，暂用线上 OpenBMI E1f（登记清楚） |
| 主指标 | 每轮 heldout：**F5 MI Acc** + 窗级 three Acc；绘 **R0→R5 爬坡曲线** |
| 与 60 分 | **不进**指定集主行；进报告「自采训练数据 / 微调有效性」与 Excel 真被试页 |

人数：官方要求自采作训练数据佐证；轨 C 先用现有被试跑通 5 轮曲线，同时继续扩至 ≥20（进度见初赛材料 `05`）。

### 6.4 超参（轨 A/B 训练）

| 项 | 值 |
|----|-----|
| seed | 42（shallow_b=43） |
| max_epochs / patience | 300 / 20 |
| batch | 256 / 512（可降并登记） |
| lr / wd / drop | 1e-4 / 1e-4 / 0.50 |
| sampler | balanced_invfreq |
| early_stop | 该折 Val Acc |
| AMP / opt | True / Adam |

### 6.5 优先级

| 优先级 | 内容 |
|--------|------|
| **P0** | 轨 A：四成员 LOSO → E1f-A59 → S-ens CSV → Excel 主行 |
| **P0** | 轨 C：现有被试 5 轮 Leave-Next 爬坡表（佐证；可与 A 并行） |
| **P1** | 轨 B：OpenBMI→官方 8ch FT + E1f-B8；B8-scratch 消融 |
| **P2** | 轨 C 换 C-from-B 底座重跑爬坡；扩被试至 ≥20 |

## 10. 风险

| 风险 | 对策 |
|------|------|
| 59ch 过拟合 | 早停；E1f；对照 B8 |
| 把自采 Acc 当 60 分 | 文档/Excel **分表**；主行只写指定集 |
| OpenBMI 热启动负迁移 | B8-scratch 对照；降 lr |
| 通道序错导致 FT 无效 | §4.2 强制模型序 |
| 自采 session 不足 6 | 该被试只报到现有轮次；扩采后再补满 R5 |

**成功标准**：E1f-A59 报表 + 主 CSV；至少 1 名被试完整 R0–R5 爬坡；B8 有 Val 对照（P1）。
