## 0. 想法冻结

### 0.1 一句话

**主推 A2**：`ConvTime` 后只做 **通道注意**，`ConvSpat` **独占导联混合**，在 spat+BN 后再做 **沿时间的空间注意**——避免 CBAM 空间支路与空间卷积重复选导联。  
**A1**（Time 后全 CBAM）保留为对照，专门检验「导联双重选择是否有害」。

| 模块 | 来源 |
|------|------|
| **CBAM / Channel / Spatial** | Woo et al., ECCV 2018（经典；不用方案 13 Stochastic IAT） |

### 0.2 接法选择（冻结角色）

| 接法 | 形状 | 本版角色 |
|------|------|----------|
| 输入 8 导前置 | `(B,8,T)` | **不做**（14 阴性） |
| **ConvTime 后仅通道 + Spat后仅时间空间** | 拆分 | **主臂 A2（冻结）** |
| **ConvTime 后 · 全 CBAM** | `(B,40,T',8)` | **对照 A1**（导联可能与 ConvSpat 重复） |
| BN 后全 CBAM（permute 时间） | `(B,40,1,T')` | **附录 B1** |
| Drop 后全 CBAM | `(B,40,Tp,1)` | **附录 B2** |

### 0.3 导联职责：为何主推 A2

**不会破坏层**：不删 `ConvSpat`、不截断梯度；近零初始化时前向接近恒等。

**会重复**：A1 在 spat 前用 CBAM Spatial 软选导联，再交给 `ConvSpat` 线性混 → 两套都碰「哪些导联重要」。本方案默认 **这是风险，不是默认优点**，故主报看 A2。

| 设计 | 导联谁管 | 时间谁管 | 角色 |
|------|----------|----------|------|
| **A2 拆分** | **仅 ConvSpat** | Spat 后时间空间注意 | **主推** |
| **A1 全 CBAM@Time后** | CBAM Spatial + ConvSpat（冗余风险） | CBAM Spatial | **对照** |
| B1/B2 Spat 后 | 仅 ConvSpat | CBAM（permute） | 附录 |

**A1 vs A2 解读（冻结）**

| 结果 | 解读 |
|------|------|
| **A2 ≥ A1 且 A2 达线** | 主推成立；Time 后空间支路多余或有害 |
| **A1 ≫ A2** | 修订叙事：先软选导联再混合可能有益（记入日志，不改已跑主报口径） |
| **A1≈A2≈S0** | 本路线阴性 |

### 0.4 骨干前向（现状）

```text
(B,8,T)
  → Ensure4d → DimShuffle → (B,1,T,8)
  → ConvTime → (B,40,T',8)     ★ A2：此处仅 Channel；A1：此处全 CBAM
  → ConvSpat → (B,40,T',1)     ★ 导联混合（A2 独占）
  → BN                         ★ A2：此处接时间空间注意
  → Square → Pool → Log → Drop → Classifier
```

### 0.5 结构草图

**S0 · 基线**

```text
原版 self_model/shallowfbcsp.py（无注意力）
```

**A2 · 拆分（主推 · 导联不与 CBAM 空间重复）**

```text
ConvTime → (B,40,T',8)
        → ChannelAttn only        # 重标定 40 个时域滤波器；无导联门控
        → ConvSpat                # 独占 8 导线性混合
        → BN
        → TemporalSpatialAttn     # (B,40,T',1)→(B,40,1,T') 后仅 Spatial
        → Square → Pool → Log → Drop → 头
```

**A1 · ConvTime 后全 CBAM（对照 · 允许导联重复选择）**

```text
ConvTime → (B,40,T',8)
        → CBAM(Channel→Spatial)   # Spatial 已含导联维软选择
        → ConvSpat → BN → Square → Pool → Log → Drop → 头
```

说明：A2 的 TemporalSpatialAttn = 标准 SpatialAttention（permute 后只沿时间）；**导联混合完全留给 ConvSpat**。

**B1 / B2 · 附录接法（初版中置/后置，非本阶段必跑）**

```text
B1: … ConvSpat → BN → CBAM(permute 时间) → Square…
B2: … Drop → CBAM(permute 时间) → Classifier
```

### 0.6 模块定义（经典）

```text
ChannelAttn(C):
  GAP/GMP → MLP(C→C/r→C) → 加 → Sigmoid → 乘

SpatialAttn:
  mean/max over C → Conv 7×7 → Sigmoid → 乘

CBAM = Spatial( Channel(x) )
```

初始化：通道 MLP 末层 / 空间 Conv **近零** → 初值近恒等。

| 项 | A1（Time后） | A2 通道 | A2 时间空间 |
|----|--------------|---------|-------------|
| channels | 40（=F_time） | 40 | 40 |
| reduction r | **16** | 16 | — |
| spatial k | **7** | — | **7**（在 `(1,T')` 上） |
| 空间作用域 | T'×8 导联 | 无 | 仅 T' |

## 2. 代码改动清单（设计冻结）

```text
self_model/
  shallowfbcsp.py
    + ChannelAttention / SpatialAttention / CBAM
    + ShallowFBCSPNet(..., attn: str | None = None)
        None      → S0
        "cbam_time" → A1（ConvTime 后全 CBAM）
        "split"     → A2（Time后通道 + BN后时间空间）
        "cbam_mid" / "cbam_late" → 附录 B1/B2
  train_shallow_cbam_hop100_accpaper.py
    --arm S0|A1|A2|B1|B2 ，数据 OpenBMI，batch 128/256
```

`forward_features` 伪代码：

```python
x = ensure → shuffle → conv_time          # (B,40,T',8)
if attn == "cbam_time":
    x = self.cbam(x)                      # 全 CBAM
elif attn == "split":
    x = self.channel_attn(x)              # 仅通道
x = conv_spat → bnorm                     # (B,40,T',1)
if attn == "split":
    x = temporal_spatial(x)               # permute → Spatial → permute 回
elif attn == "cbam_mid":
    x = cbam_time_layout(self.cbam, x)
x = square → pool → log → drop
if attn == "cbam_late":
    x = cbam_time_layout(self.cbam, x)
return x
```

`attn=None` 与当前 S0 **逐层同构**。

## 3. 实验臂顺序

```text
S0    原版 self_model Shallow
 → A2s  冒烟（2 ep / fold0）          # 先主推
 → A2   拆分 · fold0（Task+Three）
 → A1s  冒烟
 → A1   全 CBAM@Time后 · fold0        # 导联重复对照
 →（门控）以 A2 vs S0 定成败；A1 仅解释重复假说
 →（A2 弱有用）A2f 五折；A1f 可选
 →（可选附录）B1/B2；r∈{8,16}
```

| 臂 | 结构 | 说明 |
|----|------|------|
| S0 | 原版 | 协议锁 |
| **A2** | **ConvTime → 通道 → ConvSpat → 时间空间…** | **主推**；导联只归 ConvSpat |
| **A1** | **ConvTime → 全 CBAM → ConvSpat…** | **对照**；允许导联双重选择 |
| B1 / B2 | BN 后 / Drop 后全 CBAM | 附录；非必跑 |

### 本阶段不做

- 输入端 SE/ECA/CBAM  
- 改正式权重 / 正式表  
- 与 CIACNet 绝对值夺冠  
- 主报混用 BCI2a 与 OpenBMI  
- 用 A1 单独夺冠而忽略 A2（除非日志明确修订主推）
