## 0. 论文在说什么（想法冻结）

### 0.1 一句话

**CIACNet** = **双分支多尺度 CNN（CV）** → **改进 CBAM（IAT）** → **TCN（TC）** → **多层特征拼接** → Softmax。

论文报告（被试内 · 试次级 · 原文 22ch 2a / 3ch 2b）：

| 数据集 | Acc | Kappa |
|--------|-----|-------|
| BCI IV-2a（4 类） | **85.15%** | 0.80 |
| BCI IV-2b（2 类） | **90.05%** | 0.80 |

### 0.2 结构草图（P/L 共用同一模型定义）

```text
输入试次 X ∈ R^{C×T}  （Z-score，训练集聚均值方差）
        │
        ├──────────────────────────────┐
        ▼                              ▼
   ┌─────────┐                    ┌─────────┐
   │  CV1    │  F1=16, KC1=32     │  CV2    │  F3=32, KC3=64
   │ → DW D=2│                    │ → DW D=2│
   │ → Pool8 │                    │ → Pool8 │
   │ → Conv  │  F2=32, k=16       │ → Conv  │  F4=64, k=16
   │ → Pool8 │                    │ → Pool8 │
   └────┬────┘                    └────┬────┘
        ▼                              │
   ┌─────────┐  改进 CBAM              │
   │  IAT    │  Avg+Max+Stochastic     │
   └────┬────┘                         │
        ├──────────► 旁路直通 ─────────┤
        ▼                              │
   ┌─────────┐  TCN L=2, KT=4, F=32    │
   │  TC     │                         │
   └────┬────┘                         │
        └────── concat(IAT∥TC∥CV2) ────┘
                        ▼
                 FC + Softmax
```

超参与论文 Table 1 一致：Dropout **0.3**；IAT reduction **r=8**；空间注意力核 **7×7**。

| 轨道 | 一句话 | 唯一允许偏离论文之处 |
|------|--------|----------------------|

## 2. P 轨 · 完全按论文（唯一例外：8 通道）

### 2.1 必须对齐论文的项（锁定）

| 项 | 论文 / 本 P 轨取值 |
|----|-------------------|
| 模型 | 完整 CIACNet（CV1+CV2+IAT+TC+多层 concat）；对照臂同码 EEGNet |
| 数据集 | **BCI Competition IV-2a**（主）；可选附录 2b |
| 任务 | 2a：**4 类**（左/右/双脚/舌） |
| 试次几何 | **整段 MI 试次**（约 4s @250Hz，与官方切段一致）；**非** hop100 滑窗 |
| 预处理 | **全频段**；**不去伪迹**；仅 **Z-score**（**该被试训练集** μ,σ） |
| 通道 | **例外**：不用论文 22ch，改用本室 **8 导** 同序 montage |
| 划分 | **被试内**：官方 train/eval（2a：288/288）；**每人单独训练** |
| 优化 | Adam · lr=**0.001** · batch=**64** · categorical CE |
| 训练长度 | 最多 **1000** epochs |
| 早停 / 调度 | 与论文一致：验证 **loss** 平台则降 lr；early stopping **patience=300**；有提升才存权重 |
| 重复 | 每被试训 **10 次**，取 **最优一次** 作为该被试结果（与论文 §3.3 一致） |
| 指标 | 试次级 **Accuracy + Kappa**（公式同论文） |
| 消融 | 去掉 CV2 / IAT / TC（及组合）应呈掉点趋势（对照论文 Table 5） |
| IAT | **必须**含 Stochastic pooling；评测策略与训练定义写进 meta，但 **不得**改成标准 CBAM 却仍叫「全模型」 |

### 2.2 明确禁止（P 轨）

- 改成被试独立五折  
- 改成 Acc_paper / balbatch / patience=20 / lr=1e-4  
- 用 OpenBMI 冒充 P 轨  
- 用 2s 滑窗投票代替整试次  
- 为省事把「10 次取最优」改成 1～3 次却宣称「完全按论文」（若算力不够：**另开「P-lite」附录臂**，不得覆盖主报 P）

### 2.3 P 轨成功线

| 等级 | 条件 |
|------|------|
| **实现合格** | 同 8ch·同论文配置下，CIACNet 九人均值 Acc **≥ 同码 EEGNet +3pp** |
| **接近论文趋势** | 均值 Acc **≥ 80%**（允许因 **8ch vs 22ch** 低于论文 85.15；登记必须写通道差） |
| **实现可疑** | 相对 EEGNet 无增益或更差 → 先修结构；**不**用 L 轨结果给 P 洗白 |

表述模板必须带：**「8 通道适配版 · 其余按论文配置」**。

### 2.4 P 轨数据

- 优先：在现有 BCI2a 流程上输出 **8ch · 定长试次 · 保留官方 train/eval 会话划分** 的数组（可基于 `bci2a_4s` 思路，但须满足 P 的被试内划分与 4 类标签）。  
- 若现片只有三分类/缺脚舌类：须补预处理至与 2a 四类一致，否则 P 轨不得开跑。

## 3. L 轨 · 本室个性化处理

L 轨 **复用同一套 CIACNet 权重结构定义**，但数据与训练评测 **全面本室化**：

| 项 | L 轨取值（个性化） |
|----|-------------------|
| 数据 | OpenBMI `openbmi_2s_hop100`（`EEG_MI_train`；窗内 z-score 随现预处理） |
| 通道 | 同 8 导 |
| 输入 | **2s / hop100** 窗 `(8,500)`；评测走 **Acc_paper** 试次聚合 |
| 划分 | **被试独立** 5 折 · `val_ratio=0.2` · `seed=42` |
| 任务 | **Task（2）** 与 **Three（3）** 分训分报；禁止 Task 热启 Three |
| 采样 | **balbatch** |
| 优化 | AdamW 或 Adam · lr=**1e-4** · wd=**1e-4**（与正式旁路一致） |
| batch | train **128** / eval **256** |
| max_epochs / patience | **300 / 20** |
| 早停 | **Val Acc_paper**（非论文 val loss patience 300） |
| 主报 | Test Acc_paper · F1-macro · Task 护栏 |
| 对照 | 同协议 **EEGNet**；正式 **shallow 0.694/0.540** 只读 |

### 3.1 L 轨成功线

| 等级 | 条件 |
|------|------|
| **弱有用** | Three ≥ EEGNet **+1.0pp** 且 Task Δ ≥ **−1.0pp** |
| **达标** | Three ≥ EEGNet **+1.5pp**（或主攻 Task 时写清） |
| **阴性** | 相对 EEGNet 两端均无实质增益 | 停五折扩扫 |

## 4. 模块规格（P/L 结构相同 · 摘自论文 Table 1）

### 4.1 CV

| 项 | CV1 | CV2 |
|----|-----|-----|
| F_time | 16 | 32 |
| 时间核 | (1,32) | (1,64) |
| Depthwise D | 2 | 2 |
| Pool | (1,8) | (1,8) |
| 后段 Conv | F=32, k=(1,16) | F=64, k=(1,16) |
| 激活/正则 | BN；ELU；Dropout **0.3**；ridge/L2 | 同 |

### 4.2 IAT

Avg+Max+**Stochastic** → MLP(r=8) / 7×7 空间注意力；接在 CV1 后。

### 4.3 TC

L=2 · KT=4 · filters=32 · Dropout 0.3；与 IAT 旁路、CV2 做 concat。

### 4.4 头

`concat(IAT, TC, CV2) → FC → Softmax`；P：4 类；L：2 或 3 类。

## 5. 实验臂顺序

```text
P0 冒烟 → P1 EEGNet（论文配置·8ch）→ P2 CIACNet（论文配置·8ch）
 → P3 消融（论文同配置）
 →（P 实现合格后）L0：EEGNet vs CIACNet fold0（本室协议）
 →（L 弱有用）L1 五折
```

| 臂 | 轨道 | 说明 |
|----|------|------|
| P0 | P | 形状/1–2 ep |
| P1 | P | EEGNet · **论文训练配置** · 8ch |
| P2 | P | CIACNet 全模型 · **同上** |
| P3a/b/c/d | P | −CV2 / −IAT / −TC / 标准 CBAM |
| L0e / L0c | L | 本室协议 fold0 |
| L1 | L | 五折 |

### 本阶段不做

- P 轨偷换 L 的早停/lr  
- L 轨要求复现 85%  
- 覆盖正式 shallow 权重
