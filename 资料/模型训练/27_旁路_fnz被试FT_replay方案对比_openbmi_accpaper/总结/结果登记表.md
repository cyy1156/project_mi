## 跨轨结论

| 问题 | 结论 |
|------|------|
| ws01 单独 FT 最优 arm | **S-B3**：T0-36 人 · replay_ratio=**0.15** · 全模型 · heldout **63.7%** |
| ws01+ws02 合并 FT 最优 arm | **M-E1**：**无 replay** · **冻 head** · heldout **56.6%** |
| 两轨 winner 是否一致 | **否**（S 需 replay，M 不需） |
| 默认 replay_ratio | **FT1（仅 ws01）：0.15**；**合并 FT：0** |
| 默认 replay 池 | **T0 36 人** Rest/L/R 全试次（仅 FT1）；合并 FT 不开 replay |
| ws02 塌缩风险 | S-A0 无 replay 时 heldout pred **48/50/4**（几乎无 Right）；历史 FT1 导致 ws02 **100% Left** → **第一次 FT 应用 S-B3 配方** |

### 决策摘要

1. **Track M（上线权重）**：M-E1（冻 head、无 replay）**56.6%** > 当前 M-A0 全模型无 replay **43.4%** → **建议替换** `data/models/fnz/best_three.pt`
2. **Track S（第一次 FT）**：应用 **T0-36 + ratio 0.15**；避免 C1（ob12 ratio 0.05，塌缩 77.5% Left）
3. **54 人全库 replay 0.20**（A1）：S 轨 heldout 高但 M 轨 **38.8% 不过 G1**；不推荐作默认
4. **D 臂已补跑**：D1/D2 未超过 B3/E1；S-D1 59.8% < B3 63.7%；M-D1/D2 < E1 56.6%

权重路径：`experiment_game/data/models/fnz/exp27/M_E1/best_three.pt` · `S_B3/best_three.pt`
