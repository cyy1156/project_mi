# 方案三十 · 旁路 · BCI2a 聚合器对比：窗级投票 / 在线平滑早停(S) / 因果平滑早停(C)

> 版本：**v1.2**（2026-08-29）· 待批准后执行  
> 角色：在 **BCI2a 纯 Cue MI** 上，用大样本对照三种试次读出；核心对比 **S vs C**（唯一差别=平滑邻域），二者均带方案 26 式 **置信早停**。  
> 前置：方案 26（E1f · smooth=1 · τ_conf）· 方案 29（`bci2a_3s_hop100`）· 真人场因果回放

## 0. 一句话目标

同一串 **E1f 融合后的** `{p_k}`，对比：

| 臂 | 名称 | 平滑邻域 | 置信早停 | 最早可判时刻（标准 11 窗） |
|----|------|----------|----------|---------------------------|
| **W** | 窗级投票 | 无 | 无（满 MI 多数票） | **4.0 s**（必须等满） |
| **S** | 在线平滑早停（方案 26 标准 · 在线可实现） | 中心窗 **n** 用 **(n−1, n, n+1)**；**等 n+1 到达**再判 | **有**（`p_max≥τ`） | **3.1 s** 起（第 2 窗到，可评中心 0） |
| **C** | 因果平滑早停 | 当前窗 **n** 用 **(n−2, n−1, n)**；**不等未来** | **有**（同 τ 逻辑） | **3.2 s** 起（满 3 窗） |

**S 与 C 的唯一差别：平滑用哪些窗。其余完全相同**（同一 `p_k`、同一 τ、同一「够置信即提交 / 扫完强制」、同一 E1f 前级）。

**禁止误解：** S **不是**「等 MI 结束后再整段双向平滑」；那是离线 oracle，本方案 **不作主臂**。S = 方案 26 的 radius=1 邻域，但 **流式**：只要 `n+1` 到了，立刻对中心 `n` 做一次平滑+置信检查。

**预注册问题：**

1. 在默认 τ（方案 26：`τ=0.4`）及 val 选 τ 下，**C 相对 S** 的 Acc_LR Δ 是否 ≥ −1.0 pp？  
2. C 是否比 S **更早**（`t̄_dec` 更小）？早多少？  
3. S/C 相对 W：精度与时延的折中是否支持改线上主判定？

## 2. 数据与窗时间线（冻结）

### 2.1 输入

```text
code/preprocess_lab/out/bci2a_3s_hop100/
  bci2a_{X,y_three,y_task,subjects,trial_id}.npy
```

| 项 | 值 |
|----|-----|
| 被试 | A01–A09 |
| 窗 | 多数试次 **11 窗**，`t_rel ∈ {3.0, 3.1, …, 4.0}` |
| 主评测 | **L/R**（`y∈{1,2}`）；Rest 附报 |

### 2.2 时间轴与「何时能平滑」

```text
Cue ──► W0@3.0  W1@3.1  W2@3.2  W3@3.3 … W10@4.0
         n=0     n=1     n=2

S：要评中心 n，必须等到窗 n+1
   例：W1 到达 → 可算 center0 = mean(p0,p1)（左端缺则用可得窗）
       W2 到达 → 可算 center1 = mean(p0,p1,p2)
       …

C：评当前 n，只用过去
   例：W2 到达 → 可算 causal2 = mean(p0,p1,p2)
       W3 到达 → mean(p1,p2,p3)
       …
```

| 臂 | 第 i 个窗到达时（i 从 0）可做的检查 |
|----|--------------------------------------|
| **S** | 若 `i≥1`：对中心 `n=i−1` 做 `mean(p[n−1], p[n], p[n+1])`（边界裁剪），再看 `p_max≥τ` |
| **C** | 若 `i≥2`（或 `i≥0` 用可得窗）：对 `n=i` 做 `mean(p[n−2], p[n−1], p[n])`，再看 `p_max≥τ` |
| **W** | 不早停；全部窗到齐后多数票 |

标准试次最早提交：

- **S**：最早在 **W1@3.1**（检查 center0）  
- **C**：最早在 **W2@3.2**（三窗因果）  
→ C 不比 S「更早才能起步」；但 **同一时刻** C 看的是「当前」，S 看的是「滞后 1 hop 的中心」。C 的优势是 **不依赖未来窗**；S 每判一次多等 **0.1 s**（一个 hop）。

## 3. 三臂精确定义

均在同一试次 E1f 融合概率 `{p_k ∈ R^3}_{k=0}^{K-1}` 上操作。

### 3.0 公共：置信早停骨架（S 与 C 共用）

对齐方案 26 **E1f**：自早到晚扫描；平滑后 `p_max ≥ τ` 即提交该处 `argmax`；扫完强制用最后一次平滑结果。

```text
τ 主读数：方案 26 / 配置默认 τ=0.4（必须报）
τ 网格附报：{0.45, 0.50, 0.55, 0.60}；val=每人前 2 run，test=后 4 run
禁止：test 上调 τ 再报同一 test 为主读数
```

真人场示 τ=0.4 易过早停 → **主表同时报 τ=0.4 与 val 选最优 τ 的 test**，避免单点误导。

### 3.1 臂 W · 窗级投票（对照 · 无早停）

```text
等满 K 窗
trial_pred = majority(argmax(p_k))
平票：该类 p 之和最大（同 judge_aggregate）
t_dec = t_rel[K-1]   # 标准 = 4.0
```

对应现行 **计分**多数票。

### 3.2 臂 S · 在线邻域平滑 + 置信早停（方案 26 标准 · 流式）

**平滑（唯一与 C 不同之处）：** 中心索引 `n`，邻域 **`(n−1, n, n+1)`**（`r=1` 双向；边界只对已有索引取平均）。

**在线约束：** 仅当窗 **`n+1` 已到达** 时，才允许计算中心 `n` 的平滑并做置信检查（**不要**等 MI 结束再一次性平滑全家桶）。

```text
for i = 0 .. K-1:          # 窗 i 刚到达
    if i < 1: continue
    n = i - 1              # 现在可以评中心 n（因为 n+1 = i 已到）
    p_s = mean(p[max(0,n-1) : n+2])    # 含 n+1
    if max(p_s) >= τ:
        submit argmax(p_s)
        t_dec = t_rel[i]   # 决策时刻 = n+1 到达时刻
        break
else:
    # 强制：用最后可算的中心（n=K-2 若 K≥2，否则 n=0）
    …
```

这与方案 26 离线 `temporal_smooth(r=1)+simulate_conf_early_stop` 在「整段齐备」时 **数值可对齐**（同一 τ）；差别只在：离线实现是先算完全部 `p'_k` 再扫，在线是 **到一个评一个**——对早停路径，**提交的中心与 τ 判定应一致**。

### 3.3 臂 C · 因果邻域平滑 + 置信早停

**平滑：** 当前索引 `n`，邻域 **`(n−2, n−1, n)`**（无未来）。

```text
for i = 0 .. K-1:          # 窗 i 刚到达；n = i
    n = i
    p_s = mean(p[max(0,n-2) : n+1])    # 仅 n, n-1, n-2
    if n < 2 and (n+1) < 3:
        # 不足 3 窗：仍可用可得窗平均，或 skip 直至 n≥2（主规则：n≥2 才允许提交）
        if n < 2: continue
    if max(p_s) >= τ:
        submit argmax(p_s)
        t_dec = t_rel[n]   # 决策时刻 = 当前窗到达时刻（不额外等 hop）
        break
else:
    强制末窗因果平滑
```

**主规则冻结：** `n≥2` 才允许首次提交（保证平滑用满三窗）；`n<2` 只缓存。与「累计三窗」叙事一致。

### 3.4 对照表（实现自检）

| | **S** | **C** |
|--|-------|-------|
| 输入 | E1f `p_k` | 同 |
| τ / 早停 / 强制末 | 同 | 同 |
| 平滑 | `(n−1,n,n+1)` | `(n−2,n−1,n)` |
| 触发 | `n+1` 到达后评中心 `n` | 当前 `n` 到达即评 |
| `t_dec` | `t_rel[n+1]` | `t_rel[n]` |

**已删除（相对 v1.1）：** 「满 MI 双向平滑再多数票」作 S 主定义；「满 3 窗强制立即多数票、无 τ」作 C 主定义。二者若作附报，分别记为 **S-oracle-maj**（事后整段平滑+多数票）与 **C-maj3-force**（无 τ 强制三窗交），**不进预注册主树**。

## 5. 指标与预注册判定

### 5.1 主指标

| 指标 | 定义 |
|------|------|
| Acc_LR | L/R 试次正确率 |
| t̄_dec | 平均决策时刻（Cue 相对，秒） |
| early_frac | `t_dec < 3.99` 比例 |
| Δ(C−S) | Acc 与 t̄_dec 的臂差（主对比） |

被试均值 ± std；附报池化。

### 5.2 附报

- 与 W 的 disagree；不一致时谁对  
- 预测类分布  
- S-oracle-maj / C-maj3-force（若跑）

### 5.3 预注册决策树

```text
E1f · W / S(τ) / C(τ)
  主对比：同一 τ 下 C vs S

  ├─ Acc_LR(C) ≥ Acc_LR(S) − 1.0 pp  且  t̄_dec(C) ≤ t̄_dec(S)
  │     → 采纳因果邻域为在线默认平滑；报告主判定可切 C
  │
  ├─ Acc(C) 明显差，但 val 选 τ* 后 test 上 C 追上 S
  │     → 部署用 C + τ*（禁止盲用 0.4）
  │
  └─ 否则
        → 在线主判定维持 S（方案 26 流式）；或计分 W + 报告 S
        → C 仅作「更低延迟、可接受掉点」的可选开关
```

**相对 W：** S/C 若 Acc ≥ W−1 pp 且明显更早 → 支持报告侧离开「满 MI 多数票」。

**τ 协议：** 每人 **前 2 run = val 选 τ，后 4 run = test**；S 与 C **可共用同一 val 选出的 τ\***，或各自选 τ（主表报「共享 τ\*」与「各自 τ\*」两行，预注册以 **共享 τ\*** 为准，避免自由度翻倍）。
