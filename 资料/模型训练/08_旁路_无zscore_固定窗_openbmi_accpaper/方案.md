## 0. 一句话目标

回答：在 **每试次仅 1 个 Task 窗 + 1 个 Rest 窗**、且 **无 z-score** 时，各模型能否拉开 ERS+/ERS− 条件 Acc（P-gap）；相对 07 滑窗无 z-score，固定窗是否更「干净」地暴露功率特征。

| 问 | 约定 |
|----|------|
| 与 07 相同？ | 无 z-score、OpenBMI、11 模型、Acc_paper、ERS 探针口径 |
| 与 07 不同？ | **无 hop**；每试次固定 1 窗 |
| 训练代码？ | 形态对齐 5060 Acc_paper runner；数据为固定窗 tag |

---

## 1. 动机

- 滑窗多窗投票会稀释单窗功率事件；固定窗让 **Acc_paper ≡ 单窗对错**，更直接对应「该 2 s 是否含可用 ERS/ERD」。  
- 经典 MI 固定窗（BCI2a Cue+2–4 s）正处于运动想象稳态，**ERS/ERD 更易出现**。  
- 与 07 对照可分离：「无 z-score 的收益」来自 **保留功率** 还是来自 **多窗聚合**。

## 2. 数据协议（冻结）

| 项 | 取值 |
|----|------|
| 原始 / 被试 / 块 | 同正式 OpenBMI：sess01+02 · `EEG_MI_train` · `openbmi:subjNN` |
| 通道 / 滤波 | 同 hop100 正式 pipeline（仅切窗几何与 z-score 不同） |
| **Task 窗** | Cue 后 **[2, 4) s**（与 BCI2a 固定窗臂对齐；**已选定**） |
| **Rest 窗** | Cue 前 **2 s** |
| hop | **无** |
| 形状 | `(N,1,8,500)` @ 250 Hz；每 trial Task/Rest 各 ≤1 窗 |
| **z-score** | **`False`** |
| 产物目录 | `preprocess_lab/out/openbmi_2s_fixed_cue2to4_noz/` |
| data_tag | `openbmi_2s_fixed_cue2to4_noz` |

说明：正式滑窗源段是 Cue 0–4 s；本臂固定取 **后半 2 s**，与「晚期 MI / ERD」文献习惯一致。  
v2 候选（不进本版主表）：Cue **[0, 2)** 无 z-score 固定窗。
