## 2. 预处理（BCI2a · 2s/hop100）

工作目录：`code/preprocess_lab`

```bash
# 切窗冒烟（若有单测）
python -m src.common.steps.slide_2s_hop100   # 或项目内对应测试入口

# BCI2a → out/bci2a_2s_hop100  (N,1,8,500)
python -m src.datasets.bci2a.batch --cfg config/bci2a_2s_hop100.yaml
```

要点：

- Rest = Cue 前 4 s；Task = Cue 后 0–4 s；hop = 100 ms；**无 padding**  
- 输出含 `trial_id`（试次投票 / 伪在线需要）  
- **不要**再跑 Stieger `*_2s_hop100` / `*_1s` 作为主线数据

## 5. 三模型深研（阶段 C · 现行）

优先阅读与对比：

1. 窗级 / 试次级 / 固定窗三表中的 **shallow、eegnet、conformer**  
2. 结构差异：轻量 EEGNet（~2k） / Shallow（~40k） / Conformer（~360k @ T=500）  
3. 在线预备：**eegnet** 规划 RAP `(5,5,100,5)`；shallow/conformer 默认池化伪在线对照  

深研实验若改超参，必须新开 run stamp，并在 MD 头写明是否仍满足 `balacc+balbatch`。

## 6. 伪在线（阶段 B · 未实现）

- 流式 **2 s** 缓冲，每 **100 ms** 一窗  
- **禁止**用预处理窗数组直接 for 冒充在线  
- 试次过半投票为主报（Acc_paper）  
- RAP / OTTA：仅 **EEGNet RAP 臂**（须重训；与默认池化权重不可混用）

## 7. OpenBMI（阶段 D · 未开始）

- 协议克隆本主线：\(T_w=2\,\mathrm{s}\)，hop=100 ms，BalAcc + batch balance  
- 通道数 / Rest 定义以接入时补丁方案为准  
- 先复跑三模型，再决定是否扩到更多骨干  

---

## 8. 禁止事项

1. 把 Stieger 结果写进主线冠军表  
2. 用非 BalAcc 早停或关闭 batch balance 报主线结论  
3. 用旧 1 s 主线、整段 2s/4s、merged 数字夺本协议冠军  
4. 固定窗与滑窗混比夺冠（对照可以，夺冠不可以）  
5. padding；默认权重灌 RAP 网；窗数组冒充伪在线
