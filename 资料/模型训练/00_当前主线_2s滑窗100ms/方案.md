## 0. 需求与范围（冻结）

| 要回答的问题 | 判据 | 不回答 / 已放弃 |
|--------------|------|-----------------|
| 如何在 **2 s 窗、100 ms 步长** 上做离线训练，并为伪在线评估对齐输入分布？ | 离线切窗 = 在线缓冲出窗；试次级精度可复现 | 是否对齐 Wimpff 论文的 **1 s / 40 ms** 数字本身 |
| 在 BCI2a 十一模型选型后，应对哪些骨干做深度研究？ | **shallow / eegnet / conformer** | 其余八模型仅作选型对照，不进入深研主轨 |
| 下一外部库是什么？ | **OpenBMI**（后续接入） | **Stieger：放弃**（不再预处理/训练/报数） |

**参数冻结（全文共用）**

| 项 | 值 |
|----|-----|
| 窗口长度 \(T_w\) | **2 s** → **500** 点 @ 250 Hz |
| 滑动步长 | **100 ms** → **25** 点 |
| 更新频率 \(f_u\) | **10 Hz** |
| 重叠 | 95% |
| 输出形状 | `(N, 1, 8, 500)`（BCI2a 8 导；OpenBMI 接入时另定通道映射） |
| Rest（BCI2a） | **Cue 前 4 s** → 同一切窗（满段约 21 窗；\(N_w=1+(T-2)/0.1\)） |
| Task（BCI2a） | **Cue 后 0–4 s** → 约 21 窗 |
| 早停 | **严格 Val Balanced Accuracy**（禁止改用 Acc / F1 / loss 早停夺冠） |
| 类别平衡 | **严格 train batch balance**（Task 二类 1:1；Three 三类 inverse-freq；普通 CE） |
| 选型 RAP | **不做**；伪在线阶段仅 **EEGNet** 可另开 RAP 臂重训 |
| 库 | **当前：仅 BCI2a**；**后续：OpenBMI**；**禁止 Stieger / merged 夺冠** |

窗数（源时长 \(T\) 秒，\(T \ge 2\)）：

\[
N_w = 1 + \frac{T - T_w}{0.1} = 1 + (T - 2)\cdot 10
\]

不足 2 s 的源段 **丢弃**，**禁止 padding**。

**RAP 四元组（仅阶段 B · EEGNet RAP 臂；按本协议重算，勿用旧 1s 值）**

- \(f_s=250\)，取 \(k_1=s_1=5\) → \(f_{\mathrm{inter}}=50\,\mathrm{Hz}\)
- 与 \(f_u=10\,\mathrm{Hz}\) 对齐时：**`(k1,s1,k2,s2) = (5, 5, 100, 5)`**
- 伪在线 hop **必须仍为 100 ms**；默认池化权重 **不可** 灌入 RAP 网

## 1. 一句话整体逻辑

**离线用 2 s / 100 ms 切好的窗独立训练；上线用同一窗长与步长从缓冲出窗；主指标先窗级 BalAcc 选型，再试次过半投票；深研只盯 shallow / eegnet / conformer。**

```text
【离线】完整试次 ──100ms hop──► 大量 (8,500) ──shuffle──► 独立前向/loss
                              （Val BalAcc 早停 + batch balance；无 RAP 缓存 / 无 OTTA）

【伪在线】采样点流 ──► 2s 环形缓冲 ──每+100ms──► 一窗
                              │
                              ├─ （可选）EEGNet RAP 缓存加速
                              ├─ （可选）OTTA（EA+AdaBN）
                              └─ 预测；试次结束停窗
                                   │
                                   ▼
                         正确窗占比 > 50% → 该试次计对（Acc_paper）
```

## 3. 三模型深研（阶段 C）— 为何是这三个

依据 BCI2a · 2s/hop100 · BalAcc+balbatch 选型与试次复评：

| 模型 | 角色 | BCI2a 要点（量级） | 参数量级（22ch·T=500） |
|------|------|-------------------|------------------------|
| **shallow** | Task 精度主候选 | 窗级 Task≈0.60；trialmaj Acc_paper≈0.65；固定窗 Task≈0.65 | ~4×10⁴ |
| **eegnet** | 在线 / RAP 主候选 | 窗级 Three 冠军≈0.46；最轻；唯一规划 RAP 臂 | ~2×10³ |
| **conformer** | 重模型 / Three 对照 | trialmaj Three Acc_paper 前列；参数更大 | ~3–4×10⁵ |

**深研要做（建议顺序）**

1. 统一复现三模型正式 run（不改配方）并固化权重路径  
2. 误差分析：Rest/Task、左右混淆、折间方差、trialmaj vs 窗级差异  
3. 伪在线前置：确认 `trial_id`、缓冲出窗与离线切窗同分布  
4. **仅 eegnet**：可选 RAP 几何 `(5,5,100,5)` **另臂重训**（关特征缓存）  
5. shallow / conformer：伪在线用 **默认池化**，不上 RAP  

**不做**

- 把其余八模型纳入深研主轨  
- 用固定窗数字直接宣布滑窗伪在线冠军  
- 用 Stieger 任何结果参与主线排序

## 4. 训练配方（不可协商）

| 项 | 冻结值 |
|----|--------|
| Loss | 普通 CE（无加权 CE / Focal 夺冠） |
| 早停监控 | **Val Balanced Accuracy**；patience=18；max_epochs=300 |
| 采样 | **batch balance**（禁止仅靠全局 class weight 替代本主线） |
| 学习率 / wd / drop | lr=1e-4；weight_decay=1e-4；drop_prob=0.5（与现 `shared_hparams` 一致，改动须记版本） |
| 头 | Task → Three **独立重训**（不迁移权重） |
| RAP / OTTA | 选型与深研离线：**关闭** |

读数口径（窗级）：`Tw=2s hop=100ms fu=10Hz balacc+balbatch no_rap bci2a_only`  
读数口径（试次级）：`... trial_maj>50% paper_acc balacc_on_majority`

## 6. 离线滑窗 vs 伪在线（勿混）

| 项目 | 离线训练 | 伪在线推理 |
|------|----------|------------|
| 窗产生 | 预处理一次性 100 ms 切片写 npy | 流式缓冲动态出窗 |
| 顺序 | 通常 shuffle | 严格时间有序 |
| RAP 特征缓存 | **禁止** | 仅 EEGNet RAP 臂允许（可关作数值对照） |
| OTTA | **禁止** | 论文对齐时每窗可开 |
| 梯度 | 开 | `no_grad` |
| 主报 | 窗级 Test **BalAcc** | 试次 **Acc_paper**（>50% 正确窗）；附报 BalAcc_maj |

**禁止**用「把切好的窗数组 for 一遍」冒充伪在线。

## 8. 与旧方案的关系（消矛盾）

| 旧说法 | 现行 |
|--------|------|
| 主线 = 1 s / 40 ms；2s/hop100 =「旁路」 | **主线 = 2 s / 100 ms**；1s 方案已归档废止 |
| BCI2a + Stieger 同一套逻辑 | **仅 BCI2a → 后续 OpenBMI**；Stieger 放弃 |
| 八基线均衡深研 | 十一模型选型已完成；**深研三模型** |
| RAP 四元组 `(5,5,50,2)` | 那是 **1 s / 25 Hz** 用的；本主线 EEGNet RAP 用 **`(5,5,100,5)`** |
| 早停 / 平衡可换 F1、WCE、SMOTE 夺冠 | **否**；主线只认 **BalAcc 早停 + batch balance** |

对照实验（固定窗、旧 1s、旧整段）**可以保留读数**，但 **不得** 与本主线数字混比夺冠。

---

## 9. 禁止事项

1. 继续把 Stieger 纳入主线训练或主表排序  
2. 用 Acc / F1 / loss 替代 Val BalAcc 早停来报「主线冠军」  
3. 关掉 batch balance 或改用仅全局加权 CE 夺冠  
4. padding 凑窗；整段 2s/4s 训练 + 滑窗测试混用  
5. 选型/深研离线开启 RAP 特征缓存或 OTTA  
6. 默认池化权重加载进 RAP 结构  
7. 窗数组 for 冒充伪在线  
8. 用旧 1s 主线或整段 merged 数字宣布本协议冠军
