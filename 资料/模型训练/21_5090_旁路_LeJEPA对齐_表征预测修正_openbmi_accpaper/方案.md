## 0. 一句话目标

在**不新增** Gate/Decoder/U/T 的前提下，修正预测目标 / 数据过滤 / 训练阶段，检验 LeJEPA 式辅助任务能否让测试期 `p_cur` 稳定超过 **A1（0.5754）**。

## 1. 与方案十七的差异

| 项 | 方案十七 | 本系列 |
|----|----------|--------|
| 推理 | P2 双专家 / A1 单专家 | **统一仅 `p_cur`** |
| 模块 | U/T/Decoder 等 | **禁止新增** |
| 主问题 | 完整图是否超 A1 | Predictor 对齐后能否改善 Encoder |

## 2. 臂（摘要）

| 臂 | 改什么 |
|----|--------|
| **F_mi_a** | t0≤1.0 s 重滤 · Predictor 同 A2 |
| **F_mi_080** | 运行时裁切 pf1000→800pt · t0≤1.2 |
| **A2_pt** | 阶段1 L_pred+SIGReg → 阶段2 仅 CE |
| **J1_tok** | past+cur 内块掩码 JEPA · token L_pred |

数据：全部 `openbmi_2s_hop100_pf1000` v3；F_mi_* 需 `openbmi_t0_sec.npy`。

细节、泄漏验收与进主表条件见**方案正文**。

## 4. 结案（摘录）

- **F_mi_a** 最佳约 0.5765（vs A1 +0.11 pp），**未达弱有用线**  
- **系列阴性** → 主路径维持 **A1 在线**；不改写正式十一模型 / CausalFuse 底座
