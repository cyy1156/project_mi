## 1. 动机（与伪在线门控的关系）

- 正式 hop100 的 z-score **烤进** `X.npy`（`segment_to_2s_hop100_windows(..., zscore=True)`），训练侧不再归一化。  
- 窗内 z-score 拉齐幅度，**削弱绝对/相对 Mu 功率差**，模型更难直接编码 ERD/ERS。  
- 伪在线门控已在 **无 z-score** 窗上算 ERD；本臂检验：**训练也不做 z-score 时，分类网本身是否受益 / 是否更贴 ERS**。

## 4. 「是否学到 ERS」读数（本臂核心附报）

主表仍是 Acc_paper；**ERS 探针不改训练损失**，仅 Test 事后分析（用**同套无 z-score 窗**算特征）：

| 探针 | 定义 | 读法 |
|------|------|------|
| **P-base** | 全库 Test Acc_paper（Task/Three） | vs 正式有 z-score 表 Δ |
| **P-ERS+** | 对侧 Mu ERD≤−15 且 laterality≥8 的试次/窗子集 Acc | 相对全库是否升高（类 teachable） |
| **P-ERS−** | 弱偏侧子集 Acc | 相对全库是否更差 |
| **P-gap** | Acc(P-ERS+) − Acc(P-ERS−) | **越大** → 模型对 ERS/偏侧结构越敏感 |
| **P-corr**（附） | 窗级 laterality 与「预测正确」点双列相关 | 符号/强度作辅助 |

阈值与 teachable_v1 / 伪在线 H1 对齐，便于跨臂对照。  
**成功叙事（旁路，非夺冠）**：

1. 无 z-score 全库 Acc **不崩**（相对正式掉幅可控，建议观察线：Three 掉幅 &lt; 0.05 或有模型升）；且  
2. **P-gap** 相对「正式有 z-score 权重 + 在配对 noz 窗上算同一分层」**增大** → 记「更吃 ERS」；  
3. 若全库升但 P-gap 不增 → 可能只是幅度尺度变化，**不能**宣称学到 ERS。

正式有 z-score 权重的分层探针：用 **配对** `openbmi_2s_hop100_noz` 窗算 ERS 标签，权重仍加载正式 ckpt（推理时输入需与训练一致——即正式权重仍吃 **有 z-score** 窗；分层标签来自 noz）。两套输入对齐 `trial_id`/窗序。
