## 7. 结论与选型建议

1. **窗级 Task 选型冠军：`shallow`**（BalAcc 0.6027）；时域 CNN 整体领先。
2. **Three 冠军：`eegnet`**（BalAcc 0.4640 / F1m 0.4464）；与 Task 冠军不一定相同，阶段 B 需单独定目标。
3. **相对 1s/40ms**：可比时域模型普遍约 +3～4 pt BalAcc；仍 **低于** 固定整段 2s EEGNet≈0.64。
4. **bandpower / raw+图** 明显弱于时域 CNN，不宜作为本旁路 Task 冠军。
5. **Deep** 必须用 compat 缩核；满血 stride-3 历史 run `run_20260804_000553` 塌缩（BalAcc≈0.506，Spec≈0.98），本表正式 deep 为 compat+双任务。
6. 选型阶段 **不做 RAP**；阶段 B 备忘几何 `(5,5,100,5)`，须同构重训。
