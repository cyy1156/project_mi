## 0. 冻结策略

| 项 | 约定 |
|----|------|
| \(T_w\) | **2 s** → `n_times=500` @ 250 Hz |
| hop | **100 ms** → 25 点 |
| \(f_u\) | **10 Hz** |
| 重叠 | 95% |
| 输出 | `(N,1,8,500)` |
| Rest（BCI2a） | Cue 前 **4 s** → 同一切窗 |
| Task（BCI2a） | Cue 后 **0–4 s** → 约 21 窗 |
| 训练 | 普通 CE；Val **BalAcc** 早停；**batch balance**；Task→Three |
| 选型 RAP | **不做** |
| 库 | **仅 `bci2a_2s_hop100`**（**放弃 Stieger**；OpenBMI 见主线阶段 D） |

窗数：\(N_w = 1 + (T-2)/0.1\)（\(T\ge 2\)）。
