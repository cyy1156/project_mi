## 0. 一句话目标

在 **与正式 A0 相同的 Acc_paper / hop100 / balbatch 协议**下，检验三类特征工程能否提升 Shallow：  
**(A1) 偏侧差模通道** → **(A2) 试次质量加权** → **(A3) Mu 包络旁路**；主看 **Three** 左右混淆是否下降，Task 不显著变差。

| 问 | 本臂约定 |
|----|----------|
| 做什么？ | Shallow 单模型 · MI 特征消融（Task + Three） |
| 早停 / 主报？ | Val / Test **Acc_paper** |
| 对照？ | 正式 shallow：Task **0.6941** · Three **0.5404** |
| 与 04_5060 | 协议同形；**代码与 out 目录独立** |

## 1. 动机（来自 54 被试特征分析）

| 发现 | 含义 |
|------|------|
| 明显 12 / 中等 24 / 弱 18 | 全库等权训练会被弱试次稀释 |
| 优秀共性：对侧 Mu ERD + 正确偏侧 + cue 后 ~1s 谷底 | Three 需要空间不对称 + 时间 onset |
| 弱样本：偏侧失败 / 无时间形态 / 甚至 ERS | 左右易糊 |
| 同协议纯 bandpower 图/DBN 垫底 | **禁止**用 8×2 功率替换 raw |

Shallow 已吃 8–30 Hz raw `(8,500)` 并自带时–空滤波；本臂不改骨干超参，只改 **输入通道 / 训练样本权**。

## 3. 消融臂（严格单因子顺序）

```text
A0_raw8_baseline → A1_laterality_ch → A2_quality_weight → A3_mu_envelope
```

### A0 · 复现锚点

- 输入：8 导 raw（与正式相同）。
- 目的：旁路代码复现正式量级（允许 Fast 噪声；目标 |ΔAcc_paper| ≲ 0.01）。失败则停，先修管线。
- 入口：`baseline_shallow_a0.py`

### A1 · 偏侧显式通道（第一优先）

- Runtime 从 8 导派生，**追加** 2 路差模时域通道（不删原 C3/C4）：
  - `C3−C4`、`CP3−CP4`
- 形状：`(N,1,10,500)`，`n_chans=10`。
- 假设：Three left/right 召回升或 left↔right 混淆降；Task 持平或小升。
- 入口：`baseline_shallow_a1.py`

### A2 · 试次/窗质量加权

- 质量分与分析臂同几何指标子集（对侧 Mu ERD、laterality、time_drop）；**仅 train 加权**；Val/Test 不加权、不筛除。
- 权重：试次综合分分位 → 高×1.5 / 中×1.0 / 低×0.5；加权 CE（或等价）。
- 在 **A1 输入**上叠加。
- 入口：`baseline_shallow_a2.py`（依赖 `trial_quality` 缓存）。

### A3 · Mu 包络旁路

- 在 A1 的 10 通道上，对 C3、C4 追加 8–13 Hz Hilbert 包络 2 路 → `(N,1,12,500)`；包络按窗标准化。
- 不做 rest-referenced ERD%（列入 v2）。
- 入口：`baseline_shallow_a3.py`

### 本版明确不做

纯 bandpower 替 raw；TemporalEncoder；改 Deep/Conformer；正式表剔弱被试夺冠；改 Acc_paper 定义。

## 4. 指标与决策门槛

| 任务 | 主指标 | 成功线 |
|------|--------|--------|
| Three | Test Acc_paper | A1 相对 A0 **≥ +0.01**，或 left↔right 混淆明显下降且 Acc 不掉 |
| Task | Test Acc_paper | Δ ≥ −0.01；若变差可只主张 Three |
| A2 / A3 | 同上 | 相对前一臂再 **≥ +0.005** 才进「推荐组合」；否则记阴性 |

每臂：五折 MD + `summary.json`；汇总写入本目录 `总结/`。

## 6. 运行顺序与耗时

1. **A0 冒烟**：`--max-folds 1`（可选再缩 epochs）→ 确认管线。  
2. **A0 全五折**（可选，若冒烟 Acc 已贴近正式可跳过全量）。  
3. **A1 全五折** Task+Three。  
4. 导出 trial_quality → **A2** → **A3**。  

经验：Shallow 单臂 Task+Three 五折约数小时（5060）；优先夜间跑 A1。

```bash
cd code/train_lab/src/step/5060_shallow_mi_feat_openbmi_accpaper
python baseline_shallow_a0.py --max-folds 1
python baseline_shallow_a1.py
```
