## 1. 动机：为何从 10 号换到 LeJEPA

### 1.1 10 号已暴露的问题

| 观察 | 含义 |
|------|------|
| J2 相对随机仅 +2.3pp（加长后） | 表征信号弱 |
| **J3(0.339) ≪ J0(0.460)** | EMA-JEPA 预训权重 **拖累** 同骨干监督 |
| J0 ≪ shallow(0.54) | 小 Transformer 容量本身也弱；SSL 不能神话式补齐 |

经典 I-JEPA 依赖 **EMA teacher + stop-grad** 防坍缩；论文指出这类启发式脆弱、难调。10 号「损失下降但微调变差」与「表征空间未铺好 / 各向异性」相容。

### 1.2 论文主张（本旁路要借的）

1. 下游线性/非线性探测风险最小时，embedding 宜服从 **各向同性高斯**。  
2. **SIGReg**（Sketched Isotropic Gaussian Regularization）用随机切片 + 一维正态性检验，把表征推向该分布。  
3. **LeJEPA = 预测一致性 + λ·SIGReg**：可去掉 teacher–student / stop-grad；**单一 trade-off λ**。

本旁路 **不**复制 ImageNet 多裁剪视觉配方；只迁移 **损失结构**，视图改为 **EEG 双 mask**。

## 2. 方法细节（与代码一一对应）

### 2.1 输入与 Token（方案 B · 与 10 号同构）

> 相对初版 L/R/Mid 三组（60 token），现改为 **逐通道时间块**，才能严格做到「不一次盖满 8 导联」。与 10 号 **同一网格与 mask 规则**，只换预训目标（LeJEPA vs EMA）。

| 项 | 冻结值 |
|----|--------|
| 数据 | `preprocess_lab/out/openbmi_2s_hop100`（`data_tag=openbmi_2s_hop100`） |
| 通道序 | `Cz, C3, C4, CP3, FC4, FC3, CP4, CPz`（与正式 hop100 一致） |
| 窗 | `(B, 8, 500)` · 2s @ 250Hz；变长 trial **不**直接进网 |
| 时间块 | `patch_time=25`（100ms）→ 每通道 20 个时间 token |
| Token 网格 | **8 通道 × 20 时间 = 160**；下标 `ch * n_time + t` |
| 嵌入 | 每 token：该通道该段波形 → Linear→`embed_dim`（无 L/R/Mid 预聚合） |
| 嵌入维 | `embed_dim=64` |
| 编码器 | 2 层 TransformerEncoder（4 head，norm_first） |

实现：`lejepa_model.py` → `PatchEmbed` / `TokenEncoder` / `EEGLeJEPA`。

### 2.2 双视图 Mask（方案 B · EEG 稀疏四块）

每个 batch 窗 \(x\) 独立采两个 mask \(m_1, m_2\)（两视图各采一套，规则相同）：

| 规则 | 冻结值 |
|------|--------|
| 块数 | **4** 个时空矩形（通道维 × 时间维） |
| 总遮盖率 | 并集 ≈ **`mask_ratio=0.25`**（允许 0.22–0.28；约 40/160 token） |
| 单块 | 随机通道高 \(h\in\{1,2,3\}\)、时间宽 \(w\in\{2..6\}\)，再落入网格；以并集计面积 |
| 硬约束 | **任意时间步 \(t\) 不得 8 通道全遮**（该列至少 1 个可见） |
| 关闭（默认） | 旧版「连续时间步三组/全空间全遮」与「整侧半球全时间遮」 |

被遮 token 替换为可学习 `mask_token`，再过共享编码器（**双侧反传，无 stop-grad**）。

登记时记 `mask_frac`；若长期偏离 0.25，先修采样再解读 J2。

### 2.3 损失（LeJEPA）

```text
h1 = Enc(mask(x, m1))     h2 = Enc(mask(x, m2))
z1 = mean_pool(h1)         z2 = mean_pool(h2)      # (B, D)

p12 = Pred(z1)             p21 = Pred(z2)          # 2 层 MLP
L_pred = 0.5 * ( ||p12 − z2||² + ||p21 − z1||² )

L_sig  = SIGReg( concat(z1, z2) )                  # (2B, D)
L      = L_pred + λ * L_sig
```

| 符号 | 默认 | CLI |
|------|------|-----|
| λ | **0.05** | `--lambda-sigreg` |
| Pred | Linear-GELU-Linear，同维 | — |
| 无 | EMA、teacher、stop-grad | — |

### 2.4 SIGReg 实现说明（本仓库精简版）

文件：`sigreg.py`（**非**官方 pip；本机 `pip install lejepa` / GitHub clone 曾失败）。

算法（与论文「切片 + Epps–Pulley CF」同精神）：

1. 对 batch 内 embedding 中心化；  
2. 随机采 `num_slices=256` 条单位投影；  
3. 各切片经验标准化后，在 `num_points=17` 个频率 ω 上匹配标准正态特征函数：  
   \(\mathbb{E}[\cos(\omega s)] \to e^{-\omega^2/2}\)，\(\mathbb{E}[\sin(\omega s)] \to 0\)；  
4. 对切片与频率取平均得标量损失。

**已知风险（短冒烟已见）**：总损失可极快降到 ~0.004，同时 `z_std` 收缩。登记时必须记 `z_std` / `l_pred` / `l_sigreg`。若加长跑仍 `z_std→0` 且 J2 不涨，优先 **加大 λ 扫描** 或减弱切片内强制标准化（代码迭代），而非盲目五折。

日后若官方包可用：允许替换 `SIGReg` 为 `lejepa.multivariate.SlicingUnivariateTest`，**其余协议不变**，在登记表注明实现版本。

### 2.5 下游读出

| 臂 | 骨干 | 头 | 训练 |
|----|------|-----|------|
| J2 / J2_random | 冻住 | Dropout + Linear→3 | 只训头 |
| J3 | 解冻 | 同上 | Enc `lr_encoder=1e-5`，头 `lr=1e-4` |
| J0 | 随机初始化同结构 | 同上 | 全参数 `lr=1e-4` |

评测：窗 logits → 试次 **Acc_paper**（与正式 `trial_metrics` 同逻辑）；早停 Val Acc_paper。

## 8. 决策树

```text
S-长 fold0：
  记录 z_std；若 z_std 过小且 J2≈random → 先调 λ（↑）或修 SIGReg，不进 J3 解读
  J2 − random
    < +1pp  → 阴性倾向；最多 λ×3 次；仍无 → 停 SSL 扩线
    +1～3pp → 弱正向；跑 J0/J3；看 J3≥J0？
    ≥ +3pp  → 表征有用；必跑 J0/J3
  J3 vs J0
    J3 ≥ J0 → 框架赢；考虑 F-全五折
    J3 ≪ J0 → 与 10 号同类失败；停 T-臂；结论写入登记表
  五折后 J3 vs shallow
    达弱成功/达标 → 可开跨窗门控或伪在线抽检附录
    否则 → 不替换部署浅层
```
