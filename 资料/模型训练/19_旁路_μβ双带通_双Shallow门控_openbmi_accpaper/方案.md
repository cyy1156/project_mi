## 0. 一句话目标

> 在 **参数预算对齐** 下，比较：  
> **V1** 单路 8–30 Hz + TemporalConv(**40**) → Spatial，  
> 是否不如  
> **V2** 双路 8–13 / 13–30 各 TemporalConv(**20**) → Spatial，再门控（或拼接）融合？

---

## 1. 两种结构（冻结主对照）

### Version 1 · Shallow 原版（对照）

```text
X  --[bandpass 8–30]-->  TemporalConv(40)  -->  SpatialConv(40)
                        --> Square → MeanPool → Log → Dropout → Classifier
```

| 项 | 取值 |
|----|------|
| 输入语料 | 现有 `openbmi_2s_hop100`（连续段 8–30） |
| `n_filters_time` | **40** |
| `n_filters_spat` | **40**（与官方/手写默认一致） |
| 其余 | `filter_time_length=25`，`pool=75/15`，`attn=None` |

即方案 18 的 **S0（手写 Shallow · `attn=None`）**。  
本方案臂名 **V1 ≡ S0**：**不在 19 包内重跑**；主表直接引用  
`资料/模型训练/18_旁路_手写vs库_ShallowFBCSP_openbmi_accpaper/`（及对应 `runs/5070_shallow_impl_audit/`）中 **S0 五折 Acc_paper**。  
实现阶段仅校验：V2 训练环 / seed / 协议与 S0 **语义一致**（同 `openbmi_2s_hop100` 几何与 Acc_paper），避免「环不一致假对比」。

---

### Version 2 · 双频带 Shallow（容量对齐）

```text
                 ┌─[BP 8–13]─→ TemporalConv(20) → SpatialConv(20) → … → z_μ, p_μ ─┐
X_raw / 配对窗 ──┤                                                                  ├─ Fuse → p_final
                 └─[BP 13–30]→ TemporalConv(20) → SpatialConv(20) → … → z_β, p_β ─┘
```

| 项 | 取值 |
|----|------|
| 带通 | **μ=8–13**，**β=13–30**（13 相接、不重叠） |
| 每支 `n_filters_time` | **20** |
| 每支 `n_filters_spat` | **20** |
| 两支 | **权重不共享**；后续 Square/Pool/Log **各支独立**（同 V1 超参） |
| 时域滤波总数 | **20+20=40** ≡ V1，避免「双塔翻倍参数」伪增益 |

**Fuse（开跑默认）**：

\[
\alpha=\sigma\big(\mathrm{Gate}([z_\mu,z_\beta])\big),\quad
p_{\mathrm{final}}=\alpha\,p_\mu+(1-\alpha)\,p_\beta
\]

损失：`CE(p_final,y) + 0.5·(CE(p_μ,y)+CE(p_β,y))`（防单支塌缩；消融可关辅助项）。

**备选 Fuse（消融，非主表）**：`concat(z_μ,z_β)→Linear`（无 Gate），用于区分「分频特征」vs「可学习门控」。

## 2. 为何这样比（公平性）

| 风险 | 本设计如何规避 |
|------|----------------|
| V2 用两个完整 40 塔 → 参数≈2×V1 | 强制每支 **20**，总 Temporal 通道 **=40** |
| 只比结构、频带却仍是 8–30 二次滤波 | V2 **必须**独立 μ/β 预处理语料（见 §4） |
| 融合方式偷换概念 | 主报固定 **Gate 概率混合**；concat 仅附表 |
| 与方案 17 混比 | 本方案只回答「频带分塔」；不做 future Predictor |

生理叙述：V1 让 40 个时域核在 8–30 内自学 μ/β；V2 **先验切开** μ/β，各用 20 核，再门控按窗选择更可信的一支。

## 3. 实验臂（精简主线）

| 优先级 | 臂 ID | 结构 | 目的 |
|--------|-------|------|------|
| **P0** | **V1 (=S0)** | 8–30 · T40→S40 | **引用方案 18 S0 · 不重跑** |
| **P0** | **V2** | μ20 + β20 · **Gate（默认）** | **本方案唯一必跑主臂** |
| P1 | V2_cat | μ20 + β20 · concat 头 | 无门控上限/对照 |
| P1 | V2_a05 | μ20 + β20 · α=0.5 固定 | 可学习 Gate 是否必要 |
| P2 | V2_μ20 | 仅 μ · T20→S20 | 单带半容量下限 |
| P2 | V2_β20 | 仅 β · T20→S20 | 同上 |

**主结论只看：V2 vs V1（Three Acc_paper，五折 mean±std）。**  
**本方案不跑 Task 二分类主表**（与方案 17 A0-ref 等旁路「仅 Three」口径一致）；训练默认 `--three-only`。S0 对照数字只用其 **Three** 行。

判定建议：

| 结果 | 含义 |
|------|------|
| V2 **稳定 > V1**（且 std 不显著差） | 分频 + 门控 **阳性** |
| V2 ≈ V1 | 先验分带无增益；附报即可 |
| V2 < V1，但 V2_cat ≥ V1 | 分带特征有用、**Gate 有害** |
| V2 < V1，且半容量单带远差 | 20 核/带可能不够 → 远期可试 24+24 等扩容（另立项） |
