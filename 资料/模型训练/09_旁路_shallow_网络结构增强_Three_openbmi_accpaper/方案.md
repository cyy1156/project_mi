## 1. 为什么值得在「网络」上继续试（且主攻 Three）

### 1.1 现状诊断

| 观察 | 含义 |
|------|------|
| Three 全模型上限 ≈ 0.54（shallow≈deep） | 瓶颈更像 **左右可分信息 + 读出**，不是单纯「再加深」 |
| 正式 shallow 已是 Three Acc / F1 第一梯队 | 改网应 **保留 Square→log 功率先验**，在其上加容量 |
| 可教子集上 Three 条件 Acc 可达 ~0.68–0.75 | 模型 **有能力**；全库噪声 / 弱试次拉低均值 |
| 05 输入侧特征工程未达 +1pp | 优先改 **滤波器尺度、分类头、训练目标**，少再叠通道 |
| Task Acc：deep 0.717 > shallow 0.694 | 更深时域仍有 ~2pp；Three 上 deep 未明显胜出 → Three 专攻头更合理 |

### 1.2 默认 Shallow 结构瓶颈（OpenBMI 8×500）

```text
(B,8,500)
 → TimeConv 25tap×40（单尺度 ~100ms）
 → SpatConv 40×8 → BN → Square → AvgPool(75/15) → SafeLog
 → Dropout → Conv 线性分类头（盖满 T_pool=27）
```

| 瓶颈 | Three 相关假设 |
|------|----------------|
| 单时间核长 | μ/β 与跨被试频带漂移照顾不足 |
| 强功率压缩 | 相位/短时非平稳丢失；左右更吃细空-时差 |
| 线性读出头 | idle/left/right 决策边界可能不够 |
| 窗 CE ≠ Acc_paper | 训练目标与试次众数评测不一致 |
| 空间核占参 ~80% | 盲目加宽易过拟合被试独立折 |

## 3. 成功 / 失败 / 停机规则

### 3.1 主成功线（Three）

| 等级 | 条件（相对正式 0.5404 或相对同跑 S0） |
|------|----------------------------------------|
| **弱成功** | Test Acc_paper **≥ +0.010** 且 F1-macro 不降 |
| **达标成功** | Test Acc_paper **≥ +0.015** |
| **强成功** | Test Acc_paper **≥ +0.020**，或 Acc≥+0.015 且 left↔right 混淆明显下降 |

优先用 **相对同代码 S0** 的 Δ，避免 Fast 噪声误判；若 S0 与正式差 >0.01，先修再比。

### 3.2 Task 护栏

- ΔTask Acc_paper **≥ −0.010**；若 Three 达标但 Task 掉 >1pp → 记「Three 专用成功」，**不**替换正式双头默认权重。
- BalAcc_maj 显著变差（偏 idle）→ 记阴性，即使 Acc_paper 微升。

### 3.3 阶段门控（必须按序）

```text
S0 复现 → S1 超参网格 →（可选进 S2）→ S3 读出头 → S4 目标/聚合 → S5 轻量混合
```

- **S1 无任何弱成功** → 仍开 S3（头改成本低）；**跳过 S2 大规模多尺度**直至 S3/S4 有信号。  
- **S2–S4 连续两阶段阴性** → 停网络侧；转数据/可教加权或伪在线栈（不在本方案扩 scope）。  
- 单臂冒烟：`--max-folds 1`；正式结论必须 **5 折齐**。

## 4. 实验阶段与臂设计

### 阶段 S0 · 复现锚点（必做）

| 项 | 内容 |
|----|------|
| 臂名 | `S0_default_shallow` |
| 结构 | braindecode 默认：`n_filters_time=40, filter_time_length=25, n_filters_spat=40, pool=75/15, drop=0.5` |
| 目的 | 证明旁路管线 ≡ 正式量级 |
| 入口 | `baseline_shallow_s0.py` |
| 通过线 | \|ΔThree\| ≲ 0.01 vs 正式 |

---

### 阶段 S1 · 结构超参网格（低风险 · 优先）

**假设**：默认 100ms / 40 滤波器不是 Three 最优；小网格即可吃到 +1pp 级增益。

固定协议，只改构造参数（每次改 1–2 个因子，避免全因子爆炸）：

| 因子 | 候选 | 说明 |
|------|------|------|
| `filter_time_length` | 13, **25**, 50 | ~50 / 100 / 200 ms |
| `n_filters_time` / `n_filters_spat` | 20, **40**, 64 | 建议 time=spat；可选 spat≠time 的补充格 |
| `pool_time_stride` | 10, **15**, 25 | 影响 log-power 时序分辨率与分类头宽度 |
| `drop_prob` | 0.25, **0.5** | 仅与最优核组合复跑 |

**推荐搜索顺序（控制 GPU 时）**：

1. **S1a**：只扫 `filter_time_length ∈ {13,25,50}`（3 跑 ×5 折）  
2. **S1b**：在 S1a 最优核长上扫 `n_filters ∈ {20,40,64}`  
3. **S1c**：在 S1b 最优上扫 `pool_stride ∈ {10,15,25}`  
4. **S1d**（可选）：最优组合上 `drop ∈ {0.25,0.5}`

| 臂命名示例 | 含义 |
|------------|------|
| `S1a_t13` / `S1a_t50` | 时间核长 |
| `S1b_f20` / `S1b_f64` | 滤波器数 |
| `S1c_ps10` / `S1c_ps25` | 池化步长 |

**登记**：每臂写 Three Acc / F1 / Recall_idle/left/right；标出相对 S0 的 Δ。

---

### 阶段 S2 · 多尺度时间核（中风险）

**假设**：并联短/中/长核再融合，比单尺度更能兼顾 μ/β，降低左右混淆。

| 臂 | 结构要点 |
|----|----------|
| `S2_ms_concat` | 三分支 TimeConv（如 13/25/50），通道维拼接后 **共享** SpatConv→Square→Pool→Log→头 |
| `S2_ms_sum` | 三分支各自到 log-power 后 **相加/加权和** 再分类（参数更省） |

约束：

- 总时间滤波器预算接近 40（如 16+16+8），避免参数爆炸。  
- **保留** Square + mean pool + SafeLog。  
- 若 S1 已找到明显更优单核长，S2 以该尺度为中心分支。

成功线同 §3.1；若仅窗级升、试次 Acc_paper 不动 → 记「未达」，检查投票是否已饱和。

---

### 阶段 S3 · 读出头增强（中低风险 · Three 专攻）

**假设**：功率特征已够，线性头限制 idle/left/right 边界。

在 **S0 或 S1 最优骨干** 上替换 `final_layer`：

| 臂 | 读出 |
|----|------|
| `S3_mlp` | AdaptiveAvgPool / Flatten → MLP(40→64→3) + Dropout |
| `S3_stats` | 对 T 维做 mean/std/max 拼接 → 线性或浅 MLP |
| `S3_hier` | 共享骨干；**Task 二类头** + **MI 内 left/right 头**；推理：先 Task，若 task 则左右头（训练可用多任务损失） |
| `S3_three_only_tune` | 冻结 S0/S1 卷积，只训新 Three 头（省算力冒烟） |

附报必写：混淆矩阵或 left↔right 互换率。

**护栏**：`S3_hier` 若 Task 升、Three 降，不以 Task 夺冠。

---

### 阶段 S4 · 训练目标与试次聚合对齐（中风险）

**假设**：窗 CE 与 Acc_paper 众数不一致，优化 Three 时浪费在「窗对、试次错」。

| 臂 | 做法 |
|----|------|
| `S4_softvote_loss` | 同 trial 窗 logits 均值后再 CE（需 custom batch/sampler 或 trial 包装） |
| `S4_focal` | Focal loss（γ 扫 1–2），缓解 idle 易占优 |
| `S4_class_weight` | 逆频类权（与 balbatch 勿双重过猛；先小权重） |
| `S4_conf_agg`（仅评） | 训练不变；评测用置信度加权众数（对照正式众数）— **评测臂不改训练** |

建议：S4 挂在 **S1 或 S3 最优** 上，单因子。  
`S4_conf_agg` 若只评测涨、训练不变 → 可进伪在线，但 **不算网络结构夺冠**。

---

### 阶段 S5 · 轻量混合骨干（较高风险 · 最后）

**假设**：在 log-power 主干旁加短时序支路，补左右动态，而不换成 Conformer。

| 臂 | 做法 |
|----|------|
| `S5_res_pre` | Square 前加 1 个残差时序块（深度可分离 / 小组 Conv） |
| `S5_dual` | 主路 Shallow-log；旁路不加 Square 的浅 Conv；特征拼接后分类 |
| `S5_se` | SpatConv 后通道 SE/注意力（参数少） |

约束：参数量建议 **≤ 正式 ×3（约 <5e4）**；Three 无弱成功则立即停，不加深堆叠。
