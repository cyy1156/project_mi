## 1. 数据与特征定义（全部已落盘）

### 1.1 源数据

| 源 | 路径 | 内容 |
|----|------|------|
| 原始脑电 | `experiment_game/data/subjects/{id}/sessions/{sid}/eeg.csv` | 8 导 × 250 Hz + lsl_time |
| 事件流 | 同上 `events.jsonl` | session/rest/prep/cue/mi 锚点与试次号 |
| 采集报告 | 同上 `v4_report.json`（summary + windows） | 采集期质量摘要 |
| 推流健康 | 同上 `eeg.meta.json` | gap/empty_pulls/非单调修复 |
| 适配曲线 | `_analysis/leave_next_*`（方案 41/33 产物） | 逐轮 heldout、门控 |
| FT 运行 | `{id}/models/ft_runs/{ts}/report.md` | 逐成员 heldout/task、`max_class_frac`、train acc |
| BCI2a 锚 | Exp32 仿真登记表 + `sim_subjects/A0*` | 无疲劳对照（报告同含 max_class_frac 字段） |

### 1.2 派生特征（统一 `extract_features.py` 一次生成，口径与线上对齐）

- **质量指标（session 级）**：饱和窗占比（\|x\|≥0.95×轨满，FCz 中线规则单列）、流中断率（gap/empty_pulls 每秒）、CZ 与 FCz 相关、μ(8–13)/β(13–30)/δθ(0.5–7) 带相对功率、逐窗 z-score 越界窗占比（基线取 Cue 前 0.5 s，与 F1 同口径）。
- **伪迹泄漏指标（v0.2 新增，服务 C/D 臂分界）**：
  - 肌电泄漏 `emg_leak`：MI−Rest 的 25–45 Hz 功率差 > μ 波段功率差 → 标记（磨牙/颈肌会伪造 β 不对称，冒充运动想象特征）；
  - 眼动代理：FC3/FC4 额叶超额 θ（相对 CP3/CP4）。
- **疲劳/习惯化指标（试次级）**：试次序号；**Rest4s 窗 μ 功率 = primary 疲劳代理**；MI 窗 ERD 幅值与偏侧化指数 LI（secondary，注意疲劳抬高 Rest α 会反相放大 ERD）；试次级"空闲误报指示"（Rest 被判 MI）。
- **特征可分性（session 级，核心）**：8 导逐窗 z-score 后 8–30 Hz 对数带功率 + 两两 CSP 投影特征；每试次取判定窗均值。
  - **d′(L vs R)**：左右试次投影特征均值差 / 合并标准差；**d′(MI vs Rest)** 同理；
  - **probe AUC**：会话内留一场次交叉验证的 LDA AUC（**嵌套 CV 防乐观偏置**，v0.2 明确）；
  - 三个互补：单变量效应量 / 多变量可分性 / 模型可达上限代理。
- **坍塌指标（v0.2 全部改在 heldout 预测分布上统计）**：预测熵（归一化）、**heldout `max_class_frac`**（非训练集）、"MI 试次被判另一侧"占比、p_max 分布形态；训练集 `max_class_frac` 保留为②层旁证。
- **适配动态（FT 轨迹级）**：逐 epoch train/heldout 曲线（若 run 无 epoch 落盘则降级为"重跑采样终态"，登记为局限）。

### 1.3 统一窗口协议与读数口径

与线上同口径：3 s 窗 / 100 ms 步长 / 因果；MI 判定窗锚 `[mi_start, +3..4s)`，Rest 段满段；双套标签（三分类、MI 二分类 L/R）。**任何指标不得混用 2 s 或 1 s 旧锚点。**  
**读数口径（v0.2 钉死）**：主读 = F5 因果平滑 + 试次多数票（与 §3.6 表同口径）；附读 = heldout 原始窗级。窗级/试次级、三分类/MI、真人/仿真禁止同轴硬比；d′ 只作个体内/分布对比。

## 2. 臂设计

### D0 臂 · 坍塌普查（v0.2 新增，最先执行，零训练）

**设计**：全员 × 全轮 × 逐成员，统计 **heldout** 预测分布坍塌指标（§1.2）；同时解析全部 `ft_runs/report.md` 的训练集 `max_class_frac` 作对照列。

**发生率定义（登记冻结）**：heldout 归一化熵 < 0.5 **或** heldout `max_class_frac ≥ 0.8` **或** MI 试次异侧率 ≥ 0.7，任一成立记"坍塌轮"。

**产出与判定门**：
- 队列"坍塌轮占比"及其**精确二项 95% CI**，分"末轮 / 全轮"两口径；
- 每个体归类：稳定坍塌（≥2 轮）/ 偶发（1 轮）/ 无；
- **决策门**：末轮坍塌占比 CI 上界 < 20% → H0' 被否，D 臂缩为个案研究，v4"坍塌"表述按"弱而稳为主、个别坍塌"改写；CI 下界 ≥ 40% → D 臂全量展开。

### A 臂 · 混杂分解（v0.2 重构：底座全链重放）

**起点修正（核心）**：所有臂从 **OpenBMI 预训练底座 ckpt**（fold 对应三分类/task 双头）独立出发做整条 Leave-Next 链，**禁止从线上 current 出发**——current 已吸收全历史，从它出发做"仅前一场"臂会系统性低估数据量贡献，R_vol 将失去解释力。A1 同时承担线上链复现校验。

| 臂 | 链构造 | 隔离什么 |
|----|--------|----------|
| **A0 冻结底座**（v0.2 新增） | 不微调，底座直评各轮 heldout | 整条 FT 链的净贡献下界 |
| A1 full | 全历史逐轮链（复现现状） | 参照 + **复现门：与线上 current 末轮差 ≤1.5 pp（主读口径）**，超门停线查非确定性 |
| A2 recent-only | 链仅保留紧邻 heldout 的 1 场 | 近期性/状态匹配 vs 数据量 |
| A3 uniform-N | 历史中**时间均匀**抽 N 场重链，N = min(历史场数−1, 3)，各臂窗口数配平（公式在方案内写死） | 同量数据 × 时间跨度 |
| A4 shuffled-time | A1 场次顺序打乱（窗口不变） | 顺序信息本身 |
| A5 replay 敏感性 | A1，回放比例 5/10/20% 三点 | 源域锚的坍塌阻尼 dA5 = ∂(heldout)/∂(replay%) |

**统计与判定（v0.2 重构）**：
- **同 seed 配对**：全臂共享 5 个 seed，个体内先对 heldout 配对差取均值（heldout 永不进训练）；
- **评价集**：末 2–3 轮 heldout 场次合并评估——单场试次级噪声 ±4–8 pp，不可作判定单位；
- 读数：主读 = F5 因果平滑+多数票，附读 = 原始窗级；
- **三分支主判定线（v0.2）**（去重后 n≈13–15，配对差 SE≈1.3 pp 量级）：
  - `R_vol = A1 − A2 ≥ +3 pp` 且 ≥2/3 个体同号 → **数据量主导**，维持现叙事并补引 R_vol；
  - `+1 ≤ R_vol < +3 pp` → **部分贡献**，回落主因转向状态/质量，§3.6 加限定句；
  - `R_vol < +1 pp` → **叙事改写**："随数据变强"在真人队列不成立，§3.6 与摘要相应句强制修订（见 §3 回填判定）。
- `R_span = A3 − A2`、`R_order = A1 − A4`、dA5 附报。

**成本门（smoke test）**：先 1 人 × 全臂 × 1 seed 计时；单链 >2 min → seed 降 3，并先做**分层 8 人**（高/中/回落三层各取代表）出趋势，全员扩展留 Day2。正常预算：约 13–15 人 × 6 臂 × 5 seed ≈ 450 次小微调，单卡 5070 夜间批；与线上 ckpt 隔离（`out/5070_exp42_.../`），零污染。

### B 臂 · 疲劳与质量关联（声明唯一 primary test）

**primary test（唯一，登记冻结）**：试次级混合效应 `Rest 段 μ 功率 ~ 试次序号 + (1|个体·日)`，配个体内前半 vs 后半 Wilcoxon。判读：≥2/3 个体显著且队列 median 斜率 > 0 → 疲劳有实证，给出每 18 试次衰减量；否则写"本范式时长（约 8 min/场）内未见会话内疲劳信号"，疲劳解释收窄到跨天状态。

**secondary（全部降级附报）**：|ERD-LI| 随序号斜率（与 primary 方向相反时以 primary 为准）；同日第 r→r+1 场 d′ 衰减；末档增益 × 质量指标（饱和率/断流率/`emg_leak`）被试级 Spearman（Holm-Bonferroni，效应量 r 与 CI 优先于 p）。|ρ|<0.2 → "质量非主要混杂"，回落归因转向状态/执行（fnz 案例作描述性证据）。

**成本**：小时级，零训练。

### C 臂 · 会话特征显著性与质量同质性（回答"每个 session 是否一样"）

1. **同质性量化判定线（v0.2 新增）**：个体内 Friedman / Kruskal-Wallis 检验各会话 d′、饱和率、probe AUC；**若 >50% 个体 p<0.05 → 结论"会话间非同质为普遍现象"**——这是对"数据质量是否一样"的正面回答；留一场判别 AUC（时段可判别性 = 漂移强度）与**会话×会话迁移矩阵**（train-i-test-j 线性探针，**嵌套 CV**）量化漂移：对角与非对角落差 = 会话级漂移总量。
2. **特征显著性分级**（个体内中位数锚定）：d′(L vs R) 三档：明显 ≥1.0 / 中等 0.5–1.0 / 弱 <0.5；probe AUC ≥0.7 = 会话内可解码。
3. **伪迹协变量（v0.2）**：`emg_leak` 与额叶超额 θ 会话单列；**"特征明显"判定要求 d′ 达档且无 `emg_leak` 标记**，防止肌电/眼动冒充运动想象特征。
4. fnz0828→fnz0830 专题：区分"特征消失"（对角与非对角同低）vs"特征漂移"（对角高、跨场低）。

**预注册判读**：队列报告"末档弱特征（d′<0.5）会话占比"与"特征消失趋势"（随轮次 d′ 斜率）；回落个体 d′ 斜率<0 → 支持"执行/状态退化"；d′ 稳定但 heldout 跌 → 支持"漂移/模型失配"。

### D 臂 · 坍塌定位（仅在 D0 判出的坍塌个体上）

三层各有独立判据，可叠加：

| 层 | 候选机制 | 指标 | 判据 |
|----|----------|------|------|
| ① 信号层 | ERD 未产生/消失/被伪迹冒充 | C 臂 d′ 与 probe AUC **且无 `emg_leak`** | 低 d′ 且低 AUC = 生理性"无米"（BCI 不敏感谱系） |
| ② 优化层 | 小样本 FT 压塌 BN 统计/步长过大 | FT 轨迹（train↑ heldout↓）、训练集 max_class_frac、**lr 减半消融、BN 动量 0.9→0.99 消融** | heldout 随 epoch 单调跌且 train>0.9 = 过拟合坍塌；lr 减半缓解 = 步长问题；BN 消融缓解 = 统计漂移机制确认 |
| ③ 读出层 | 多数投票吞类、融合权固定 | 同窗概率下 argmax vs 多数票 vs **验证先验重标定**（先验仅由训练场次估计，heldout 标签不参与）三读出的类占比 | 先验校正显著改善 = 读出层坍塌 |

**出口纪律（v0.2）**：②层若确认 BN/步长机制，**结论不直接改 `ft_policy.json`**——触发另立"方案 43 · 微调配方修正"，走 F24（先配置+测试，再文档）。

**预期假设（登记为待检，非结论）**：H1 弱执行（①层，d′<0.5）占坍塌多数；H2 ②层对全体普遍存在（BN+小样本），强特征被试被信号冗余掩盖；H3 ③层只放大空闲类偏置（38.6% 窗级误报同源）。三者可叠加，报告交集。D0 发生率低时，D 臂缩为个案研究，假设检验范围相应收窄。

**成本**：解析小时级；lr/BN 消融约 30 runs（分钟级 × 5070 数小时），**仅在 D0 决策门放行后执行**。

### E 臂 · BCI2a 对照锚（零计算）

复用 Exp32 落盘：同轮次曲线与 heldout/训练集 `max_class_frac` 分布与真人并排。作用：(i) 真人独有回落（跨天/疲劳/阻抗）的定量边界；(ii) 若仿真同现高训练集 max_class_frac → ②层机制非"人"专属。

### F 臂（可选，P2）· 特征层漂移分解

对强特征被试（syj0828）：类条件协方差对齐后 probe 恢复度；时间共享/个体共享子空间。仅当 D 臂显示"①层正常但读出跌"时立项。

## 3. 判定线汇总与回填判定（v0.2 新增节）

| 判定线 | 结果 → 动作 |
|--------|-------------|
| D0 末轮坍塌占比 CI 上界 < 20% | H0' 否 → D 臂缩个案；v4 §3.6/摘要"坍塌"表述改"弱而稳为主、个别坍塌" |
| D0 CI 下界 ≥ 40% | D 臂全量展开；v4 增补坍塌发生率句（带 CI） |
| A 臂 R_vol < +1 pp | §3.6"随数据变强"叙事与摘要相应句**强制修订**；A0 读数入正文 |
| A 臂 R_vol ∈ [1,3) pp | §3.6 加"数据量部分贡献"限定句 |
| A 臂 R_vol ≥ +3 pp 且 2/3 同号 | 维持现叙事，补引 R_vol 数字 |
| A1 复现门超 1.5 pp | 停线查链非确定性；本方案产出降为 D0/B/C/E |
| B 臂 primary 显著 | §4 混杂段填"每 18 试次疲劳衰减量"实证 |
| C 臂 >50% 个体非同质 p<0.05 | §3.6 补"会话质量不同质"结论与门控证据 |
| D 臂 ②层确认 | 触发方案 43（微调配方修正），42 只登记不执行 |

**报告口径纪律**（沿用 §1.2 规格禁忌）：窗级/试次级、三分类/MI、真人/仿真不得同轴硬比；d′ 只作个体内/分布对比，禁止跨被试绝对值排名。所有臂只读既有数据/重训不碰 heldout；任一臂若需触碰未用过的测试信息 → 停止并升版评审。

## 6. 风险
