# 方案 L1：超参与结构扫描

## 1. 目的

在 **P1 基座**上做网格，用 **Val Acc_paper** 选「当前较好」组合，回填到 P1「当前采用」。  
不宣称全局最优，但本扫描 **整表必做**。

## 2. 优先级

**必做**（P1 初跑通后做）。一次动一类。

## 3. 扫描顺序（均必做）

1. `λ_pred`；分类是否 **+CE(future)**；Gate 输入（仅 z vs z+p）
2. **`D=40` vs `Linear(40→128)`（必做消融，按 Val Acc_paper 选优回填）**；`λ_sig`；读出（segment vs 截段后 global）
3. Predictor/Expert 深度与宽度；Adam vs AdamW
4. 骨干：自写 Shallow / EEGNet / Deep4（后两者须带 T′ 特征 API）
5. （接 P2 后）`λ_dec` 网格；SIGReg `num_slices`∈{512,1024}（默认 1024）

## 4. 必做网格

| 维 | 取值 |
|----|------|
| λ_pred | 0.25, 0.5, 1.0, 2.0 |
| λ_sig | 0, 0.01, 0.05, 0.1 |
| cls 组合 | cur+final / cur+future+final |
| Gate 输入 | z only / z+probs |
| 骨干 | 自写 Shallow, EEGNet, Deep4 |
| 投影 | 无 / `Linear(40→128)` |
| `num_slices` | 512, 1024 |
| 优化器 | Adam, AdamW |
| λ_dec（P2） | 0.05, 0.1, 0.2, 0.5 |
