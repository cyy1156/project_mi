# 方案 A1：可见上下文单专家

## 1. 目的

在**不加 Predictor/双专家**的前提下，只把输入从 500 扩到 past+cur，量化 **cache 0.4s** 的贡献。

## 2. 优先级

**必做**（公平性关键：证明 P1 增益不是只靠更长窗）。

## 3. 模块开关

| 模块 | 状态 |
|------|------|
| 输入 | `X_mask`：past100+cur500+future0，形状见下表 |
| Encoder | **自写** [`self_model/shallowfbcsp.py`](../../../../self_model/shallowfbcsp.py)（`forward_features`；**不用**原 `final_layer`） |
| Expert_cur | 开（`D→C`，D=40） |
| Predictor / Expert_future / Gate / Decoder / SIGReg / X_full | 关 |
| 推理 | `ŷ=argmax(p_cur)` |

## 4. 配置（两项输入形式均必做）

| 项 | 主跑（与后续张量一致） | 必做对照 |
|----|------------------------|----------|
| 输入形式 | **`(B, 8, 1000)` future=0** | **`(B, 8, 600)` 真短输入** |
| 读出 | §3.2.1 可见段 mean（1000 点） | 整段 mean |
| Expert | `D→C` | 同左 |
| 优化 / 协议 | 同协议 batch/patience；Task + Three | |

## 5. 损失

仅 `CE(p_cur, y)`。

## 6. 对比读法

- A1 − A0 ≈ cache/加长输入贡献
- 若 P1 − A1 很小 → 方法故事弱，需检查实现或改结构
