# 方案 A0：OpenBMI · 2s 单专家基线（Shallow）

> 协议：必须遵守 [`协议_滑窗投票与Acc_paper.md`](./协议_滑窗投票与Acc_paper.md)。  
> 实现锚点：`5060/5090_baselines_openbmi_2s_hop100_accpaper` 的 shallow。

## 1. 目的

对齐仓库 **OpenBMI · 2s/hop100 · Acc_paper 早停** 的 Shallow 结果，作为新方法历史锚点。

## 2. 优先级

**必做**。须按本协议 **batch=256/512** 重训 Task + Three（旧 128/256 run 仅量级参考，不进主表对照）。

## 3. 模块开关

| 模块 | 状态 |
|------|------|
| 数据 | **OpenBMI** `openbmi_2s_hop100`，sess01+02 |
| 输入 | `(B, 8, 500)` 仅当前窗 |
| Encoder | **braindecode** `ShallowFBCSPNet`（正式臂；**非** self_model 自写） |
| Predictor / Expert_future / Gate / Decoder / SIGReg | 全关 |
| 输出 | 单头 → 试次 **Acc_paper** |

## 4. 配置

| 项 | 值 |
|----|-----|
| early_stop | **Val Acc_paper** |
| patience / max_epochs | **20** / 300 |
| lr / wd / drop | 1e-4 / 1e-4 / 0.5 |
| batch | **256 / 512** |
| sampler | balbatch |
| seed / folds / val_ratio | 42 / 5 / 0.2 |
| 头任务 | **Task + Three 均必做** |

## 5. 损失

窗级 CE；选模 Acc_paper。

## 6. 性能参考

见协议 §4.1。主表数字以本协议重训为准。
