## 0. 一页结论（Executive Summary）

在 **OpenBMI · 三类（Rest / Left / Right）· Subject 5-fold · Val Acc_paper 早停** 协议下，本机 RTX 5060 完成了主线 **A0→P2** 与结构升级 **U1/U3/U2** 的正式五折。

| 结论 | 依据 |
|------|------|
| **主结果仍取 P2**（波形 Decoder 定稿） | Test Acc_paper **0.5707±0.0112**；主线中 **方差最小** |
| **最大增益来自「可见上下文 1000pt」而非后续模块堆叠** | A0→A1：**+3.75 pp**；其后 P0/A2/P1 相对 A1 **略降或持平** |
| **Decoder（P2）相对 P1 有小幅正增益且更稳** | P2−P1：**+0.64 pp**；std 0.022→0.011 |
| **U1（时间维 Predictor）均值略超 P2，但不更稳** | U1 **0.5722±0.0180**（Δ+0.15 pp）；std 变大 |
| **U3（Gate+熵）基本无效** | **0.5708±0.0180**（Δ+0.01 pp） |
| **U2（Spectral Decoder）略逊于波形 Decoder** | **0.5665±0.0236**（Δ−0.42 pp） |
| **5090 已完成 B/C 全消融**（5060 未跑） | L_pred、CE(p_final)、Expert_future 有因果贡献；C1≈P2 证实 Decoder 不抬均值；C2a 略优 P2（见 [分析 doc §6](./分析_为何U系列模块未提升.md#6-5090-bc-消融5060-缺失的因果证据)） |
| **U 组合 U13/U12/U123 均低于 P2** | −0.48～−0.75 pp vs P2；不宜堆叠 |

**推荐叙述口径（论文/答辩）**：在线契约下，**past+cur+mask-future 的 1000pt 可见上下文**是主要收益源；**P2 波形生理解码**在均值与稳定性上优于无 Decoder 的 P1；相对 P2 的三项结构升级（U1–U3）**未产生可宣称的稳健提升**，其中仅 U1 有微弱均值优势。

## 1. 实验目的与问题设定

### 1.1 方法目标

面向 **在线流式** MI-EEG 分类：训练可读未来真值，推理严格无未来泄漏。核心构件（定稿 v1.x）：

1. `X_full = [past100, cur500, future400]`，`X_mask` 将 future 置零（训练/推理统一）；
2. 共享 **ShallowFBCSP** Encoder（D=40）；`X_full` 路 **no_grad** 作未来表征目标；
3. Predictor：可见表征 → 未来隐向量 `z_pre`；
4. （P2）Decoder：`z_pre → 8×400` 波形 + PSD/μ/β/time 约束；
5. Expert_cur / Expert_future + Gate → `p_final = α p_cur + (1-α) p_future`；
6. SIGReg 约束可见段表征（P1/P2）。

SIGReg 思想对齐本目录上级 **LeJEPA / Shallow** 工作线；实现落在方案 17 训练包。

## 5. 主线路径解读（A0 → P2）

### 5.1 A0 / A0_ref：500pt 单专家地板

- 自写 A0：**0.5342±0.0242**；braindecode A0_ref：**0.5403±0.0256**。  
- 二者同量级，说明后续增益主要来自 **数据几何与结构**，而非「换官方实现」本身。

### 5.2 A1：可见上下文是主因

- **0.5717±0.0236**，相对 A0 **+3.75 pp**。  
- 仅使用 `X_mask` + Expert_cur，**无 Predictor / 双专家 / Decoder**。  
- 含义：在线可用的 past+cur（及零填 future 占位）已提供大部分可分信息；后续模块应证明 **在 A1 之上仍有增量**，或带来 **稳定性/在线鲁棒性** 等非 Acc 单一收益。

### 5.3 P0 / A2：Predictor 单独不够

- P0 / A2 均低于 A1（约 −0.5～−0.6 pp）。  
- 在仅 Three、当前超参下，**MLP 未来预测辅助并未转化为更高 Acc_paper**；可能原因包括：目标过难、λ_pred=1 过强、或 mean-pool 后 Predictor 表达力不足（后者由 U1 部分检验）。

### 5.4 P1：双专家闭环未超 A1

- **0.5643±0.0217**，低于 A1。  
- 在缺少 Decoder 时，Gate 融合未来支路可能引入噪声或优化冲突。  
- **5090 B 系列**已跑：Expert_future+Gate（B4）、融合 CE（B7）、L_pred（B1）均有 ~0.4–1.2 pp 因果贡献；5090 上 P1≈A1。5060 上 P1&lt;A1 更可能来自 batch/优化差异，而非结构无效。

### 5.5 P2：定稿主结果

- **0.5707±0.0112**，相对 P1 **+0.64 pp**，相对 A1 **≈持平（−0.10 pp）**。  
- 关键贡献：**方差显著下降**（0.0236→0.0112 vs A1），五折更一致。  
- 与训练图对齐：波形 Decoder + PSD/μ/β/time 约束，使 `z_pre` 更具生理可解释性，并稳定多任务训练。

**主线叙事建议**：

```text
A0（地板）──(+3.75pp)──► A1（上下文）──(模块试验)──► P1（略退）──(+0.64pp)──► P2（定稿·最稳）
```

## 6. U 系列（相对 P2 结构升级）

执行：2026-08-18 19:41 → 2026-08-19 07:10 · 顺序 U1→U3→U2 · 各约 3.4–4.1h。

### 6.1 U1 · 时间维 Predictor

| 项 | 值 |
|----|-----|
| 变更 | Predictor 输入由 `mean(Z_vis)` 改为 `Z_vis` 序列；Attn + Dilated TCN → `z_pre` |
| Acc_paper | **0.5722±0.0180** |
| vs P2 | **+0.15 pp** |
| 逐折 | 0.5536 / 0.5842 / 0.5479 / 0.5821 / 0.5933 |

**解读**：序列 Predictor 带来 **边缘均值收益**，但 fold 间波动大于 P2。若论文强调「结构升级必超基线」，证据不足；若作为 **可选增强 / 消融对照**，可报道「不伤均值、略增方差」。Expert_cur 仍为 mean-pool（与方案「实现时二选一写死」一致）。

### 6.2 U3 · Gate + 专家熵

| 项 | 值 |
|----|-----|
| 变更 | Gate 输入 `[z_vis, z_pre, H(p_cur), H(p_future)]` |
| Acc_paper | **0.5708±0.0180** |
| vs P2 | **+0.01 pp** |
| 逐折 | 0.5542 / 0.5818 / 0.5442 / 0.5867 / 0.5870 |

**解读**：**无效改动**（在当前协议下）。熵标量未改善融合；与「L1 Gate 输入扫描」同属门控族，后续若跑 L1 的 z+p 变体可合并讨论，但 **U3 本身不宜作为正贡献模块**。

### 6.3 U2 · Spectral Decoder

| 项 | 值 |
|----|-----|
| 变更 | 去掉 8×400 波形重建；`z_pre → (log μ, log β)` MSE |
| Acc_paper | **0.5665±0.0236** |
| vs P2 | **−0.42 pp** |
| 逐折 | 0.5521 / 0.5824 / 0.5267 / 0.5882 / 0.5830 |

**解读**：直接频带头 **未能替代** 波形 Decoder；fold2 明显偏低拉低均值与抬高方差。支持定稿叙述：**P2 波形路径仍是更好的生理约束接口**。C 系列（相对波形 Decoder 的消融）仍有独立价值，U2 **不替代** C。

| 臂 | Acc_paper | vs P2 | run |

| U13（U1+U3） | 0.5659±0.0213 | −0.48 pp | `20260819_120859_U13` |

## 8. 讨论

更细的机制分析（**全部已完成五折臂**，对照物为 A1，不限 U 系列）：[分析_为何U系列模块未提升.md](./分析_为何U系列模块未提升.md)。

### 8.1 「模块越多越好」不成立

在相同数据协议下，**最简 A1** 已接近甚至略高于复杂 P1；P2 的价值更体现在 **稳定性 + 训练图完整性**，而非大幅抬分。论文应避免堆叠叙事，改为：

1. 上下文几何（A1）；  
2. 在线契约下的未来预测与门控（P1）；  
3. 生理解码约束如何稳住训练（P2）。

### 8.2 与外部「只升三处」建议的对照

| 建议 | 本实验对应 | 结果 |
|------|------------|------|
| 升级时间维 Predictor | U1 | 微弱 +0.15 pp，方差↑ |
| Spectral Decoder | U2 | −0.42 pp |
| Gate 加不确定性 | U3 | ≈0 |

→ **保留 v1.x（P2）作为主结果是合理的**；三处升级不宜替换主表。

### 8.3 5090 B/C 已补因果链（5060 未跑）

5090 全量 B1–B10、C1–C2c 已完成（见 [分析 doc §6](./分析_为何U系列模块未提升.md#6-5090-bc-消融5060-缺失的因果证据)）。要点：

| 问题 | 5090 答案 |
|------|-----------|
| L_pred 是否必要？ | **是**（B1 −1.24 pp vs P1） |
| CE(p_final) 是否必要？ | **是**（B7 −1.00 pp） |
| Expert_future+Gate 是否有贡献？ | **是**（B4 −0.36 pp；B5a 仅 p_cur −0.87 pp） |
| 可学习 Gate vs 固定 0.5？ | **≈无差**（B5b +0.02 pp vs P1） |
| Decoder 是否抬 Test 均值？ | **否**（C1 −0.10 pp vs P2） |
| Decoder 哪一项最重要？ | **time MSE**（C2c −0.48 pp） |
| 去掉 PSD 是否更好？ | **5090 上 C2a 最高**（0.5758，+0.56 pp vs P2） |

**跨机差异**：5090 P1≈A1，5060 P1 低 A1 0.74 pp——双专家在 5090 可工作，5060 上更可能是优化环境而非结构无效。

仍缺：**5060 复现 C2a**、**L1** Gate/λ 网格、**Task** 二分类。
