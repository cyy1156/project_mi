> 覆盖本方案 **全部已出正式五折** 的臂，不以 U 系列为限。

## 0. 总判断（先看这张表）

对照物不是 P2，而是 **最简且最强的分类器 A1**（1000pt `X_mask` + 单专家，无 Predictor / Gate / Decoder）。

1. **唯一大步是 A0→A1（+3.75 pp）**，改的是数据几何，不是网络模块。
2. **A1 之后每一个方法模块，五折均值都不高于 A1，或只在噪声内（U1 +0.05 pp）。**
3. 多数「加模块」臂对 A1 只赢 **1/5 折**，而且赢的几乎都是 fold4；**fold1（A1=0.6079）全部被打掉。**
4. P2 是唯一值得保留的后处理：均值与 A1 打平，**方差减半**。这是正则，不是抬分。

## 2. 按加入顺序：每一臂加了什么、为什么无效

### 2.1 A0 / A0_ref：不是 Encoder 写错了

自写 A0 0.5342，官方 braindecode A0_ref 0.5403，差 0.61 pp、同量级。  
后续 +3.75 pp **不能**归因于「换成自写 Shallow」或「换成官方实现」。地板由 **500pt 窗、8 导、三类跨被试** 决定。

### 2.2 A1：唯一成立的正增益（数据，不是模块）

只改几何：`past100+cur500+零填 future400`，仍单专家。推理与训练都只看 `X_mask`。

含义：在线已经允许使用的 past+cur（外加等长占位）把 Shallow 能用的信息基本给齐了。后面所有模块的验收标准应是 **在 A1 之上还有增量**。本轮没有任何模块稳定跨过这条线。

### 2.3 P0 / A2：只加 Predictor，五折里 4 折更差

设计目的：用 `L_pred`（可见表征 → 未来隐向量 MSE）做辅助，推理仍 `p_cur`。  
实现上两臂开关几乎相同（都是 `use_predictor=True`，无 Gate / 双专家 / Decoder），均值差 0.16 pp，视为复跑噪声。

为何无效：

- 推理决策 **完全不用** `z_pre`，预测头只通过反传到 Encoder 起作用。
- `λ_pred = λ_cls = 1`，未来表征 MSE 含大量非类别动态，Encoder 被拉向「可预测」。
- 目标是 `mean(Z_fut)` 的 40 维向量，本身不一定类条件可分。
- 证据：相对 A1，P0/A2 各只赢 fold4；Val Acc_paper 从 0.572 降到 0.563。早停看的就是被辅助损失压低的 val。

结论：**「预测辅助表征」在当前损失权重下伤害分类，而不是帮助分类。**

### 2.4 P1：再加双专家 + Gate + SIGReg，主线最差均值

相对 A1 **−0.74 pp**，Val 0.5583 为已跑臂中较低。fold1 相对 A1 **−2.91 pp**。

为何无效：

- 推理仍只喂 `X_mask`。`z_pre` 是 `z_vis` 的预测，`p_future` 与 `p_cur` 高度相关。Gate 混合两路相关概率，期望增益接近 0，估计误差却会注入。
- 无 Decoder 时 `z_pre` 缺乏生理约束，未来支路更像噪声专家。
- 同时开了 SIGReg（λ=0.05）和 `L_pred`，三个辅助目标叠在分类上。5060 上闭环整体未过 A1 验收；**5090 B 系列**（§6）表明：L_pred、CE(p_final)、Expert_future 均有因果贡献，但 **5060 上 P1 仍低于 A1**，更可能是 batch/优化环境差异，而非「双专家结构本身无效」。

结论（5060）：**双专家闭环没有兑现「噪声下更稳」的设计承诺**——std 仍是 0.022，均值还低于 A1。5090 上 P1≈A1（−0.19 pp），双专家在该环境下可工作。

### 2.5 P2：Decoder 不抬均值，但稳住难折

相对 P1 +0.64 pp，相对 A1 **−0.10 pp（持平）**，std **0.0112（全表最低）**。  
独有贡献：fold2 +1.73 pp vs A1。U2 去掉波形后 fold2 再崩，从反面支持「波形约束在起正则作用」。

为何「有用」却看起来「没提升」：

- Decoder 只在训练出现，推理不用。它不增加测试时信息，只塑造 `z_pre`。
- 塑造的结果是：**别在难折上崩、别在易折上冲太高**。Acc_paper 均值因此贴着 A1，方差下降。
- 这是定稿理由（训练图完整 + 跨折稳健），不是「加了 Decoder 所以准确率更高」。
- **5090 C 系列**（§6）：C1（无 Decoder）与 P2 均值差仅 0.1 pp，支持「Decoder 不抬 Test 均值」；C2c（去 time MSE）−0.48 pp，说明波形 Decoder 里 **时域项** 最关键；C2a（去 PSD）反而为 5090 最高非 oracle 配置（0.5758），提示 PSD 项可能过约束。

### 2.6 U1：时间维 Predictor 仍接不到分类头

相对 P2 +0.15 pp，相对 A1 **+0.05 pp**。五折 2 胜 3 负；fold4 +3.90 pp vs A1 把均值拉正。

结构缺口：序列进了 Predictor，但 `L_pred` 仍对齐 mean 向量，Expert_cur **仍 mean-pool**。时间建模到不了真正做决策的头。  
相对 A1 的 fold1 仍 −2.37 pp，说明没解决「辅助任务打高峰」的问题。

### 2.7 U3：Gate 加熵

相对 A1 −0.09 pp。熵是 `p` 的函数，`p` 已由 z 决定，对已有 `[z_vis, z_pre]` 近似冗余。无效改动。

### 2.8 U2：换更弱的生理头

相对 A1 −0.52 pp。监督从 8×400 波形变成 2 个频带标量，fold2 回到比 A1 更差。说明 P2 里真正起作用的是 **波形级约束**，不是「有个 Decoder 就行」。

## 3. 贯穿全部实验的四条机制

这些机制同时解释 P0、A2、P1、P2、U1–U3，不是为 U 系列临时找的理由。

### 3.1 推理信息没变

A1 及之后所有臂，在线输入都是 `X_mask`。  
Predictor / 双专家 / Gate / Decoder / 时间维 / 熵 / 频带头，要么只在训练存在，要么是可见表征的确定性函数。  
**测试时没有多读到任何新的 EEG。** 能涨的只有「同一输入上更好的归纳偏置」。本轮除 P2 的折间正则外，归纳偏置没有转化成 Acc_paper。

### 3.2 多任务从打开 Predictor 起就在抢分类

损失默认 `λ_cls=λ_pred=1`（P1 起再加 SIGReg，P2 起再加 λ_dec=0.2）。  
Val Acc_paper：A1 0.5721 → P0/A2 ≈0.563 → P1 0.5583 → P2 0.5641。  
早停监控的就是这项被压低的 val，检查点不会按「纯分类最好」来选。  
P0/A2 已经单独证明：**只加 L_pred、推理不用预测头，均值也会掉。** 后面的双专家是在这块已经受损的 Encoder 上继续堆。

### 3.3 读出与 Encoder 容量封顶

全程 Shallow D=40、Expert 前 mean-pool。U1 只升级了 Predictor，分类主路没升级。  
A1 已把这条浅骨干在 1000pt 上推到约 57%。再堆头，增加的是辅助损失的拟合对象，不是类条件特征的维度。

### 3.4 Acc_paper 过半投票 + 折间重分配

试次须窗正确率 >0.5 才计对。窗级小幅变化翻不了试次。  
各复杂臂用 fold4 的涨去填 fold1 的跌，均值像「差不多」，逐折看则是 **不稳定的重分配**。P2 是唯一把难折补上、把易折削峰的臂。

## 5. 口径与下一步

**可以写**：在线契约下，把可见上下文扩到 past+cur（A1）是准确率的主来源；在此之上，波形 Decoder（P2）不显著改变 Test 均值（5090 C1≈P2 已证实），但 5060 上降低折间方差，故作定稿。5090 B 系列提供因果证据：L_pred、CE(p_final)、Expert_future 对 P1 必要；可学习 Gate ≈ 固定 α=0.5（B5b）。

**不能写**：Predictor、双专家门控、SIGReg、时间维升级、熵门控、频带 Decoder「在 5060 上带来了稳健提升」。相对 A1，它们或为负、或为单折拉动。

**若还想从模块挤分**（优先顺序，已更新）：

1. **λ_pred 网格**（B1 证明 L_pred 必要，但 λ=1 可能过强；应扫描而非去掉）。  
2. **5060 复现 C2a**（去 PSD 的 Decoder 变体，5090 上略优于 P2）。  
3. 推进 v2：D=128、Token+Phase Predictor（B9 oracle 仅 +0.5 pp vs P1，头上限有限）。  
4. **不要继续堆 U 组合**——5060 U13/U12/U123 均低于 P2（−0.48～−0.75 pp）。

