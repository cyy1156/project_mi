## 0. 目标

1. 在**同一数据、同一划分、同一训练策略**下，对比多个基线主干。  
2. 二分类与三分类**独立训练、不迁权重**；分类头用各模型**原生头**（不统一 Linear）。  
3. 以后加入**自研模型**时，走**同一套实验步骤与报数模板**，只登记模型、不改协议。

一句话：

```text
固定协议壳（数据/划分/任务/指标/目录）
  + 可插拔模型注册表（基线 + 自研）
  = 可扩展的实验3流水线
```

## 1. 冻结协议（所有模型必须遵守）

### 1.1 数据

| 项 | 约定 |
|----|------|
| 默认库 | `code/preprocess_lab/out/merged_2s/`（方案 A）；单库对照用 `bci2a_2s` / `stieger_2s` |
| 磁盘张量 | `(N, 1, 8, 500)` float32 |
| 进模型张量 | **`(B, 8, 500)`**（Dataset 去掉中间维 `1`） |
| 通道序 | Cz, C3, C4, CP3, FC4, FC3, CP4, CPz（模型不读名字，只认 8 导） |
| 标签 | 同一份 `X` + `y_task` / `y_three` |
| 采样率 | 250 Hz；窗长 2 s → 500 点 |

### 1.2 划分与优化

| 项 | 约定 |
|----|------|
| 划分 | 被试独立五折；`seed=42`；合并库按库分层 |
| 折内 | 非 test 人再按人抽约 20% 为 val |
| 损失 / 优化器 | CrossEntropy + Adam |
| 早停 | 只看 **Val**（二分类 F1；三分类 F1-macro） |
| Test | 每折训练结束后只评一次；报 **5 折 mean±std** |
| 调参 | 只看 Val；禁止用 Test 选型 |

### 1.3 训练策略（每个模型各跑两遍）

```text
【Task】  build(model, n_outputs=2) → 随机初始化 → 五折 → 记录
【Three】 build(model, n_outputs=3) → 再次随机初始化 → 同一 seed 五折 → 记录
禁止：Three 加载 Task 任何权重；禁止：换成统一 Linear 头
标注：weight_transfer=false，classifier=native
```

### 1.4 模型前向契约（自研也必须满足）

```text
输入:  x  shape = (B, 8, 500)  float32/float64 tensor
输出:  logits shape = (B, n_outputs)   # 二分类 n_outputs=2；三分类=3
禁止: 输出 (B, n_outputs, T) 等未收成类别维的张量（裸 TCN 不合格）
```

## 2. 总体架构

```text
                    ┌─────────────────────────────┐
  merged_2s npy ──► │  共用：Dataset / 五折 / 指标  │
                    └─────────────┬───────────────┘
                                  │
                    ┌─────────────▼───────────────┐
                    │  model registry（注册表）      │
                    │  eegnet / shallow / … / mine │
                    └─────────────┬───────────────┘
                                  │
              ┌───────────────────┼───────────────────┐
              ▼                   ▼                   ▼
        train_task_kfold    train_three_kfold    run_baseline_matrix
        (n_outputs=2)       (n_outputs=3,        (多模型 × 两任务)
                             不迁权重)
```

原则：

- **训练壳只认注册表**，不在 `train_*_kfold.py` 里写死 `EEGNet(...)`。  
- **超参分「共享」与「模型私有」**两层，避免 Conformer 硬套 EEGNet 的 `F1/D/F2`。  
- 自研模型 = **新注册一条**，不复制一套过夜脚本。

## 3. 模型注册表（核心）

建议路径：`code/train_lab/src/step/models/registry.py`（落地时再建）。

### 3.1 每条登记必须包含的字段

| 字段 | 含义 | 示例 |
|------|------|------|
| `name` | 短名（目录/CLI） | `eegnet` / `my_mi_net` |
| `family` | 族：`cnn` / `tcn` / `transformer` / `custom` | 用于分组报数 |
| `builder` | `build(n_chans, n_times, n_outputs, **hp) -> nn.Module` | 返回带原生头的整网 |
| `input_layout` | 固定 `bct` = `(B,C,T)` | 与现 Dataset 一致 |
| `needs_n_times` | 是否要把 `n_times=500` 传进构造 | CNN/多数为 true |
| `default_hparams` | 该模型默认超参 | 见下 |
| `search_space` | Val 调参网格（可空） | 按族给 |
| `notes` | 适配备注 | 如「禁止裸 TCN」 |

### 3.2 内置基线登记（与计划 §3.1.2 对齐）

| `name` | braindecode / 说明 | `family` | 输入 | 输出 |
|--------|-------------------|----------|------|------|
| `eegnet` | `EEGNet` | cnn | `(B,8,500)` | `(B,n_outputs)` |
| `shallow` | `ShallowFBCSPNet` | cnn | 同左 | 同左 |
| `deep` | `Deep4Net` | cnn | 同左 | 同左 |
| `eegtcnet` | `EEGTCNet`（对应「EEGNet+TCN」） | tcn | 同左 | 同左 |
| `conformer` | `EEGConformer`（`final_fc_length='auto'`） | transformer | 同左 | 同左 |

**不要登记**裸 `TCN`：前向易得到 `(B, n_outputs, T')`，不满足 §1.4。

可选增强：`bdtcn`（`BDTCN`）作为 TCN 族对照，不算计划必选。

### 3.3 Builder 伪代码

```python
def build_model(name: str, n_chans: int, n_times: int, n_outputs: int, **hp) -> nn.Module:
    spec = REGISTRY[name]
    return spec.builder(n_chans=n_chans, n_times=n_times, n_outputs=n_outputs, **hp)
```

训练循环里：

```python
model = build_model(cfg.model_name, n_chans=8, n_times=X.shape[-1], n_outputs=2, **model_hp)
# Three 任务仅改 n_outputs=3，禁止 load_state_dict(task_ckpt)
```

## 4. 超参分层（保证适配性）

### 4.1 全体共享（公平壳）

```text
n_folds=5, val_ratio=0.2, seed=42
max_epochs / patience（可全体同一起步值，再按族微调）
batch_train / batch_eval
优化器: Adam + weight_decay（共享搜索范围）
数据: 同一 merged_2s（或报告中声明的同一单库）
```

### 4.2 模型私有（按族，不互相硬套）

| 族 | 典型私有键 |
|----|------------|
| cnn（EEGNet） | `F1, D, F2, drop_prob, kernel_length` |
| cnn（Shallow/Deep） | `n_filters_*`, `pool_*`, `drop_prob` |
| tcn（EEGTCNet） | `depth, filters, kernel_size, kern_length, drop_prob` |
| transformer（Conformer） | `n_filters_time, num_layers, num_heads, att_drop_prob, drop_prob` |
| custom | 自研自己声明；写入登记表 |

规则：

- 对比表可以并排报 **Test**，但选型时每个模型只用**自己的 Val 网格**。  
- 禁止「所有模型共用一份 EEGNet 网格」当作唯一公平（对 Conformer 不公平）。

## 5. 标准实验步骤（基线与自研同一套）

对**每一个** `model_name`：

### Step A — 二分类（Task）

1. `build(model, n_outputs=2)`，随机初始化。  
2. 被试独立五折；Val F1 早停 / 调参。  
3. 写目录与 summary（含 Overall；合并库另写 `bci2a_only` / `stieger_only`）。  
4. **本步权重不传给三分类。**

### Step B — 三分类（Three）

1. `build(model, n_outputs=3)`，**重新**随机初始化。  
2. **同一** `seed` 与五折被试划分。  
3. Val F1-macro 早停 / 调参。  
4. 独立目录保存；meta 写明 `weight_transfer=false`。

### Step C — 归档

1. 每个模型一份小节 MD/JSON。  
2. 矩阵跑完后汇总表：行=模型，列=Task/Three 的 Val·Test。  
3. 历史迁移结果可并列，但必须标 `weight_transfer=true`（旧）。

过夜 / 矩阵建议顺序：

```text
for model in models:
    task 网格 → task 调参 → 记录最优超参与 Test
    three 网格 → three 调参 → 记录最优超参与 Test   # 不读 task ckpt
写总表 baseline_matrix_<stamp>.md
```

> **基线必须各自找最佳参数**：不得用 EEGNet 的最优超参直接套到 Shallow/Deep/Conformer。  
> 细则见下一节 §5.1。

---

## 5.1 基线最佳参数搜索协议（必做）

每个 `(model, task)` 独立搜参；选型指标**只看五折 Val 均值**（二分类 Val F1；三分类 Val F1-macro）。Test 只写进报告，**不参与选优**。

### 流程（与现有过夜同构，按模型复制）

```text
阶段 0  小网格（3～6 组）→ 取 Val 最优一组
阶段 1  规则微调 1 轮（可沿用 overnight 的 suggest_*_hparams 逻辑）
阶段 2  固定最优超参 → 该次五折的 Test 作为该模型该任务的正式报数
（可选）阶段 3  对争议模型再加一轮私有结构网格（见下表）
```

「最佳参数」定义：

```text
best_hparams(model, task) =
  argmax_{hp in search_space(model, task)}  mean_Val(model, task, hp)
```

Task 与 Three **两套独立 best**；即使同一模型，也允许 `lr/drop/...` 不同。

### 共享搜索维（所有基线都扫）

| 维 | 建议候选（起步） |
|----|------------------|
| `lr` | `5e-4, 7e-4, 1e-3, 1.5e-3` |
| `weight_decay` | `5e-5, 1e-4, 2e-4` |
| `drop_prob`（若模型有） | `0.40, 0.50, 0.55, 0.60` |
| `patience` | `15, 18, 20` |
| `batch_train` | 默认 `32`；显存不够再降，须写入报告 |

可先做 **4 点小网格**（与当前 `run_overnight_kfold` 头1网格同风格），再规则微调 1 次，控制过夜时长。

### 模型私有搜索维（最佳参数必须含这些）

| 模型 | 除共享维外应搜 / 至少扫的私有键 | 说明 |
|------|----------------------------------|------|
| `eegnet` | `F1∈{4,8}`, `D∈{2}`, `F2∈{8,16}`（可先锁默认 8/2/16，只扫优化器维） | 与现 overnight 一致时可先只扫 lr/drop/wd |
| `shallow` | `n_filters_time`, `filter_time_length`, `pool_time_length` | **不要**用 EEGNet 的 F1/D/F2 |
| `deep` | `n_filters_time`, `n_filters_2/3/4` 或默认 + 只调优化器维 | 结构默认可先锁，优先扫 lr/drop/wd |
| `eegtcnet` | `filters`, `depth`, `kernel_size`, `kern_length`, `drop_prob` | TCN 族感受野敏感 |
| `conformer` | `num_layers∈{2,4,6}`, `num_heads`, `att_drop_prob`, `n_filters_time` | 必须本族网格；禁止套用 CNN 网格赢家 |
| 自研 | 登记表里的 `search_space` | 接入时一并声明 |

### 公平性规则

1. **每个基线自己的 Val 最优** → 再比各模型的 Test（这才是「调过参的基线对比」）。  
2. 搜参预算尽量对齐：例如每模型每任务「网格 ≤6 + 微调 ≤1」；若某模型多开私有结构网格，须在总表注明「额外结构搜索」。  
3. 合并库选型看 **Overall Val**；分库指标只报告、不拿来改 hp。  
4. `seed=42`、五折划分全程固定；换 hp 不换划分。  
5. 选出的 `best_hparams` 写入 `summary.json` 与总表，便于复现与自研对照。

### 总表应多出的列

| model | task_best_hp | task_Val | task_Test | three_best_hp | three_Val | three_Test |
|-------|--------------|----------|-----------|---------------|-----------|------------|

## 7. 自研模型接入清单（按相同步骤）

### 7.1 实现要求

1. `nn.Module`，`forward(x) -> logits`，`x:(B,8,500)`，`logits:(B,n_outputs)`。  
2. **自带分类头**（或你认为「该模型原生」的最后一层）；实验3阶段**不要**为了公平改成统一 Linear。  
3. 构造函数至少能接收：`n_chans`, `n_outputs`；若依赖窗长则接收 `n_times`。  
4. 可放在例如：`code/train_lab/src/step/models/custom/my_mi_net.py`。

### 7.2 注册（唯一必做的「接入」动作）

```python
# 伪代码
register(
    name="my_mi_net",
    family="custom",
    builder=build_my_mi_net,
    input_layout="bct",
    needs_n_times=True,
    default_hparams={...},
    search_space={...},
    notes="自研；原生头；独立训 2/3 类",
)
```

### 7.3 跑通验收（与基线同一清单）

- [ ] 随机 `x = randn(4,8,500)` 前向得 `(4,2)` / `(4,3)`  
- [ ] Task 五折跑通，写出 `summary.json`  
- [ ] Three 五折跑通，且**未**加载 Task ckpt  
- [ ] 合并库时 Overall + 分库指标齐全  
- [ ] 总表里出现一行 `my_mi_net`，字段与基线同列  

### 7.4 禁止事项（自研常见踩坑）

| 禁止 | 原因 |
|------|------|
| 输入仍用 `(B,1,8,500)` 不挤维 | 与 Dataset/基线不一致 |
| Three 从 Task 迁主干「先看看」 | 违反现行策略；对照须另开 `weight_transfer=true` 实验 |
| 为对齐基线强行换 Linear 头 | 违反原生头约定 |
| 改五折 seed / 偷看 Test 调参 | 破坏跨模型可比性 |
| 自研用另一套预处理窗长却不声明 | 不可比 |

## 10. 推荐推进顺序（实验，不是改造量）

1. **协议落地**：Three 默认独立训（先 EEGNet 复跑一条，确认脚本）。  
2. **CNN 族**：`eegnet / shallow / deep` 同壳对比（公平性最好）。  
3. **扩展族**：`eegtcnet`、`conformer`（用本族私有超参）。  
4. **自研**：登记 `my_*` → 同一矩阵加一行。  

报数时建议分两张表：

- 表 A：CNN 同构族  
- 表 B：全模型（含 TCN / Transformer / 自研），注明族别与私有超参来源

## 12. 拍板摘要

| 项 | 决定 |
|----|------|
| 输入 | 全体 `(B, 8, 500)` |
| 输出 | 全体 `(B, n_outputs)` |
| 任务 | Task 与 Three **独立**、不迁权重 |
| 分类头 | **原生**；不统一 Linear |
| **调参** | **每个基线、每个任务各自 Val 搜最优超参**；禁止套用他模最优；Test 不选型 |
| 扩展方式 | **注册表**；自研只登记 + 同步骤 A/B/C（含本模型 `search_space`） |
| 「EEGNet+TCN」 | 用 `EEGTCNet`（不用裸 TCN） |
| 代码 | **已按 §9 落地** |
