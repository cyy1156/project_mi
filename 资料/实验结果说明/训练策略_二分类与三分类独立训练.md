# 训练策略变更：二分类与三分类独立训练（不迁权重）

> 版本：v0.4（2026-07-29）  
> 状态：**策略约定仍有效**；现行入口为 `baselines_single/`（五基线脚本已落地，见 §5）。  
> 适用：多主干基线对比（计划实验3）及后续实验；历史「迁主干训头2」结果仍作对照归档，不再作为新实验默认。  
> 归类清单：[`资料/模型训练/归类清单_单模型入口重构.md`](../模型训练/归类清单_单模型入口重构.md)

---

## 0. 一句话

先独立训练 **静息/任务二分类**，完整记录结果；再 **从头随机初始化** 训练 **空闲/左/右三分类**。  
**禁止**加载二分类权重（含主干与分类器）；**不**统一各模型分类头，一律使用该模型 **自带分类器**。

---

## 1. 与旧策略对照

| 项 | 旧策略（已跑过夜，如 `141553` 等） | **新策略（本文）** |
|----|-----------------------------------|-------------------|
| 二分类 | 训 `n_outputs=2` 整网 | 同左：独立训二分类并记录 |
| 三分类 | 新建 `n_outputs=3`，**迁移**二分类主干（跳过分类层） | 新建 `n_outputs=3`，**完全不加载**二分类任何参数 |
| 分类器 | 各模型自带头（EEGNet 为 Conv 头） | **仍用各模型自带头**，不统一 Linear |
| 并行双头 | 未做 | 本阶段不做 |
| 串行门控 | 仅在线规划 | 本阶段不改训练结构 |

旧文档 `资料/模型训练/阶段B_第二分类头与权重迁移.md` 描述的是**迁移策略**，作历史对照；**新实验以本文为准**。

## 2. 训练流程（每个主干模型各自跑一遍）

```text
【阶段 Task】静息 vs 任务
  模型 = Backbone_X 自带分类头，n_outputs=2
  随机初始化 → 被试独立五折 → Val F1 早停/选型 → 记录 Test
  保存：本阶段权重与 summary（仅作二分类结论，不供三分类加载）

【阶段 Three】空闲 / 左 / 右
  模型 = 同一 Backbone_X 结构，自带分类头，n_outputs=3
  再次随机初始化（与 Task 权重无关）
  同一 seed / 同一被试五折划分 → Val F1-macro 早停/选型 → 记录 Test
  保存：三分类权重与 summary（独立目录）
```

单模型脚本内建议顺序（新代码放在 `baselines_single/`）：

```text
Task 五折（或共用超参网格）→ 写报告
→ Three 从零五折（不加载 Task 权重）→ 写报告
```

注意：三分类 **不再**需要 `task_kfold_dir` / `best_task.pt`。

---

## 3. 必须固定的实验变量

| 项 | 约定 |
|----|------|
| 数据 | 与对比实验一致（建议先 `merged_2s` 或单库 `*_2s`，全文声明） |
| 划分 | 被试独立五折，`seed=42`；合并库用按库分层 |
| 优化 | CrossEntropy + Adam；Val 选型，Test 终评 |
| 分类头 | **模型原生头**（不拆、不换成统一 Linear） |
| 双标签 | 仍用同一份 `X` + `y_task` / `y_three`（只是两个任务分开训） |

## 4. 报数与目录（现行实现）

权重与折结果（`baselines_single` 实际写出）：

```text
code/train_lab/out/baseline/<model>/<data>/run_<stamp>/
  task/     # 仅二分类
  three/    # 仅三分类（不加载 Task 权重）
```

实验记录 MD：

```text
资料/模型训练/runs/<stamp>_<model>/五折实验记录.md
资料/模型训练/五折实验记录_最新.md   # 指针
```

报告至少包含：

1. **二分类**：Val/Test Acc、F1（及合并库时 Overall / bci2a_only / stieger_only）  
2. **三分类**：Val/Test Acc、F1-macro（及按库拆分）  
3. 明确标注：`weight_transfer=false`，`classifier=native`

## 5. 代码入口（现行）

| 位置 | 状态 |
|------|------|
| `code/train_lab/src/step/baselines_single/` | **现行入口**：`baseline_{eegnet,shallow,deep,eegtcnet,conformer}.py` + `shared_hparams.py` |
| `baselines_single/run_all_five_model.py` | **可选**串跑五基线（仍各跑独立脚本）；日常对照优先单脚本 |
| `code/train_lab/src/step/dataset.py` 等 | **继续复用**（Dataset / metrics / data_paths） |
| `code/train_lab/src/step/归档_旧训练入口/` | **仅对照**：原 registry / matrix / overnight / `train_*_kfold`；搬迁后路径未修，**不可直接当可运行入口** |

示例：

```bash
cd code/train_lab/src/step/baselines_single
python baseline_eegnet.py --data merged_2s
python baseline_shallow.py --data stieger_2s
```

约定变更要点：

- **不用**统一模型注册表作为现行入口；每个基线单独脚本构建模型。  
- **不用**旧矩阵/`run_overnight_kfold` 作现行入口；需要连跑时用可选的 `run_all_five_model.py`。  
- **共用**一套训练超参（`shared_hparams.py`）；各脚本只换网络构造。  
- MD 写入 `资料/模型训练/runs/`。  
- **复现**：各 `baseline_*.py` 使用 `seed_everything(hp.seed)` + 每折 `seed_everything(hp.seed+fold)` + DataLoader `generator`；详见 [`baselines_single/README.md`](../../code/train_lab/src/step/baselines_single/README.md)。
