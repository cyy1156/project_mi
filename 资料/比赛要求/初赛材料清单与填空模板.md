## 2. 系统与 SOP 说明（初赛必写）

### 2.1 一句话架构

公开数据集预训练通用表征 → E1f 四成员融合推理 → 自采被试采后 Leave-Next 个性化 → 在线交互（因果平滑 + 多数票读出）。

### 2.2 现行现场协议（写给评委的短表）

| 项 | 现行设定 | 配置/文档锚点 |
|----|----------|----------------|
| 时序 | OpenBMI-Align v1 | F1；`v3_session.yaml` |
| Rest | 专用试次间 Rest 4s（不含其后 prep 2s） | F2 |
| 窗 | 3 s / hop 100 ms；推理侧按线上配置 | 与训练 3s 主线对齐 |
| 零样本底座 | E1f 四成员（含 T-shallow） | F3/F4 |
| 窗级读出 | E1f `p_three` → 因果平滑（n,n−1,n−2）→ argmax | F5 |
| 试次判定/计分 | **同一多数票**；MI 对 +1；Rest 对 +0.5 | F5/F6 |
| 微调 | 采后 Leave-Next；默认 replay 0.10 | F7/F9 |
| 弱 MI / 门控 FAIL | 可警告后强制晋升 current | F8 |
