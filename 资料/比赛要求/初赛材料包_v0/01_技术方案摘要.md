## 1. 目标与需求响应

面向卒中康复与辅助控制场景，完成 **左手 / 右手 / 静息（空闲）** 三类运动想象相关脑电的实时解码，并提供网页游戏诱导与少样本个性化适配。

| 赛事需求 | 初赛响应 |
|----------|----------|
| 三分类精准识别 + 完整采集—解码—交互系统 | 已建成 `experiment_game` 实时链路 |
| 用户引导 + 算法自适应 | 游戏诱导 + 采后 Leave-Next 微调 |
| ≥20 名自采数据训练/验证 | **进行中**；公开集已完成预训练与离线验证 |
| 鲁棒解码 / 空闲判别 / 少样本 / 低延迟 | 公开集与真人样例已有量化证据 |

---

## 2. 总体技术路线（三级优化）

```text
公开 MI 数据预训练（OpenBMI）
        ↓
通用底座 + E1f 四成员融合推理
        ↓
自采被试（OpenBMI-Align 范式）→ 采后 Leave-Next 个性化
        ↓
在线交互：因果平滑 + 多数票读出（计分与主判定单轨）
```

对应框架：**迁移学习 → 少样本个性化 → 在线校准（读出侧）**。

---

## 3. 实验范式（现场现行）

采用 **OpenBMI-Align v1**（与公开训练底座语义对齐）：

```text
[专用 Rest 4s] → [prep 2s] → [Cue = MI onset] → [MI 4s] → [ITI 3s] → …
```

- 采样率：**250 Hz**  
- 通道序（设备=模型轴，F25）：**FC3, C3, CP3, CZ, CPZ, FC4, C4, CP4**（不得按字母/文件序重排）  
- 分类窗：相对 Cue 前向 **3 s** / hop **100 ms**（窗尾判定约 3.0…4.0 s；Cue 前 0.5 s 段级基线）  
- Rest：专用试次间 Rest 段（不含 prep），与 MI 共用 F5 读出族  

详细冻结见：`experiment_game/docs/框架冻结确认_20260829.md`（2026-08-30 代码复核版）。

## 4. 解码与读出

### 4.1 零样本底座

- 骨干成员：shallow、T-shallow、EEGNet、Conformer（OpenBMI 3s 协议训练）  
- 融合：**E1f 四成员**加权概率融合（温度/权重在验证集选定后冻结）  

### 4.2 正式读出（F5，已冻结）

| 层级 | 规则 |
|------|------|
| 窗级 | 融合概率 → **因果平滑**（当前窗与前两窗）→ argmax |
| 试次（MI） | 窗预测 **多数票**；正确 **+1** |
| 试次（Rest） | 同一规则；判 Rest 正确 **+0.5** |

> 旁路最优读数含置信早停（E1f=0.6173）；**正式部署废除 τ 早停双轨**，以保证在线因果与计分一致。

## 5. 少样本个性化

- **主路径**：采集完成后 **Leave-Next** 增量微调（非整场轮间在线 FT）  
- 底座：E1f 成员中的 shallow（task+three）  
- 回放：前段默认混入源域窗（replay≈0.10）防遗忘  
- 门控：档位评估；FAIL 可警告后 **强制晋升** 并标记弱 MI  

真人爬坡证据见 `04_个性化适配证据.md`。

## 6. 验证现状（初赛可陈述）

1. **离线（OpenBMI）**：被试独立五折；融合相对单模型有稳定增益；详见 `03`。  
2. **在线系统**：采集、对齐校验、实时读出与计分链路已冻结可演示。  
3. **真人适配**：至少 2 名正式协议被试完成 Leave-Next；强被试末档 MI **94.4%**。  
4. **自采扩库**：目标 ≥20；当前正式 FT 证据 **N=2**，历史试点 session 另计（见 `05`）。
