# 方案 L1：超参与结构扫描（仅 Three）

## 1. 目的

在 **P2（训练定稿）** 上小网格，Val Acc_paper 选优回填。不做 Task。不做 40→128。  
结构消融仍可先在 P1 上扫（B 系列），λ_dec / Decoder 子项在 P2 上扫。

## 2. 优先级

**必做**（P2 通后为主；P1 通后可先扫无 Dec 项）。一次动一类。

## 3. 顺序

1. λ_pred；是否 +CE(future)；Gate 仅 z vs z+p（可在 P1 上先扫）  
2. λ_sig；读出 / RF 表（可选）  
3. 头宽度微调；骨干 Shallow / EEGNet / Deep4  
4. **P2**：λ_dec；`num_slices`∈{512,1024}

**不做**：Task 五折；`Linear(40→128)`；默认不扫 AdamW（冻结 Adam）。

## 4. 网格

| 维 | 取值 |
|----|------|
| λ_pred | 0.25, 0.5, 1.0, 2.0 |
| λ_sig | 0, 0.01, 0.05, 0.1 |
| cls | cur+final / +future |
| Gate | z only / z+probs |
| 骨干 | Shallow, EEGNet, Deep4 |
| λ_dec（P2） | 0.05, 0.1, 0.2, 0.5 |

## 5. 回填

写入 [P2](./P2_生理解码约束.md)「当前采用」（主结果）；无 Dec 项亦可备注到 [P1](./P1_双专家门控与SIGReg.md)。
