# 方案 A1：可见上下文单专家

## 1. 目的 / 这是什么

在**不加 Predictor/双专家**时，只把输入从「仅当前 500 点」扩成「再多看 past 0.4 s」，量化 **cache** 贡献。

**口径（冻结）**：与后续 P* 公平对比时，**只用 1000pt `X_mask`**（future 零填，张量形状一致）。  
`(B,8,600)` 不是主对照，只回答「若根本不建 future 维，Acc 会不会更好」——**附报一行即可，不进主表减法**。

| 形式 | 形状 | 用途 |
|------|------|------|
| **主对比（必做）** | `(B,8,1000)`，future 段填 0 | 算 P1−A1、A1−A0 |
| **附报** | `(B,8,600)` 真短输入（无 future 维） | 检查零填 future 是否有害 |

## 2. 优先级

**必做** = 1000pt 主对比；600pt = **附报**（建议同折同超参顺手跑，不阻塞主线）。

## 3. 模块

| 模块 | 状态 |
|------|------|
| Encoder | 自写 shallowfbcsp，`forward_features`；**不用**原 final_layer |
| Expert_cur | **`D→64→C`**，D=40 |
| Predictor / future / Gate / SIGReg / X_full | 关 |
| 任务 | 仅 Three；Adam；batch 256/512 |

## 4. 读出

1000pt：§3.2.1 对 `I_vis` mean（不看 `I_future`）。  
600pt：整段 mean。

## 5. 损失

仅 `CE(p_cur, y)`。
