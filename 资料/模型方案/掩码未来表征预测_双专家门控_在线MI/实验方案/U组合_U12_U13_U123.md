## 0. 总则

### 0.1 目的

在 **已完成 U1/U2/U3 单因素对照** 的前提下，检验两两或三者叠加是否出现：

1. **超加性**（组合 Δ 明显优于各单改之和，或相对 P2 有稳健增益）；  
2. **相消 / 过拟合**（组合不如最好的单改，或方差进一步放大）；  
3. **叙事完整性**（「融合版完整形态」仅作附录形态展示，不进主表）。

### 0.2 共同冻结项（相对 P2 不变）

| 项 | 取值 |
|----|------|
| Encoder | ShallowFBCSP · D=40 · drop 0.5 |
| Mask / `X_full` no_grad 目标 | 同 P2 |
| Expert_cur / Expert_future | 同 P2（Expert_cur 仍 mean-pool `z_vis`） |
| SIGReg | 开 · λ_sig=0.05 · slices=1024 |
| λ_cls / λ_pred / λ_dec | 1.0 / 1.0 / **0.2** |
| 早停 | Val Acc_paper · patience=20 |
| 主报 | Test Acc_paper mean±std |
| 附报 | vs **P2** Δ；vs **相关单改**（U1/U2/U3）Δ；BalAcc_maj / F1-macro(maj) |
| 数据 | `openbmi_2s_hop100_pf1000` · protocol_version≥3 |
| chain | **不进**自动主链；手动 `run_arm` / guarded 脚本 |

### 0.3 开关矩阵（与代码一致）

| 臂 | `predictor_temporal` (U1) | `use_spectral_decoder` (U2) | `gate_entropy` (U3) | 波形 Decoder |
|----|---------------------------|-----------------------------|---------------------|--------------|
| P2 | ✗ | ✗ | ✗ | ✓ |
| U1 | ✓ | ✗ | ✗ | ✓ |
| U2 | ✗ | ✓ | ✗ | ✗（互斥） |

说明：Spectral Decoder 与波形 Decoder **互斥**（实现侧 `use_spectral_decoder` 优先关波形头）。

### 0.4 开跑门槛（决策树）

单改已出数后，按下列规则决定是否投入五折算力（5060 单臂约 3.5–4.5h）：

```text
若 max(U1,U2,U3 vs P2) 均 ≤ +0.3 pp 且无「中性且方差↓」
    → 组合默认「可跳过」；若仍需附录形态，只跑 U13（最便宜叙事：时间 Predictor + 熵）
若 U1 有增益或中性，且 U2 未显著伤分（Δ ≥ −0.3 pp）
    → 可跑 U12
若 U1 有增益或中性，且 U3 中性/正
    → 优先跑 U13（保留波形 Decoder，风险低于 U12）
若 U1∩U2∩U3 均增益或中性，且 U12/U13 至少一者 ≥ P2
    → 再跑 U123；否则 U123 明确跳过
```

**结合已出单改（2026-08-19）的建议优先级**：

| 优先级 | 臂 | 建议 | 理由 |
|--------|-----|------|------|
| 1 | **U13** | **建议跑（附报）** | U1 微正 + U3 中性；保留波形 Decoder，与 P2 接口一致 |
| 2 | **U12** | **可选 / 低优先** | U2 已 −0.42 pp；叠加 U1 需证明能否挽回 Spectral 损失 |
| 3 | **U123** | **默认跳过** | 单改无一致增益；堆三处易成过拟合叙事；仅当 U12 或 U13 明显 ≥ P2 再开 |

### 0.5 执行顺序（若开跑）

```text
U13 →（若 U13≥P2 或需证 Spectral+时间）U12 →（仅门槛满足）U123
```

与 B/C/L1：**不抢主消融算力**；可插在 C1 之后或与 L1 Gate 扫描并行机位。

### 0.6 统一验收

- `_smoke_local` / 前向：对应开关组合无 shape 错误；`band_hat` 与 `x_hat_future` 不同时出现。  
- §3.2.1 future-perturb 单测仍通过。

- **禁止**因组合均值略高就改写「主结果=P2」。

## U13 · U1 + U3（时间维 Predictor + 熵 Gate）【优先附报】

### 1. 目的

检验：**序列 Predictor 给出的 `z_pre`** 与 **熵条件 Gate** 是否互补 ——  
U1 改善未来支路表征，U3 改善 α 对专家不确定性的响应；二者叠加是否相对 P2/U1 更稳或更高。

### 2. 相对 P2 的变更点（仅两处）

| 项 | P2 | U13 |
|----|-----|-----|
| Predictor | MLP(`mean Z_vis`) | **Temporal**（同 U1） |
| Gate 输入 | `[z_vis, z_pre]` | `[z_vis, z_pre, H(p_cur), H(p_future)]`（同 U3） |
| Decoder | 波形 8×400 | **同 P2 波形** |
| 其余 | — | 同 P2 |

### 3. 对照读数

| 对照 | 期望解读 |
|------|----------|
| vs P2 | 主附报 Δ |
| vs U1 | 熵是否在 U1 之上再贡献 |
| vs U3 | 时间 Predictor 是否在 U3 之上再贡献 |

### 4. 优先级

**附报 · 组合中最高优先**（单改结论下仍值得跑一条「非 Spectral」融合）。

### 5. 验收 / 失败模式

- 若 U13 ≤ min(U1, P2) 且 std ≥ U1：记「无协同，组合不采纳」。  
- 若 U13 > U1 且 ≥ P2：可写「弱协同」；仍不替代 P2 主表。

## U12 · U1 + U2（时间维 Predictor + Spectral Decoder）【可选】

### 1. 目的

检验：U2 单改落后，是否因 **MLP Predictor 的 `z_pre` 对频带头不够信息丰富**；换 U1 序列 Predictor 后，Spectral μ/β 约束是否回到 P2 附近或更好。

### 2. 相对 P2 的变更点

| 项 | P2 | U12 |
|----|-----|-----|
| Predictor | MLP | **Temporal**（U1） |
| Decoder | 波形 + PSD/μβ/time | **仅 Spectral μ/β**（U2）；无 8×400 |
| Gate | `[z_vis, z_pre]` | 同 P2（无熵） |
| 其余 | — | 同 P2 |

### 3. 对照读数

| 对照 | 期望解读 |
|------|----------|
| vs P2 | Spectral 路径能否追平波形定稿 |
| vs U1 | 去掉波形 Decoder 的代价（在更好 Predictor 下） |
| vs U2 | 时间 Predictor 能否挽回 Spectral 单改跌幅 |

### 4. 优先级

**可选 · 低优先**。开跑条件建议：

- 需要论文附录回答「Spectral + 更好 Predictor」；或  
- 算力充裕且 U13 已完成。

若 U12 仍显著 < P2（如 Δ ≤ −0.3 pp），则强化「**保留波形 Decoder（P2）**」结论，无需再开 U123。

### 5. 验收 / 失败模式

- 预期高概率：**U12 ∈ [U2, U1]**，难以超过 P2。  
- 若 U12 ≥ P2：罕见正结果，再考虑 U123。

## U123 · U1 + U2 + U3（融合完整形态）【门槛制】

### 1. 目的

展示「外部建议三处升级同时打开」的 **完整形态**；检验三因子是否出现额外交互，而非追求新主结果。

### 2. 相对 P2 的变更点

| 项 | P2 | U123 |
|----|-----|------|
| Predictor | MLP | **Temporal**（U1） |
| Decoder | 波形 | **Spectral μ/β**（U2） |
| Gate | 两 z | **+熵**（U3） |

即开关：`predictor_temporal ∧ use_spectral_decoder ∧ gate_entropy`（无波形 Decoder）。

### 3. 开跑硬门槛（须同时满足）

1. U1、U2、U3 **均已五折出数**（已满足）；且  
2. **U12 或 U13** 至少一者 Test Acc_paper **≥ P2 mean**（或 Δ ≥ −0.1 pp 且 std 不差于 P2）；且  
3. 明确标注为 **附录形态**，不进主表、不改 P2 定义。

任一不满足 → **跳过 U123**，在结果栏填「门槛未过 · 未跑」。

### 4. 对照读数

| 对照 | 用途 |
|------|------|
| vs P2 | 完整形态相对定稿 |
| vs U12 / U13 | 第三人因子边际贡献 |
| vs U1 | 相对最强单改 |

### 5. 优先级

**默认跳过**；仅门槛通过后五折一次。
