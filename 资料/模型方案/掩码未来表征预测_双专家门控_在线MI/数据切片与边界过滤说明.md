## 3. Trial 连续段如何取（核心差异）

### 3.1 时间轴（相对 Cue = 0）

```text
        baseline(0.5s)     MI 评分区 4s              post-MI ≥1.6s
    |←—— cue 前 ——→|←——————————————→|←——————————————→|
  -0.5             0                 4.0              ≥5.6
                   |                 |
                 cue              mi_end
```

- **基线校正**：用 Cue 前 0.5 s 均值（与旧 `task_window_cue_0_to_4` 同思路），施加到后续整段取出的波形上。  
- **评分有效段** `[0, 4)` s：只有 **当前窗 `X_cur` 完全落在该区间内** 的锚点才进入本臂样本集（与 Acc_paper「MI 试次内投票」口径一致）。  
- **post-MI**：从 `mi_end=4.0 s` 起，在连续 EEG 上再取 **至少 1.6 s**（不够则该 trial **整 trial 丢弃**或记 meta 跳过，不得缩短 future）。

### 3.2 连续段 `seg` 定义（`fs_raw` 或先滤后切，实现自选但需固定）

对每个 left/right cue：

1. 需要的样本范围（相对 cue，秒）：  
   `t_need0 = -0.4`（最早 past 起点，相对**第一个合法锚点**）到 `t_need1 = 4.0 + 1.6 = 5.6`。  
   为简化实现，推荐直接切：

```text
seg_t0 = cue - 0.5*fs     # 含基线
seg_t1 = cue + 5.6*fs     # 评分 4s + post 1.6s
```

2. 若 `seg_t1` 越出录音末尾 → **丢弃该 trial**（不零填 future）。  
3. 基线校正后，丢掉基线段，得到：

```text
seg_corr: 从 cue 起长 ≥5.6 s 的 (T_seg, 8)   # 相对 cue: [0, ≥5.6)
```

4. 再 **重采样到 250 Hz**（若尚未），得到 `seg250`，长度 `T_seg_pts ≥ 5.6*250 = 1400`。

> Rest 类：本臂若保留 Rest，须单独规定「past/future 语义」；**开跑主表仅 Three 时，可先只产 left/right 齐全窗**，Rest 策略在实现清单中单列（默认：与 Task 相同几何，或本 v1 **不产 Rest**——实现前在 PR 注明）。**推荐 v1：只产 left/right（y_three∈{1,2}），不做 Rest。**

## 4. 锚点与齐全窗过滤

### 4.1 锚点集合（相对 cue，`fs_out=250`）

当前窗起点 `t0`（秒，相对 cue）：

```text
t0 ∈ {0.0, 0.1, 0.2, …} 且  t0 + 2.0 ≤ 4.0
⇒ t0 ∈ {0.0, 0.1, …, 2.0}
```

即最多 **21** 个候选锚点 / trial（与旧 4 s 上 2 s/hop100 的几何一致）。

### 4.2 每个锚点切三段（点数 @250 Hz）

相对 cue 的样本下标（整数）：

```text
i0 = round(t0 * 250)           # 当前窗起点
past   = seg250[i0-100 : i0]           # 100
cur    = seg250[i0     : i0+500]       # 500
future = seg250[i0+500 : i0+900]       # 400
```

### 4.3 边界过滤（冻结）

| 条件 | 动作 |
|------|------|
| `i0 < 100`（past 不足） | **裁掉**该锚点 |
| `i0+900 > len(seg250)`（future 不足） | **裁掉**（正常 trial 因 post≥1.6s 且 `t0≤2.0` 不应发生） |
| `i0+500 > 4.0*250`（当前窗越出评分区） | **裁掉** |
| 任一段长度不等于标称点数 | **裁掉** |

**训 / Acc_paper 共用过滤后的同一套锚点**；禁止「训练齐全、评估放宽」。

因 `t0≥0` 且需 `i0≥100`，**第一个合法锚点从 `t0=0.4 s` 起**（`t0=0.0…0.3` 因缺 past 被裁）。  
合法 `t0`：`{0.4, 0.5, …, 2.0}` → 每 trial 最多 **17** 窗。

### 4.4 冷启动（仅在线推理，不进本预处理产物）

流式时可见长 &lt; 600 点 → 不预测。离线 npy **不含**这类不完整窗。

## 5. 样本张量构造

对每个通过过滤的锚点：

```text
X_full = concat(past, cur, future)     # (8, 1000) 或存盘 (1,8,1000)
X_mask = concat(past, cur, zeros(8,400))
y      = 当前窗标签（与旧臂 left/right → y_three 相同映射）
```

**禁止**：用零填 future 写入任何名为 `X_full` 的字段。

可选存盘布局（推荐一种，实现时固定）：

| 文件 | 形状 | 说明 |
|------|------|------|
| `openbmi_X_full.npy` | `(N, 1, 8, 1000)` 或 `(N, 8, 1000)` | 真 future |
| `openbmi_X_mask.npy` | 同左 | future=0；也可训练时现算，不必双份落盘 |
| `openbmi_y_three.npy` | `(N,)` | 仅 Three |
| `openbmi_subjects.npy` | `(N,)` | `openbmi:subjNN` |
| `openbmi_trial_id.npy` | `(N,)` | 全局 trial |
| `openbmi_t0_sec.npy` | `(N,)` | 相对 cue 的当前窗起点（秒） |
| `manifest.json` | — | protocol、fs、通道、过滤统计 |

若为省磁盘只存 `X_full`，则 DataLoader 内现场：`X_mask = X_full.clone(); X_mask[..., -400:]=0`。

**A1 附报 600pt**：另存或现场 `X_vis = X_full[..., :600]`，**不**进主表减法。

## 6. 窗内 z-score 口径（必须写死）

与旧臂一致时推荐：

- 在 **1000 点整窗**（`X_full`）上做通道维/时间维的窗内 z-score（实现与旧 `segment_to_2s_hop100_windows` 对齐方式须在代码注释标明）。  
- 然后由 z-scored 的 `X_full` 生成 `X_mask`（后 400 再置零），保证 mask/full 前 600 点一致。

禁止：只对 cur 500 做 z-score 再拼 past/future（分布会裂）。

---

## 7. Acc_paper 与 trial 投票

1. 投票单元 = **同一 `trial_id` 下、本臂过滤后的全部窗**。  
2. 窗预测正确占比 **> 0.5** → trial 计对（=0.5 计错）。  
3. 因缺 past 裁掉的窗 **不参与** 分母（与「同一套齐全窗」一致）。  
4. 旧臂 A0 的 Acc_paper 仍按其 500 点窗集计算，**不与本臂窗数强行对齐**；对比时注明几何差异。

## 8. 伪代码（实现蓝图 · 非仓库代码）

```python
# 伪代码：新文件实现；勿改 openbmi/pipeline.py

PAST, CUR, FUT = 100, 500, 400
POST_SEC, MI_SEC, FS = 1.6, 4.0, 250
HOP = 25  # 0.1s @250Hz

def process_trial(x_raw, cue, fs_raw, y_three):
    # 1) 选通道 / CAR / notch / bp —— 复制旧臂逻辑到新模块
    # 2) 切 [cue-0.5s, cue+5.6s)，基线校正，丢基线 → seg 从 cue 起
    # 3) resample → seg250, 要求 len >= int(5.6*FS)
    if len(seg250) < int((MI_SEC + POST_SEC) * FS):
        return []

    samples = []
    mi_end = int(MI_SEC * FS)
    for i0 in range(0, mi_end - CUR + 1, HOP):
        if i0 < PAST:
            continue  # 缺 past → 裁
        if i0 + CUR > mi_end:
            continue  # 当前窗越出评分区
        if i0 + CUR + FUT > len(seg250):
            continue  # 缺 future → 裁
        past = seg250[i0 - PAST : i0]
        cur = seg250[i0 : i0 + CUR]
        future = seg250[i0 + CUR : i0 + CUR + FUT]
        x_full = np.concatenate([past, cur, future], axis=0)  # (1000, 8)
        x_full = window_zscore(x_full)  # 与旧臂口径对齐
        samples.append((x_full, y_three, i0 / FS))
    return samples
```
