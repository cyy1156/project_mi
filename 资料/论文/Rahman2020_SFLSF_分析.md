## 1. 方法：一句话

**把 FBCSP 的"频域分块"再往通道轴推一步，空间也分块。**

- FBCSP = 频段 × 全通道 CSP
- SFLSF = 频段 × **局部通道** CSP

处理链：

```
22 导 EEG
  → 空间窗口切分（3 组局部重叠通道）
  → 滤波器组（每组 9 个频带）          22 → 180 路
  → 每块单独解 CSP（取首尾各 2 分量）   180 → 72 路
  → MAV 特征提取 + 拼接
  → SVM 分类（左右手）
```

特征三者择一：MAV（小波细节系数均值绝对）、Energy、Log-Variance。论文用测试集挑中 MAV。

## 4. 独立复算：论文没报的数

### 4.1 +5.2% 是两个人撑起来的

逐被试对齐 Table 2（CSP 基线，MAV 列）与 Table 4（SFLSF，window set-c + freq set-a）：

| 被试 | CSP | SFLSF | 增益 |
|---|---|---|---|
| Sub-1 | 77.7 | 87.5 | +9.8 |
| Sub-2 | 54.1 | 58.3 | +4.2 |
| Sub-3 | 91.6 | 92.3 | +0.7 |
| Sub-4 | 71.5 | 65.9 | **−5.6** |
| Sub-5 | 50.6 | 72.9 | **+22.3** |
| Sub-6 | 63.1 | 62.5 | −0.6 |
| Sub-7 | 67.3 | 90.2 | **+22.9** |
| Sub-8 | 97.2 | 92.3 | **−4.9** |
| Sub-9 | 82.6 | 81.2 | −1.4 |
| **均值** | **72.9** | **78.1** | **+5.27** |

- **中位数增益只有 +0.7%**，均值 +5.27% —— 分布极度右偏
- 9 人中 **4 人反而变差**
- Sub-5 + Sub-7 两人合计 +45.2，**占净增益的 95.4%**
- 这两人恰是 CSP 基线里最差的（50.6、67.3）→ 存在地板效应 / 回归均值成分

### 4.2 消融近似可加（论文最可信的部分）

- 只加空间窗（SW-CSP）：+2.1
- 只加滤波器组（FBCSP）：+2.7
- 两者都加（SFLSF）：+5.2

2.1 + 2.7 = 4.8，交互项仅 +0.4 → 两个机制确实互补，不是同一个东西换皮。**这个结论不依赖超参选择，是全文最站得住的一句话。**

### 4.3 频带个体化才是更大的杠杆

Table 4 的逐被试最优频带分布：

| 频带组 | 夺冠被试数 |
|---|---|
| **set-f**（8–32，3 带） | **4** |
| set-a（4–40，9 带） | 2 |
| set-b（3–41，9 带） | 2 |
| set-e（8–36，3 带） | 1 |
| set-c / set-d | 0 |

- **逐被试 oracle（每人用自己最优频带）= 80.42%**
- 固定 set-a = 78.12%
- **个体化 headroom = +2.30%**

更关键：频带选择造成的个体内波动均值 **9.26 个百分点**（min~max 跨度），**比 SFLSF 整个方法的增益（5.27）还大**。

### 4.4 "set-a 最优"站不住

配对 t 检验（df=8）：

| 对比 | 均值差 | 配对差 sd | t | 判断 |
|---|---|---|---|---|
| set-a vs set-c | +3.48 | 3.92 | 2.66 | p≈0.03，勉强显著 |
| set-a vs set-f | +0.40 | 4.72 | 0.25 | 完全在噪声内 |

set-a 只显著优于**最差的** set-c，与 set-b/e/f 均无差异。6 组取最大值 → 赢家诅咒。

### 4.5 方差主张无统计支撑

论文称 SFLSF"方差最小"，但全文未报任何 std：

- CSP std = 15.96
- SFLSF std = 13.50

n=9 下，方差比检验功效极低，此主张不可判定。

## 5. 方法学硬伤

1. **超参全在测试集上选。** Table 2 用测试集挑 MAV → Table 4 用测试集挑 freq set-a → Table 3 用测试集挑 window set-c → 最后报 78.1。三者循环依赖，78.1% 是乐观偏估计。
   - 附：Table 3 跑在哪个频带组上论文**根本没写**。经核对，Table 3 的 set-c 列与 Table 4 的 set-a 列逐位一致（仅 Sub-9 差 0.1），可推定 Table 3 跑在 freq set-a 上 —— 而 set-a 是 Table 4 选出来的。
2. **无任何统计检验。** 全程只报均值。
3. **自相矛盾。** 正文先称"SFLSF 对 FBCSP 赢 7/9"（符号检验 p≈0.18，不显著），后文又称"四方法中 SFLSF 只在 1/9 被试夺魁"，再以"均值高 + 方差最小"圆回。
4. **基线被压低。** Reg-CSP 70.9 < 普通 CSP 72.9。正则化在小样本上本应更稳，反更差 → Lu 2010 的正则化参数没调。ICA 是无监督方法，作监督方法对照组属稻草人。
5. **选择性对标。** Table 5 只比 CSP 家族 + ICA。2020 年 Shallow ConvNet / EEGNet 在同数据集同设定下已能到 80–85%，论文未比。
6. **无在线评估。** 只用完整 3 s trial，无滑动窗、无伪在线模拟，对在线 BCI 参考价值有限。
7. **小瑕疵。** 正文"three spatial windows and 9 frequency bands produce **2** × 9 × 4"——三窗却写 2（Fig.3 画的也是 2 个窗）。

## 6. 对本项目的结论（8 导 / fs 250 / 3s 窗 hop 0.1 / e1f 四成员深度集成）

通道序：FC3, C3, CP3, CZ, CPZ, FC4, C4, CP4

### 6.1 空间窗口：不要照搬（死胡同）

- 论文 22 导切 3 窗，每窗仍有 8–10 导，CSP 有解空间
- 8 导再切 3 窗 → 每窗 2–3 导，协方差矩阵 2×2 / 3×3，CSP 解空间维度仅 C−1 = 1 或 2 → 判别力归零，只剩过拟合
- **该 8 导布局本身已是从 OpenBMI 62 导做过一次空间选择的结果**，再局部化是二次选择，边际收益极低
- Shallow ConvNet / Conformer 的第一层空间卷积本就是数据驱动的空间滤波，强于人工切窗

### 6.2 频带个体化：值得做，是本论文唯一可迁移的产出

- 个体内波动 9.3 pt > 方法增益 5.3 pt → 选频带比换方法更划算
- oracle headroom +2.3%
- 首轮候选超参可直接借用论文结论：**4 Hz 带宽 / 4 Hz 步长 / 覆盖 4–40 Hz**（set-a）

### 6.3 落地协议（防泄漏，务必遵守）

```
1. backbone：沿用 e1f 四成员（shallow / t_shallow / eegnet / conformer）
2. 搜索数据：只准用目标被试的 train session
3. 候选网格：4–40 Hz，步长 4 Hz，带宽 {4, 6, 8} Hz；外加宽带基线
4. 选择方式：train session 内做嵌套 CV（内层选频带，外层估泛化）
5. heldout：只评估一次，不回头改
6. Leave-Next 微调用的数据：不参与频带搜索
```

> **红线**：频段搜索一旦碰到 heldout，就是复刻本论文的错误。Rahman 组自己栽在这里，别跟着栽。

### 6.4 数字不可比，别当目标

| | 本论文 SFLSF | 本项目 e1f |
|---|---|---|
| 设定 | 被试内（subject-dependent） | 跨被试（54 人） |
| 被试 | 9 | 54 |
| 通道 | 22 | 8 |
| 准确率 | 78.1% | 61.7% |

两者差着 15–20 个点的设定难度，**78.1% 不能作为本项目的目标值**。

## 7. 2020 → 2026 演进线索

对照目标论文 *MI recognition by subject specific localised frequency fusion*（Rahman & Shuvo, J Med Eng Technol 2026, DOI 10.1080/03091902.2026.2720510, PMID 42622537）：

| | 2020 SFLSF | 2026 SSLFF |
|---|---|---|
| 局部化轴 | 空间 | **频率** |
| 频带 | 固定频带表（6 选 1） | **个体化子频段搜索** |
| 频带关系 | 独立 | **互补频带合并** |
| 时域 | 整段 3 s | **时间局部化特征** |

演进逻辑清晰：频率的个体差异 ≫ 空间个体差异，故 2026 把局部化从空间轴挪到频率轴，并补上 2020 的两个短板（频带不个体化、未做时间局部化）。

**对本项目的个体化优先级排序：频率 > 空间 > 时间。**

本项目的 Leave-Next 微调属**权重层**个体化，SSLFF 属**特征层**个体化，二者正交，可叠加。

## 8. 复算脚本（可自行验证）

```python
import statistics as st
from collections import Counter

# Table 2 MAV 列 = CSP 基线；Table 4 Set-a = SFLSF 最终配置
csp   = [77.7, 54.1, 91.6, 71.5, 50.6, 63.1, 67.3, 97.2, 82.6]
sflsf = [87.5, 58.3, 92.3, 65.9, 72.9, 62.5, 90.2, 92.3, 81.2]
d = [round(b - a, 1) for a, b in zip(csp, sflsf)]
print('逐被试增益', d)
print('均值 %.2f  中位数 %.1f' % (sum(d)/9, st.median(d)))
top2 = sorted(d, reverse=True)[:2]
print('前二 %.1f%% of net' % (100 * sum(top2) / sum(d)))
print('CSP std %.2f  SFLSF std %.2f' % (st.stdev(csp), st.stdev(sflsf)))

T4 = {
 'a': [87.5, 58.3, 92.3, 65.9, 72.9, 62.5, 90.2, 92.3, 81.2],
 'b': [86.8, 54.1, 91.6, 58.3, 75.0, 56.9, 86.8, 95.1, 81.9],
 'c': [84.0, 54.8, 86.1, 70.1, 65.9, 56.9, 88.8, 92.3, 72.9],
 'd': [88.1, 57.6, 87.5, 54.8, 72.2, 56.2, 86.8, 88.8, 73.6],
 'e': [92.3, 57.6, 88.1, 69.4, 76.3, 59.0, 80.5, 92.3, 78.4],
 'f': [93.7, 56.2, 93.0, 70.8, 63.1, 64.5, 87.5, 90.2, 80.5],
}
win, oracle = Counter(), []
for i in range(9):
    best = max(T4, key=lambda k: T4[k][i]); win[best] += 1; oracle.append(T4[best][i])
print('逐被试最优频带分布', dict(win))
print('oracle %.2f  fixed set-a %.2f  headroom +%.2f'
      % (sum(oracle)/9, sum(T4['a'])/9, (sum(oracle)-sum(T4['a']))/9))
print('个体内波动均值 %.2f' % (sum(max(T4[k][i] for k in T4) - min(T4[k][i] for k in T4)
                                for i in range(9)) / 9))

for other in ('c', 'f'):
    dd = [T4['a'][i] - T4[other][i] for i in range(9)]
    m, s = sum(dd)/9, st.stdev(dd)
    print('set-a vs set-%s: 均值 %.2f  t=%.2f' % (other, m, m / (s / 3)))
```

## 9. 一句话结论

方法思路清晰、消融干净（两个局部化可加），但**全部超参在测试集上选、无统计检验、基线未调优、选择性对标**，78.1% 不可直接采信。

对本项目的净产出只有一条：**频带个体化的收益（>+2.3%，个体内波动 9.3 pt）大于换方法的收益（+5.3% 且集中于 2 人）**；空间窗口在 8 导上不可行。若要做，频带搜索必须锁死在 train session 内，heldout 只评估一次。
