# 游戏 v2 开发计划（范式引擎 + 适配引擎 + 第一人称游戏协同）

> 日期：2026-08-23 · **2026-08-24 对齐 v2 标准**（`experiment_game/docs/v2_upgrade_plan.md` v1.5 · D1–D8：机械臂/秒判定位移作废 → 第一人称伸手/触碰 + D8 加权计分；组级微调 → 轮级批量 + 分组平衡排程）  
> 上游：[项目计划 v2.0](./面向少样本个体适配的运动想象脑机接口系统设计.md) · [采集流程 v2.0](./采集流程_20被试底座v2.md)  
> 目标：实现完整新用户流——**动觉引导 → 4 轮标定（动画 Cue 6s 试次 + 轮间增量 FT + 累积小考）→ 准入 → 第一人称游戏协同（D8 加权计分判定 + 轮级微调 + 漂移保护）**。  
> 硬约束：采集战役开始前 M1–M3 必须就绪；比赛提交前全部就绪。与实验 24/25 **无依赖**（仅留三个替换接口，见 §3）。

## 1. 总体架构

```text
code/adapt_engine/            ★ 新建 · 共享核心库（一份代码三处复用）
  ft.py        增量微调（上次权重继续 + 回放混合）
  quiz.py      累积小考卷（留出试次存取 + 试次级评估 + 曲线点记录）
  gate.py      准入判定（常量驱动）
  drift.py     漂移保护（指标/耐心值/回滚/lr减半/冻结）
  recipes.py   FT 配方（lr/回放比例/增广开关）
  runner.py    三模式入口：offline-replay ｜ batch（采集后台）｜ runtime（游戏）

experiment_game/
  web/         前端：v1 页面原地扩展（v2_bridge.js + scene.js __v2scene 挂点）——
               动画 Cue + 标定进度条 + 第一人称伸手/触碰场景
  experiment/  试次状态机 + LSL 推理服务 + 事件落盘 + 适配引擎调用（session_v2）
```

三个使用场景：**offline-replay** = 方案 25-A0 爬坡曲线（Stieger 调通）；**batch** = 采集轮间后台微调；**runtime** = 游戏轮级微调（轮内试次窗累积、轮界一次增量更新）。

## 2. 里程碑计划（单人 ~11–13 个工作日）

### M0 · 架构与接口冻结（0.5 天）

- 文件结构如 §1；确认前端（Three.js）↔ 后端通信沿现有 marker 通路（Phase0–1 已验证 EEG/事件对齐）。
- 权威时钟：`pylsl.local_clock()`（既有约定）。
- **交付**：架构图 + §3 三接口签名冻结。

### M1 · 范式层：6s 试次引擎（2 天）★采集前置

- 试次状态机：`准备2s → Cue2s（动画）→ 想象6s → ITI 3s`。
- Cue 素材：左手=抓握网球动画、右手=书写动画、静息=固定图标（现有 Three.js 资产改造：静画→动画）。
- 排程器：标定轮 18 试次（3 子块 × 2L+2R+2Rest 置换，同类连出≤2）；游戏轮 16 试次（6/5/5 轮转）。
- 引导体验界面：不采集，倒计时 + 操作员确认 + 引导事件落盘（次数/时长）。
- 事件：`cue_onset / trial_end / reject / guidance_begin_end`。
- **验收**：cue 时戳与呈现误差 <50ms（合成板 100 试次干跑无崩溃；复用 Phase0–1 对齐校验）。

### M2 · 在线推理服务（2 天）

- LSL inlet → 环形缓冲（8ch × 250Hz × ≥10s）。
- 判定点取窗：D8 栅格 t_k=0.6k s（k=1..10，相对 `mi_start`），取**结束于判定点的 3s 滑窗**。
- 在线预处理 = 离线同款：CAR → notch → **8–30Hz** → 逐窗 z-score（**直接 import preprocess_lab 同一函数**）。
- 模型注册表：加载 S3 的 task+three 双头；串行门控读数（`TASK_P_ON=0.6`：Task 概率不足 → 直接静息档）。
- **验收（本里程碑的命门）**：录制会话回放走在线路径 vs 离线管线，**逐窗 logits 一致**（容差 1e-4）。单窗推理耗时 <50ms。

### M3 · 适配引擎核心库（2–3 天）★采集前置

| 模块 | 要点 | 单测 |
|------|------|------|
| `ft.py` | 上轮 ckpt 继续 · lr=1e-4 · 回放混 15% 源域窗（按类平衡） | 断言：小考卷试次**从不**进 FT |
| `quiz.py` | 留出试次累积（6/12/18/24…）；试次级评估 = D8 10 档栅格多数票；曲线点 (k, acc) 落盘 | 曲线点与手算一致 |
| `gate.py` | `GATE_ENTER_THREE=0.60` · 小考≥12 起判 · 4→6 轮加轮 · 弱MI标记 | 边界用例 |
| `drift.py` | 每轮前存 ckpt · 连续2轮降 → 回滚+lr减半 · 再触发 → 冻结 | 回滚后权重逐位等于历史 ckpt |
| `runner.py` | offline-replay 模式接 Stieger | **跑通 = 方案 25-A0 交付** |

- **验收**：Stieger 3 被试回放产出完整爬坡曲线 + 准入判定日志。

### M4 · 游戏协同模式（2 天）· v2 标准

- 第一人称伸手/触碰场景：左/右 Cue → 同侧手抓桌物；D8 加权计分驱动的得分/进度可视化。
- **Score≥5 → `score_reach` 提前结束**；**touch（D4 模拟 touch 先行 → 场景碰撞）→ 立即 `mi_end`**（后端脑电录至 `mi_end`，短试次走 fragment 拼接池）。
- 轮结束 → 后台调 `runner(batch)`：本轮全部有效试次窗入 FT（D2）+ 漂移保护。
- **验收**：合成板全流程（含 score_reach/touch 提前结束路径）无事件丢失。

### M5 · 操作台 v2 + 注意力/ERD 面板（1–2 天）

- 控制台：会话建立（连主登记表 Excel）· 轮控制/暂停/Reject · 实时信号质量 · 轮内逐档判定（D8 得分/无效）· **累积小考曲线图 + 准入状态** · 轮间 **ERD 反馈面板**（对侧 ERD + laterality，复用 H 门控公式）。
- 注意力模块（比赛 2.3）：单通道注意力分数逐试次**只记不控**（初版：Cz α/θ 比值，spec 冻结后可换）。
- **验收**：操作员照 runbook 独立跑完一个假人会话。

### M6 · Phase4 切窗升级 + 端到端联调（1–2 天）

- 切窗支持 `mi_end`（score_reach/touch/满 6s）：游戏试次窗只切到真实 `mi_end`（D2/D3：短试次走 fragment 拼接池）；输出 **仅 `3s_hop100` 一版**（4s 固定窗已删除 · 2026-08-23）。切窗器已落地：`offline/phase4_v2.py` / `phase4_v2_game.py`；pooled + merge 待实现（D3/D5）。
- 端到端：合成板完整会话（引导 → 4 标定轮 → 准入 → 2 游戏轮，FT 真实运行）。
- **试点**：1–2 名真人被试预演 → 修问题 → 冻结。

### M7 · 冻结与文档（0.5 天）

- 常量表落配置文件（现场禁改）；操作 runbook；已知问题清单。

## 3. 三个可替换接口（给实验 24/25 留插槽）

| 接口 | 现默认 | 24/25 阳性后替换为 |
|------|--------|---------------------|
| `ModelRegistry` | S3 双头单模型 | 24-E 集成（多模型概率平均）/ 24-W 窗长模型组（t 秒用 t 秒窗模型） |
| `ReadoutPolicy` | 串行门控 + D8 加权计分（栅格/半票/满票） | 24-V 置信/时间加权 |
| `FTRecipe` | lr=1e-4 + 15% 回放 | 25-G2 调比例 / 25-G3 加轻增广；25-G1 换增广底座权重 |

**规则**：接口签名 M0 冻结；实验结果只改实现不改调用方。

## 4. 与采集/实验的并行排期

```text
第 1 周：M0–M2（范式+推理）          夜间挂机：24-T/E、25-G1 五折
第 2 周：M3–M4（引擎+游戏）→ 真人试点  采集战役启动（M1+M3 就绪即可排期）
第 3 周：M5–M7（操作台/联调/冻结）→ 正式采集铺开
汇合：底座 v2（采集完）→ 换权重；24/25 出结果 → 换插件
```

## 5. 风险与预案

| 风险 | 预案 |
|------|------|
| **在线/离线预处理不一致**（最大正确性风险） | M2 的 logits 一致性测试是硬门；预处函函数直接 import preprocess_lab |
| 浏览器/后端时钟漂移 | 沿用 Phase0–1 对齐机制；cue 误差 >50ms 即修 |
| 轮间 FT 挤占节奏 | FT 放后台线程，与抬臂引导并行（~1min < 引导 2min） |
| 游戏 v2 延误卡采集 | **降级路径**：采集先跑"标定轮 + 补充正式块"变体（M1+M3 即可支撑），游戏轮后补 |
| 双头加载/接线错误 | M2 冒烟含 task/three 各出一路 logit 的断言 |
