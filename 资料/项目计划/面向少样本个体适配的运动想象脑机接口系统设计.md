# 面向少样本个体适配的运动想象脑机接口系统设计

## 1. 研究目标

构建**通用预训练 + 少样本个体微调**的个性化 MI-BCI：新受试者仅需短时标定试次，即可快速得到可用的个体解码模型，用于在线左/右/空闲意图识别。

核心问题：在跨被试通用模型基础上，用少量个体数据平衡泛化性与特异性，降低标定成本。

---

## 2. 背景（简述）

| 方案 | 优点 | 短板 |
|------|------|------|
| 全量个体训练 | 精度高 | 标定久、成本高 |
| 纯跨被试通用模型 | 免标定 | 个体差异大，在线精度差 |

本项目走中间路线：**先训稳跨被试基线，再做少样本微调**。当前阶段优先把预处理、双头基线与评估协议跑通；主干优选与少样本消融放在后续。

---

## 3. 总体技术路线

```text
阶段 A（进行中）：统一预处理 → 双头 EEGNet 跨被试基线 → 被试独立五折评测
阶段 B（下一步）：接入更大样本库（如 Stieger）→ 多主干对比 → 固化通用权重
阶段 C（核心创新）：少样本个体微调（层级 / 样本量 / 超参 / 分类头消融）
阶段 D：在线滑动窗推理 + 交互控制
```

### 3.1 统一数据与预处理（已落地）

| 项 | 现行约定 |
|----|----------|
| 通道（固定序） | Cz, C3, C4, CP3, FC4, FC3, CP4, CPz |
| 采样率 | 250 Hz |
| 双标签 | `y_task`∈{0,1}；`y_three`∈{0,1,2} |
| 映射 | 静息 (0,0)；左手 (1,1)；右手 (1,2) |
| **BCI IV 2a 切窗** | 任务：**Cue 后 2~4 s**；静息：**Cue 前 2 s** |
| **2a 张量** | `(N, 1, 8, 500)` → `out/bci2a_2s/` |
| 其它库 | 窗长按库配置（如 Stieger 可仍为反馈段最后 4 s → 1000 点）；训练用 `n_times=X.shape[-1]` |

工程目录：

- 预处理：`code/preprocess_lab/`（`common/` + `datasets/{bci2a,stieger}/`）
- 训练：`code/train_lab/`（五折过夜脚本、双头 kfold）

### 3.2 双头结构（现行基线）

共享 EEGNet 主干 + 两个分类头（样本不复制，同一窗双标签）：

| 头 | 任务 | 标签 |
|----|------|------|
| 头1 | 静息 / 任务 | `y_task` |
| 头2 | 空闲 / 左 / 右 | `y_three` |

训练：先训头1；再迁移主干权重训头2（可冻/不冻主干）。  
在线规则（规划）：头1未过任务阈值 → 空闲；过阈值再看头2 左右；冲突或差距不足 → 空闲/不确定。

> 说明：计划中的多主干对比（Shallow/Deep/TCN/Conformer）**尚未开跑**；当前固定 **EEGNet** 作为阶段 A 基线，不提前认定 Conformer 为最优。

### 3.3 正式评估协议（已落地）

- 被试独立五折；折内再按人划 val
- **只用 Val 早停与调参**；Test 仅终评
- 过夜顺序：头1网格/基线 → 头1调参 → 选优 → 头2 基线 → 头2 调参

## 6. 后续计划

| 优先级 | 内容 |
|--------|------|
| P0 | 补全 Stieger `batch.py`，跑通大样本预处理与五折基线 |
| P1 | 多主干公平对比（EEGNet / Shallow / Deep / +TCN / Conformer），选跨被试通用骨干 |
| P2 | 少样本微调消融：微调层级、标定样本量（10/20/40/60）、学习率与轮次、Linear/MLP/Prototype 头 |
| P3 | 在线滑动窗推理 + 网页/外设控制联调 |

少样本阶段固定阶段 B 选出的骨干，不再改结构，只做适配策略。

---

## 7. 明确不做什么

1. 不做样本回放 / 长期增量持续学习（聚焦单次短时标定）  
2. 不新设计 CNN/Transformer 结构（结构对比用现成模型）  
3. 不拿 Test 调参

## 9. 系统落地流程（目标形态）

1. **离线**：多源数据 → 统一预处理 → 跨被试训双头 → 固化通用权重  
2. **标定**：新用户采约 20～40 trial → 少样本微调 → 个体模型  
3. **在线**：实时预处理 → 个体模型解码（左/右/空闲）→ 交互控制
