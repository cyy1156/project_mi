> **版本 v2.0（2026-08-23 重写）**：核心定位不变，分期、协议、适配时序按近一个月全部实验结论重构；v1.x（2026-07 底，BCI2a/EEGNet/2s 阶段）见 git 历史。  
> **2026-08-24 v2 标准对齐**：§3.3/§3.4/§3.6/§四/§五 按 `experiment_game/docs/v2_upgrade_plan.md` v1.5（D1–D8 冻结）改写——游戏反馈由第三人称机械臂改为**第一人称伸手/触碰 + D8 加权计分判定**；在线微调粒度由组级即时改为**轮级批量**（组 = 排程平衡单位）；常量表与 `config/v2_session.yaml` 对齐。  
> 基座模型（v2.0 冻结）：**Shallow（braindecode 库版）· 3s/750pt · hop 100ms 滑窗**。自采数据由项目组自行采集，按 §3.2 口径对接。

## 一、项目研究目标（Project Goal）

本研究不设计新型卷积网络、Transformer 或分类头模块，核心定位为**面向少样本个体适配（Few-shot Personalized Adaptation）的个体化运动想象脑机接口系统构建**。针对新用户标定成本高、跨被试泛化差的痛点，依托跨被试通用底座 + 少量个体标定试次，通过快速微调生成专属解码模型，实现稳定的在线三类（左/右/静息）运动意图解码与人机交互。

核心科学问题：如何依托跨被试通用模型与少量个体标定数据，平衡泛化性与个体特异性，实现低成本、高效率的个体化 MI-BCI 快速适配。

## 二、研究背景与意义

两种主流方案的固有矛盾（v1 论述保留）：全量个体训练精度高但标定昂贵；纯跨被试通用模型免标定但个体精度大幅下降。**本项目已用实验将该矛盾定量**：

| 方案 | 实测（Stieger 24 被试 · 3s） | 出处 |
|------|------------------------------|------|
| 纯通用（跨库零样本） | Three **0.42**（离线域内 0.59 → 掉 17 pp） | S07-01 |
| 会话内标定 + 全量 FT | Three **0.66**（+24 pp，**24/24** 被试达标） | S07-02/05 |
| FT + 生理门控 H2 | Three ~0.69 | S07-06 |
| 测试时廉价适配（EA/AdaBN） | 无效乃至有害（FT 后 −11 pp） | 09 号 |

结论：**权重级适配（微调）是个体精度的唯一有效来源**，本研究即以此为系统核心。

## 三、总体技术路线

### 3.0 近期机制结论（选型依据，论文"分析"章素材）

1. **模块时代已证伪**：SE/ECA/CBAM/双专家门控/JEPA/双带通等系列（方案 13/14/15/17/19/21/23）均未稳定超过裸基线；oracle 实验证明**未来段无增量类别信息**（2s −0.15 pp / 1s +0.09 pp）。
2. **测试时统计量校正已证伪**：EA ≈ 0（+0.4 pp），AdaBN 在 FT 后有害（−11 pp）——域间隙不在二阶统计量里，适配必须发生在权重层。
3. **数据几何与训练质量是域内杠杆**：3s > 2s > 1s（0.588/0.576/0.562）；训练锚点含晚窗有害（−1.1 pp）。

### 3.1 阶段 A（已完成）· 底座研究与机制验证

统一预处理、十一模型 2s 正式表、3s 基线（S3）、全部机制验证实验（详见 §五）。产出：底座选型 = Shallow + balbatch + 纯 CE + Acc_paper 早停。

### 3.2 阶段 B（已定型）· 通用底座：Shallow 3s 滑窗

| 项 | 冻结约定 |
|----|----------|
| 模型 | `braindecode.models.ShallowFBCSPNet` 默认超参（~17k 参数；方案 18 已证库版≡自写版） |
| 窗长/步长 | **Tw=3s（750pt）/ hop=100ms 滑窗** |
| 采样率/通道 | 250 Hz · `Cz,C3,C4,CP3,FC4,FC3,CP4,CPz`（固定序，禁止重排） |
| 预处理 | 与 `openbmi_3s_hop100` 同口径（选 8 导 / 滤波 / 逐窗 z-score）；切段 Task=左/右反馈段、Rest=Cue 前静息段 |
| 训练 | 被试独立五折 · balbatch · Val Acc_paper 早停 · patience 20 · seed 42 · lr 1e-4 · wd 1e-4 · drop 0.5 |
| 双标签双头 | `label_task`（静息/任务）与 `label_three`（静息/左/右）**独立训练、不迁权重**（沿 v1 约定） |
| 正式权重 | **S3**：5070 `run_20260822_094942`（Task 0.7410 / Three 0.5873）；5060 对照 `run_20260821_190504`（0.7415/0.5876） |
| 自采数据 | 项目组自行采集；落盘后按本表口径切窗入库，微调通用底座即"20 被试版底座 v2" |

### 3.3 阶段 C（核心创新）· 少样本个体适配

**适配时序（v2.0 关键修正）**：反馈游戏必须运行在**微调后的个人模型**上——通用底座零样本仅 ~0.42，垃圾反馈会使用户学到错误关联并污染分组微调。比赛规定的"三轮预实验"（任务时序与正式一致）天然就是**带标签标定数据**，前移为标定环节：

```text
通用底座（公开库预训练 + 20 被试微调）
  → 新用户三轮预实验 = 标定采集（带标签，留出 20% 做准入小考卷）
  → 个人全量 FT（分钟级；已验证 +24 pp 路径）
  → 【准入门槛】小考卷 Three ≥ GATE_ENTER_THREE 才放行进游戏
  → 反馈游戏（第一人称伸手/触碰）：个人模型 + 轮级增量微调（分组=平衡排程）+ 【漂移保护】
```

#### 3.3.1 个人 FT 配方（初值，阶段 C 标定后冻结）

全参数 · Adam lr=1e-4 · Val（小考卷）Acc 早停 patience 10 · 每被试分钟级完成。

#### 3.3.2 分组在线微调（比赛规则对齐 · v2 标准）

每组 = 左/右/静息各 1 试次（有 cue，**有监督**，非伪标签），组作为**最小排程平衡单位**（轮/子块内类别均衡、同类连出 ≤2；标定 6 试次子块 = 2 组，游戏轮 16 试次 6/5/5 轮转）。模型更新以**轮为界批量执行**：轮内全部有效试次窗累积后一次增量更新（上轮权重继续 + 混入 15% 源域窗回放防遗忘，方案 25-G2）——3 试次超小批更新梯度噪声大、少样本下易遗忘；轮级批更新平衡约束相同、梯度更稳定、回放可按类配比。若答辩要求逐组即时更新，增量接口仅改调用频率即可支持（默认关）。

#### 3.3.3 消融体系（论文核心实验）

| 消融 | 设计 | 现状 |
|------|------|------|
| 标定样本量 | 爬坡曲线 k∈{0,10,20,40,80} 的精度曲线（Stieger 24 被试 + 自采），定最少标定轮数与准入线 | 评测器已设计（方案 25-A0） |
| 微调层级 | 头 / 头+BN / 末块+头 / 全网 四档 | **待补**（主线一直全量） |
| 微调超参 | lr×轮次小网格（嵌在爬坡框架内） | 待补 |
| 读出结构 | 串行门控（Task 阈值→空闲，再 Three 定向）vs 平行三分类 | 待跑（双头已备） |
| 增广/回放 | 方案 25-G2/G3 作为正则件 | 已立项 |

### 3.4 阶段 D · 在线系统（工程）

`experiment_game` Phase5：LSL 流 → 3s 滑窗（hop100）推理 → 串行门控 + 可选 H2 生理门控 → 游戏反馈（**第一人称同侧手伸手/触碰**）。判定采用 **D8 加权计分**：`mi_start` 后 0.6s 栅格 ×10 档，各档用结束于该档的 3s 滑窗；≤2.4s 早期档跨 Cue 计半票（0.5）、≥3.0s 计满票（1.0）；Score≥5 早停、错类累计 ≥5 或终局 Score≤3 判无效、连 5 无效熔断降级（规格源：`experiment_game/docs/v2_upgrade_plan.md` v1.5 §3.4）。含单通道注意力监测模块（比赛 2.3 要求）。

### 3.5 阶段 E · 验证与材料

20 被试留出离线验证（爬坡曲线 + 层级消融）→ 在线演示 → 提交材料（PDF 方案 / Excel 结果表 / MP4 视频）。**评分权重与截止日期待确认**后定投入比例。

### 3.6 系统常量表（v2.0 新增 · 现场禁改）

> 原则：进场安检（准入门槛）+ 场内熔断（漂移保护）全部写死在配置；所有被试同一规则；每组动作入日志，事后可审计。初值如下，阶段 C 标定后冻结。

| 常量 | 初值 | 含义 |
|------|------|------|
| `CAL_ROUNDS_MIN / MAX` | 4 / 6 | 标定轮（预实验升级版）设计轮数 / 上限；小考 ≥12 试次即可提前准入 |
| `TRIALS_PER_ROUND` | 18 = 12 FT + 6 小考 | 每轮试次构成；小考卷不参与 FT（防泄漏） |
| `GATE_ENTER_THREE` | **0.60** | 准入线：小考卷 Three Acc ≥ 此值才进反馈游戏 |
| `GATE_FAIL_ACTION` | 加一轮预实验并重 FT | 超上限 → ERD 有效性排查 + 引导训练（不硬调） |
| `GROUP_SIZE` | 3 trial（1L+1R+1Rest） | 排程平衡单位（轮/子块按组倍数排布）；模型更新在轮界批量执行（D2） |
| D8 计分参数 | 见 `config/v2_session.yaml` | 栅格 0.6s×10 档 / 半票 0.5 / 早停 5.0 / 错类 5.0 / 无效 ≤3.0 / 连 5 熔断 |
| `GROUP_LR` | 1e-4 | 组内更新步长（C1-改造实验扫 {5e-5, 1e-4} 后冻结） |
| `REPLAY_RATIO` | 0.15 | 每组混入源域回放窗比例 |
| `DRIFT_METRIC` | 轮内逐档判定准确率趋势 | D8 栅格判定本来就在算，零成本复用 |
| `DRIFT_PATIENCE` | 2 轮 | 连续 2 轮不升反降 → 触发保护 |
| `DRIFT_ACTION_1` | 回滚上一 ckpt + lr 减半 | 每轮微调前自动存 ckpt（模型 ~17k 参数） |
| `DRIFT_ACTION_2` | 冻结在线更新 | 二次触发后模型锁定，游戏继续 |
| `TASK_P_ON` | 0.6 | 串行门控：Task 头概率低于此值 → 直接判空闲 |

## 四、完整系统落地流程

```text
公开库（OpenBMI/Stieger/BCI2a）3s 预训练 → 通用底座
自采 20 被试 → 微调 → 底座 v2
新用户标定轮预实验（≥3 轮：ERD 校验 + 注意力监测 + 增量微调 + 累积小考）
  → 个人 FT → 准入门槛放行
  → 反馈游戏（第一人称 · 个人模型）：轮级在线微调（分组平衡排程）+ 回放 + 漂移保护
  → 用户专属模型 → 三类实时分类 + 在线演示
```

框架口径：迁移学习 + 少样本个体适配 + **有监督**在线校准（轮级增量微调）。

## 六、论文核心创新点（v2.0）

1. **跨被试底座选型与机制分析**：统一协议下多主干对比 + oracle/消融体系证明"信息在可见窗内完备、域间隙不在统计量层"——为"权重级适配"路线提供机制依据（负结果链条：模块系列 + OTTA 系列）。
2. **少样本监督微调快速适配范式**：预实验即标定 → 个人 FT → 准入门槛 → 受保护分组在线微调；以数十试次生成个体模型（+24 pp 实证）。
3. **系统性适配消融**：标定样本量爬坡曲线、微调层级、超参、读出结构（串行门控）四维量化，形成可复用适配流程。

## 七、非研究内容界定（v2.0 修订）

1. **不做无标签在线更新**（伪标签/TENT 类，09-C1 线）；**有监督**增量微调与源域回放属系统组件，照常研究。
2. 不设计新型 CNN/Transformer 主干；结构对比使用现成模型。
3. 不使用测试集调参（Test 仅终评）；系统常量（§3.6）在阶段 C 标定后冻结，现场禁改。
