## 0. 流程总览（每被试一会话，约 60–75 分钟）

```text
装置与检查（15–20 min）
→ 阶段1 动觉引导体验（不采集，5–10 min）
→ 阶段2 标定轮 ×4（每轮 18 试次；= 比赛预实验的升级版）
     轮内：前 12 试次 → 增量微调数据；后 6 试次 → 累积小考卷
     轮间：操作者重复抬臂引导（2 min）‖ 后台增量 FT（1 min，不占等待）
→ 【准入判定】累积小考卷 Three ≥ 60% → 进游戏；未达 → 加轮（最多 6 轮）
→ 阶段3 游戏协同（第一人称伸手/触碰，每轮 16 试次 × 2–3 轮）
     MI ≤6s；D8 判定（0.6s 栅格 ×10 档加权计分）；Score≥5 或 touch → 提前结束（脑电录至 mi_end）
     轮间：引导复习 + 增量 FT（全部有效试次窗入训，D2）+ 漂移保护
→ 收工验收与切窗
```

## 1. 设备与环境（全被试冻结一致，沿 v1）

| 项 | 约定 |
|----|------|
| 设备 | OpenBCI Cyton（8ch @ 250Hz）· 同一块板、同一套电极（序列号入登记表） |
| 电极（10-20） | `Cz, C3, C4, CP3, FC4, FC3, CP4, CPz`（索引 0–7）；参考/地位置记录 |
| 环境 | 同一房间 / 显示器 ~70cm / 灯光一致；记录时段 |
| 信号链（训练/推理） | 0.5–45Hz+陷波在**采集软件层**完成（自研 `lsl_connect/preprocessing.py`，run_config `filter.enabled` 控制；**非** OpenBCI 官方软件/板端——Cyton 仅推原始计数，软件转 µV 后滤波）。**2026-08-25 更改**：由「按推流批（≤25 样本）逐块零相位」改为**因果流式滤波**（`StreamingEegFilter`：scipy Butterworth SOS 级联，每通道滤波状态跨批保持，等价于对整段连续信号做因果滤波——无块边界伪迹、延迟极小；代价是引入相位延迟（非零相位），但 MI 解码只读 µ/β 功率/包络，不受影响；板卡重连时复位状态）。更改依据：逐块零相位需要前后文，按批独立做会在批两端算错，实测与连续滤波差约 51%（0.5–45 域），经下游 8–30Hz 后仍残留约 18% 波形差，真实数据可见 25 样本周期痕迹；此前数据均为测试数据、不入正式底座，故无需与旧数据一致性复验。旧分块路径（`apply_eeg_filters`/`preprocess_eeg_batch`）保留仅作对照与回归测试对照组；回归测试见 `LSL_connect_model/tests/test_streaming_filter.py`（流式输出与整段因果滤波逐位相等、无批边界伪迹、变批长稳定） → 离线 CAR（逐时点空间）→ 50Hz 陷波 + **8–30Hz** 带通（mne FIR 零相位，同 `openbmi_3s_hop100`；已核对双滤波无害）→ 重采样 250Hz → **逐窗 z-score**。逐窗 z-score 为**冻结协议**，全部已发表数字基于它；合理性：去掉跨会话/跨被试的幅值尺度差异，让模型读窗内相对谱-空间模式（项目实证域间隙不是幅值差，方案 25 阶段 0）。实测消融（实验 07/08，5060 · Acc_paper 五折，见 `资料/模型训练/07、08`）：07 滑窗关 z-score 与正式版**持平**（shallow Three 0.5422 vs 0.5404、Task 0.6964 vs 0.6941），十一模型无崩，仅弱图模型 Three 升 +7.5–9.0pp（更吃幅值）；08 固定窗关 z-score 明显弱（shallow Three 0.4812，较 07 −6.10pp）→ z-score 本身不是 Acc 增益来源，冻结它是为跨会话可比性；已知代价：丢弃绝对幅值信息，幅值类特征/增广会被归一化抵消 |
| 信号链（质检 v4） | 同上至重采样，**不做 z-score**；质量阈值（中位 std / 峰峰值 / 饱和 / 平坦通道）以原始 µV 计 |

## 2. 被试准备与筛查（沿 v1）

健康成人、无神经疾病史；登记年龄/性别/利手/MI 策略/睡眠/咖啡因；采前洗头（无护发素）；安置后无平坦通道、无大幅漂移；知情同意留档。

## 3. 阶段 1 · 动觉引导体验（不采集，5–10 min）

**目的**：被动运动建立动觉记忆——文献支持的 MI 质量提升手段，对新手/BCI 文盲被试尤其有效。

| 项 | 规约 |
|----|------|
| 操作 | 被试闭眼放松坐姿；操作者**缓慢被动抬起/屈伸**其手臂：左手 Cue 对应左臂（抓握动作模式）、右手 Cue 对应右臂（书写动作模式）；静息类不做引导 |
| 记忆任务 | 被试记住这种感觉；随后睁眼，在**无实际运动**下想象复现该感觉 |
| 通过标准 | 被试自评能清晰复现（口头确认连续 2 次成功想象）方可进入阶段 2 |
| 记录 | 不采集脑电；引导次数/时长/通过耗时记入登记表（后续分析"引导剂量 vs ERD 质量"） |
| 安全 | 动作轻缓、不加阻力、被试可随时叫停 |

## 4. 阶段 2 · 标定轮（4 轮 × 18 试次 · 少样本适配实验本体）

### 4.1 单试次结构（比赛 6s 范式，冻结）

```text
0–2 s  准备段（注视点）
2–4 s  Cue 动画（左手抓握网球 / 右手书写 / 静息图标）
4 s    mi_start：想象期最长 6 s（D8 判定：0.6s 栅格 ×10 档，公式见阶段 3；
       标定轮恒满 6 s、无早停，仅进度条）
之后   ITI 3 s（≤13 s/试次）
```

### 4.2 轮结构与序贯切分（无泄漏）

- 每轮 **18 试次 = 3 个子块 × 6（每子块 2L+2R+2Rest 置换）**，同类连出 ≤2。
- **前 2 个子块（12 试次）→ 本轮微调数据；第 3 个子块（6 试次，恰 2/类）→ 累积小考卷（不参与任何微调）**。
- 轮间（约 3 min）：操作者重复抬臂引导（1–2 min）‖ **后台增量 FT**（~1 min）：从该被试上一轮微调后的权重继续，lr=1e-4，batch 混入 15% 源域回放窗（防遗忘），仅用本轮 12 试次的窗。

### 4.3 准入判定（系统常量，现场禁改）

| 常量 | 值 |
|------|-----|
| `CAL_ROUNDS_MIN / MAX` | 4 / 6 |
| `TRIALS_PER_ROUND` | 18（12 FT + 6 小考） |
| `GATE_ENTER_THREE` | **0.60**（累积小考卷，试次级：D8 10 档栅格多数票） |
| 判定时机 | 每轮 FT 完成后在小考卷上评估；小考卷 ≥12 试次起判 |
| 通过 | 进阶段 3 |
| 4 轮未达 | 加轮（重复 4.2 结构），最多 6 轮 |
| 6 轮未达 | 记"弱 MI 被试"：仍完成游戏阶段（用历史最优 ckpt），全程标记，不硬调 |

**少样本研究数据产出**：每轮的累积小考卷精度 = **爬坡曲线的实测点**（k = 12/24/36/48… FT 试次数），直接填论文与 `GATE_ENTER_THREE` 标定。

## 5. 阶段 3 · 游戏协同（微调后的个人模型 · 每轮 16 试次 × 2–3 轮）

### 5.1 游戏机制（对齐比赛 3.2/3.3 · v2 标准 D1–D8）

- 模型 = **准入通过时的个人模型**（垃圾反馈防线，v2.0 计划 §3.3）。
- 每试次：Cue 结束后开始想象（`mi_start`），**MI ≤6s**；**D8 判定**：`mi_start` 后 0.6s 栅格 ×10 档，各档用结束于该档的 3s 滑窗；≤2.4s 半票 0.5、≥3.0s 满票 1.0。**Score≥5 → `score_reach` 提前结束**；**touch（D4 模拟 touch 先行 → 场景碰撞）→ 立即 `mi_end`**（D1）；错类累计 ≥5 或终局 Score≤3 → 试次无效；均未触发则满 6s。
- 每轮 16 试次（6/5/5 类别轮转均衡）；轮间引导复习 + 增量 FT（**全部有效试次窗入训**，D2；无效试次不入训）。

### 5.2 在线适配与保护（系统常量）

| 常量 | 值 |
|------|-----|
| `GAME_FT_DATA` | 每轮全部**有效**试次窗轮间入 FT（D2=B；游戏试次有 Cue，有监督；无效试次不入训） |
| `DRIFT_METRIC` | 轮内逐档判定准确率趋势（D8 栅格本来就在算，零成本复用） |
| `DRIFT_PATIENCE` | 连续 2 轮不升反降 → 回滚上一 ckpt + lr 减半；再触发 → 冻结更新 |

### 5.3 游戏阶段数据用途

游戏试次同样是带标签数据（入底座 v2 训练池）；`score_reach`/`touch` 时刻、逐档判定结果（每档 `t_k/pred/score`）、试次级交互特征（终局 Score、达标档位差、早停时刻、错类累计）全部落盘（比赛 Excel/MP4 素材 + 论文交互分析）。

## 10. 分组与两组职责（15 微调 + 5 留出 · 冻结）

> 两组角色：微调组是底座 v2 的"工厂"，留出组是"新用户模拟器"——验收冻结管线、产出正式提交数字。两组会话流程**完全相同**（同一套 v2 协议），差异只在**数据用途**与**采集时序**。**两组都不做 v1 游戏**（v1 机制作废；已有 v1 旧数据只进离线汇合，不进任何在线评估口径）。

### 10.1 分配规则（入组时执行 · 禁止事后挑人）

| 项 | 约定 |
|----|------|
| 分配时机 | **入组时随机预分配**：登记后按固定种子对入组序号洗牌定组；旧条文"集齐后划分冻结"作废（事后划分有挑人嫌疑，答辩站不住） |
| 超招 | 招 **23 人**：16 微调候选 + 7 留出候选；最终目标 15+5 |
| 递补 | 预分配的留出被试数据质量差（平坦通道/伪迹多/无法完成会话）→ 按入组顺序从其余留出候选递补，登记表记录替换原因 |
| 分层 | 两组性别比例一致（如留出组 2–3 女）；利手优先右利手，左利手照常随机入组并注明；年龄/睡眠/咖啡因只登记不控制 |
| 设盲 | 操作者不知分组，两组待遇完全一致；分配表由登记管理人单独保管，采集全部结束后揭盲 |
| 采集顺序 | 微调组先（调试队列）→ 底座 v2 训练 + 常量冻结 → 留出组后（彩排队列，协议完全冻结） |

### 10.2 微调组（15 人）：做什么

1. **跑完整会话**（§0–§9）：动觉引导 → 标定轮 ×4–6（每轮 12 FT + 6 小考）→ 准入 Three ≥0.60 → 游戏轮 ×2–3 → 当日切窗 + 登记表。
2. **承担管线调试**：前期采集，协议/引擎问题在他们的会话里暴露并修复；其在线指标**不作为正式验证数字**。
3. **产出底座 v2 数据**：标定窗（`phase4_v2`）+ 游戏有效试次窗（`phase4_v2_game` / D3 拼接池）全部汇入训练池 → 微调 S3 → **底座 v2**。
4. **提供常量调优材料**：他们的录制数据做离线回放，敲定 `GROUP_LR` / `REPLAY_RATIO` / 门线等常量终值——**必须在留出组坐下之前完成**。
5. **画开发期爬坡曲线**：每轮小考精度（k=12/24/36/48…）= 爬坡实测点——横轴"该被试累计微调试次数"、纵轴 Three 精度，用于实证校准 `CAL_ROUNDS`/`GATE_ENTER_THREE` 并作为"少样本适配"核心图。
6. **收工后分析产出**：本组数据除训底座外，还产出 A1–A9 结论（留一法底座增益、标定预算校准、引导剂量–效果关系、弱 MI 发生率、轮级微调稳定性、D8 参数验证、个体差异画像、跨会话漂移、采集可行性）——全部用流程中顺手落盘的数据，不加额外实验；清单与用途详见《15+5两组实验任务书_20260824》§2.1–2.2。

数据权限：微调组窗可进一切训练与调优循环，无特殊禁忌。

### 10.3 留出组（5 人）：做什么

1. **在完全冻结的协议下跑完整会话**——起始模型为**已训好的底座 v2**、常量全部定死；这一场即"比赛彩排"，演示视频素材优先从这 5 场出。
2. **数据三不进入**（防泄漏纪律，留出组的价值全部来自此）：
   - ❌ 不进底座 v2 训练池；
   - ❌ 不进回放池（回放池为 OpenBMI 子集，天然隔离，保持即可）;
   - ❌ 不进任何常量调优循环——常量在他们坐下之前已定死；他们的会话暴露问题只记录、不修改。
3. **产出正式验证数字**（在线单次通过，每人一遍）：
   - 准入：通过率、通过轮次（第 4/5/6 轮）、`weak_mi` 人数（5 人中自然出现 0–2 个属预期，出现即验证了弱 MI 通路；全过也是结果）；
   - 爬坡曲线实测点：各轮小考 Three，与微调组 / Stieger（0.410→0.658）曲线对照；
   - 游戏轮增益：轮内逐档准确率趋势（DRIFT_METRIC）、FT 前后精度对比、漂移保护触发次数；
   - 效率与质量：会话时长、早停率（score_reach/touch）、平均早停时刻、无效试次率；
   - **报告口径**：零样本 → 标定后 → 游戏后的三段精度轨迹，逐人列表 + 均值，对标 Stieger 0.42→0.66 叙事。
4. **事后离线回放只作确认**：常量敏感性复核（证明冻结决策不误），不据结果回头改参；若 5 人中无弱 MI 被试，用回放人为压低小考精度模拟 `weak_mi` 分支。

### 10.4 事后处理链（当周）

1. 收工即评（全体）：零样本 Three（管线 sanity；S3 ~0.42 量级 / 底座 v2 应更高，仅监控）。
2. 微调组数据 → 底座 v2 训练 → 回放敲定常量终值 → 冻结。
3. 留出组在线单次数字**产出即锁定**：不重跑、不调参；填登记表归档。

## 11. 排期与人力

单被试 60–75 min（安置 15–20 + 引导 5–10 + 标定 ~15 + 游戏 ~15–20 + 缓冲）；每日 5 人 → **23 人 ≈ 5 个采集日**：

| 时段 | 内容 |
|------|------|
| D1–D3 | 微调组 15–16 人（调试队列；协议修订窗口） |
| D3–D4 | 不采人：底座 v2 汇合训练 + 回放冻结常量 |
| D4–D5 | 留出候选 7 人（取 5 · 彩排队列 · 完全冻结协议；演示素材） |

岗位：操作员 1（操作台/抬臂引导/Reject）+ 陪同 1（同意/安置/登记）。**可选**：5–8 被试隔 3–7 天复访第二会话（跨会话漂移 + Joint-Sequential 论文素材）；复访会话**组别不变**——微调组复访窗入训练池，留出组复访会话同样只做验证、不进训练。

## 12. 与系统常量表（v2.0 计划 §3.6）的对应
