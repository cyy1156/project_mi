# 标准化表格生成提示词（适配脑电 MI 多模型对比文档，可直接复制使用）

## 完整版提示词（完整规范，输出含说明 \+ 多表格 \+ 注释 \+ 结论）

```Plain Text
# 任务要求
基于给定多模型脑电运动想象实验原始指标，输出规范Markdown对比文档，严格遵循下文制表格式、指标逻辑、排版规则，最终文档结构固定，指标拆分清晰，区分灵敏度/特异性，标注无回归指标说明。

## 一、基础实验统一设定（固定前置文字）
1. 实验条件：OpenBMI数据集，2s窗口hop100ms，被试独立五折交叉验证，统一超参，balbatch均衡训练，早停依据val_acc_paper；
2. 两类任务：Task二分类（左手/右手）、Three三分类（Idle静息/左手/右手）；
3. 输入分为两类：Bandpower频域手工特征、Raw时域+TemporalEncoder原始信号；
4. 数值规范：所有均值±标准差保留4位小数，表格按Test Acc_paper降序排序。

## 二、固定文档结构（必须按顺序输出，不可调换）
1. 文档标题：11个模型在二分类、三分类及综合排名的对比分析
2. 开篇总述：说明所有指标整理为多张分层对比表格，用于横向模型对比
3. 表1：Task二分类完整基础指标表
    表头：排名、模型、输入类型、Val Acc_paper、Test Acc_paper、Test BalAcc_maj、窗级BalAcc、窗级平均F1、窗级平均Acc
    表格前置注释：标注排序规则、数值格式
4. 表2：Three三分类完整基础指标表
    表头：排名、模型、输入类型、Val Acc_paper、Test Acc_paper、Test BalAcc_maj、窗级BalAcc、macro-F1、Recall Idle、Recall Left、Recall Right
    表格前置注释：标注Recall为各类召回均值
5. 表3：双任务综合梯队划分表
    表头：梯队、模型、Task排名、Three排名、输入类型、核心特点
    梯队分级：🥇第一梯队、🥈第二梯队、🥉第三梯队，提炼模型优缺点
6. 关键发现速览：4条客观量化实验结论（模型提升幅度、最优模型、类别偏倚、任务难度区分效果）
7. 表4：Task二分类拆分灵敏度&特异性专用表
    前置指标说明：定义灵敏度Se、特异性Sp、BalAcc=(Se+Sp)/2；说明数据由均衡准确率拆分得到
    表头：排名、模型、输入类型、试次级BalAcc_maj(Se+Sp)/2、窗级BalAcc(Se+Sp)/2、窗级灵敏度Se、窗级特异性Sp、窗级F1
    排序规则：同表1Test Acc_paper降序
8. 表5：Three三分类拆分各类灵敏度&特异性专用表
    前置指标说明：多分类Recall=对应类别灵敏度，Sp为该类真阴性率，macro-F1无加权平均
    表头：排名、模型、输入类型、Recall Idle(灵敏度)、Sp Idle(特异性)、Recall Left(灵敏度)、Sp Left(特异性)、Recall Right(灵敏度)、Sp Right(特异性)、macro-F1
9. 独立章节：回归性说明
    固定文案：本实验为离散分类任务，无MAE/MSE/R²等回归评价指标；若需回归任务需重新设计标签与损失函数
10. 末尾可选交互问句：是否导出在线表格用于筛选排序

## 三、制表硬性格式规范
1. 全部使用标准Markdown表格，横线分割每个表格，表格之间空行；
2. 模型最优数值加粗显示；
3. 指标符号统一：下划线保留（如Acc_paper、BalAcc_maj），不修改命名；
4. 所有均值±标准差统一格式，小数位数对齐；
5. 指标定义放在对应表格上方callout/说明文字，先解释再放表格；
6. 梯队表格使用emoji区分档次，特点简洁凝练；
7. 禁止合并单元格、复杂排版，纯通用Markdown，可复制到飞书/语雀/Word；
8. 二/三分类分开两张独立表格单独罗列灵敏度、特异性，不合并混放；
9. 区分「试次级（trial投票聚合）」与「单窗级」两套指标，分开列；
10. 三分类逐类单独列灵敏度、特异性，不合并汇总。

## 四、输入输出约束
输入：多组模型五折实验原始均值、标准差、各折细分指标
输出：严格按照上述结构、表格表头、文字模板输出完整文档，不删减表格、不合并指标，必须拆分灵敏度、特异性为独立列，单独制作两张专项对比表，末尾补充回归指标说明。
```

## 精简短提示词（快速调用，适合单次制表）

```Plain Text
根据提供的多模型脑电MI实验数据，生成标准Markdown对比文档，结构固定：
1. 标题+总述；
2. 表1 二分类全指标（按Test Acc_paper降序）；
3. 表2 三分类全指标；
4. 表3 综合梯队排名表，分金银铜梯队；
5. 4条量化关键实验结论；
6. 表4 二分类单独拆分灵敏度、特异性独立列；
7. 表5 三分类逐类拆分灵敏度、特异性独立列；
8. 单独一段说明：本任务是分类，无任何回归指标。
格式要求：标准MD表格，最优值加粗，均值±标准差4位小数，每个表格前加指标说明，二/三分类灵敏度、特异性分开两张表罗列，不能合并，全文可直接粘贴飞书文档。
```

## 提示词核心设计逻辑（给你写文档时参考）

1. 结构锁死：固定 6 块核心内容，不会漏综合排名、拆分特异性表格；

2. 指标强制拆分：明确要求 Se、Sp 单独成列，解决你 “分开罗列” 需求；

3. 格式标准化：统一小数、排序、加粗、符号规则，输出格式统一；

4. 边界补充：强制增加回归说明，解决你之前询问 “回归性” 的问题；

5. 场景适配：输出纯通用 Markdown，适配飞书、Word、语雀等各类文档工具；

6. 信息分层：先基础总指标表，再细分灵敏度专项表，阅读逻辑自上而下。
