## 0. 文档目的与原则

1. 现有 `资料/图片/` 以流程框图为主，偏叙事，**不足以钉死实验结果**。  
2. 现有 `figures/图1–图3` 为系统方法图，可保留；结果章需另增**数据图**。  
3. 本规格要求：每张结果图只回答一个问题；图内文字极少；数字与正文/Excel 一致。  
4. 制图顺序建议：先按本 MD 定稿图注与数据表 → 再脚本出图 → 再改 v4 引用。

## 1. 统一视觉风格（全报告）

| 项 | 规格 |
|----|------|
| 用途定位 | 挑战杯技术报告 / 期刊风格结果图，**非**产品海报、非 PPT 大卡片 |
| 画布 | 半栏约 80–90 mm 宽，或通栏 160–170 mm；导出 **PNG + PDF**，**300 dpi** |
| 背景 | 纯白；无渐变底、无阴影、无 3D |
| 字体 | 中文：黑体（标题）/ 宋体（图注）；英文与数字：**Arial** 或 Helvetica |
| 字号 | 轴标题 8–9 pt；刻度/图例 7–8 pt；图内标注 ≤8 pt |
| 配色（色盲友好，≤4 色） | 主色 `#2C5F8A`；对照 `#C45C26`；中性 `#6B7280`；通过 `#2A9D6E`；失败 `#B91C1C` |
| 线与标记 | 轴线 0.6–0.8 pt；折线 1.5–2.0 pt；标记为小空心/实心圆，勿用星形花哨符号 |
| 误差表示 | 优先 mean±SD（图注写明样本标准差）；若画色带用 mean±SEM 并在图注声明 |
| 显著性 | 需要时在柱顶/线旁标 `*` / `n.s.`，图注写检验名（Wilcoxon / McNemar） |
| 禁止 | emoji；大段段落塞进图；圆角渐变卡片墙；与正文重复的长脚注条 |

### 1.1 图注写法模板

> **图 X　\<短标题\>。** \<协议/数据集/样本量\>。\<纵轴含义与粒度（窗级/试次级；三分类/MI）\>。\<模型名\>。\<统计量定义\>。\<一句结论（可选）\>。

### 1.2 口径禁忌（防混比）

- OpenBMI 主结果、BCI2a Leave-Next、Stieger 伪在线、指定集嵌套、真人末档 **不得画在同一坐标轴上硬比绝对值**。  
- 图注必须区分：**窗级 vs 试次级**；**三分类 vs 仅 L+R 的 MI**。  
- 生理门控柱必须标注「离线旁路 / 弃权率」，避免被读成线上协议。
