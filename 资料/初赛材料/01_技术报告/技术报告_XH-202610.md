# 基于运动想象的脑-机交互算法研究与系统实现 · 技术报告

**题目编号：XH-202610 ｜ 挑战杯"揭榜挂帅"擂台赛 ｜ 提交日期：2026 年 9 月**

> 摘要：针对运动想象脑机接口（MI-BCI）从实验室走向实际应用面临的噪声鲁棒解码、控制/空闲状态判别、少样本个性化适配与低延迟实时运算四大瓶颈，本报告提出并实现了一套完整的"迁移学习 + 少样本个性化适配 + 在线校准"三级优化 MI-BCI 系统。系统以 OpenBMI 54 名被试公开数据预训练 ShallowFBCSPNet-E1f 四成员融合底座，在标准被试独立五折协议下取得三分类（左手/右手/空闲）试次级准确率 **61.88%**（召回率 macro 61.88%、特异性 macro 80.94%）；在**主办方指定标准数据集**上交卷栈为 **59ch 从零 E1f-A59（S0）**：leave-fold 嵌套主读 **0.511±0.066**，折内附报 **0.558±0.069**（in-sample 乐观约 **+4.7pp**，实验 37）；备选 OpenBMI→8ch FT 栈 nested **0.540** 已登记但因 Val 支撑外推风险否决（实验 40）。通过跨库伪在线与 Leave-Next 仿真证明权重级增量微调是个体适配的唯一有效来源（Stieger 24 人零样本 41.98% → 少样本微调 65.90% → 生理门控 70.03%；BCI2a 仿真末档 all4 **66.3%** vs 单成员 so **45.2%**，Δ+21.1 pp）；真实被试采后 Leave-Next 适配最优个体窗级准确率达 **92.4%**（F5 试次计分 41.5/45，MI 33/36）。在线端单窗前向增量耗时 1.11 ms，判定延迟约 3.5 s，配合网页游戏化诱导与第一人称反馈界面，形成可验证、可复现、可演示的完整闭环系统。

## 1. 引言

### 1.1 应用背景与核心技术瓶颈

我国 60 岁及以上人口已达 2.8 亿，脑卒中患者总数超 2876 万，绝大多数患者遗留运动功能障碍，对智能康复与辅助移动技术形成庞大刚性需求。运动想象脑机接口（Motor Imagery BCI, MI-BCI）无需外部刺激与残存肌力参与，仅通过用户想象肢体动作即可产生控制信号，是实现"随心而动"智能辅具的核心技术路径。

但该范式从实验室走向真实应用仍存在三大瓶颈：其一，日常环境电磁干扰与生理噪声下，微弱且个体差异显著的运动想象脑电信号难以实现鲁棒、高精度解码；其二，缺乏可靠的异步交互协议，无法精准判别用户"控制状态"与"空闲状态"，存在使用安全隐患；其三，算法在有限训练数据下的快速个性化适配及实时低延迟运算难题尚未突破。此外，运动想象"操作要领"因人而异，初学者摸索周期长，制约技术规模化推广。

### 1.2 赛题需求对接与本文贡献

对照赛题攻关任务（三类认知状态精准分类与实时识别、不少于 20 人自采数据佐证、完整可演示系统），本文贡献如下：

1. **统一协议下的底座选型与机制分析**：对 11 种主流脑电解码模型在 OpenBMI 54 人数据上完成统一协议正式对比，结合"未来信息上界 oracle""测试时适配（OTTA/EA/AdaBN）"等机制实验，证明"信息在可见窗内基本完备、域间隙不在二阶统计量层"，为"权重级适配"路线提供机制依据（§5、§7）。
2. **E1f 四成员概率级融合与因果读出**：以温度校准 + 验证集加权的四成员融合（Shallow/T-Shallow/EEGNet/Conformer）叠加因果平滑读出，取得 OpenBMI 三分类 61.88%（§5）。
3. **采后 Leave-Next 少样本个性化适配**：新被试每完成一个会话即对全部四成员做增量微调并晋升，配合源域回放、质量门控与强制晋升告警，实现"边采边适配"；在公开库仿真与真实被试上均显著优于单成员微调与零样本（§7）。
4. **完整在线系统**：网页游戏化诱导、第一人称虚拟手反馈、操作台实时监测与三类实时分类，单窗前向 1.11 ms 的低延迟推理链路（§8、§10）。
5. **全套可复现材料**：离线验证 Excel（含混淆矩阵、每类召回率/特异性、延迟与原始数据索引）、源代码包与本报告（§11）。
6. **指定集嵌套协议与交卷定稿**：在主办方指定集上完成 Exp34–40；交卷为从零栈 **S0**（嵌套 0.511 / 折内 0.558 双标注），并量化折内融合乐观约 **+4.7pp**；备选 R-B8=0.540 因外推风险否决并归档（§9.7）。

## 2. 系统总体设计

### 2.1 三级优化框架

系统采用"迁移学习（Transfer Learning）+ 少样本个性化适配（Few-shot Adaptation）+ 在线校准（Online Calibration）"三级优化框架：

- **第一级（通用表征）**：在公开运动想象数据集（OpenBMI 54 人）上按统一协议预训练通用底座，学习跨被试脑电表征；
- **第二级（底座强化）**：以自行采集的真实被试数据对底座做增量微调，构成贴近目标人群的通用模型；
- **第三级（个体适配）**：新用户每完成一个采集/游戏会话，即触发一次采后 Leave-Next 增量微调，生成用户专属模型，并以质量门控与回放正则保证适配稳定性。

### 2.2 系统运行链路

```
公开数据（OpenBMI/BCI2a/Stieger）统一切窗 → 预训练通用底座（E1f 四成员）
  → 新用户采集会话（网页游戏范式，8 通道 250 Hz）
  → 采后 Leave-Next 增量微调（all4 + replay 0.10 + 门控）
  → 用户专属模型（subjects/*/models/current）
  → 在线三类实时分类（因果平滑 + 多数票读出）+ 第一人称游戏反馈
  → 会话数据回灌 → 持续适配
```

### 2.3 关键设计原则

1. **通道序冻结**：8 通道顺序 Cz, C3, C4, CP3, FC4, FC3, CP4, CPz 同时作为模型输入通道轴顺序（索引 0=Cz, 1=C3, 2=C4, 3=CP3, 4=FC4, 5=FC3, 6=CP4, 7=CPz），全部数据集、训练、微调与在线推理均不重排；
2. **配置即权威**：范式时序、微调策略等全部冻结在配置文件（`v3_session.yaml`、`ft_policy.json`）中，文档与代码冲突时以配置为准，保证"报告—代码—演示"三者一致；
3. **全链路留痕**：每个会话的原始脑电（eeg.csv）、事件（events.jsonl）、清单（manifest.json）与模型快照均落盘，任何一次评测均可从原始数据重放复现。

## 4. 信号预处理与特征提取

### 4.1 统一预处理口径

所有数据集与在线流共用同一预处理：选 8 导固定序 → CAR → 8–30 Hz 带通（覆盖 μ 节律 8–13 Hz 与 β 节律 13–30 Hz 的运动相关成分）→ 250 Hz 重采样 → 逐窗 z-score。实验表明训练锚点含想象期之后窗有害（−1.1 pp），故切窗严格限定于有效想象期。

### 4.2 滑窗特征

特征窗长 3 s（750 点）、步长 100 ms。窗长消融（OpenBMI，统一协议）：1 s 0.562 → 2 s 0.576 → 3 s **0.588**（三分类试次级），3 s 窗显著优于 2 s 窗（+4.7 pp 于二分类），确定 3 s/hop100 为冻结口径。

### 4.3 双标签双头

训练标签同时维护两套：`label_task`（空闲/任务二分类）与 `label_three`（空闲/左手/右手三分类），两任务头独立训练、不迁移权重。二分类头用于状态监测与质量评估，三分类头为正式读出。

## 5. 分类模型架构

### 5.1 主干统一对比与选型

在 OpenBMI 54 人、2 s 窗统一协议（统一超参 lr 1e-4、wd 1e-4、drop 0.5、批均衡、验证集 Acc_paper 早停、被试独立五折）下对比 11 种主流模型（试次级 Test Acc）：

| 模型 | 三分类 | 二分类（左/右） |
|---|---|---|
| Deep4Net | 0.5431 | 0.7218 |
| ShallowFBCSPNet | 0.5398 | 0.6982 |
| Conformer | 0.5378 | 0.7102 |
| EEGNet | 0.5307 | 0.6433 |
| EEGTCNet | 0.5067 | 0.6938 |
| DGCNN_raw / DBN_raw / GCBNet_raw | 0.4906 / 0.4885 / 0.4764 | 0.7064 / 0.6940 / 0.6741 |
| DGCNN / DBN / GCBNet | 0.3891 / 0.3809 / 0.3746 | 0.5947 / 0.6210 / 0.6151 |

三分类任务下 ShallowFBCSPNet 表现突出且参数量仅约 17 k，适合在线低延迟推理与少样本微调，选为底座主干。窗长升级到 3 s 后单模型三分类达 **0.5876±0.0296**（二分类 0.7415±0.0306）。

### 5.2 E1f 四成员概率级融合

单模型之上，对 shallow、T-shallow（Task 头增强版 shallow）、eegnet、conformer 四个成员的输出概率做融合（E1f，实验 26）：各成员先做温度校准（temperatures 由验证集 NLL 拟合），再按验证集网格搜索的权重加权求和。冻结配置下 OpenBMI 三分类试次级 **0.6173**。机制实验（oracle 上界、λ 扫描、SE/ECA/CBAM 模块增强、双专家门控、JEPA 系列等）均为阴性，说明增益不在结构模块层而在校准与集成层。

### 5.3 读出层（因果平滑 + 多数票，冻结 F5）

在线读出为单轨三分类（F5 冻结）：

- **窗级**：E1f 融合概率 → 因果平滑（当前窗与前两窗，lookback=2）→ argmax；
- **试次级**：各窗平滑后判定做多数票 = 试次结果 = 计分依据。

该读出在 OpenBMI 上取得试次级 **0.6188**（C 臂，实验 30），优于离线双向平滑 classic 臂 0.6173，说明因果化不损失精度；多数票（W 臂）0.6125 作为现行线上读出。置信度 τ 早停双轨已退出正式协议，仅保留为离线分析旁路。

## 6. 异步交互协议（控制状态/空闲状态判别）

### 6.1 状态判别机制

本系统的异步判别由三层构成：

1. **分类层（主判定）**：三分类读出直接包含"空闲"类。在线推理按 100 ms 节拍持续输出 E1f 融合概率，因果平滑 + argmax 给出窗级判定；空闲判别即三分类 argmax 命中空闲类，配合专用 Rest 试次段（4 s）构成显式的空闲状态监督样本。
2. **监测层（双头辅助）**：Task 二分类头独立输出"任务概率"，与单通道运动皮层 ERD 偏侧化指标（对侧 ERD 幅值与 laterality 指数，见伪在线实验 07 的 H1 门控定义：对侧 ERD ≤ −15 且 laterality ≥ 8）共同构成全状态监测，用于会话质量门控与无效试次标记；τ 阈值串行门控保留为离线旁路与部署可选策略。
3. **会话层（安全机制）**：采集/游戏会话内设置质量门控（heldout 会话窗级 **raw** 准确率判定 PASS/FAIL，展示用因果平滑），FAIL 时告警落盘（`force_promote_warning.json`）并强制晋升，保证异常被显式记录而非静默吸收；EEG 断流看门狗（停滞 2 s 告警 / **5 s 中止**）保护采集完整性；游戏侧另有无效试次计分判定与连续无效触发会话熔断降级机制（v2 遗产，保留为保护路径），确保用户从控制状态回到空闲状态时系统行为安全可预期。

### 6.2 判定时延

判定延迟由窗口时程主导：3 s 窗 + 100 ms 步进下，C 臂平均判定时刻 t̄≈3.50 s（自 Cue 起），W 臂全窗多数票 t̄=4.00 s；算法单窗前向增量耗时 1.11 ms（RTX 5070 实测，见 §9.6），远小于窗步进节拍，满足实时性要求。

## 7. 少样本个性化适配

### 7.1 采后 Leave-Next 增量微调

新用户不需要专门的标定会话：每完成一个采集/游戏会话，即以"已完成会话为训练集、下一会话为 heldout 评测"执行一轮增量微调（Leave-Next），机制如下：

- **微调范围 all4**：四成员各自增量微调（非仅 shallow 单成员），门控 FAIL 可警告后强制晋升（默认开启）；
- **源域回放**：混入 10% OpenBMI 源域窗防灾难性遗忘；
- **轮级批量更新**：以会话为界批量执行，而非逐试次超小批更新，梯度更稳定、回放可按类配比；
- **权重落盘**：个体模型写入 `subjects/*/models/current`（含 `members/` 与 `e1f_overlay.json`），历史快照归档可审计。

### 7.2 适配有效性证据链

| 实验 | 设计 | 关键结果 |
|---|---|---|
| 实验 07（Stieger 24 人伪在线） | 前半会话训练、后半评测 | 零样本 41.98% → 少样本 FT **65.90%**（24/24 被试提升）→ FT+生理门控 **70.03%** |
| 实验 09（OTTA 消融） | EA/AdaBN 测试时适配 | 全部阴性（EA ≈ 0，微调后 EA+AdaBN 最多 −11 pp）→ 权重级适配是个体精度的唯一有效来源 |
| 实验 32（BCI2a Leave-Next 仿真） | 9 人 × 6 轮采后微调（stamp=`20260901_124502`） | 末档 all4 **66.3%** vs 单成员 so **45.2%**（Δ+21.1 pp）；零样本 33.8%；门控 PASS（strict）S/so/all4 = 29/32/29 /45 |
| 实验 33 + Leave-Next all4 全表（真实被试） | 10 名 v3 被试（含 ytl0901） | 最优个体 syj0828 末档窗级 **92.4%**（F5 41.5/45，MI 33/36）；门控合计 **20/50 PASS**；all4 较 so 平均 ΔMI +54.2 pp（实验 33） |

个体间差异大（末档窗级约 0.35–0.92）恰是少样本个性化适配必要性的直接证据：零样本底座不足以覆盖全部用户，而采后微调在绝大多数个体上带来大幅增益。

### 7.3 漂移保护

每轮微调前自动存档权重；质量门控连续不通过时先回滚上一权重并降低学习率，再次触发则冻结在线更新、游戏照常运行（配置化，现场不可改）。该机制与强制晋升告警共同构成适配安全网。

## 8. 网页游戏诱导系统

### 8.1 游戏化诱导（v3 采集板块）

系统以轻量网页（HTML/JS + Three.js + WebSocket）实现第一人称运动想象诱导：被试屏呈现虚拟双手与桌面目标物（杯子/瓶子/苹果等；默认每 2 试次换物、每 10 试次换场景主题），Cue 阶段 HUD 同步给出「左手/右手抓握××」动觉引导语，正式想象段双手可见，被试按提示执行运动想象。

正式采集板块为 **v3 探针会话**（`phase_mode=v3_session`，配置权威源 `v3_session.yaml`）：

| 项 | 规格 |
|---|---|
| 会话结构 | **2 块 × 18 试次 = 36 试次**（块内 Left/Right 均衡）；开场静息基线 30 s；块间休息 30 s |
| 单试次时序 | 专用 Rest **4 s** → prep **2 s** → Cue **1 s** → MI **4 s** → ITI **3 s**（OpenBMI-Align v1） |
| 在线读出 | E1f 四成员融合 → 因果平滑 lookback=2 → argmax；试次级多数票（判定窗锚定 `mi_start`，窗尾相对 MI 3.0–4.0 s） |
| 计分 | MI 判对 **+1** · 专用 Rest 判对 **+0.5** · 满分 **54** |
| 权重 | 优先加载被试个人 `models/current`，否则回退通用底座 |
| 反馈 | 默认 `arm_reach`：判定相关到达/抓取动画；会话全程落盘（eeg/events/manifest） |

会话结束后按 Leave-Next 触发采后 all4 增量微调并晋升个人模型，构成「采集 → 适配 → 再采集」闭环。另有旁路游戏测试路径（v2 · `game_mode=v3_test`，20 试次连击计分）仅用于快速验证权重，**不以该路径作为正式采集口径**。

### 8.2 操作台

操作台（operator UI）承担被试登录、会话号管理、采集启停（Cyton/合成板）、实时波形与信号质量监测、实时三分类概率显示、门控确认、暂停/Reject/中止等控制；所有操作按键化（P/N/G/R/Esc）并有审计日志。

### 8.3 工程与安全

前后端经 WebSocket 通信，控制面带 token 鉴权，输出经 XSS 转义；会话收尾具备崩溃安全落盘；核心流水线（通道布局、原子写盘）与窗口切分均有回归测试覆盖（pytest）。

## 9. 离线实验验证

官方要求的准确率、召回率、特异性与运算延迟指标全部在《离线性能验证报告》（Excel，随附）中给出可追溯明细，本章摘要核心结果。

### 9.1 OpenBMI 主结果（54 人五折，三分类）

被试独立五折，test 共 16,200 试次（每类 5,400）：

|---|---|---|---|---|
| E1f + 因果平滑（C 臂，主结果） | **0.6188** | 0.6188 | 0.8094 | 0.6196 |
| E1f + 多数票（W 臂，线上读出） | 0.6125 | 0.6125 | 0.8062 | 0.6132 |
| E1f 窗级 argmax | 0.5925 | 0.5925 | 0.7962 | 0.5930 |
| Shallow 3s 单模型 | 0.5876±0.0296 | — | — | — |

C 臂混淆矩阵（行=真实，列=预测；窗计数，试次判定广播到窗）：

| | Rest | Left | Right |
|---|---|---|---|
| **Rest** | 36476 | 12408 | 10516 |
| **Left** | 8129 | 38148 | 13123 |

每类召回率：空闲 61.41%、左手 64.22%、右手 60.00%；每类特异性：空闲 86.44%、左手 76.28%、右手 80.10%。左右混淆主要发生在左-右之间（13,123/15,774），空闲-任务边界混淆相对更低，符合运动想象解码的一般规律。

### 9.2 基线与消融

11 模型统一协议对比（§5.1）表明三分类下 Shallow 系最优；机制消融（oracle 未来信息上界 −0.15 pp、OTTA 全阴性、模块类增强全阴性）确认增益来源为"更长窗口 + 校准集成 + 权重级适配"。全部明细见 Excel 报告 sheet 02/03/04。

### 9.3 BCI2a Leave-Next 仿真

9 名被试各 6 轮采后微调仿真（stamp=`20260901_124502`，当前方法复跑），末档（R5）九人 μ±σ：all4 force **0.663±0.067** vs 单成员 so force **0.452±0.047**（Δ+0.211），零样本 R0 0.338；all4 在 9 人中 **7** 人 ≥0.62，最大个体 A09 **0.756**。逐被试与逐轮明细见 Excel sheet 03；与旧跑 `20260829_235900` 末档均值差约 ±1 pp，主结论稳定。

### 9.4 Stieger 跨库伪在线

24 人跨库伪在线：零样本 0.4198±0.0585 → 前半少样本微调 0.6590±0.0929（24/24 被试提升 ≥3 pp）→ 加生理门控 H1 0.7003±0.0869（弃权率 59.3%）。证明跨域部署必须个体化微调，门控可在微调基础上进一步叠加收益。

### 9.5 真实被试验证

10 名 v3 范式被试 Leave-Next all4 全表（口径方案 A，报告 `leave_next_all4_full_report_20260831_233943`，含 2026-09-01 被试 ytl0901）：最优个体 **syj0828** 末档窗级 smooth **0.924**（F5 41.5/45，MI 33/36、Rest 17/18，门控 **5/5 PASS**）；全表门控 **20/50 PASS**；末档窗级约 0.35–0.92。全部明细见 Excel sheet 05。

### 9.6 运算延迟

| 指标 | 数值 |
|---|---|
| 单窗前向增量耗时（RTX 5070，macro 均值） | 1.11 ms |
| 判定延迟 t̄（C 臂 / W 臂，自 Cue 起） | 3.50 s / 4.00 s |
| 在线判定节拍（窗步长） | 100 ms |

模型约 17 k 参数，四成员融合为概率级加权，开销与单成员同量级；端到端延迟由窗口时程主导，满足交互节拍要求。

### 9.7 主办方指定标准数据集（Challenge MI · Exp34–40）

**交卷口径**：指定集提交 **59ch 从零 E1f-A59（S0）**。OpenBMI 预训练用于系统底座与公开库主结果，**不是**指定集交卷依赖。备选 OpenBMI→8ch FT（R-B8）已完整登记并归档。

**主读数尺子**：leave-fold 嵌套 Val；折内读数双标注附报。

| 口径 | 栈 | Acc mean±std | 角色 |
|---|---|---|---|
| **嵌套（交卷主读）** | **E1f-A59（N0 / S0）** | **0.511±0.066** | **提交 CSV** |
| 折内（交卷双标注） | E1f-A59 | 0.558±0.069 | 同文件；相对嵌套乐观 ≈+4.7pp |
| 嵌套（备选归档） | E1f-B8-ft（R-B8） | 0.540±0.146 | Exp39 §5 程序终态；Exp40 风险否决 |
| 折内（备选附报） | E1f-B8-ft | 0.573±0.140 | Exp34 |
| 嵌套（附报） | b8_shallow_b | 0.528±0.130 | Exp38 G* |

**方法论要点（150 试次折内融合乐观）**：同一 E1f-A59 栈，折内 0.558 相对嵌套 0.511 高约 **+4.7pp**。Exp36 折内跨轨融合曾达 0.604/0.626，嵌套复核后涨点基本消失——说明小样本折内拟合融合权重会产生显著 in-sample 伪影。Exp38–40 在嵌套尺子下均未过加固门槛；算法线已冻结。

**交卷风险否决（Exp40 补记）**：将 R-B8 的 900 试次 OOF 按折拆开，预测 Rest 占比最高仅约 33%（fold1），而 test 预测 Rest≈**51%**，落在 Val 六折支撑之外；且与 fold0「Rest 仅 12% 后崩到 0.300」方向相反。两栈对 test 皆为外推，但 S0 Val 最差折 0.427、无 0.300 前科，设计均衡下边际上限亦更高（90.8% vs 82.5%）。故提交 S0，R-B8 CSV 保留归档。该决策**未使用 test 标签调参**，未改 Val 过线门槛。明细见 Excel sheet 00/07/11。

## 10. 在线系统集成与演示

在线系统由四部分组成：采集前端（Cyton + LSL）、推理服务（3 s/hop100 滑窗 + E1f 四成员 + 因果平滑读出）、游戏前端（第一人称虚拟手 + 连击计分）、操作台（会话控制与实时监测）。演示视频（MP4，≤10 分钟）按"实时采集 → 三类实时分类 → 视觉反馈 → 状态切换响应"四要素录制，脚本与分镜见随附《演示视频脚本》。

## 12. 结论与展望

本系统完成了从公开数据预训练、指定集从零评测、自采数据强化、少样本个体适配到在线游戏化交互的完整 MI-BCI 链路：OpenBMI 标准五折三分类 **61.88%**；主办方指定集交卷 **S0 嵌套主读 0.511**（折内双标注 0.558；备选 R-B8=0.540 已归档）；BCI2a Leave-Next 末档 all4 **66.3%**（相对 so +21.1 pp）；真实被试个体适配最优 **92.4%**；单窗前向 **1.11 ms**。指定集算法旁路 Exp34–40 已在嵌套尺子下收束并冻结。后续工作：① 完成不少于 20 名被试采集并以自采数据强化底座（轨 C）；② 决赛阶段视算力考虑外源多语料预训练（备查）；③ 扩展注意力监测与更多异步控制语义，面向康复辅具落地。
