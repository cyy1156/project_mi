## 在 Cursor 里预览插图

Cursor 编辑器右上角的 **Preview** 开关（内联预览）目前**不渲染本地图片**（产品已知问题）。请改用：

- `Ctrl+Shift+V`：打开 Markdown 预览，或
- `Ctrl+K` 再按 `V`：侧边预览

图文件在 `交稿/figures/`，路径已是同级 `figures/...`。

## 改稿后如何重导

在仓库根或任意位置执行：

```bash
python 资料/初赛材料/_build/md2docx_pdf.py
```

脚本会读取本目录 `技术报告_XH-202610.md`，嵌入 `figures/` 中的 `![...](...)` 图片，并覆盖写入 `交稿/` 下的 PDF 与 DOCX。

结果图若需重画，先跑本目录 `make_result_figures.py`，再跑上面的导出脚本。
