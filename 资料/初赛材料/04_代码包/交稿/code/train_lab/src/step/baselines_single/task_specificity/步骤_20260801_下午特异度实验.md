## 步骤 A：改训练目标（加权 CE + BalAcc 早停）

**目的**：不再用 Val F1 选模（会偏向全猜任务）；加重静息类损失。

| 子步 | 做什么 | 脚本 / 参数 | 产出 |
|------|--------|-------------|------|
| A1 | 固定权重 `w0=2, w1=1`，早停=BalAcc | 现脚本：`baseline_shallow_wce2_balacc.py`（当时改在 `baseline_shallow.py`） | `run_20260801_153617` |
| A2 | 试 `mode=invfreq`（按折内标签逆频） | 同上，改 `TASK_WEIGHT_MODE` | `run_20260801_155437` |
| A3 | 扫固定权重 `w0=2.5` | `TASK_W0=2.5` | `run_20260801_160326` |
| A4 | 扫固定权重 `w0=2.2`（最均衡一档） | `TASK_W0=2.2` | `run_20260801_161301`（`163900` 为复现） |

**当前复现命令（主臂，默认 w0=2.2）：**

```bash
python baseline_shallow_wce2_balacc.py --data merged_2s
```

若要复现其它 `w0` / `invfreq`：改脚本顶部 `TASK_W0` / `TASK_WEIGHT_MODE` 后再跑。

**看结果：**

- 权重：`code/train_lab/out/baseline/shallow_wce2_balacc/merged_2s/run_<stamp>/`  
- MD：`资料/模型训练/runs/<stamp>_shallow_wce2_balacc/`  
- 主看 Test Spec / Rec / BalAcc，不要只看 F1  

**A 的读数要点（下午）：**

- `w0=2`：Rec 过线，Spec 不够  
- `w0=2.2`：Spec 刚过、Rec 差一点，BalAcc≈0.57  
- 加大 `w0` / `invfreq`：只是 Spec↑ Rec↓，**BalAcc 几乎不动** → 停止盲目加大权重  

---

## 步骤 B：Batch balance（采样平衡）

**目的**：每个 train batch 近似 1:1，不叠 / 叠加权 CE。

| 子步 | 臂 | 设定 | 命令 | 代表 run |
|------|----|------|------|----------|
| B1 | 仅 balance | 普通 CE + sampler | `python baseline_shallow_balbatch.py --data merged_2s --arm B1` | `164852` |
| B2 | 加权+balance | w0=2 + sampler | `python baseline_shallow_balbatch.py --data merged_2s --arm B2` | 多轮 `165736` 等 |

```bash
python baseline_shallow_balbatch.py --data merged_2s --arm B1
python baseline_shallow_balbatch.py --data merged_2s --arm B2
# 或一次跑完：
python baseline_shallow_balbatch.py --data merged_2s --arm both
```

**B 的读数要点：**

- B1：Spec 提到约 0.49，但 Rec 掉到约 0.64；BalAcc 仍≈0.57  
- B2：结果不稳，易过偏静息（Rec 可低至 0.3x）；**不作为主臂，停止重跑**  

---

## 步骤 C：SMOTE（过采样少数类）

**目的**：仅在 train 折对静息做 SMOTE，再普通 shuffle 训练。

| 子步 | 臂 | 设定 | 命令 | 代表 run |
|------|----|------|------|----------|
| C1 | S1 | 普通 CE + SMOTE | `python baseline_shallow_smote.py --data merged_2s --arm S1` | `175902` |
| C2 | S2 | w0=2 + SMOTE（下午未作为主结论；优先级低） | `--arm S2` | — |

```bash
python baseline_shallow_smote.py --data merged_2s --arm S1
```

**C 的读数要点：**

- S1：Spec≈0.32（更差），Rec 升高 → raw EEG 上 SMOTE **无效**，不必再叠 S2  

---

## 步骤 D：阈值扫描（不训练）

**目的**：固定 A 步已有 `best_task.pt`，扫 `P(任务)≥τ`，看能否在决策层双过关。

```bash
# w0=2.0
python eval_threshold_sweep.py --data merged_2s ^
  --run_dir ../../../../out/baseline/shallow_wce2_balacc/merged_2s/run_20260801_153617

# w0=2.2
python eval_threshold_sweep.py --data merged_2s ^
  --run_dir ../../../../out/baseline/shallow_wce2_balacc/merged_2s/run_20260801_161301
```

选 τ 规则：各折 **val** 上优先 Spec≥0.40 且 Rec≥0.75，取 BalAcc 最大；再到 test 报告。

**D 的读数要点：**

- 五折均值 **不能** 靠 τ 过关  
- val 选 τ 后均值甚至略差于 τ=0.5  
- 仅个别折（如 fold2）test 曲线上有双过关余量  

产出：`run_*/threshold_sweep.json`，MD 在 `资料/模型训练/runs/*_tau_sweep/`。
