# 操作台顺畅度审查与优化清单（v2 会话）

> 日期：2026-08-24 · 起因：实测"操作起来不舒畅"。方法：v2 操作链全链路走查（setup → 引导 → 标定 → 准入 → 游戏 → 收尾），消息流与 DOM 逐一核对。  
> 本文只审查与出方案，不代改代码。结构项（Setup/Summary 对齐）见《v2操作台升级文档_20260824》，本文聚焦**运行期顺畅度与实时监控**。

## 1. v2 操作链现状（谁在什么时候看什么、点什么）

| 阶段 | 系统行为 | 被试屏 | 操作台 | 人工动作 |
|------|----------|--------|--------|----------|
| 引导（阶段0） | 广播 guidance_begin，**阻塞等确认 600s**（session_v2.py:394） | **空白场景，无文字**（F1） | 提示行 + 按钮解禁（F3） | 双手分别抓握杯子引导 → 点"确认动觉引导完成" |
| 标定轮 | 试次渲染正常（cue/mi/iti 走场景函数） | 轮间过渡**空白**（F2） | 仅原始 stage 名 | 无 |
| 轮间 | 同步 FT → guidance_begin，等确认 ≤180s（session_v2.py:501） | 空白（F1/F2） | 无倒计时/无提示音（F3） | 再次双手抓握杯子引导 → 点确认 |
| 准入 | 每轮后 v2_gate 更新 gate 盒 | — | gate 盒正常（唯一活着的监控） | 无；**通过时无提示直接进游戏**（F10） |
| 游戏 | 试次 + score_reach/touch 渲染正常 | 正常 | **Score 条/轮进度/FT 状态全死**（F5+F6） | 无 |
| 熔断 | 广播 v2_abort（session_v2.py:354） | 降级 v1 记录 | **控制台无处理，静默**（F13） | 操作者可能完全没察觉 |
| 收尾 | 三管道自动切窗 | — | Summary 仍 v1 切窗 UI（升级文档 G12） | — |

**结论：v2 运行期监控是"半座桥"——gate 盒活着，其余实时反馈（轮进度/Score/FT/熔断/引导提示）要么后端没发、要么前端没节点、要么场景钩子丢文字。**

## 3. 优化批次

**P0 · 真机采集前必修**（影响数据有效性）：
1. F1+F2：被试屏引导/轮过渡文字（改 `v2Idle` 一处即覆盖全部）；
2. F4：真机引导硬门；
3. F5+F6：监控半桥接通（后端发 progress/score + HTML 补 7 个节点）；
4. F9：weak_mi 标记；
5. F11：降级横幅；
6. F13：熔断横幅。

**P1 · 体验**：F3 倒计时/蜂鸣；F10 准入通过提示；F7/F8 死按钮隐藏；F12 死配置清理。

**P2 · 结构**：升级文档 G1–G13（M1–M4）。
