# v3 探针面板二轮审查清单

日期：2026-08-24 · 基线：一轮清单（S1–S6）已落地，面板已可读（滚动时域图 + 增益读数 + ERD 条 + 结论句 + checks）
本轮结论：**无算法问题，无流程问题**；剩余 10 项，其中 2 项是"事实性错误"（P1，必须修），其余为可读性/健壮性/性能打磨。

---

## P1 · 事实性错误（必修）

### R1 通道名被 µV 刻度条压住（截图可见的"删除线"）
- 位置：`web/js/operator.js:226-231`
- 现状：通道名 `fillText(V3_CH[ci], 4, yMid+4)` 画在 x=4，紧接着 `strokeRect(4, yMid-barH/2, 8, barH)` 把 8px 宽的刻度条画在**同一位置**，文字被矩形横穿 → 截图里 Cz/C3/… 像被划掉。
- 修：刻度条移到 x=26–34（标签右侧），或标签移到刻度条右侧；二者不共 x。

### R2 结论文句方向写反（ERS 时说成"降"）
- 位置：`experiment/feature_probe.py:138-141`
- 现状：`mu_abs = abs(mu_contra)`，文案恒为"…mu 较静息**降** {mu_abs}%"。当 mu_contra 为**正**（功率上升=ERS，常见于弱 MI/伪迹）时，操作者读到的是与事实相反的句子（"降 10%"实际是升 10%）。
- 修：按符号分词——`降 {x}%` / `升 {x}%`；"升"时直接追加"（未出现 ERD）"，verdict 色调用 erd-bad。

## P2 · 可读性/健壮性

### R3 −15% 合格刻度没画出来
- 位置：`operator.js:284` 渲染了 `<span class="tick-15">`，但 `web/css/operator.css` **无 `.tick-15` 规则** → 刻度隐形；图例承诺的"≤−15% 绿"只有颜色没有刻度线。
- 修：补 CSS：`.v3-pbar-track .tick-15{position:absolute;left:65%;top:0;bottom:0;width:2px;background:#e8eefc55}`（映射 `bar=50−erd`，−15% 对应 65%）。

### R4 beta 条误用 mu 的合格线着色
- 位置：`operator.js:286-287`（beta 也走 `erdClass`，阈值 −15%）
- 现状：标准里 beta 的判定是"mu 不弱于 βL+5pp"（`mu_vs_betal`），**不是** β 自身 ≤−15%；beta 条按 mu 线变绿/变红会给出错误暗示。
- 修：beta 条改中性色（仅表幅度），或单独标注"β 参考"；图例补一句 beta 无独立合格线。

### R5 同屏两种基线口径未标注
- 现状：功率条的 ERD 相对**开场 60s 基线**（`v3_baseline`），特征卡的 ERD 相对**块内 Rest 基线**（`feature_probe` 滚动 Rest 窗）。两个数字同屏、口径不同、无标注 → 操作者会对不上数。
- 修：功率条区标题加"vs 开场基线"，特征卡 ERD 网格加"vs 块内 Rest"；v3_report.md 同样注明两口径。

### R6 发布器静默吞异常
- 位置：`experiment/eeg_frame_publisher.py` `_loop` 的 `except Exception: pass`
- 风险：broadcast/滤波一旦持续异常，画布静默冻结，后端无日志，现场无法定位。
- 修：节流告警（每 10s 最多一条 `on_console("[v3] eeg_frame 异常: …")`），连续失败 N 次广播一条 `v3_warn` 到操作台横幅。

## P3 · 打磨项（可选）

### R7 画布渲染 O(nPx×ring) 可降为 O(ring+nPx)
- 位置：`operator.js:239-249` 每像素列全扫 ring（≈668×625×8 ≈ 330 万次比较/帧，3.3Hz）；`appendV3EegSamples` 每帧新建 ~1248 个 `{t,v}` 小对象。
- 修：ring 按 t 有序 → 双指针一次扫过做像素分箱 min/max；ring 改 Float64Array 双缓冲。当前不卡，但这是全面板最大 CPU 消耗，与诱导页同机运行时值得修。

### R8 基线阶段头部提前显示块条件
- 位置：`operator.js:1275-1281`（session_started 即把 `v3_block_order[0]` 写进"条件"）
- 现状：基线 60s 期间显示"块 0/2 · 条件 guided"，块尚未开始。
- 修：基线期显示"条件：基线"，`v3_block begin` 后再切真实条件。

### R9 功率条每帧整块 innerHTML 重建
- 位置：`operator.js:272-289`（3.3Hz 全量 DOM 重建）
- 修：首帧建结构、后续只更新 width/文本（可选，收益小）。

### R10 全局增益下安静通道发平
- 现状：增益取全通道 p95（`operator.js:151-164`），Cz/C3 等安静道贴近直线。
- 修（可选）：加"逐通道增益"开关（默认关，保持跨通道可比）；开启时每行右侧显示该道 ±NµV。
