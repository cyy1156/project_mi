# 00 · 目录结构与复现总览

> 本包即参赛作品 XH-202610 的全部源代码。目录按**数据流分层**组织：
> 采集 → 预处理 → 离线训练 → 在线运行。每层一个目录，互不混放。

## 1. 分层目录树

```
源代码包根/
├── 00_目录结构与复现总览.md      本文件
├── 01_数据集获取说明.md          四个数据集的官方出处、下载与放置路径（数据不随包）
├── 02_附录A_实验证据链索引.md    支撑报告主数字的实验链索引
├── 03_附录B_自采数据质控样例.md
├── README_代码包说明.md          总说明：环境安装、快速开始、冻结配置
├── README.md / requirements.txt  仓库说明 / 依赖清单
│
├── collect_data/                 【第 1 层 · 数据采集】
│   │                             OpenBCI Cyton 8 导连接、滤波、LSL 推流
│   └── README_采集软件说明.md    ← 本层怎么跑
│
├── code/                         【第 2 层 · 数据准备 + 第 3 层 · 离线训练】
│   ├── README_离线代码复现指南.md  ← 本层怎么跑（预处理、训练、复算、权重）
│   ├── preprocess_lab/           公开数据集统一切窗预处理（每数据集一个配置目录）
│   ├── train_lab/                全部离线实验（一实验一目录，自包含，见其 README）
│   └── adapt_engine/             算法本体：融合 e1f.py / 因果读出 readout.py / 增量微调 ft.py
│
└── experiment_game/              【第 4 层 · 在线系统】
    ├── README_在线系统运行指南.md  ← 本层怎么跑
    ├── tools/ open_operator.bat  一键启动操作台
    ├── experiment/               会话、推理、计分、采后微调核心逻辑
    ├── config/                   冻结配置（v3_session.yaml、ft_policy.json、e1f_four_member.json）
    └── web/                      操作台与游戏前端（纯 HTML/JS，无需构建）
```

## 2. 数据流：四层如何串起来

```
 公开数据集（不随包，按 01 文档下载）
        │
        ▼
 code/preprocess_lab     统一 8/59 导切窗（3 s / hop 100 ms 等）
        │  切窗产物
        ▼
 code/train_lab          成员预训练 → 五折评测 → 融合实验（QuadFold-59 / CausalFuse-8）
        │  权重 best_*.pt
        ▼
 experiment_game         e1f_four_member.json 登记四个成员权重路径
        │                会话运行时加载 → 在线推理 → 试次级读出（因果平滑多数票）→ 游戏反馈
 collect_data ──LSL──►   （真实采集时替换为 Cyton 硬件）
```

- `code/adapt_engine` 是第 3、4 层共用的算法库：离线用它做融合实验，在线用它做实时读出与增量微调，保证线上线下同一套实现。
- 训练与预处理的中间产物落在各自 `out/` 目录，**未随包附带**（体积约百 GB），重新生成方式见 `code/README_离线代码复现指南.md` §3。

## 3. 三条复现主线（按评审需要选一条即可）

| 主线 | 前置条件 | 入口 | 对应提交件 |
|---|---|---|---|
| ① 在线系统跑通 | 权重包（或按主线③重训取得） | `experiment_game/open_operator.bat` | 演示视频 |
| ② 离线指标复算 | 公开数据集 + 成员概率 dump（dump 可按附录A入口重生成） | `code/train_lab/.../cm_e1f_arms.py` 等 | 离线验证 Excel |
| ③ 从数据全量重训 | 公开数据集 + GPU | 预处理 → train_lab 各实验入口（附录A 登记） | 技术报告全部数字 |

无 GPU / 无数据的最低要求路径：主线①选合成板（synthetic）数据源，装好依赖即可跑通采集→分类→反馈全链路（性能数字不构成证据，仅验证流程）。

## 4. 环境（三主线通用）

Python 3.11（≥3.10）+ conda 建议；torch 按本机 CUDA 单独装；其余 `pip install -r requirements.txt`。逐条命令见 `README_代码包说明.md` §3。
