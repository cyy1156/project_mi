## 1. 方案 A 一句话

| 环节 | 指标 | 口径 |
|---|---|---|
| **在线 v3** | `acc_argmax` / `acc_window` | 优先 **被试 current** 权重；试次级含 **截断 Rest**（`max_rest=min(L,R)`）；窗级/试次级均 **因果平滑 lookback=2** |
| **微调 Leave-Next · 展示** | `heldout_acc` | **因果平滑**窗级三分类（对齐在线 `acc_window`） |

| **微调 Leave-Next · 试次级** | `f5_ft` | 因果平滑 + 多数票；MI +1 / Rest +0.5 |

## 2. 在线采集（v3）

### 2.1 权重

| 字段 | 含义 |
|---|---|
| `weight_source=subject_current` | 推理用 `data/subjects/<sid>/models/current`（E1f 四成员 + overlay） |
| `weight_source=base` | 回退 `config/v3_session.yaml` 底座（零样本） |
| `frozen` | **仅**表示会话内权重指纹是否变化，**不**表示是否用底座 |

orchestrator 在 v3 启动时若存在 `models/current` 则注入 `subject_models_dir`（`orchestrator._inject_v3_subject_weights`）。

### 2.2 准确率字段

| 字段 | 粒度 | 平滑 | 类别 | 代码 |
|---|---|---|---|---|
| `acc_argmax` | 试次级多数票 | lb=2 | L/R + 截断 Rest | `v3_report.records_for_acc_scoring` + `_acc_at_primary` |
| `acc_window` | 窗级 | lb=2 | L/R + Rest 窗 | `v3_report._acc_window` |
| 本场得分 | 试次级 | lb=2 + 多数票 | MI +1 / Rest +0.5 | `trial_scoring.MiTrialTracker` |

Rest 记录：`session_v3._finalize_pre_cue_rest`（`label=0, role=pre_cue_rest`）；截断与离线 openbmi_align 一致。

### 2.3 前端

- 块内实时 `acc_argmax`：含截断 Rest；标注 `(current)` / `(base)`。
- 结束页：展示 `weight_source` 文案 + `acc_window` / `acc_argmax`。

## 3. Leave-Next 微调

### 3.1 切窗与平衡

- 协议：**openbmi_align**（trial_table 含 `t_rest_*` → 自动判定）。
- 段级 **18:18:18**；窗级 **198:198:198**（每 session）。
- Rest 截断：`max_rest = min(n_left, n_right)`（`finetune._build_session_windows_openbmi_align`）。

### 3.2 字段定义（ramp summary JSON）

| JSON 字段 | 内部来源 | 口径 | 用途 |
|---|---|---|---|
| `heldout_acc` | `acc_after_heldout_smooth` | 窗级 · **因果平滑** | **主展示**、cohort 表、操作台 `three_heldout` |
| `heldout_acc_raw` | `acc_after_heldout` | 窗级 · raw argmax | **门控 G1**、`train_minus_heldout` |
| `heldout_acc_smooth` | 同 `heldout_acc` | 别名 | 兼容 |
| `train_acc` | `acc_after_train` | 窗级 · raw | 训练集参考 |
| `train_minus_heldout` | `train_acc − heldout_acc_raw` | raw 差 | 门控 G4（train_gap） |
| `max_class_frac` | `_pred_distribution` | raw pred 占比 | 门控 G2 |
| `release_pass` | `evaluate_release_gate` | 见 §3.3 | 是否建议 promote |
| `f5_ft` | `_f5_from_probs` | 试次级平滑+多数票 | 对齐在线试次计分 |

### 3.3 门控四项（仍 raw）

| 检查 | 条件 | 数据源 |
|---|---|---|
| `heldout_acc` | ≥ `max(0.40, Rest/L/R 窗先验 + 0.05)` | **raw** `acc_after_heldout` |
| `max_class_frac` | < 0.60（代码常数 `RELEASE_MAX_CLASS_FRAC`） | raw pred 分布 |
| `train_gap` | < 0.35 | raw train − raw heldout |
| `three_classes_pred` | {0,1,2} 均有预测 | raw pred 计数 |

**门控 deliberately 不用平滑**：Rest 窗占比高时 raw acc ≈ 类先验，便于发现「全猜 Rest」；平滑会掩盖瞬态塌缩。

### 3.4 早停（因果平滑）

- `finetune_head` → `train_with_early_stop(eval_fn=_eval_acc_causal)`（有 `split_ids_te` 时）。
- meta：`heldout_early_stop_metric=causal_smooth`。
- 无 `split_ids_te` 时回退 raw `_eval_acc`。

## 4. 在线 vs 微调：对比矩阵

| 对比目的 | 在线 | 微调后 |
|---|---|---|
| 试次级（含 Rest） | `v3_report.overall.acc_argmax` | `f5_ft.score / score_max` |
| 窗级（平滑，主展示） | `v3_report.overall.acc_window` | **`heldout_acc`**（smooth） |
| 门控 / 类坍塌诊断 | — | **`heldout_acc_raw`** + `max_class_frac` |
| 权重 | `weight_source` | FT 后 `best_three.pt` |

**禁止**：用在线底座 `acc_argmax` 直接对比微调 `heldout_acc` 而不注明权重与口径差异。

**满分分层**：在线 session 计分满分 **54**（36 MI×1 + 18 Rest×0.5）；Leave-Next `f5_ft` 在 Rest 截断平衡后 `score_max` 常为 **45**（或同类截断值），**勿与在线 54 混读**。
