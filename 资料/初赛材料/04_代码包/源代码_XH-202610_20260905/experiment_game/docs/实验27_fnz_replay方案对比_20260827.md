## 1. 实验在做什么

在 **同一 OpenBMI 3s 底座**（`run_20260822_094942`）上，对 fnz 做 session 间 **离线 FT**，双轨对比 14 种 Replay 配方：

| Track | 训练 session | 模拟场景 |
|-------|--------------|----------|
| **S** | 仅 ws01 | 第一次 FT 后采 ws02 |
| **M** | ws01 + ws02 合并 | 合并 FT 后采下一场 |

共 28 runs · 脚本：`experiment_game/tools/exp27_fnz_replay_grid.py`  
结果：`experiment_game/data/models/fnz/exp27/report.json` · `online_leaderboard.json`

## 2. 网格结论（摘要）

### 2.1 heldout 冠军（勿直接当部署默认）

| Track | heldout 冠军 | heldout acc |
|-------|-------------|-------------|
| S | S-B3（t0 · 0.15 · 全模型） | 63.7% |
| M | M-E1（无 replay · 冻 head） | 56.6% |

### 2.2 下一场 session 在线（更贴近部署）

| 过渡 | 在线较好配方 | ws 在线 trial acc | 备注 |
|------|-------------|-------------------|------|
| ws01→ws02 | S-A1（all54 · 0.20） | 45% | pred 7/13/0，Right 试次 0/8 |
| merge→ws03 | M-B1（t0 · 0.05） | 38.9% | pred 8/24/4 |

**教训：** heldout 高 ≠ 下一场在线好；无 replay / 冻 head 易 **类塌缩**。

### 2.3 Replay 池只能选一种时的折中

54 人与 36 人池 **容量相同**（每类上限 3000 窗 ≈ 9000 窗），差别在被试构成。  
合并 FT 阶段 **t0 更优**；单 session 需 **更高 ratio** 补锚定。

**拍板：统一 Replay 池 + 统一 ratio**

```text
Replay 池：T0-36（pool=t0）
replay_ratio：0.10（全程固定）
```

对应网格臂 **S-B2 / M-B2**（t0 · ratio=0.10 · 全模型 · 5 epoch）：

| 轨 | heldout after | heldout 三类 pred | 在线（若有） |
|----|---------------|-------------------|--------------|
| S（ws01） | 56.8% | Rest/Left/Right 均有 | ws02 trial 45%（4/16/0） |
| M（ws01+ws02） | 42.1% | 三类均有 | ws03 未单独测；M-B1(0.05) 在线略优 |

`t0 + 0.10` 在 **单 session heldout 与合并 heldout 两头均保三类预测**；ratio 介于 B1(0.05) 与 B3(0.15) 之间，工程上 **只维护一个池、一个比例**。

## 3. 统一离线 FT 策略（session 间 · 已拍板）

### 3.1 一句话

> **OpenBMI 固定底座 + 本被试合格 session 监督 + T0-36 replay（ratio=0.10）batch 内混入 → 全模型 5 epoch → 验收后供下一场 session 在线推理。**

### 3.2 固定项

| 项 | 取值 |
|----|------|
| 底座 | `run_20260822_094942` · `best_{task,three}.pt` |
| 切窗 | 3s / hop 100ms · CAR 8–30Hz · 窗内 z-score · `(8,750)` |
| 标签 | **协议 cue**（`trial_table.label`：Rest=0 / Left=1 / Right=2）；默认含 invalid 试次 |
| train/heldout | 试次级 70/30 · `seed=42` · heldout **仅本被试 fnz 窗** |
| Replay 池 | **T0-36** · `code/preprocess_lab/out/openbmi_3s_hop100_t0` |
| `replay_ratio` | **0.10** |
| Replay 抽样 | `n_rep = round(n_fnz_train × 0.10)`；池内 **Rest/Left/Right 类均衡** |
| 超参 | `lr=1e-4` · `wd=1e-4` · `batch=32` · `epochs=5` · 全模型 |
| 采集中 | v3 **权重冻结**；FT 仅在 session 之间离线执行 |

### 3.3 T0-36 被试名单

```text
01, 02, 03, 04, 05, 06, 07, 08, 11, 12, 16, 17, 18, 19,
21, 22, 23, 24, 26, 27, 28, 29, 30, 32, 33, 35, 36, 37,
38, 39, 41, 42, 43, 44, 45, 47
```

（与 find_best_trail T0 名单一致；**不含**弱/不明显 18 人。）

### 3.4 发布验收

| # | 检查项 | 阈值 |
|---|--------|------|
| 1 | heldout acc | ≥ 0.40 |
| 2 | heldout **三类试次均有预测** | 必过 |
| 3 | heldout 任一类占比 | < 60% |
| 4 | train − heldout | < 0.35 |
| 5 | 电极 QC | Cz/CPz 非平线才并入训练 |

### 3.5 与实验 25 的关系

实验 25 **否定** G1 增广底座 + Stieger 增量 FT 的 G2 replay；**不否定** 本策略（纯 OpenBMI 底座 + fnz 本被试 FT + replay）。
