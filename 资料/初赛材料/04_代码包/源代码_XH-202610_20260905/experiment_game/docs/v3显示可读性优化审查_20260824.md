# v3 探针面板可读性审查与优化清单

日期：2026-08-24 · 触发：操作者反馈"特征不明显、看不懂"（附运行截图：波形呈扁平细带、功率条无刻度无数字）
结论先行：**算法口径是对的**（feature_probe 与离线 analyze_mi_features_25 同源），问题出在**呈现层**——波形画错尺度、功率条画了无意义的绝对量、特征卡只有裸数字没有"人话"。本清单给出 F1–F13 根因与 S1–S6 修复规格，交工程师施工；不改算法、不改会话流程。

---

## 1. 根因诊断

### A. 脑电波形"扁平"（截图主诉①）

| # | 根因 | 位置 | 说明 |
|---|---|---|---|
| F1 | **幅度尺度硬编码 ±100** | `web/js/operator.js:378` `scale=(rowH*0.35)/100` | 假定满量程 ±100µV。合成板（BrainFlow synthetic）幅度极小 → 直线；真机 ±20–80µV 也无定标。无 µV 刻度条，操作者无法区分"没信号"还是"尺度错" |
| F2 | **横向压缩 85s 挤一屏** | `operator.js:373` `step=floor(676/34)≈19px/帧` | 每帧 2.5s×62.5Hz=156 点（`i+=2` 后 78 点）画进 19px，34 帧=85s 铺满画布 → 波形糊成细带（截图所见）。正常 EEG 读数需要 ~80px/s |
| F3 | 抽取无抗混叠 | `experiment/eeg_frame_publisher.py:60` `raw[::4]` | 0.5–45Hz 信号 4 倍抽稀（显示 Nyquist 31.25Hz），高频折回成毛刺 |
| F4 | 无事件线/时间尺 | `operator.js:350-390` | cue/mi 起止不打竖线、无 1s 刻度 → 看不出"哪段是想象期"，波形与试次对不上 |

### B. 功率条"读不懂"（截图主诉②）

| # | 根因 | 位置 | 说明 |
|---|---|---|---|
| F5 | **画的是绝对功率的 log 条** | `operator.js:395-396` `log10(P+1)*30` | 原始 FFT 功率（µV²）跨人/跨设备差几个数量级，条长无参照；无数字、无单位、无图例（蓝=mu 紫=beta 靠猜）、无阈值 |
| F6 | **基线功率没下发** | `session_v3.py:382-388` | 基线阶段只算了 `rest_mu_frac` 一个标量；每通道基线 mu/beta 功率没广播 → 前端算不出现场最有意义的量：**相对基线的实时 ERD%** |

### C. 特征卡"看不懂"

| # | 根因 | 位置 | 说明 |
|---|---|---|---|
| F7 | 裸数字无判定语义 | `operator.js:410-414` | `pred=1` 不翻译左/右/静息、不判对错；muERD/偏侧无合格线着色；`grade.checks`（5 项打勾数据）已在消息里却**没渲染**——操作者看到"弱/不明显"但不知道为什么弱 |
| F8 | Rest 试次也算"对侧 ERD" | `experiment/feature_probe.py:253-254` | label=0 时 contra 硬取 c3，生理语义错误；Rest 卡应显示"基线已更新" |
| F9 | **两种统计口径混在一张卡** | `feature_probe.py:266-278` | 卡上 ERD 数字是**单试次**，grade 却来自**块累计** side_metrics → "数字看着不错评级却弱"，操作者困惑的直接来源 |
| F10 | 首 Rest 试次自比自 | `feature_probe.py:241` `wins[:1]` | 块内第一个 Rest 用自身当基线 → ERD≈0，应标"基线预热、不计评级" |
| F11 | 信息缺层 | `operator.js:402-419` | 无 p_three 概率条、无 C3/C4/CP3/CP4 分通道 ERD（数据在 `features.mu_erd` 里，没画） |

|---|---|---|---|

## 2. 修复规格（S1–S6）

### S1 · 脑电画布重画（P0，解 F1–F4）

- **固定时间尺度滚动**：80 px/s，720px 画布 ≈ 9s 视窗；前端维护样本环（不再按帧拼），每帧 append 新样本后整体左移。
- **逐通道自动增益**：scale = (rowH×0.4) / max(rolling_p95(|x|), 5µV)；p95 用最近 10s 滑动计算；画布右上角显示当前全局增益"±N µV"。
- **定标与刻度**：左侧每道画 50µV 刻度条；底部 1s 刻度线。
- **事件竖线**：收到 `v2_stage` 的 `cue`/`mi`/`iti` 时按时间戳在对应 x 画竖线（cue 黄、mi 绿、iti 灰）。
- **抗混叠绘制**：每像素列取 min/max 包络连线（代替 `i+=2` 抽样）；后端 `raw[::4]` 改为 4 点均值抽稀。

### S2 · 功率条 → 实时 ERD 条（P0，解 F5–F6）

- 后端：基线阶段结束广播 `{"type":"v3_baseline","baseline_mu":[8],"baseline_beta":[8],"rest_mu_frac":…}`（在现有 `session_v3.py:382-388` 处把 `bandpowers_fft` 的逐通道结果一并下发）。
- 前端：每通道显示 **ERD% = 100×(P−P₀)/P₀** 数字 + 水平条：≤−15% 绿、−15–0% 灰、>0% 红；条上画 −15% 合格刻度；图例"蓝=mu 8–13Hz · 紫=βL 13–20Hz"；悬停 title 显示原始功率 µV²。
- 基线未就绪（前 60s）时条置灰并标"基线采集中"。

### S3 · 特征卡重构（P0，解 F7–F11）

卡片三区：
1. **结论句**（S4，大字置顶）；
2. **单试次区**：pred 翻译+对错（`pred==label` → ✓/✗，Rest 显示"静息"）；p_three 三概率条；C3/C4/CP3/CP4 四格 ERD（对侧加粗、按合格线着色）；偏侧 pp 带 ≥8 刻度；
3. **块累计区**（小字分隔）：grade 评级 + 5 项 checks 打勾清单（✓/✗ + 项名）+ 累计 n 试次；明确标"块累计口径"。
- Rest 试次卡：不显示对侧 ERD，改显"基线更新：累计 N 个 Rest 窗"（解 F8）；首 Rest 标"预热"（解 F10）。

### S4 · 人话结论句（P0，解 F13）

后端 `feature_probe.compute_trial_features` 增加 `verdict_text` 字段，规则拼接，例：
- 左手试次："左手想象：C4 mu 较静息降 22%（合格线 15%✓），偏侧 9pp（合格线 8✓）→ 本试次特征明显"
- 不达标时："…降 6%（未达 15%✗）→ 本试次特征弱；建议检查引导/电极"
前端卡片置顶渲染，颜色随结论（明显=绿/中等=黄/弱=红）。

### S5 · 后端小修（P1，解 F12、F3 后端部分）

- `_broadcast_block_stats` 增 `blocks_total`、`n_valid`；
- `eeg_frame_publisher` 抽稀改 4 点均值；
- `feature_probe` label=0 跳过 contra/ipsi 计算、首 Rest 打 `warmup=True` 标记。

### S6 · 合成板调试增强（P2，可选）

合成板幅度极小，面板调试观感差。可选：v3 调试模式下由后端向 RingBuffer 注入"合成 MI 模式"（MI 期对侧通道 10Hz mu 爆发 ×0.5 幅度），使演示/验收不依赖真机。**默认不做**，先用真机验收 S1–S4。

## 3. 优先级与验收

| 优先级 | 项 | 验收 |
|---|---|---|
| P0 | S1 S2 S3 S4 | V1：真机跑 1 块，波形可见 mu 节律起伏、增益读数合理（±20–100µV）；V2：功率条在 MI 期对侧通道转绿且数字 ≤−15% 与离线复核一致（误差 <2pp）；V3：特征卡结论句与 checks 清单与 `v3_trial_features.jsonl` 字段一致 |
| P1 | S5 | V4：块进度显示 n/valid；Rest 卡不再出现"对侧 ERD" |
| P2 | S6 | 合成板冒烟时面板有可见动态（仅调试用途） |

边界：不改特征算法口径、不改会话流程、不改被试屏；所有改动限于 `operator.js` 渲染 + `eeg_frame_publisher`/`feature_probe` 的**输出字段扩展**（向后兼容，jsonl 旧记录仍可读）。
