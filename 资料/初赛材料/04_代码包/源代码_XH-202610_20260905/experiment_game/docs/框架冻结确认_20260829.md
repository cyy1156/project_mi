## F5 冻结正文（2026-08-29 操作方确认）

**废除计分 / 主判定双轨；废除正式路径上的置信 τ 早停门控。**

| 层级 | 规则 |
|------|------|
| **窗级** | E1f 融合 `p_three` → **因果平滑**（`lookback=2`：当前窗与前两窗 `n,n−1,n−2`）→ **`pred = argmax`** |
| **试次（MI）** | 各窗平滑后 `pred` **多数票** = 试次结果 = 计分依据 = 主判定；对则 **+1** |
| **试次（专用 Rest）** | **同一规则**（因果平滑 + 多数票）；判 Rest 对则 **+0.5** |
| **τ / e1f_conf_stop** | **退出正式 SOP**（仅可作离线分析旁路） |

### 场景

| | 约定 |
|--|------|
| **v3 探针/采集** | 计分 = 主判定 = 上表；继续落盘；在线窗 **3s/hop100**，判定点窗尾相对 **`mi_start`** `3.0…4.0`（11 档）；段级基线 = 锚点前 0.5s；FT 切窗 **`[t_mi_start,+4s)`** 与 Rest 段满段 |
| **v2 · v3test（现行默认）** | 10 Rest + 5L + 5R；Rest/MI **连击 N 窗**（默认 5）计分；满分 15；权重 = 被试 v3 最终 `current` |
| **v2 · legacy（旁路）** | 实时反馈 = 每窗因果平滑后 argmax；试次结算若启用则 **同一多数票** |

### 历史数据

- **不重采**；旧 session 可按新规则回放重算。  
- **不重训**实验 26；OpenBMI 上多数票离线约 **0.6125**（对照 E1f 早停 0.6173）。  
- `cue_s=0` 旧 Align session 与现行 `cue_s=1` **事件时刻不同**（cue 与 mi_start 是否重合）；**切窗/判定一律认 `t_mi_start`**（缺省才回退 `t_cue`）。

## 现行时序（冻结口述）

权威源：`experiment_game/config/v3_session.yaml`

```text
[专用 Rest 4s] → [prep 2s] → [Cue 1s · 想象开始] → [MI 4s · mi_start…] → [ITI ≥3s] → …
 rest_start/end                                   mi_start = 判定/切窗锚点
 （Rest：因果平滑+多数票 → +0.5）
                                |←—— OpenBMI Task [0,4) ——→|
```

| 参数 | 现行默认 |
|------|----------|
| `inter_trial_rest_s` | 4.0 |
| `prep_s` | 2.0 |
| `cue_s` | **1.0** |
| `imagine_s` | 4.0 |
| `iti_s` | 3.0 |
| `block_gap_s` | 30 |
| 在线窗 | `openbmi_hop100` · 3s / hop 100ms · 基线锚点前 0.5s（相对 `mi_start`） |
| 读出 | E1f + **因果平滑 lookback=2 + argmax**；试次 **多数票单轨** |

> 物理序：… → ITI → **专用 Rest 4s** → **prep 2s** → Cue → MI → …。  
> **禁止**把「Cue 前 4s」说成 Rest——Cue 前还有 prep；Rest 只认 `rest_start`–`rest_end`。
