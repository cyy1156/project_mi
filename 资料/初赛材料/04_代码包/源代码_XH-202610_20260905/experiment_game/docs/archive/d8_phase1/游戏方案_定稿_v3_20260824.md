## 2. 范式时序（冻结 · v2）

```text
0–2s   prep（注视）
2–4s   Cue 动画（左=抓网球 / 右=书写 / 静息=图标）；MI 未开始
4s     mi_start
4–10s  MI ≤6s：D8 栅格判定（mi 后 0.6/1.2/…/6.0s 共 10 档）
       早停：Score≥5（score_reach）或 touch 或 错类作废；否则满 6s
+3s    ITI
```

特征窗：**结束于各判定点的 3s 窗（750pt）**；`t_rel ≤ 2.4s` 的窗跨 Cue 段，仅作半票弱证据（D8 已内建）。静息试次同时序，受试全程放松，切窗口径与任务类一致。

## 4. 游戏反馈（v2 标准：第一人称伸手/触碰）

- 左/右 Cue → **同侧手**抓桌物；**touch（或模拟 touch）即 `mi_end`**（D1）；Score≥5 → `score_reach` 早停；rest 试次无手部动画（静息指示）。
- 里程碑：D4 操作台**模拟 touch** 先行 → 场景碰撞检测（Raycast/AABB）收尾。
- 前端必备（审查 F11）：逐档 `judge` 渲染（得分/进度可视化）、标定进度条真实 tick、rest 专属反馈（禁止触发抓取动画）、Cue 资产补齐、`?v2demo` 渲染循环修复。

### 4.1 对原方案条文 3.2 的等价性论证（写入提交材料）

1. **判定信息量更高**：0.6s 栅格 × 加权票（10 档）严格细于"每秒 1 次、共 4 次"的二值秒判；半票/满票区分早期弱证据，错类对称累计可提前作废坏试次——二值秒判中单次误判即污染整试次统计。
2. **"到位"语义保留**：机械臂"4 档到位"对应本文"Score≥5 达标早停"，且更早给出成功反馈（最快 4.2s vs 固定 4 判定），试次时长自适应，脑电照录满。
3. **诱导一致性**：第一人称同侧手伸手与抓握/书写想象的动作意向同构（具身一致），第三人称机械臂是间接映射。
4. 交互误差特征（§7）替代"机械臂位移误差"，信息不减。

## 6. 在线适配（v2 标准）

### 6.1 分组规则的 v2 落实（对原方案 3.3 的口径）

- **组（1 左 + 1 右 + 1 静息）= 最小排程平衡单位**：标定子块 6 = 2 组（2L+2R+2Rest 置换、同类连出 ≤2）；游戏轮 16 按 6/5/5 轮转。类别平衡约束与比赛分组规则完全一致。
- **模型更新以轮为单位**：轮内试次窗累积后一次增量更新（Adam 1 步段、`GROUP_LR=1e-4`、混 15% 源域回放）。理由（写入提交材料）：3 试次 ≈ 数十窗的小批更新梯度噪声大、易灾难性遗忘；轮级批更新在保持相同类别平衡约束下稳定得多，且回放防遗忘只能在批式下按类配比。Stieger 爬坡（25-A0）验证的是轮级增量链。
- **防御性备选项（默认关）**：若答辩明确要求逐组即时更新，`adapt_engine` 增量接口天然支持把调用频率改为每 3 试次——只改调度不改引擎；本文冻结默认 = 轮级。

### 6.2 微调配方与保护

| 环节 | 规则 |
|------|------|
| 标定轮间 | 12 试次增量 FT；异步执行（D6，`ft_lagged` 记次）；**回放池必须接线**（§6.3） |
| 游戏轮间 | 全部试次窗入训（D2，无效试次除外，见下） |
| 无效试次 | **永不进 FT/小考**（`valid_trials` 过滤；验收硬门 §12-2） |
| 漂移保护 | `DriftGuard` 接线：每次更新前存 ckpt；连 2 轮不升反降 → 回滚 + lr 减半；再触发 → 冻结 |
| 微调对象 | 仅 three 头全参数（~17k）；task 头冻结（门控稳定，防小样本门控漂移）；底座 v2 阶段双头均微调 |
| weak_mi | 游戏阶段用**历史最优 ckpt**（小考精度最高轮），全程标记 |

### 6.3 回放池（前置必备）

回放池 = OpenBMI S3 训练集子集（按类平衡，每类 ≥200 窗），随权重加载进 `ReplayPool`。**无回放池不得开正式采集**（现状未传池、15% 回放静默蒸发——审查 H3）。

## 7. 多维交互特征记录（P4 · 只记录不入模）

每试次落盘 `v2_trial_features.csv/json`（替代比赛条文的"机械臂误差 + 多维融合"）：

| 特征 | 来源 | 用途 |
|------|------|------|
| 交互误差：终局 Score、达标档位差（5−Score）、达早停时刻 `t_rel`、错类累计 | D8 事件 | 比赛 3.2 误差特征等价物；`DRIFT_METRIC`（轮内逐档准确率趋势） |
| 逐档判定序列（0.6s × pred） | `judge` 事件 | 提交 Excel；1s 分箱可导出"单秒准确率"供对照陈述 |
| 8–13Hz / 13–30Hz 带功率、对侧 ERD、laterality | 判定窗 PSD（H 门控公式复用） | ERD 有效性验收；质量加权候选 |
| 个体最优通道（贡献排序） | 基线 top 特征（§8）比对 | 通道特征 |

**不拼入模型输入**。机制说明（写入提交材料）：ShallowFBCSPNet 首层时间卷积为可学习带通滤波，窗级原始输入已隐式包含 8–13Hz 带功率；小样本下拼接手工特征过拟合风险大于收益（方案 05/19 阴性结论）。特征表用途：比赛要求的"微调输入集"之记录与展示、漂移监控、后续 FT 样本加权（二阶段可选）。
