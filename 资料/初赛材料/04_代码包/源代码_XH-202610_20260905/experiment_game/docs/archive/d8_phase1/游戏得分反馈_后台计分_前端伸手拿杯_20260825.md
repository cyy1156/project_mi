# 游戏得分反馈方案：后台计分 · 前端伸手拿杯

> 日期：2026-08-25  
> 状态：**已实施**  
> 范围：`experiment_game` v2/v3 游戏轮被试屏反馈；不改 D8 计分公式  
> 相关：[`游戏方案_定稿_v3_20260824.md`](./游戏方案_定稿_v3_20260824.md) · D8 / `score_reach` · `v2_bridge.js` / `scene.js`  
> 代码：`experiment/score_feedback.py` · `session_v2.py` / `session_v3.py` · `web/js/v2_bridge.js` · `web/js/scene.js`

---

## 1. 目标

| 项 | 约定 |
|----|------|
| 被试屏 | **不显示数字分数**（禁止 `Score x.x`、进度条百分比） |
| 后台 | **完整保留 D8 计分**（累加、早停、有效/无效、events 落盘） |
| 被试反馈 | 仅用场景动作：**手臂伸出 → 满分拿到杯子** |
| 操作台 | 仍可显示 Score / 有效性（给操作者，不给被试） |

一句话：分数在后台算；被试只看见「伸手有多远、有没有拿到杯」。

---

## 2. 现状与问题

### 2.1 已有能力

- 后端 D8：`OnlineScoreTracker` 累加 `score`；`Score ≥ 5` → `score_reach` 早停。
- 场景：`v2GameLevel(level, reach)` 已支持伸手档位与抓杯姿态。
- 桥接：`v2_bridge.js` 在 `judge` / `score_reach` 等阶段驱动 HUD 与场景。

### 2.2 问题

- 被试 HUD 仍渲染 `Score x.x`，并用 `calProgress` 画数值进度条。
- 伸手/拿杯与连续得分的映射未冻结，与数字反馈并存，语义不统一。

- Rest 试次：无伸手、无拿杯。

## 4. 消息与职责划分

```text
后端 D8（计分公式不变）
  judge → score / pred / gated / signal_bad
  score≥5 → score_reach（早停）
       ↓ 规范广播字段
  v2_stage: judge | score_reach | …
       data: {
         arm_level: 0..4,
         cup_grasp: bool,
         // score 可仍带上供操作台；被试屏禁止渲染
       }
       ↓
被试屏：只驱动手臂/杯子 + 短文案（「请继续想象」/「拿到了」）
操作台：显示 Score、有效性、熔断原因
events.jsonl：完整写入 score（科研/复盘）
```

| 角色 | 可见内容 |
|------|----------|
| 被试 | 伸手档位、拿杯成功/失败姿态、左右 cue 文案 |
| 操作者 | Score 数字、quiz/gate、signal_bad、invalid 原因 |
| 落盘 | 全部数值字段不变 |

## 5. 单试次画面时间线（游戏轮）

| 阶段 | 画面 |
|------|------|
| prep | 十字；双手复位；杯子在桌上 |
| cue | 左/右提示；杯子可高亮；手尚未按得分伸出 |
| mi + 各 judge | **同侧手按 `arm_level` 平滑伸出** |
| score_reach / touch | **抓住杯子并略抬起**（满分反馈，约 0.8–1.2 s） |
| iti | 放手、杯子复位、手回休息位 |

标定轮：可与游戏共用映射，或使用更克制反馈（见 §8 待拍板）。

---

## 6. 交互细则（建议默认）

| 项 | 默认约定 |
|----|----------|
| 平滑 | 档位变化 150–300 ms 插值，避免 0.6 s 一跳过硬 |
| 单调性 | **同试次内 `arm_level` 只前进不回缩**，减少「伸了又缩」干扰想象 |
| signal_bad | 不伸手、不拿杯；可选极淡「信号不稳」（仍无分数） |
| 错类作废 | 手臂回缩/复位，杯子不抓；操作台显示原因 |
| touch | 与满分拿杯同等成功反馈（或优先真实触碰语义） |
| 无效试次（Score≤3） | 结束时未拿到杯；操作台记 `trial_invalid_low_score` |

可选开关（日后 yaml，非首版必做）：

- `arm_allow_retract: false`（默认）— 是否允许随瞬时分下降回缩  
- `subject_show_score: false`（默认）— 被试是否显示数字（正式采集必须为 false）

---

## 7. 与 D8 规则的等价关系

| D8 规则 | 前端等价物 |
|---------|------------|
| Score 累加 | 伸手档位上升 |
| Score ≥ 5 早停 | **拿到杯子** |
| touch | 同满分拿杯（或优先 touch） |
| 终局 Score ≤ 3 → 无效 | 未拿到杯 + 操作台 invalid |
| 操作者监控 | 仅 operator 面板显示数字 |

「满分拿杯」= 现有 `score_reach`，便于写入采集文档与结果登记。

---

## 8. 已拍板默认

1. **拿杯阈值**：严格对齐 `Score ≥ 5`（`score_early_stop`）  
2. **手臂回缩**：同试次内只前进不回缩  
3. **标定轮**：隐藏数字分；保留无数字进度条。伸手拿杯仅游戏轮强制启用
