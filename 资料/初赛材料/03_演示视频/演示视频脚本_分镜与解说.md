## S1 开场与系统总览（0:00–0:40）

- **画面**：黑场淡入 → 系统名称字卡 → 三级优化框架图逐级点亮（公开库预训练 → 20 人自采微调 → 少样本个体适配）→ 三个界面快切（操作台 / 诱导页第一人称 / 实时概率条）。
- **解说词**：
  > 这是一套面向康复场景的运动想象脑机接口系统。用户无需肢体动作，仅凭想象左手抓握、右手抓握或全身放松，即可被系统实时识别为三类控制指令。系统采用"迁移学习、少样本个性化适配、在线校准"三级框架：先在 54 名被试的公开数据集上预训练通用底座，再用自行采集的真实脑电数据强化，最后为每位新用户做采后增量微调，生成专属模型。
- **字幕要点**：`左手 MI / 右手 MI / 空闲 三分类`；`单窗前向延迟 1.11 ms`

## S2 硬件佩戴与采集启动（0:40–1:50）——要素①

- **画面**：
  1. 特写：Cyton 放大器 + 8 个湿电极按 `Cz, C3, C4, CP3, FC4, FC3, CP4, CPz` 位置佩戴（可加头顶电极位置示意图叠加）。
  2. 屏录：双击 `open_operator.bat` → 操作台 Setup 页 → 选择 Cyton、串口号、会话号 → 「开启采集」→ 信号波形出现 → 点「开始实验」自动拉起诱导页。
- **解说词**：
  > 系统使用 8 通道 OpenBCI Cyton 放大器，250 Hz 采样。电极覆盖两侧运动皮层与中线，通道顺序与模型输入严格一致。采集层完成 0.5 至 45 赫兹带通与 50 赫兹工频陷波，经 LSL 实时推流。操作台一键完成设备连接、信号自检与会话创建，全程留痕、可审计。
- **字幕要点**：`8 通道 · 250 Hz · LSL 流式`；`采集层滤波：0.5–45 Hz 带通 + 50 Hz 陷波`

## S3 实时采集与信号质量（1:50–3:00）——要素①

- **画面**：操作台实时波形滚动（8 导）；信号质量/缓冲健康指示；右侧事件日志出现 `rest_start / cue / mi_start` 等标记；叠加一个试次时序动画条（Rest 4s → 准备 2s → Cue 1s → 想象 4s → 间隔 3s）。
- **解说词**：
  > 每个试次遵循固定的 OpenBMI 对齐范式：四秒静息、两秒准备、一秒提示，随后四秒运动想象。事件标记与脑电数据在同一时间轴上对齐落盘，会话结束自动校验标记对齐质量，不合格数据不入库。这条"数据质量护栏"保证了后续模型训练与个体适配的可靠性。
- **字幕要点**：`Rest 4s → prep 2s → Cue 1s → MI 4s → ITI 3s`；`标记-脑电对齐自动校验`

## S4 三类状态实时分类（3:00–4:40）——要素②

- **画面**：**双屏同框**——左侧操作台三分类实时概率条（空闲/左手/右手三色），右侧诱导页 Cue 画面。被试依次执行：想象左手抓握 → 想象右手抓握 → 放松静息。每类至少 2 个试次。概率条出现明显类间切换，字幕同步打出当前判定（"判定：左手"）。
- **解说词**：
  > 这就是系统的核心：三分类实时解码。每个 3 秒滑窗以 100 毫秒步长持续推理，四成员模型融合后经因果平滑输出窗级判定，再由多数票得到试次级结论。注意看：被试想象左手时，左手概率显著抬升；切换到右手后判定随之翻转；静息段则稳定落在空闲类。控制状态与空闲状态的判别直接内嵌在三分类读出中，并配合专用静息段与状态监测完成异步判别。
- **字幕要点**：`3s 窗 / 100ms 步进 · E1f 四成员融合 · 因果平滑 + 多数票`；`当前判定：左手 / 右手 / 空闲`

## S5 游戏视觉反馈（4:40–6:20）——要素③

- **画面**：诱导页第一人称视角全屏。Cue 指示左/右目标物 → 对应虚拟手完成"伸手-抓握-收回"动作 → 得分与连击特效（v3test 连击计分）→ 静息试次双手静止。展示 4–6 个试次，含一次满分连击。
- **解说词**：
  > 分类结果通过第一人称游戏画面实时反馈：提示左手，就想象左手抓握桌上的杯子，判定正确时对应的手完成抓取动作并计入连击得分。游戏化诱导既提高了被试的投入度，也让"想象是否被正确识别"一目了然。计分与判定全部由后台模型驱动，画面仅做可视化。
- **字幕要点**：`第一人称虚拟手 · 连击计分 · 由模型实时驱动`

## S6 状态切换与响应性能（6:20–7:30）——要素④

- **画面**：操作台判定时间轴放大展示：连续 Rest→MI→Rest 切换段的逐窗判定序列；右下角实时延迟计数器（或字幕卡）依次弹出：`单窗前向 1.11 ms`、`判定节拍 100 ms`、`判定延迟 ≈3.5 s（窗口时程）`；演示一次操作台「暂停 P」与「标记无效 R」的即时响应。
- **解说词**：
  > 状态切换的响应性能由两部分保证：算法侧，单窗推理耗时仅 1.11 毫秒，远低于 100 毫秒的滑窗节拍，系统延迟主要由窗口时程决定，约 3.5 秒量级；工程侧，操作者随时可以暂停、标记无效试次或中止会话，所有异常处理即时生效并写入日志，保证交互安全。
- **字幕要点**：`单窗前向 1.11 ms @ RTX 5070`；`判定节拍 100 ms`；`P 暂停 / R 无效 / Esc 中止`

## S7 少样本个性化适配（7:30–8:40）——亮点段

- **画面**：屏录终端：会话结束 → Leave-Next 增量微调日志滚动（加载上轮权重 → 训练轮次 → replay 回放提示）→ 质量门控输出 `PASS` → `current` 模型更新完成。切回操作台显示被试模型版本已切换。右侧结果卡：`公开库仿真 67.1% vs 单成员微调 44.5%`、`真实被试最优个体 91.6%`。
- **解说词**：
  > 新用户不需要专门的标定流程：每完成一个会话，系统立即以历史会话为训练集、下一会话为留出评测执行增量微调，四成员全部适配并混入源域回放防止遗忘，微调后自动过质量门控、生成个人专属模型。在公开数据集仿真中，这套机制把留出会话准确率从 44.5% 提升到 67.1%；真实被试的最好个体达到 91.6% 的窗级准确率。
- **字幕要点**：`采后 Leave-Next · all4 四成员增量微调 · replay 10%`；`门控 PASS → 个人模型上线`

## S8 数据资产与结果摘要（8:40–9:30）

- **画面**：资源管理器展示会话目录结构（eeg.csv / events.jsonl / manifest.json / models/current）；快切离线验证 Excel 的总表与混淆矩阵页。
- **解说词**：
  > 每个会话沉淀为结构化数据资产：原始脑电、事件标记、会话清单与模型快照，全部可追溯、可复现。基于这些数据完成的离线验证、混淆矩阵、每类召回率与特异性、运算延迟指标，见随附的离线性能验证报告。
- **字幕要点**：`原始数据 · 事件 · 模型快照 全链路留痕`

## S9 结尾（9:30–9:50）

- **画面**：系统链路图收束到"三类实时分类 + 在线交互演示"字卡，淡出。
- **解说词**：
  > 从公开数据预训练，到少样本个体适配，再到实时游戏化交互——本系统实现了运动想象脑机接口的完整闭环。谢谢观看。
- **字幕要点**：`可验证 · 可复现 · 可落地`

## 9. 录制准备清单

| 项 | 内容 |
|---|---|
| 被试 | 优先 syj0828（表现最优、画面稳定）；提前确认设备与电极 |
| 会话 | 建议录两段素材：一段正式采集（S2–S4）+ 一段 v3test 游戏模式（S5），后期剪辑 |
| 录屏 | 1080p 及以上、≥30fps；操作台与诱导页分屏或双显示器同拍；OBS 等录屏工具 |
| 配音 | 按本稿解说词录制，语速约 220 字/分钟；或采用 TTS 后人工校对 |
| 字幕 | 依据各段"字幕要点"，关键参数必须上字幕 |
| 合规 | 出镜需被试知情同意；界面中如有个人真实姓名请打码或使用被试编号 |
| 时长 | 成片 ≤10 分钟，硬性要求；建议 9:30 左右 |
| 备用 | 若真机故障，S3/S4 可用合成板（synthetic）演示数据链路，但需字幕注明"演示用合成信号"；正式分类效果段落必须用真实数据 |
