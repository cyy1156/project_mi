## 二、核心技术口径（全套材料一致，勿混用旧口径）

- 对外模型名（冻结）：离线提交评测 **QuadFold-59**；在线主线 **CausalFuse-8** / 个体适配 **CausalFuse-8FT**（映射见 [`../模型训练/模型命名_QuadFold-CausalFuse.md`](../模型训练/模型命名_QuadFold-CausalFuse.md)）
- 范式：**OpenBMI-Align v1**（Rest 4s → prep 2s → **Cue 1s** → **MI 4s** → ITI 3s）
- 特征窗：**3s / 750 点，hop 100ms**，逐窗 z-score；通道序 **`FC3, C3, CP3, CZ, CPZ, FC4, C4, CP4`** 冻结（与报告附录 B / `protocol.yaml` 一致）
- 滤波：**Cyton 板载带通/陷波关闭**；主机软件 CAR + **8–30 Hz**（勿再写「采集层 0.5–45 Hz 在用」）
- 在线模型：**CausalFuse-8** = 四成员融合（温度冻结 + 权重 `[0.2,0.2,0.3,0.3]` 冻结）+ 因果滑窗
- 读出：**因果平滑 lookback=2 + argmax；试次多数票**（试次级读出冻结；对外展示用因果平滑，场次质量门控用原始窗级精度）
- 适配：**CausalFuse-8FT** = 采后 Leave-Next 增量微调（四成员全量），源域回放比例 0.10，门控 FAIL 强制晋升 + 告警（融合温度与权重仍冻结）
- EEG 看门狗：缓冲停滞告警 **2 s** / 会话中止 **5 s**
- 术语：指定集「**留一被试**六折」= LOSO leave-fold（旧称「嵌套」）；对外动词用「**提交**」不用「交卷」
- 头条数字（与《技术报告》09-07 口径一致）：OpenBMI 54 人五折三分类 **61.88%**；**指定集提交模型 QuadFold-59 留一被试 51.11% ± 6.57%**（登记 0.5111±0.0657；折内 55.80% 仅附报；备选 54.00% 归档不交）；Stieger 伪在线 41.98%→**65.90%**（叠加生理门控可达 70.03%，弃权 59.3%，**不进在线协议**）；BCI2a 仿真四成员全量微调 **66.30%** 对仅微调浅层单成员 **45.20%**（差 +21.1 个百分点）；真人 20 人队列末档均值 **47.60%**、最优个体 **92.40%**；单窗前向 **1.11 ms**
