## 二、核心技术口径（全套材料一致，勿混用旧口径）

- 范式：**OpenBMI-Align v1**（Rest 4s → prep 2s → **Cue 1s** → **MI 4s** → ITI 3s）
- 特征窗：**3s / 750 点，hop 100ms**，逐窗 z-score；通道序 `Cz,C3,C4,CP3,FC4,FC3,CP4,CPz` 冻结
- 模型：ShallowFBCSPNet 底座 + **E1f 四成员融合**（温度校准 + 加权）
- 读出：**因果平滑 lookback=2 + argmax；试次多数票**（F5 冻结；展示=smooth，门控=raw）
- 适配：**采后 Leave-Next 增量微调 all4**，replay 0.10，门控 FAIL 强制晋升 + 告警
- EEG 看门狗：缓冲停滞告警 **2 s** / 会话中止 **5 s**
- 头条数字：OpenBMI 54 人五折三分类 **61.88%**；**指定集交卷 S0 nested 0.511**（折内 0.558；备选 R-B8 0.540 归档）；Stieger 伪在线 41.98%→**65.90%**→**70.03%**；BCI2a 仿真 all4 **66.3%** vs so **45.2%**（Δ+21.1 pp）；真被试最优个体 **92.4%**；单窗前向 **1.11 ms**
