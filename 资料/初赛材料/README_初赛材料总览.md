## 二、核心技术口径（全套材料一致，勿混用旧口径）

- 范式：**OpenBMI-Align v1**（Rest 4s → prep 2s → **Cue 1s** → **MI 4s** → ITI 3s）
- 特征窗：**3s / 750 点，hop 100ms**，逐窗 z-score；通道序 `Cz,C3,C4,CP3,FC4,FC3,CP4,CPz` 冻结
- 模型：ShallowFBCSPNet 底座 + **E1f 四成员融合**（温度校准 + 加权）
- 读出：**因果平滑 lookback=2 + argmax；试次多数票**（F5 冻结；τ 早停双轨仅离线旁路）
- 适配：**采后 Leave-Next 增量微调 all4**，replay 0.10，门控 FAIL 强制晋升 + 告警
- 头条数字：OpenBMI 54 人五折三分类 **61.88%**（召回 macro 61.88% / 特异 macro 80.94%，混淆矩阵见 Excel sheet 01）；Stieger 伪在线 41.98%→**65.90%**→**70.03%**；BCI2a 仿真 **67.1%** vs 44.5%；真被试最优个体 **91.6%**（MI 94.4%）；单窗前向 **1.11 ms**
