# 离线验证 · 本目录说明

本目录为 **主办方指定标准数据集** 的离线性能验证交稿区（不含自采数据指标）。

## 官方提交形态（Excel）

| 官方要求 | 交稿内文件 |
|---|---|
| **离线验证结果 + 数据集使用说明** | `交稿/离线性能验证报告_XH-202610.xlsx`（**唯一正文**） |
| 验证过程截图 | `交稿/验证过程截图/S01–S07.png`（Excel sheet 06 已嵌图） |
| 原始验证数据 | `交稿/原始验证数据/`（CSV / JSON / npy / 官方说明副本） |

说明写在 Excel **sheet `04_数据集使用说明`**；准/召/特/延迟在 sheet `00`–`03`。  
勿另交独立「结果 PDF / 说明 PDF」充当官方件。

邮件附件推荐：`交稿_离线验证_XH-202610.zip`（或整夹 `交稿/`）。
