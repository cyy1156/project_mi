## 基于运动想象的脑-机交互算法研究与系统实现

### 数据说明

1. 任务

根据每个 3 秒 EEG trial，预测以下三类之一：

提交标签 训练集 trigger 类别

0 201 左手运动想象

1 202 右手运动想象

2 204 静息态

2. 目录结构

xxx/ ├─ train/ │ ├─ S01/block_1.pkl ... block_5.pkl │ ├─ ... │ └─ S06/block_1.pkl ... block_5.pkl ├─ test/ │ ├─ S07/block_1.pkl, block_2.pkl │ └─ S08/block_1.pkl, block_2.pkl ├─ sample_submission.csv └─ 数据说明.md 训练集共 6 名被试、30 个 block、900 个 trial；1 名被试包含 5 个 block，每个 block 包含 30 个 trial（左手、右手、静息态各十个随机出现）

测试集共 2 名被试、4 个 block、120 个 trial。1 名被试包含 2 个 block，每个 block 包 含 30 个 trial（左手、右手、静息态各十个随机出现）

3. PKL 结构

PKL 顶层为字典，主要字段包括 data、srate、ch_names、nchan 和 dimensions。

- 采样率：250 Hz。

- 每个 trial：750 采样点，即 3 秒。
- 每个 block：30 个 trial，共 22500 采样点。
- 每个 trial 的起点依次为 0, 750, 1500, ..., 21750。

personID 和 blockID 为原始采集元数据，参赛时请以公开目录名和文件名为准。

4. 训练数据

训练 block 的 data.shape == (65, 22500)：

signals = data[:64] # 64 个信号通道 trigger = data[64] # 训练标签/原始事件通道

starts = np.flatnonzero(np.isin(trigger, (201, 202, 204))) trials = np.stack([signals[:, start:start + 750] for start in starts]) labels = np.asarray([{201: 0, 202: 1, 204: 2}[int(trigger[start])] for start in starts]) 每个训练 block 三类各 10 个。可通过 201/202/204 定位 trial 起点，240/241 是原始实 验事件码，不是分类标签，请忽略。

5. 测试数据

测试 block 的 data.shape == (64, 22500)，已完全删除 trigger 通道和类别标签。因为每 个 trial 固定为 750 点，可直接切分：

signals = obj["data"] # (64, 22500) trials = signals.reshape(64, 30, 750).transpose(1, 0, 2) # trials.shape == (30, 64, 750) 请先切分 trial，再执行滤波或其他时域处理，避免信号处理跨越两个不连续 trial 的拼 接边界。
